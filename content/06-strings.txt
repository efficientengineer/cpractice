blurb: Null-terminated char arrays, string.h and its traps, writing your own string functions, snprintf, ctype.h, and converting between numbers and text.
--- body
## There is no string type

In C# a `string` is an immutable object that knows its length. In C a string is a *convention*: a sequence of `char` that ends at the first byte with value `0` (written `'\0'`, the *null terminator*). Every string function walks memory until it finds that zero.

```c
#include <stdio.h>

int main(void) {
    char s[] = "cat";                 // 4 bytes: 'c' 'a' 't' '\0'
    printf("%zu\n", sizeof s);        // 4
    for (int i = 0; i < 4; i++)
        printf("%d ", s[i]);          // 99 97 116 0
    printf("\n");

    char t[] = {'d', 'o', 'g', '\0'}; // the same thing, spelled out
    printf("%s\n", t);
    return 0;
}
```

Consequences you have to absorb:

- **Length is O(n).** `strlen` counts until the zero. Calling it in a loop condition (`for (i = 0; i < strlen(s); i++)`) makes the loop O(n²).
- **The buffer needs one extra byte.** A 5-letter word needs `char buf[6]`. Forgetting the `+ 1` is the classic off-by-one.
- **A missing terminator is a disaster.** `printf("%s")` and `strlen` keep reading past the end of your array until they happen to hit a zero byte.
- **A string cannot contain a zero byte.** For binary data use a pointer plus a length (and the `mem*` functions).
- `char` holds one byte. UTF-8 text works (it is just bytes), but `strlen` counts bytes, not characters, and `s[i]` is a byte, not a code point.

> **Performance:** the O(n) length is the root of most slow C string code. `for (i = 0; i < strlen(s); i++)` rescans the whole string on every iteration: a 1 MB string (a big L-system, a loaded shader, a level file) costs half a trillion byte reads. Call `strlen` once and keep the result, or loop `for (p = s; *p; p++)`. Better still, once you know a length, carry it with the pointer (`const char *s, size_t len`) instead of rediscovering it. And don't compare strings in hot loops at all: look a name up *once* (a material name, a uniform name, an asset path) and keep the resulting index or handle, then compare integers.

## Literals, arrays, and pointers

```c
char a[] = "hello";       // an array of 6 chars, initialized with a COPY of the literal
const char *p = "hello";  // a pointer to the literal itself, stored in read-only memory
```

These look similar and behave very differently:

| | `char a[] = "hello"` | `const char *p = "hello"` |
|---|---|---|
| What it is | a 6-byte array you own | an 8-byte pointer to someone else's bytes |
| `sizeof` | 6 | 8 |
| Modify `a[0]` / `p[0]` | fine | undefined behavior (usually a segfault) |
| Reassign `a = ...` / `p = ...` | compile error | fine: point it elsewhere |

String literals live in read-only memory, shared between identical literals. For historical reasons their type is `char[N]`, not `const char[N]`, so `char *p = "hello"; p[0] = 'H';` compiles and then crashes. Always declare pointers to literals as `const char *`, and the compiler will stop you.

Adjacent literals are concatenated at compile time, handy for long strings:

```c
const char *msg = "first part, "
                  "second part";
```

## string.h

`#include <string.h>`. These are the ones you will use every day. All of them assume valid, terminated strings and enough room in the destination. None of them check.

| Function | Does | Trap |
|---|---|---|
| `strlen(s)` | length, not counting the `'\0'` | O(n); returns `size_t` |
| `strcpy(d, s)` | copy `s` into `d` including the `'\0'` | no size: overflows `d` if `s` is too long |
| `strncpy(d, s, n)` | copy at most `n` chars | does **not** terminate if `s` has `n` or more chars; pads with zeros otherwise |
| `strcat(d, s)` | append `s` to the end of `d` | rescans `d` every call; no size |
| `strcmp(a, b)` | `<0`, `0`, `>0` by byte value | not `-1/0/1`; never `a == b` |
| `strncmp(a, b, n)` | compare at most `n` chars | good for prefixes |
| `strchr(s, c)` | pointer to first `c`, or `NULL` | `strrchr` finds the last |
| `strstr(h, n)` | pointer to first occurrence of `n` in `h`, or `NULL` | |
| `memcpy(d, s, n)` | copy `n` bytes | regions must not overlap |
| `memmove(d, s, n)` | copy `n` bytes | safe for overlapping regions |
| `memset(d, v, n)` | fill `n` bytes with byte `v` | sets *bytes*: `memset(ints, 1, ...)` gives 16843009, not 1 |
| `memcmp(a, b, n)` | compare `n` bytes | |

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char buf[32];
    strcpy(buf, "Hello");
    strcat(buf, ", world");
    printf("%s (%zu)\n", buf, strlen(buf));

    printf("%d\n", strcmp("apple", "banana") < 0);   // 1: compare like this
    printf("%d\n", strncmp("prefix-rest", "prefix", 6) == 0);

    const char *comma = strchr(buf, ',');
    if (comma) printf("comma at index %td\n", comma - buf);

    const char *w = strstr(buf, "world");
    if (w) printf("found: %s\n", w);                  // "world": a pointer INTO buf

    char line[10];
    memset(line, '-', sizeof line - 1);
    line[sizeof line - 1] = '\0';
    printf("%s\n", line);

    char s[] = "abcdef";
    memmove(s + 1, s, 3);          // overlapping: memcpy here would be undefined
    printf("%s\n", s);             // aabcef
    return 0;
}
```

Never compare strings with `==`. `a == b` compares the *pointers*: are they the same address? It can even appear to work, because identical literals often share storage. Use `strcmp(a, b) == 0`.

> **Performance:** `strcat` is the classic accidental O(n²), known as *Schlemiel the painter's algorithm*: each call walks `d` from the start to find its end before appending. Appending n short pieces makes the total work grow with n². Building a 100,000-piece string (an L-system, a generated OBJ file, a long log) that way can take minutes. Keep a write position (or an end pointer) and copy each piece to it: `memcpy(buf + len, piece, n); len += n;`. The total cost is then the length of the result, once.

### Why strncpy is not the safe strcpy

`strncpy` was designed for fixed-width record fields, not for safety. When the source is too long it copies exactly `n` bytes and **no terminator**:

```c
char buf[4];
strncpy(buf, "hello", sizeof buf);   // buf = 'h' 'e' 'l' 'l', no '\0'
printf("%s\n", buf);                 // reads past the end: undefined behavior
```

If you must use it, terminate by hand: `buf[sizeof buf - 1] = '\0';`. Better: use `snprintf`, below.

## Writing your own

Writing these yourself is the best way to get fluent with pointers. The idioms are short:

```c
#include <stdio.h>
#include <stddef.h>

size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p) p++;          // *p is false at the '\0'
    return (size_t)(p - s);
}

char *my_strcpy(char *dst, const char *src) {
    char *d = dst;
    while ((*d++ = *src++))  // copy, including the final '\0', then stop
        ;
    return dst;
}

int my_strcmp(const char *a, const char *b) {
    while (*a && *a == *b) { a++; b++; }
    return (unsigned char)*a - (unsigned char)*b;
}

int main(void) {
    char buf[16];
    my_strcpy(buf, "pointer");
    printf("%s %zu %d %d\n", buf, my_strlen(buf), my_strcmp("abc", "abd") < 0, my_strcmp("x", "x"));
    return 0;
}
```

The `(unsigned char)` casts matter: `strcmp` compares bytes as unsigned, and `char` is signed on x86-64, so a byte like `0xE9` (é in Latin-1) would otherwise compare as negative.

## Buffer overflows

```c
char name[8];
scanf("%s", name);     // typing a 20-letter name writes 13 bytes past the array
gets(name);            // so dangerous it was removed from the language in C11
strcpy(name, input);   // same problem when input is long
```

Writing past a buffer on the stack can overwrite the saved return address, which is how decades of exploits worked. Rules:

- Every write into a buffer must know the buffer's size.
- Read lines with `fgets(buf, sizeof buf, stdin)`. It stops at `sizeof buf - 1` chars, always terminates, and keeps the `'\n'` (strip it with `buf[strcspn(buf, "\n")] = '\0';`).
- Limit `scanf`: `scanf("%7s", name)` for an 8-byte buffer.
- Build strings with `snprintf`.

## snprintf: the safe string builder

`snprintf(buf, size, fmt, ...)` is `printf` into a buffer. It writes at most `size - 1` characters plus a terminator, so it **never overflows and always terminates** (when `size > 0`). It returns the length the full output *would* have had, so you can detect truncation:

```c
#include <stdio.h>

int main(void) {
    char buf[16];
    int n = snprintf(buf, sizeof buf, "%s_%03d.ppm", "frame", 7);
    printf("[%s] %d\n", buf, n);                // [frame_007.ppm] 13

    // gcc can see this truncation at compile time and warns about it
    n = snprintf(buf, sizeof buf, "%s_%dx%d.ppm", "terrain", 1024, 1024);
    if ((size_t)n >= sizeof buf)
        printf("truncated: [%s], needed %d\n", buf, n + 1);

    // Size it first, then allocate exactly: snprintf(NULL, 0, ...) only measures
    int need = snprintf(NULL, 0, "%d-%d", 2024, 12);
    printf("needs %d chars\n", need);
    return 0;
}
```

To append, keep a position and pass `buf + pos, size - pos` each time. Treat it as C's `StringBuilder`; `sprintf` (no `n`) has no size and is as dangerous as `strcpy`.

> **Performance:** `snprintf` is convenient and not fast: it interprets the format string every call. For text you rebuild every frame (an FPS counter, a debug overlay), format into a buffer you reuse, and only when the value actually changed. For bulk output (millions of numbers into a PPM image or an OBJ mesh), formatting dominates the run time; a hand-written integer-to-digits routine like the `itoa` exercise below is several times faster.

## Characters are small integers

A `char` is an integer type. `'A'` is just 65. All arithmetic works on characters, and the digits and letters are contiguous in ASCII:

```c
#include <stdio.h>

int main(void) {
    char d = '7';
    int value = d - '0';                 // 7: digit character to number
    char back = (char)('0' + 3);         // '3'
    char next = 'a' + 1;                 // 'b'
    int pos = 'e' - 'a';                 // 4: letter position
    char upper = 'q' - 'a' + 'A';        // 'Q'
    printf("%d %c %c %d %c %d\n", value, back, next, pos, upper, 'A');
    return 0;
}
```

`<ctype.h>` classifies and converts: `isdigit`, `isalpha`, `isalnum`, `isspace`, `isupper`, `islower`, `ispunct`, `toupper`, `tolower`. One trap: their argument must be an `unsigned char` value or `EOF`. Passing a negative `char` (any byte above 127) is undefined behavior, so cast: `isalpha((unsigned char)c)`.

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    const char *s = "Hello, World 42!";
    int letters = 0, digits = 0, spaces = 0;
    for (const char *p = s; *p; p++) {
        unsigned char c = (unsigned char)*p;
        if (isalpha(c)) letters++;
        else if (isdigit(c)) digits++;
        else if (isspace(c)) spaces++;
        putchar(toupper(c));
    }
    printf("\n%d letters, %d digits, %d spaces\n", letters, digits, spaces);
    return 0;
}
```

## Numbers to strings and back

**Number to string**: `snprintf(buf, sizeof buf, "%d", n)`. An `int` needs at most 12 bytes (`-2147483648` plus `'\0'`).

**String to number**: `atoi(s)` exists but cannot report errors (`atoi("abc")` is 0, and overflow is undefined). Use `strtol`, which tells you where it stopped and sets `errno` on overflow:

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(void) {
    const char *inputs[] = {"42", "  -17xyz", "abc", "99999999999999999999"};
    for (int i = 0; i < 4; i++) {
        char *end;
        errno = 0;
        long v = strtol(inputs[i], &end, 10);
        if (end == inputs[i])
            printf("'%s': no number\n", inputs[i]);
        else if (errno == ERANGE)
            printf("'%s': out of range\n", inputs[i]);
        else
            printf("'%s': %ld, rest '%s'\n", inputs[i], v, end);
    }
    printf("%f\n", strtod("3.5e2", NULL));   // 350.000000
    return 0;
}
```

For a strict "the whole string is a number" check, also require `*end == '\0'`. The base argument handles hex (`16`), binary (`2`), and `0` for "detect from a `0x` or `0` prefix".

Converting by hand is a good exercise and shows how it works: accumulate `value = value * 10 + (c - '0')` for each digit, and go the other way by repeatedly taking `n % 10` and `n / 10`, which produces digits in reverse.

=== exercise strfuncs
title: strlen and strcmp by hand
--- prompt
Write your own versions of two library functions, without using `<string.h>`:

- `size_t my_strlen(const char *s)`: the number of characters before the `'\0'`.
- `int my_strcmp(const char *a, const char *b)`: negative if `a` sorts before `b`, zero if equal, positive if after. Compare bytes as `unsigned char`, like the real `strcmp`, so a byte like `'\xff'` sorts after `'a'`.

The tests only check the sign of `my_strcmp`.
--- starter
#include <stddef.h>

size_t my_strlen(const char *s) {
    return 0;
}

int my_strcmp(const char *a, const char *b) {
    return 0;
}
--- solution
#include <stddef.h>

size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p) p++;
    return (size_t)(p - s);
}

int my_strcmp(const char *a, const char *b) {
    while (*a && *a == *b) {
        a++;
        b++;
    }
    return (unsigned char)*a - (unsigned char)*b;
}
--- hint
For the length, walk a pointer until `*p == '\0'`; the difference between it and the start is the length.
--- hint
For the comparison, advance both pointers while the characters are equal and not the end. Then the answer is the difference of the current characters, both cast to `unsigned char`. If one string is a prefix of the other, its `'\0'` (zero) is smaller than any real character.
--- harness
#define SIGN(x) ((x) > 0 ? 1 : (x) < 0 ? -1 : 0)
int main(void) {
    CHECK_UINT(my_strlen(""), 0);
    CHECK_UINT(my_strlen("a"), 1);
    CHECK_UINT(my_strlen("hello, world"), 12);
    CHECK_UINT(my_strlen("ab\0cd"), 2);
    char big[1001];
    memset(big, 'x', 1000);
    big[1000] = '\0';
    CHECK_UINT(my_strlen(big), 1000);

    CHECK_INT(SIGN(my_strcmp("", "")), 0);
    CHECK_INT(SIGN(my_strcmp("abc", "abc")), 0);
    CHECK_INT(SIGN(my_strcmp("abc", "abd")), -1);
    CHECK_INT(SIGN(my_strcmp("abd", "abc")), 1);
    CHECK_INT(SIGN(my_strcmp("ab", "abc")), -1);
    CHECK_INT(SIGN(my_strcmp("abc", "ab")), 1);
    CHECK_INT(SIGN(my_strcmp("", "a")), -1);
    CHECK_INT(SIGN(my_strcmp("Z", "a")), -1);
    CHECK_INT(SIGN(my_strcmp("\xff", "a")), 1);
    CHECK_INT(SIGN(my_strcmp("a", "\xe9")), -1);
    return TEST_END();
}

=== exercise strrev
title: Reverse a string in place
--- prompt
Write `void str_reverse(char *s)` that reverses the string `s` in place. `"hello"` becomes `"olleh"`. The terminator stays where it is.

The empty string must work.
--- starter
#include <string.h>

void str_reverse(char *s) {
}
--- solution
#include <string.h>

void str_reverse(char *s) {
    size_t n = strlen(s);
    if (n < 2) return;
    char *a = s, *b = s + n - 1;
    while (a < b) {
        char t = *a;
        *a++ = *b;
        *b-- = t;
    }
}
--- hint
Find the length with `strlen`, then swap `s[i]` and `s[n - 1 - i]` for the first half.
--- hint
Two pointers work nicely: one at the start, one at the last character (`s + n - 1`), swapping and moving inward while `a < b`. Return early for strings shorter than 2.
--- harness
int main(void) {
    char a[] = "hello";
    str_reverse(a);
    CHECK_STR(a, "olleh");

    char b[] = "abcd";
    str_reverse(b);
    CHECK_STR(b, "dcba");

    char c[] = "x";
    str_reverse(c);
    CHECK_STR(c, "x");

    char d[] = "";
    str_reverse(d);
    CHECK_STR(d, "");

    char e[] = "racecar";
    str_reverse(e);
    CHECK_STR(e, "racecar");

    char f[] = "ab cd!";
    str_reverse(f);
    CHECK_STR(f, "!dc ba");
    return TEST_END();
}

=== exercise titlecase
title: Title case
--- prompt
Read lines from stdin until end of file (use `fgets` with a 256-byte buffer; lines are shorter than that). For each line, print it with the first letter of every word in upper case and every other letter in lower case. A word starts at a letter that is at the start of the line or follows a non-letter.

Input:

```text
hello WORLD
the c programming LANGUAGE, second ed.
```

Output:

```text

```

Non-letters are printed unchanged, and they do end a word: `2nd` becomes `2Nd`, `o'neil` becomes `O'Neil`. Use `<ctype.h>`.
--- starter
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char line[256];
    while (fgets(line, sizeof line, stdin)) {
        printf("%s", line);
    }
    return 0;
}
--- solution
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char line[256];
    while (fgets(line, sizeof line, stdin)) {
        int prev_alpha = 0;
        for (char *p = line; *p; p++) {
            unsigned char c = (unsigned char)*p;
            if (isalpha(c)) {
                *p = (char)(prev_alpha ? tolower(c) : toupper(c));
                prev_alpha = 1;
            } else {
                prev_alpha = 0;
            }
        }
        printf("%s", line);
    }
    return 0;
}
--- hint
Keep a flag: was the previous character a letter? If not, this letter starts a word.
--- hint
`fgets` keeps the newline in the buffer, so printing the modified buffer with `"%s"` reproduces the line breaks.
--- hint
Cast to `unsigned char` before calling `isalpha`, `toupper` and `tolower`.

=== exercise strlcpy
title: A bounded copy
--- prompt
`strcpy` can overflow and `strncpy` may not terminate. Write the function many C libraries add to fix both (BSD calls it `strlcpy`):

`size_t copy_bounded(char *dst, size_t size, const char *src)`

- `size` is the full size of `dst` in bytes.
- Copy as much of `src` as fits, leaving room for the terminator, and always terminate `dst`, as long as `size > 0`.
- If `size == 0`, write nothing at all (`dst` might even be `NULL`).
- Return `strlen(src)`, so the caller can check `if (result >= size)` to detect truncation.
--- starter
#include <string.h>

size_t copy_bounded(char *dst, size_t size, const char *src) {
    strcpy(dst, src);
    return strlen(src);
}
--- solution
#include <string.h>

size_t copy_bounded(char *dst, size_t size, const char *src) {
    size_t len = strlen(src);
    if (size > 0) {
        size_t n = len < size - 1 ? len : size - 1;
        memcpy(dst, src, n);
        dst[n] = '\0';
    }
    return len;
}
--- hint
Compute `len = strlen(src)`. The number of characters to copy is the smaller of `len` and `size - 1`.
--- hint
Check `size > 0` before computing `size - 1`: it is unsigned.
--- harness
int main(void) {
    char buf[8];
    CHECK_UINT(copy_bounded(buf, sizeof buf, "hi"), 2);
    CHECK_STR(buf, "hi");

    CHECK_UINT(copy_bounded(buf, sizeof buf, "1234567"), 7);
    CHECK_STR(buf, "1234567");

    CHECK_UINT(copy_bounded(buf, sizeof buf, "12345678"), 8);
    CHECK_STR(buf, "1234567");

    CHECK_UINT(copy_bounded(buf, sizeof buf, "a much longer string"), 20);
    CHECK_STR(buf, "a much ");

    CHECK_UINT(copy_bounded(buf, sizeof buf, ""), 0);
    CHECK_STR(buf, "");

    char one[1] = {'Z'};
    CHECK_UINT(copy_bounded(one, 1, "abc"), 3);
    CHECK_INT(one[0], 0);

    char guard[4] = {'Q', 'Q', 'Q', 'Q'};
    CHECK_UINT(copy_bounded(guard, 0, "abc"), 3);
    CHECK_INT(guard[0], 'Q');
    CHECK_UINT(copy_bounded(NULL, 0, "hello"), 5);

    char small[3];
    CHECK_UINT(copy_bounded(small, sizeof small, "xyz"), 3);
    CHECK_STR(small, "xy");
    return TEST_END();
}

=== exercise count
title: Count occurrences
--- prompt
Write `int count_occurrences(const char *hay, const char *needle)` that returns how many times `needle` appears in `hay`, counting non-overlapping matches from left to right. `"aaaa"` contains `"aa"` twice, not three times.

If `needle` is empty, return 0. Use `strstr`.
--- starter
#include <string.h>

int count_occurrences(const char *hay, const char *needle) {
    return 0;
}
--- solution
#include <string.h>

int count_occurrences(const char *hay, const char *needle) {
    size_t n = strlen(needle);
    if (n == 0) return 0;
    int count = 0;
    const char *p = hay;
    while ((p = strstr(p, needle)) != NULL) {
        count++;
        p += n;
    }
    return count;
}
--- hint
`strstr(p, needle)` returns a pointer to the next match at or after `p`, or `NULL`.
--- hint
After a match at `p`, continue searching from `p + strlen(needle)` so matches do not overlap.
--- harness
int main(void) {

    CHECK_INT(count_occurrences("aaaaa", "aa"), 2);
    CHECK_INT(count_occurrences("abc", "abcd"), 0);
    CHECK_INT(count_occurrences("abc", "abc"), 1);
    CHECK_INT(count_occurrences("", "a"), 0);

=== exercise atoi
title: Parse an integer, strictly
--- prompt
Write `int parse_int(const char *s, int *out)` without using `atoi`, `strtol` or `sscanf`.

The string is valid if it is an optional `+` or `-` followed by one or more decimal digits, and nothing else (no spaces). On success, store the value in `*out` and return 1. If the string is invalid **or the value does not fit in an `int`**, return 0 and leave `*out` unchanged.

All of `INT_MIN` (`-2147483648`) through `INT_MAX` must parse. Detecting overflow *before* it happens is the hard part: signed overflow is undefined behavior, and the sanitizer will catch you.
--- starter
#include <limits.h>

int parse_int(const char *s, int *out) {
    return 0;
}
--- solution
#include <limits.h>

int parse_int(const char *s, int *out) {
    int neg = 0;
    if (*s == '+' || *s == '-') {
        neg = *s == '-';
        s++;
    }
    if (*s == '\0') return 0;

    // Accumulate as a negative number: its range is one bigger.
    int v = 0;
    for (; *s; s++) {
        if (*s < '0' || *s > '9') return 0;
        int d = *s - '0';
        if (v < (INT_MIN + d) / 10) return 0;
        v = v * 10 - d;
    }
    if (!neg) {
        if (v == INT_MIN) return 0;
        v = -v;
    }
    *out = v;
    return 1;
}
--- hint
Handle the sign first, then require at least one character, then require every remaining character to be a digit.
--- hint
Before doing `v = v * 10 + d`, check that it cannot exceed the limit: `v > (INT_MAX - d) / 10` means it would overflow.
--- hint
`INT_MIN` has no positive counterpart, so `-2147483648` overflows if you build `2147483648` and then negate. Either accumulate in a `long long` and range-check at the end (a `long long` easily holds 10 digits, but you still need to stop once it gets too big), or accumulate as a negative number.

--- prompt

--- solution
void int_to_str(int v, char *buf) {
    char tmp[12];
    int n = 0;
    int neg = v < 0;
    // Work with non-positive values: every int has a non-positive counterpart.
    if (!neg) v = -v;
    do {
        tmp[n++] = (char)('0' - v % 10);   // v % 10 is in -9..0
        v /= 10;
    } while (v != 0);
    int i = 0;
    if (neg) buf[i++] = '-';
    while (n > 0) buf[i++] = tmp[--n];
    buf[i] = '\0';
}
--- hint
`v % 10` gives the last digit and `v / 10` drops it, so a loop produces the digits backwards. Collect them in a temporary array, then copy them out in reverse.
--- hint

--- hint
For `INT_MIN`: convert positive values to negative instead of the other way round, since every `int` has a negative counterpart. In C, `-7 % 10` is `-7`, so the digit is `'0' - v % 10`. Or work in `long long`.

title: Build a string with snprintf
--- prompt
Write `size_t format_list(char *buf, size_t size, const int *a, size_t n)` that formats the array like `[1, 2, 3]` into `buf`, with `snprintf` semantics:

- Never write more than `size` bytes, and always terminate when `size > 0`. When it does not fit, `buf` holds as much of the start of the text as fits.
- `size` may be 0, in which case `buf` may be `NULL` and nothing is written.
- Return the length of the *full* text, whether or not it fit.

An empty array is `[]`. This is the standard "append with a running position" pattern: each `snprintf` call writes at `buf + pos` with `size - pos` bytes left, and its return value advances `pos`.
--- starter

#include <stddef.h>

    return 0;
}
--- solution
#include <stdio.h>
#include <stddef.h>

size_t format_list(char *buf, size_t size, const int *a, size_t n) {
    size_t len = 0;
    for (size_t i = 0; i <= n + 1; i++) {
        char *dst = len < size ? buf + len : NULL;
        size_t room = len < size ? size - len : 0;
        int w;
        if (i == 0) w = snprintf(dst, room, "[");
        else if (i == n + 1) w = snprintf(dst, room, "]");
        else w = snprintf(dst, room, "%s%d", i > 1 ? ", " : "", a[i - 1]);
        len += (size_t)w;
    }
    return len;
}
--- hint
Keep `len`, the length so far of the full text. Each piece goes to `buf + len` with `size - len` bytes of room, and its return value is added to `len`.
--- hint

--- hint
`snprintf(dst, room, "%s%d", first ? "" : ", ", value)` writes a separator and a number in one call.

=== exercise hexcolor
title: Parse a hex color
--- prompt
Colors in config files, shaders tools and CSS are written as hex strings. Write `int parse_hex_color(const char *s, uint32_t *out)` that accepts exactly these forms (digits in either case):

- `#RRGGBB`: alpha is 255,
- `#RRGGBBAA`,
- `#RGB`: each digit doubled, so `#f80` means `#ff8800`.

On success store the color packed with red in the lowest byte (`r | g << 8 | b << 16 | a << 24`, the `rgba8` layout from the types chapter) and return 1. Anything else (no `#`, wrong length, a non-hex character, trailing spaces) returns 0 and leaves `*out` unchanged.

Write a small helper that turns one character into its value 0-15, or -1. Don't use `strtol` here: it would accept `"#+12345"` and `"# 12345"`, and you want strict.
--- starter
#include <stdint.h>
#include <string.h>

int parse_hex_color(const char *s, uint32_t *out) {
    return 0;
}
--- solution
#include <stdint.h>
#include <string.h>

static int hexval(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'a' && c <= 'f') return c - 'a' + 10;
    if (c >= 'A' && c <= 'F') return c - 'A' + 10;
    return -1;
}

int parse_hex_color(const char *s, uint32_t *out) {
    if (s[0] != '#') return 0;
    s++;
    size_t n = strlen(s);
    if (n != 3 && n != 6 && n != 8) return 0;
    int d[8];
    for (size_t i = 0; i < n; i++)
        if ((d[i] = hexval(s[i])) < 0) return 0;
    uint32_t r, g, b, a = 255;
    if (n == 3) {
        r = (uint32_t)d[0] * 17;             // 0xA -> 0xAA is 10 * 17
        g = (uint32_t)d[1] * 17;
        b = (uint32_t)d[2] * 17;
    } else {
        r = (uint32_t)(d[0] << 4 | d[1]);
        g = (uint32_t)(d[2] << 4 | d[3]);
        b = (uint32_t)(d[4] << 4 | d[5]);
        if (n == 8) a = (uint32_t)(d[6] << 4 | d[7]);
    }
    *out = r | g << 8 | b << 16 | a << 24;
    return 1;
}
--- hint
Check the `#`, then the length of the rest (3, 6 or 8), then convert every digit, failing on the first bad one. Only write `*out` at the very end.
--- hint
Doubling a hex digit `d` gives `d * 16 + d`, which is `d * 17`.
--- harness

=== exercise lsystem
title: One L-system step
--- prompt
An **L-system** grows plants, fractals and road networks from a string. Each step replaces every character that has a *rule* with the rule's text, all at once; characters without a rule are copied. With the rule `F -> F+F-F-F+F`, `F` becomes `F+F-F-F+F`, which becomes `F+F-F-F+F+F+F-F-F+F-...`, and drawn with a turtle (next exercises) that is a Koch curve.

Rules are given as a table indexed by character: `rules['F']` is the replacement for `F`, or `NULL` for "copy". Write

```c
size_t lsys_expand(const char *in, const char *const rules[128], char *out, size_t cap);
```

It writes the expanded string into `out`, never more than `cap - 1` characters plus the terminator (`cap` is at least 1), and returns the length the *full* result has, like `snprintf`. So the caller can detect truncation with `result >= cap`. Characters are plain ASCII.

Keep a write position and copy each piece there. Do not build the output with `strcat`: it rescans the whole output to find its end on every call. The next exercise grows strings to millions of characters, where that makes the difference between instant and never finishing.
--- starter
#include <stddef.h>
#include <string.h>

size_t lsys_expand(const char *in, const char *const rules[128], char *out, size_t cap) {
    out[0] = '\0';
    return 0;
}
--- solution
#include <stddef.h>
#include <string.h>

size_t lsys_expand(const char *in, const char *const rules[128], char *out, size_t cap) {
    size_t len = 0;                                  // full length so far
    for (; *in; in++) {
        unsigned char c = (unsigned char)*in;
        const char *rep = c < 128 ? rules[c] : NULL;
        if (rep) {
            for (; *rep; rep++, len++)
                if (len + 1 < cap) out[len] = *rep;
        } else {
            if (len + 1 < cap) out[len] = (char)c;
            len++;
        }
    }
    out[len < cap ? len : cap - 1] = '\0';
    return len;
}
--- hint
Count `len` for every character you *would* write, but only store it when `len + 1 < cap`. At the end, terminate at `len` or at `cap - 1`, whichever is smaller.
--- harness

    const char *algae[128] = {0};
    algae['A'] = "AB";
    algae['B'] = "A";

    CHECK_STR(out, "ABAABABA");
    char small[5];
    CHECK_INT(lsys_expand("F", rules, small, sizeof small), 9);
    CHECK_STR(small, "F+F-");
    char one[1];
    CHECK_INT(lsys_expand("FF", rules, one, 1), 18);
    CHECK_STR(one, "");

=== exercise lsysgrow
title: Growing an L-system
continues: lsystem
--- prompt
Add the driver:

```c
const char *lsys_generate(const char *axiom, const char *const rules[128], int iterations,
                          char *a, char *b, size_t cap);
```

Start from `axiom`, apply `iterations` steps, and return a pointer to whichever of the two caller-provided buffers `a` and `b` (each `cap` bytes) holds the result. If the axiom or any step does not fit (length `>= cap`), return `NULL`.

This is the **ping-pong** (double buffer) pattern: expand `a` into `b`, then `b` into `a`, and so on, swapping two pointers instead of allocating or copying. The tests grow a Koch curve for 9 steps, almost 4 million characters, in buffers allocated once. Any per-character `strcat` or `strlen(out)` turns that into trillions of steps.
--- stubs
const char *lsys_generate(const char *axiom, const char *const rules[128], int iterations,
                          char *a, char *b, size_t cap) {
    return NULL;
}
--- solution
#include <stddef.h>
#include <string.h>

size_t lsys_expand(const char *in, const char *const rules[128], char *out, size_t cap) {
    size_t len = 0;
    for (; *in; in++) {
        unsigned char c = (unsigned char)*in;
        const char *rep = c < 128 ? rules[c] : NULL;
        if (rep) {
            for (; *rep; rep++, len++)
                if (len + 1 < cap) out[len] = *rep;
        } else {
            if (len + 1 < cap) out[len] = (char)c;
            len++;
        }
    }
    out[len < cap ? len : cap - 1] = '\0';
    return len;
}

const char *lsys_generate(const char *axiom, const char *const rules[128], int iterations,
                          char *a, char *b, size_t cap) {
    size_t n = strlen(axiom);
    if (n >= cap) return NULL;
    memcpy(a, axiom, n + 1);
    char *cur = a, *next = b;
    for (int i = 0; i < iterations; i++) {
        if (lsys_expand(cur, rules, next, cap) >= cap) return NULL;
        char *t = cur; cur = next; next = t;      // swap roles, no copying
    }
    return cur;
}
--- hint
Copy the axiom into `a` (check it fits first). Keep two pointers `cur` and `next`; after each step swap them.

=== exercise turtle
title: Turtle bounds

--- prompt
An L-system string is a program for a **turtle**: `F` moves one unit forward (drawing a line), `+` turns 90 degrees left, `-` turns 90 degrees right; anything else is ignored. The turtle starts at `(0, 0)` facing `+x`.

#include <string.h>

const char *lsys_generate(const char *axiom, const char *const rules[128], int iterations,
                          char *a, char *b, size_t cap) {
    size_t n = strlen(axiom);
    if (n >= cap) return NULL;
    memcpy(a, axiom, n + 1);
    char *cur = a, *next = b;
    for (int i = 0; i < iterations; i++) {

int turtle_bounds(const char *cmds, int *minx, int *miny, int *maxx, int *maxy) {
    int x = 0, y = 0, dx = 1, dy = 0, moves = 0;
    int x0 = 0, y0 = 0, x1 = 0, y1 = 0;
    for (; *cmds; cmds++) {
        int t;
        switch (*cmds) {
        case 'F':
            x += dx; y += dy; moves++;
            if (x < x0) x0 = x;
            if (x > x1) x1 = x;
            if (y < y0) y0 = y;
            if (y > y1) y1 = y;
            break;
        case '+': t = dx; dx = -dy; dy = t; break;
        case '-': t = dx; dx = dy; dy = -t; break;
        default: break;
        }
    }
    *minx = x0; *miny = y0; *maxx = x1; *maxy = y1;
    return moves;
}

Characters are integers. `'7' - '0'` is 7. `'a' + 2` printed with `%c` is `c`. `'A'` printed with `%d` is its code, 65. Shifting a letter by `'A' - 'a'` changes its case.
