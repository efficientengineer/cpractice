## What you are building

This chapter turns the image library from "Images from scratch" into a tiny **software renderer**: the same pipeline a GPU runs, written out by hand in about 300 lines. Every step adds math you will use for the rest of your graphics life:

1. `vec3` operations (dot, cross, normalize, reflect)
2. 4×4 matrices, column-major
3. translate, rotate, scale and composing them
4. a camera: lookAt, perspective projection, the viewport
5. quaternions
6. parametric meshes: cube and UV sphere
7. a torus
8. wireframe rendering
9. filled triangles: edge functions, the top-left rule, a z-buffer
10. flat-shaded meshes, and a lit 3D scene

The first step's starter contains the finished image library from the previous chapter (images, sRGB output, `put_pixel`, `draw_line`), trimmed to what the renderer needs.

## Small vectors, passed by value

```c
typedef struct { float x, y; } vec2;
typedef struct { float x, y, z; } vec3;
typedef struct { float x, y, z, w; } vec4;

static inline vec3 v3(float x, float y, float z) { return (vec3){ x, y, z }; }
vec3 v3_add(vec3 a, vec3 b) { return v3(a.x + b.x, a.y + b.y, a.z + b.z); }
```

Pass and return these **by value**. A `vec3` is 12 bytes; on x86-64 and ARM64 small structs travel in registers, and the compiler inlines these functions away. Pointers (`void v3_add(vec3 *out, const vec3 *a, const vec3 *b)`) look "faster" to C# eyes but force values through memory, invite aliasing questions, and make expressions unreadable. C has no operator overloading, so you write `v3_add(a, v3_scale(b, 2))`; keep the names short.

The operations you will use constantly:

| Operation | Formula | Meaning |
|---|---|---|
| `dot(a, b)` | `ax bx + ay by + az bz` | `|a||b| cos θ`: how aligned two directions are; projection of `a` onto unit `b` |
| `cross(a, b)` | `(ay bz - az by, az bx - ax bz, ax by - ay bx)` | perpendicular to both, length `|a||b| sin θ` (twice the triangle area); right-hand rule: `x × y = z` |
| `length(a)` | `sqrt(dot(a, a))` | compare `dot(a, a)` against `r²` when you only need "closer than" |
| `normalize(a)` | `a / length(a)` | unit direction; **guard the zero vector**, or you divide by zero and spread NaN through the frame |
| `reflect(i, n)` | `i - 2 dot(i, n) n` | mirror direction `i` about unit normal `n`: bounces, specular highlights |

Lambert's law, the basis of diffuse lighting, is one dot product: brightness `= max(0, dot(n, l))` with `n` the unit surface normal and `l` the unit direction *towards* the light. The first exercise uses exactly that to shade a sphere per pixel.

> **Performance:** a `sqrtf` and a division per `normalize` are cheap today, but in per-pixel code avoid normalizing what is already unit length (normals from a normal map, directions you just normalized) and compare squared lengths instead of lengths. Multiply by `1.0f / len` once rather than dividing three times.

## Matrices, column-major

A 4×4 matrix transforms points in 3D with one multiply. We store it as 16 floats, **column-major**: element (row `r`, column `c`) lives at `m[c*4 + r]`. That is the layout OpenGL, WebGPU/WGSL (`mat4x4<f32>`), glm and most engines use, so a `mat4` can be copied straight into a GPU uniform buffer.

```text
         column 0   column 1   column 2   column 3
row 0    m[0]       m[4]       m[8]       m[12]        | x' |   | Xx Yx Zx Tx | | x |
row 1    m[1]       m[5]       m[9]       m[13]        | y' | = | Xy Yy Zy Ty | | y |
row 2    m[2]       m[6]       m[10]      m[14]        | z' |   | Xz Yz Zz Tz | | z |
row 3    m[3]       m[7]       m[11]      m[15]        | w' |   | 0  0  0  1  | | 1 |
```

The columns have a meaning: the first three are where the x, y and z axes go, and the fourth (`m[12..14]`) is the translation. Read a matrix by its columns and it tells you what it does.

Vectors are columns and multiply on the right: `M v`. So `A B v = A (B v)`: **`B` is applied first**. A typical model matrix is `T * R * S`: scale the object, then rotate it, then move it into place. Reversing that order rotates the object around the world origin instead (an orbit, not a spin).

### Points versus directions

The fourth coordinate `w` separates them. A **point** has `w = 1`, so the translation column is added. A **direction** (a velocity, a normal, a light direction) has `w = 0` and only rotates and scales. Transforming a direction as a point is a classic bug: your light direction moves when the camera does.

Normals have one more subtlety: under non-uniform scaling they must be transformed by the **inverse transpose** of the upper 3×3, or they stop being perpendicular to the surface. With only rotations and uniform scale the matrix itself works, and computing face normals from transformed positions (as the renderer here does) avoids the issue entirely.

### The transforms

```text
translate(t):  identity with m[12], m[13], m[14] = t.x, t.y, t.z
scale(s):      diagonal s.x, s.y, s.z, 1
rotate_y(a):   x' =  cos a x + sin a z          right-handed: positive angles turn
               z' = -sin a x + cos a z          counter-clockwise looking down the axis
```

Rotation about an arbitrary unit axis `(x, y, z)` is **Rodrigues' formula**; with `c = cos a`, `s = sin a`, `t = 1 - c`:

```text
| t x x + c     t x y - s z   t x z + s y |
| t x y + s z   t y y + c     t y z - s x |
| t x z - s y   t y z + s x   t z z + c   |
```

> **Performance:** a `mat4` is 64 bytes; passing it by value is fine for setup code, which runs a few times per object per frame. What matters is the per-vertex loop: compute `mvp = projection * view * model` **once**, then transform each vertex with one matrix-vector multiply. Multiplying three matrices per vertex is 3× the work for the same result. Hoisting invariant math out of loops is the most valuable habit in this chapter.

## The camera: view, projection, viewport

Rendering a point takes it through a chain of spaces:

```text
model space --model--> world space --view--> camera space --projection--> clip space
   --divide by w--> NDC (-1..1, -1..1, 0..1) --viewport--> pixels
```

**View (lookAt).** The camera sits at `eye` and looks at `target`. Build an orthonormal basis: forward `f = normalize(target - eye)`, right `s = normalize(cross(f, up))`, true up `u = cross(s, f)`. The view matrix has `s`, `u`, `-f` as its *rows* (it is the inverse of the camera's own rotation) and a translation of `(-dot(s, eye), -dot(u, eye), dot(f, eye))`. In camera space the camera is at the origin looking down **-Z**, with +Y up: the right-handed convention of OpenGL and WebGPU.

**Projection (perspective).** Things twice as far look half as big: divide x and y by the distance. A matrix can't divide, so it copies the distance `-z` into `w`, and the GPU divides by `w` afterwards (the *perspective divide*). With `f = 1 / tan(fovy / 2)`:

```text
| f/aspect  0    0                  0                |
| 0         f    0                  0                |       w' = -z
| 0         0    far/(near-far)     near*far/(near-far)|     depth = z'/w': 0 at near, 1 at far
| 0         0   -1                  0                |
```

This is the WebGPU/Direct3D/Vulkan depth range, 0 to 1. (OpenGL's classic matrix maps to -1..1 instead; mixing the two up gives you a depth buffer that clips half the scene.) Depth is not linear in distance: most of the precision is near the near plane, so keep `near` as large as you can afford (0.1, not 0.0001).

**Viewport.** NDC `x, y` in -1..1 become pixels: `sx = (x + 1)/2 * width`, and since image rows go *down*, `sy = (1 - y)/2 * height`.

```c
#include <math.h>
#include <stdio.h>

typedef struct { float x, y, z; } vec3;

int main(void) {
    /* Perspective by hand: a grid of points on the floor y = -1, camera at the origin looking down -Z. */
    int w = 128, h = 96;
    static unsigned char img[96][128];
    float f = 1.0f / tanf(0.5f * 1.0f);                     /* fovy = 1 radian */
    for (int i = -10; i <= 10; i++)
        for (int k = 1; k <= 40; k++) {
            vec3 p = { i * 0.5f, -1.0f, -k * 0.5f };
            float ndc_x = f * (h / (float)w) * p.x / -p.z, ndc_y = f * p.y / -p.z;
            int sx = (int)floorf((ndc_x + 1) * 0.5f * w), sy = (int)floorf((1 - ndc_y) * 0.5f * h);
            if (sx >= 0 && sx < w && sy >= 0 && sy < h) img[sy][sx] = (unsigned char)(255 - k * 5);
        }
    printf("P2\n%d %d\n255\n", w, h);
    for (int y = 0; y < h; y++) {
        for (int x = 0; x < w; x++) printf("%d ", img[y][x]);
        printf("\n");
    }
    return 0;
}
```

The rows of dots crowd together toward the horizon line: that is the division by distance.

## Quaternions

Rotation matrices compose fine, but interpolating between two of them (an animation, a camera blend) by lerping their entries gives garbage, and Euler angles (yaw, pitch, roll) suffer gimbal lock. A **unit quaternion** `q = (axis sin(θ/2), cos(θ/2))` represents a rotation by `θ` about `axis` in four numbers:

- compose: the Hamilton product `a * b` (rotate by `b`, then by `a`, like matrices);
- rotate a vector: `t = 2 cross(q.xyz, v)`, `v' = v + q.w t + cross(q.xyz, t)`;
- interpolate: **slerp**, constant angular speed along the shortest arc. `q` and `-q` are the same rotation, so if `dot(a, b) < 0` negate one to take the short way round; when they are nearly equal fall back to a normalized lerp to avoid dividing by `sin θ ≈ 0`.

Engines store orientations as quaternions (cheaper to renormalize, smaller, interpolate well) and convert to a matrix once per object per frame for rendering.

## Meshes are arrays

A triangle mesh is a **vertex array** and an **index array**: three indices per triangle. Shared vertices are stored once, which is why GPUs take this format directly.

```c
typedef struct { vec3 *pos; int npos; int *idx; int nidx; } Mesh;   // nidx = 3 * triangles
```

Procedural models are parametric surfaces sampled on a grid. A **UV sphere** maps `(θ, φ)` (from the north pole down, and around) to `r (sin θ cos φ, cos θ, -sin θ sin φ)`; a **torus** maps `(u, v)` to `((R + r cos v) cos u, r sin v, -(R + r cos v) sin u)`. Sample a grid of `(i, j)`, generate vertices row by row, then two triangles per grid cell. The work is all in two details:

- **Winding.** Triangles list their vertices counter-clockwise when seen from outside, so `cross(b - a, c - a)` points *outward*. The renderer uses that to skip back faces, and a mesh with mixed winding renders with holes.
- **Seams and poles.** The sphere's grid has a seam where `φ` wraps (we duplicate that column, which texture coordinates will need later) and its first and last rows collapse to a point: those quads are triangles, so emit one triangle, not a degenerate one. The torus wraps in both directions, so it uses `(i + 1) % nu` and needs no duplicates.

> **Performance:** compute the vertex and triangle counts first, allocate both arrays once, and fill them with a running index. Never `realloc` per vertex. Precompute the `cos`/`sin` of each column angle in a small table if you generate meshes per frame.

## Rasterizing triangles

**Wireframe** is the first view of any mesh: project every vertex once, then draw three lines per triangle.

**Filling** uses **edge functions** (Pineda, 1988). For the edge from `a` to `b`,

```text
E_ab(p) = (b.x - a.x)(p.y - a.y) - (b.y - a.y)(p.x - a.x)
```

is twice the signed area of triangle `a, b, p`: positive on one side of the line, negative on the other. A pixel center `p` is inside the triangle when all three edge functions have the same sign as the triangle's area `E_ab(c)`. The three normalized values `E_bc(p)/area`, `E_ca(p)/area`, `E_ab(p)/area` are the **barycentric coordinates** of `p`: weights for interpolating anything across the triangle (depth now, colors and texture coordinates later).

The algorithm is the same one GPUs implement in hardware:

1. compute the triangle's bounding box, clipped to the image;
2. for each pixel center in it, evaluate the three edge functions;
3. if inside, interpolate depth, compare with the **z-buffer**, and write the pixel and depth if nearer.

**The top-left rule.** A pixel center exactly on an edge shared by two triangles must be drawn by exactly one of them: drawing it twice double-blends transparent surfaces, drawing it zero times leaves cracks. The rule used by Direct3D, Vulkan and WebGPU: a center on an edge belongs to the triangle if that edge is a **top** edge (exactly horizontal, with the triangle below it) or a **left** edge (the triangle to its right). With vertices ordered so the area is positive in our y-down coordinates, a top edge has `dy == 0 && dx > 0` and a left edge has `dy < 0`.

**Back-face culling.** After projection, triangles facing away from the camera have the opposite winding on screen. Skipping them halves the fill work for closed meshes and costs one cross product.

**Flat shading.** One color per triangle, from its face normal: `base * (ambient + diffuse * max(0, dot(n, -light_dir)))`. Faceted, but it shows the form, and it is all you need to see your procedural meshes.

> **Performance:** the bounding box keeps a small triangle from scanning the screen; the depth test before shading avoids work for hidden pixels; edge functions are linear, so a real rasterizer adds a constant per pixel instead of re-evaluating them (try it once your version passes). And transform each *vertex* once, not each triangle corner: a closed mesh shares every vertex between about six triangles.

Further reading: Fabian Giesen's "A trip through the graphics pipeline" and his rasterization posts; Scratchapixel's rasterization lessons.

    im->px = NULL;

    return &im->px[(size_t)y * im->w + x];
}

void image_fill(Image *im, Color c) {
    size_t n = (size_t)im->w * im->h;
    for (size_t i = 0; i < n; i++) im->px[i] = c;
}

uint8_t to_byte(float v) {
    if (!(v > 0.0f)) return 0;
    if (v >= 1.0f) return 255;
    return (uint8_t)(v * 255.0f + 0.5f);
}

float srgb_encode(float l) {
    if (!(l > 0.0f)) return 0.0f;
    if (l >= 1.0f) return 1.0f;
    return l <= 0.0031308f ? 12.92f * l : 1.055f * powf(l, 1.0f / 2.4f) - 0.055f;
}

void srgb_lut_init(uint8_t lut[4096]) {
    for (int i = 0; i < 4096; i++) lut[i] = to_byte(srgb_encode(i / 4095.0f));
}

static inline int lut_index(float v) {
    if (!(v > 0.0f)) return 0;
    if (v >= 1.0f) return 4095;
    return (int)(v * 4095.0f + 0.5f);
}

void image_write_ppm_srgb(const Image *im, FILE *f, const uint8_t lut[4096]) {
    fprintf(f, "P3\n%d %d\n255\n", im->w, im->h);
    for (int y = 0; y < im->h; y++) {
        const Color *row = im->px + (size_t)y * im->w;
        for (int x = 0; x < im->w; x++)
            fprintf(f, x ? " %d %d %d" : "%d %d %d", lut[lut_index(row[x].r)], lut[lut_index(row[x].g)],
                    lut[lut_index(row[x].b)]);
        fputc('\n', f);
    }
}

void put_pixel(Image *im, int x, int y, Color c) {
    if (x < 0 || y < 0 || x >= im->w || y >= im->h) return;
    im->px[(size_t)y * im->w + x] = c;
}

void draw_line(Image *im, int x0, int y0, int x1, int y1, Color c) {
    int dx = abs(x1 - x0), sx = x0 < x1 ? 1 : -1;
    int dy = -abs(y1 - y0), sy = y0 < y1 ? 1 : -1;
    int err = dx + dy;
    for (;;) {
        put_pixel(im, x0, y0, c);
        if (x0 == x1 && y0 == y1) break;
        int e2 = 2 * err;
        if (e2 >= dy) { err += dy; x0 += sx; }
        if (e2 <= dx) { err += dx; y0 += sy; }
    }
}

/* ---------- Vector math ---------- */
typedef struct { float x, y; } vec2;
typedef struct { float x, y, z; } vec3;

static inline vec3 v3(float x, float y, float z) { return (vec3){ x, y, z }; }

vec3 v3_add(vec3 a, vec3 b) { return v3(a.x + b.x, a.y + b.y, a.z + b.z); }
vec3 v3_sub(vec3 a, vec3 b) { return v3(a.x - b.x, a.y - b.y, a.z - b.z); }

--- prompt
Add the matrix type and its core operations. Put the type in your code:

```c
typedef struct { float m[16]; } mat4;   /* column-major: row r, column c is m[c * 4 + r] */
```

- `mat4 mat4_identity(void)`
- `mat4 mat4_mul(mat4 a, mat4 b)`: the product `a * b` (apply `b` first, then `a`): `r[c][row] = sum over k of a[k][row] * b[c][k]`, where `[col][row]` means `m[col * 4 + row]`.
- `vec4 mat4_mul_vec4(mat4 a, vec4 v)`: `a * v`, so `x' = m[0] x + m[4] y + m[8] z + m[12] w`, and so on.
- `vec3 mat4_mul_point(mat4 a, vec3 p)`: `a * (p, 1)`, returning `x, y, z` (no division by `w`; for affine matrices `w` stays 1).
- `vec3 mat4_mul_dir(mat4 a, vec3 d)`: `a * (d, 0)`: translation does not apply to directions.

The tests fill a matrix with `m[c*4 + r] = 10*r + c` so that a row/column mix-up shows immediately.

--- prompt
Add the camera. Right-handed, the camera looks down **-Z** in view space, and depth maps to **0..1** (the WebGPU/Direct3D/Vulkan convention).

- `mat4 mat4_look_at(vec3 eye, vec3 target, vec3 up)`: `f = normalize(target - eye)`, `s = normalize(cross(f, up))`, `u = cross(s, f)`. Rows 0, 1, 2 of the upper 3×3 are `s`, `u`, `-f` (so `m[0] = s.x, m[4] = s.y, m[8] = s.z`, and so on), and the translation column is `(-dot(s, eye), -dot(u, eye), dot(f, eye))`.
- `mat4 mat4_perspective(float fovy, float aspect, float znear, float zfar)`: with `f = 1 / tanf(fovy / 2)`: `m[0] = f / aspect`, `m[5] = f`, `m[10] = zfar / (znear - zfar)`, `m[11] = -1`, `m[14] = znear * zfar / (znear - zfar)`, everything else 0. A view-space point at `z = -znear` gets depth 0, at `z = -zfar` depth 1.
- `vec4 to_screen(mat4 mvp, vec3 p, int w, int h)`: transform `(p, 1)` to clip space `c`. If `c.w <= 1e-6` (at or behind the camera) return `(0, 0, -1, c.w)`. Otherwise divide by `c.w` and map to pixels: `x = (ndc.x * 0.5 + 0.5) * w`, `y = (0.5 - ndc.y * 0.5) * h` (rows go down), `z = ndc.z` (depth), and keep `c.w` in the result's `w`. The renderer will use `w` to know whether a vertex is usable.

        if (e2 <= dx) { err += dx; y0 += sy; }

mat4 mat4_look_at(vec3 eye, vec3 target, vec3 up) {

    vec3 s = v3_normalize(v3_cross(f, up));
    vec3 u = v3_cross(s, f);
    mat4 r = mat4_identity();
    r.m[0] = s.x;  r.m[4] = s.y;  r.m[8] = s.z;
    r.m[1] = u.x;  r.m[5] = u.y;  r.m[9] = u.z;
    r.m[2] = -f.x; r.m[6] = -f.y; r.m[10] = -f.z;
    r.m[12] = -v3_dot(s, eye);
    r.m[13] = -v3_dot(u, eye);
    r.m[14] = v3_dot(f, eye);
    return r;

--- prompt
Add quaternions for orientation. Put the type in your code:

```c
typedef struct { float x, y, z, w; } quat;   /* (axis * sin(a/2), cos(a/2)) */
```

- `quat quat_from_axis_angle(vec3 axis, float angle)`: normalize `axis` first.
- `quat quat_mul(quat a, quat b)`: the Hamilton product, rotating by `b` then by `a`:
  `w = aw bw - ax bx - ay by - az bz`, `x = aw bx + ax bw + ay bz - az by`, `y = aw by - ax bz + ay bw + az bx`, `z = aw bz + ax by - ay bx + az bw`.
- `vec3 quat_rotate(quat q, vec3 v)`: `t = 2 cross(q.xyz, v)`, `v + q.w t + cross(q.xyz, t)`.
- `mat4 quat_to_mat4(quat q)`: the rotation matrix of a unit quaternion (row-major view; store it column-major):

```text
| 1-2(yy+zz)   2(xy-wz)     2(xz+wy)   |
| 2(xy+wz)     1-2(xx+zz)   2(yz-wx)   |
| 2(xz-wy)     2(yz+wx)     1-2(xx+yy) |
```

- `quat quat_slerp(quat a, quat b, float t)`: if `dot(a, b) < 0`, negate `b` (shortest arc). If the dot is then above `0.9995`, return the normalized component-wise lerp. Otherwise with `θ = acos(dot)`: `(sin((1-t)θ) a + sin(tθ) b) / sin θ`.

Run spins a wire cube along a slerp between two orientations and leaves a trail.

void draw_line(Image *im, int x0, int y0, int x1, int y1, Color c) {

    int dy = -abs(y1 - y0), sy = y0 < y1 ? 1 : -1;

        if (e2 <= dx) { err += dx; y0 += sy; }

mat4 mat4_rotate_axis(vec3 axis, float a) {

    r.m[1] = t * x * y + s * z; r.m[5] = t * y * y + c;     r.m[9] = t * y * z - s * x;

mat4 mat4_look_at(vec3 eye, vec3 target, vec3 up) {
    vec3 f = v3_normalize(v3_sub(target, eye));
    vec3 s = v3_normalize(v3_cross(f, up));
    vec3 u = v3_cross(s, f);
    mat4 r = mat4_identity();
    r.m[0] = s.x;  r.m[4] = s.y;  r.m[8] = s.z;
    r.m[1] = u.x;  r.m[5] = u.y;  r.m[9] = u.z;
    r.m[2] = -f.x; r.m[6] = -f.y; r.m[10] = -f.z;
    r.m[12] = -v3_dot(s, eye);
    r.m[13] = -v3_dot(u, eye);
    r.m[14] = v3_dot(f, eye);
    return r;
}

mat4 mat4_perspective(float fovy, float aspect, float znear, float zfar) {
    float f = 1.0f / tanf(fovy * 0.5f);
    mat4 r = { { 0 } };
    r.m[0] = f / aspect;
    r.m[5] = f;
    r.m[10] = zfar / (znear - zfar);
    r.m[11] = -1.0f;
    r.m[14] = znear * zfar / (znear - zfar);
    return r;
}

typedef struct { float x, y, z, w; } quat;

quat quat_from_axis_angle(vec3 axis, float angle) {
    vec3 n = v3_normalize(axis);
    float s = sinf(angle * 0.5f);
    return (quat){ n.x * s, n.y * s, n.z * s, cosf(angle * 0.5f) };
}

quat quat_mul(quat a, quat b) {
    return (quat){ a.w * b.x + a.x * b.w + a.y * b.z - a.z * b.y,
                   a.w * b.y - a.x * b.z + a.y * b.w + a.z * b.x,
                   a.w * b.z + a.x * b.y - a.y * b.x + a.z * b.w,
                   a.w * b.w - a.x * b.x - a.y * b.y - a.z * b.z };
}

vec3 quat_rotate(quat q, vec3 v) {
    vec3 u = v3(q.x, q.y, q.z);
    vec3 t = v3_scale(v3_cross(u, v), 2.0f);
    return v3_add(v3_add(v, v3_scale(t, q.w)), v3_cross(u, t));
}

mat4 quat_to_mat4(quat q) {
    float x = q.x, y = q.y, z = q.z, w = q.w;
    mat4 r = mat4_identity();
    r.m[0] = 1 - 2 * (y * y + z * z); r.m[4] = 2 * (x * y - w * z);     r.m[8] = 2 * (x * z + w * y);
    r.m[1] = 2 * (x * y + w * z);     r.m[5] = 1 - 2 * (x * x + z * z); r.m[9] = 2 * (y * z - w * x);
    r.m[2] = 2 * (x * z - w * y);     r.m[6] = 2 * (y * z + w * x);     r.m[10] = 1 - 2 * (x * x + y * y);
    return r;
}

quat quat_slerp(quat a, quat b, float t) {
    float d = a.x * b.x + a.y * b.y + a.z * b.z + a.w * b.w;
    if (d < 0) { b = (quat){ -b.x, -b.y, -b.z, -b.w }; d = -d; }
    float wa, wb;
    if (d > 0.9995f) {
        wa = 1 - t; wb = t;
    } else {
        float th = acosf(d), s = sinf(th);
        wa = sinf((1 - t) * th) / s; wb = sinf(t * th) / s;
    }
    quat r = { wa * a.x + wb * b.x, wa * a.y + wb * b.y, wa * a.z + wb * b.z, wa * a.w + wb * b.w };
    float len = sqrtf(r.x * r.x + r.y * r.y + r.z * r.z + r.w * r.w);
    return (quat){ r.x / len, r.y / len, r.z / len, r.w / len };
}

static void wire_cube(Image *im, mat4 mvp, Color c) {

    vec4 s[8];
    for (int i = 0; i < 8; i++)
        s[i] = to_screen(mvp, v3(i & 1 ? 1 : -1, i & 2 ? 1 : -1, i & 4 ? 1 : -1), im->w, im->h);

mat4 mat4_look_at(vec3 eye, vec3 target, vec3 up) {

    vec3 s = v3_normalize(v3_cross(f, up));
    vec3 u = v3_cross(s, f);
    mat4 r = mat4_identity();
    r.m[0] = s.x;  r.m[4] = s.y;  r.m[8] = s.z;
    r.m[1] = u.x;  r.m[5] = u.y;  r.m[9] = u.z;
    r.m[2] = -f.x; r.m[6] = -f.y; r.m[10] = -f.z;

    r.m[13] = -v3_dot(u, eye);

typedef struct { float x, y, z, w; } quat;

    return (quat){ n.x * s, n.y * s, n.z * s, cosf(angle * 0.5f) };
}

quat quat_mul(quat a, quat b) {
    return (quat){ a.w * b.x + a.x * b.w + a.y * b.z - a.z * b.y,
                   a.w * b.y - a.x * b.z + a.y * b.w + a.z * b.x,
                   a.w * b.z + a.x * b.y - a.y * b.x + a.z * b.w,
                   a.w * b.w - a.x * b.x - a.y * b.y - a.z * b.z };
}

vec3 quat_rotate(quat q, vec3 v) {
    vec3 u = v3(q.x, q.y, q.z);
    vec3 t = v3_scale(v3_cross(u, v), 2.0f);
    return v3_add(v3_add(v, v3_scale(t, q.w)), v3_cross(u, t));
}

mat4 quat_to_mat4(quat q) {
    float x = q.x, y = q.y, z = q.z, w = q.w;
    mat4 r = mat4_identity();
    r.m[0] = 1 - 2 * (y * y + z * z); r.m[4] = 2 * (x * y - w * z);     r.m[8] = 2 * (x * z + w * y);
    r.m[1] = 2 * (x * y + w * z);     r.m[5] = 1 - 2 * (x * x + z * z); r.m[9] = 2 * (y * z - w * x);
    r.m[2] = 2 * (x * z - w * y);     r.m[6] = 2 * (y * z + w * x);     r.m[10] = 1 - 2 * (x * x + y * y);
    return r;
}

quat quat_slerp(quat a, quat b, float t) {
    float d = a.x * b.x + a.y * b.y + a.z * b.z + a.w * b.w;
    if (d < 0) { b = (quat){ -b.x, -b.y, -b.z, -b.w }; d = -d; }
    float wa, wb;
    if (d > 0.9995f) {
        wa = 1 - t; wb = t;
    } else {
        float th = acosf(d), s = sinf(th);
        wa = sinf((1 - t) * th) / s; wb = sinf(t * th) / s;
    }
    quat r = { wa * a.x + wb * b.x, wa * a.y + wb * b.y, wa * a.z + wb * b.z, wa * a.w + wb * b.w };
    float len = sqrtf(r.x * r.x + r.y * r.y + r.z * r.z + r.w * r.w);
    return (quat){ r.x / len, r.y / len, r.z / len, r.w / len };
}

Mesh mesh_cube(float half) {
    static const int quads[6][4] = { { 0, 4, 6, 2 }, { 1, 3, 7, 5 }, { 0, 1, 5, 4 },
                                     { 2, 6, 7, 3 }, { 0, 2, 3, 1 }, { 4, 5, 7, 6 } };
    Mesh m = mesh_alloc(8, 12);
    if (!m.pos) return m;
    for (int i = 0; i < 8; i++) m.pos[i] = v3(i & 1 ? half : -half, i & 2 ? half : -half, i & 4 ? half : -half);
    int *t = m.idx;
    for (int f = 0; f < 6; f++) {
        const int *q = quads[f];
        *t++ = q[0]; *t++ = q[1]; *t++ = q[2];
        *t++ = q[0]; *t++ = q[2]; *t++ = q[3];
    }
    return m;
}

Mesh mesh_uv_sphere(int slices, int stacks, float r) {
    Mesh m = mesh_alloc((stacks + 1) * (slices + 1), 2 * slices * (stacks - 1));
    if (!m.pos) return m;
    const float PI = 3.14159265f;
    for (int i = 0; i <= stacks; i++) {
        float th = PI * i / stacks, st = sinf(th), ct = cosf(th);
        for (int j = 0; j <= slices; j++) {
            float ph = 2 * PI * j / slices;
            m.pos[i * (slices + 1) + j] = v3(r * st * cosf(ph), r * ct, -r * st * sinf(ph));
        }
    }
    int *t = m.idx;
    for (int i = 0; i < stacks; i++)
        for (int j = 0; j < slices; j++) {

static int outward_ok(const Mesh *m, vec3 center) {
    for (int t = 0; t < m->nidx; t += 3) {
        int i0 = m->idx[t], i1 = m->idx[t + 1], i2 = m->idx[t + 2];
        if (i0 < 0 || i1 < 0 || i2 < 0 || i0 >= m->npos || i1 >= m->npos || i2 >= m->npos) return 0;
        vec3 a = m->pos[i0], b = m->pos[i1], c = m->pos[i2];
        vec3 n = v3_cross(v3_sub(b, a), v3_sub(c, a));
        if (v3_length(n) < 1e-9f) return 0;
        vec3 mid = v3_scale(v3_add(v3_add(a, b), c), 1.0f / 3);
        if (v3_dot(n, v3_sub(mid, center)) <= 0) return 0;
    }
    return 1;
}

static int closed_ok(const Mesh *m) {
    int n = m->npos, *cnt = calloc((size_t)n * n, sizeof(int)), ok = 1;
    if (!cnt) return 0;
    for (int t = 0; t < m->nidx; t += 3)
        for (int k = 0; k < 3; k++) cnt[m->idx[t + k] * n + m->idx[t + (k + 1) % 3]]++;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (cnt[i * n + j] > 1 || cnt[i * n + j] != cnt[j * n + i]) ok = 0;
    free(cnt);
    return ok;
}

static double area(const Mesh *m) {

}

mat4 mat4_look_at(vec3 eye, vec3 target, vec3 up) {

    vec3 s = v3_normalize(v3_cross(f, up));
    vec3 u = v3_cross(s, f);
    mat4 r = mat4_identity();
    r.m[0] = s.x;  r.m[4] = s.y;  r.m[8] = s.z;
    r.m[1] = u.x;  r.m[5] = u.y;  r.m[9] = u.z;
    r.m[2] = -f.x; r.m[6] = -f.y; r.m[10] = -f.z;
    r.m[12] = -v3_dot(s, eye);
    r.m[13] = -v3_dot(u, eye);
    r.m[14] = v3_dot(f, eye);
    return r;

    r.m[5] = f;
    r.m[10] = zfar / (znear - zfar);

                   a.w * b.y - a.x * b.z + a.y * b.w + a.z * b.x,
                   a.w * b.z + a.x * b.y - a.y * b.x + a.z * b.w,

mat4 quat_to_mat4(quat q) {
    float x = q.x, y = q.y, z = q.z, w = q.w;
    mat4 r = mat4_identity();
    r.m[0] = 1 - 2 * (y * y + z * z); r.m[4] = 2 * (x * y - w * z);     r.m[8] = 2 * (x * z + w * y);
    r.m[1] = 2 * (x * y + w * z);     r.m[5] = 1 - 2 * (x * x + z * z); r.m[9] = 2 * (y * z - w * x);
    r.m[2] = 2 * (x * z - w * y);     r.m[6] = 2 * (y * z + w * x);     r.m[10] = 1 - 2 * (x * x + y * y);
    return r;
}

quat quat_slerp(quat a, quat b, float t) {
    float d = a.x * b.x + a.y * b.y + a.z * b.z + a.w * b.w;
    if (d < 0) { b = (quat){ -b.x, -b.y, -b.z, -b.w }; d = -d; }
    float wa, wb;
    if (d > 0.9995f) {
        wa = 1 - t; wb = t;
    } else {
        float th = acosf(d), s = sinf(th);
        wa = sinf((1 - t) * th) / s; wb = sinf(t * th) / s;
    }
    quat r = { wa * a.x + wb * b.x, wa * a.y + wb * b.y, wa * a.z + wb * b.z, wa * a.w + wb * b.w };
    float len = sqrtf(r.x * r.x + r.y * r.y + r.z * r.z + r.w * r.w);
    return (quat){ r.x / len, r.y / len, r.z / len, r.w / len };
}

Mesh mesh_cube(float half) {
    static const int quads[6][4] = { { 0, 4, 6, 2 }, { 1, 3, 7, 5 }, { 0, 1, 5, 4 },
                                     { 2, 6, 7, 3 }, { 0, 2, 3, 1 }, { 4, 5, 7, 6 } };

    for (int i = 0; i < 8; i++) m.pos[i] = v3(i & 1 ? half : -half, i & 2 ? half : -half, i & 4 ? half : -half);
    int *t = m.idx;
    for (int f = 0; f < 6; f++) {
        const int *q = quads[f];
        *t++ = q[0]; *t++ = q[1]; *t++ = q[2];
        *t++ = q[0]; *t++ = q[2]; *t++ = q[3];
    }
    return m;
}

Mesh mesh_uv_sphere(int slices, int stacks, float r) {

    if (!m.pos) return m;
    const float PI = 3.14159265f;
    for (int i = 0; i <= stacks; i++) {
        float th = PI * i / stacks, st = sinf(th), ct = cosf(th);
        for (int j = 0; j <= slices; j++) {
            float ph = 2 * PI * j / slices;
            m.pos[i * (slices + 1) + j] = v3(r * st * cosf(ph), r * ct, -r * st * sinf(ph));
        }
    }
    int *t = m.idx;
    for (int i = 0; i < stacks; i++)
        for (int j = 0; j < slices; j++) {
            int a = i * (slices + 1) + j, b = a + slices + 1, c = b + 1, d = a + 1;
            if (i != stacks - 1) { *t++ = a; *t++ = b; *t++ = c; }
            if (i != 0) { *t++ = a; *t++ = c; *t++ = d; }
        }
    return m;
}

Mesh mesh_torus(float R, float r, int nu, int nv) {
    Mesh m = mesh_alloc(nu * nv, 2 * nu * nv);
    if (!m.pos) return m;
    const float TAU = 6.2831853f;
    for (int i = 0; i < nu; i++) {
        float u = TAU * i / nu, cu = cosf(u), su = sinf(u);
        for (int j = 0; j < nv; j++) {
            float v = TAU * j / nv, ring = R + r * cosf(v);
            m.pos[i * nv + j] = v3(ring * cu, r * sinf(v), -ring * su);
        }
    }
    int *t = m.idx;
    for (int i = 0; i < nu; i++) {
        int i1 = (i + 1) % nu;
        for (int j = 0; j < nv; j++) {
            int j1 = (j + 1) % nv;
            int a = i * nv + j, b = i1 * nv + j, c = i1 * nv + j1, d = i * nv + j1;
            *t++ = a; *t++ = b; *t++ = c;
            *t++ = a; *t++ = c; *t++ = d;
        }
    }
    return m;
}

}

--- prompt
Add `void draw_wireframe(Image *im, const Mesh *m, mat4 mvp, Color c, vec4 *screen)`.

1. Project **every vertex once** into the caller's scratch array: `screen[i] = to_screen(mvp, m->pos[i], im->w, im->h)`. A closed mesh shares each vertex between about six triangles; projecting per triangle corner does the same work six times.
2. For each triangle, if all three vertices are usable, draw its three edges with `draw_line`, converting coordinates with `(int)floorf(...)`.

A vertex is usable when `w > 1e-6`, `z >= 0` (not in front of the near plane) and its screen position lies inside a **guard band** of four image sizes around the image: `-4w < x < 5w` and `-4h < y < 5h`. Write this as a helper `int screen_ok(vec4 s, int w, int h)`; the filled renderer reuses it.

Why the guard band: a vertex just in front of the camera's near plane can project millions of pixels off-screen. `draw_line` would walk every one of them, and converting a float beyond `INT_MAX` to `int` is undefined behavior. Real renderers *clip* triangles against the near plane (Sutherland-Hodgman); skipping the triangle is the simple version, good enough here.

The tests draw a cube from a known camera, put the camera inside a torus (half its vertices behind the camera), and draw a mesh entirely behind the camera.

void draw_line(Image *im, int x0, int y0, int x1, int y1, Color c) {
    int dx = abs(x1 - x0), sx = x0 < x1 ? 1 : -1;
    int dy = -abs(y1 - y0), sy = y0 < y1 ? 1 : -1;
    int err = dx + dy;
    for (;;) {
        put_pixel(im, x0, y0, c);
        if (x0 == x1 && y0 == y1) break;
        int e2 = 2 * err;
        if (e2 >= dy) { err += dy; x0 += sx; }
        if (e2 <= dx) { err += dx; y0 += sy; }
    }
}

                   a.w * b.z + a.x * b.y - a.y * b.x + a.z * b.w,

    float x = q.x, y = q.y, z = q.z, w = q.w;
    mat4 r = mat4_identity();
    r.m[0] = 1 - 2 * (y * y + z * z); r.m[4] = 2 * (x * y - w * z);     r.m[8] = 2 * (x * z + w * y);
    r.m[1] = 2 * (x * y + w * z);     r.m[5] = 1 - 2 * (x * x + z * z); r.m[9] = 2 * (y * z - w * x);
    r.m[2] = 2 * (x * z - w * y);     r.m[6] = 2 * (y * z + w * x);     r.m[10] = 1 - 2 * (x * x + y * y);

quat quat_slerp(quat a, quat b, float t) {
    float d = a.x * b.x + a.y * b.y + a.z * b.z + a.w * b.w;
    if (d < 0) { b = (quat){ -b.x, -b.y, -b.z, -b.w }; d = -d; }
    float wa, wb;
    if (d > 0.9995f) {
        wa = 1 - t; wb = t;
    } else {
        float th = acosf(d), s = sinf(th);
        wa = sinf((1 - t) * th) / s; wb = sinf(t * th) / s;
    }
    quat r = { wa * a.x + wb * b.x, wa * a.y + wb * b.y, wa * a.z + wb * b.z, wa * a.w + wb * b.w };
    float len = sqrtf(r.x * r.x + r.y * r.y + r.z * r.z + r.w * r.w);
    return (quat){ r.x / len, r.y / len, r.z / len, r.w / len };
}

            float ph = 2 * PI * j / slices;
            m.pos[i * (slices + 1) + j] = v3(r * st * cosf(ph), r * ct, -r * st * sinf(ph));
        }
    }
    int *t = m.idx;
    for (int i = 0; i < stacks; i++)
        for (int j = 0; j < slices; j++) {
            int a = i * (slices + 1) + j, b = a + slices + 1, c = b + 1, d = a + 1;
            if (i != stacks - 1) { *t++ = a; *t++ = b; *t++ = c; }
            if (i != 0) { *t++ = a; *t++ = c; *t++ = d; }
        }
    return m;
}

Mesh mesh_torus(float R, float r, int nu, int nv) {
    Mesh m = mesh_alloc(nu * nv, 2 * nu * nv);
    if (!m.pos) return m;
    const float TAU = 6.2831853f;
    for (int i = 0; i < nu; i++) {
        float u = TAU * i / nu, cu = cosf(u), su = sinf(u);
        for (int j = 0; j < nv; j++) {
            float v = TAU * j / nv, ring = R + r * cosf(v);
            m.pos[i * nv + j] = v3(ring * cu, r * sinf(v), -ring * su);
        }
    }
    int *t = m.idx;
    for (int i = 0; i < nu; i++) {
        int i1 = (i + 1) % nu;
        for (int j = 0; j < nv; j++) {
            int j1 = (j + 1) % nv;
            int a = i * nv + j, b = i1 * nv + j, c = i1 * nv + j1, d = i * nv + j1;
            *t++ = a; *t++ = b; *t++ = c;
            *t++ = a; *t++ = c; *t++ = d;
        }
    }
    return m;
}

--- prompt
Add the triangle rasterizer: `void fill_triangle(Image *im, float *zbuf, vec4 a, vec4 b, vec4 c, Color col)`. The vertices are screen-space (`x`, `y` in pixels, `z` depth 0..1; `w` is ignored). `zbuf` holds one float per pixel, the depth of what is drawn there (callers clear it to `1.0f` or `INFINITY`).

1. `area = E(a, b, c)` with the edge function `E(a, b, p) = (b.x - a.x)(p.y - a.y) - (b.y - a.y)(p.x - a.x)`. If `area == 0` return. If `area < 0`, swap `b` and `c` (and negate `area`) so both windings work.
2. Bounding box of the three vertices, clipped to the image: `floorf(min x)` to `ceilf(max x)`, and the same for `y`.
3. For each pixel center `p = (x + 0.5, y + 0.5)` in the box: `w0 = E(b, c, p)`, `w1 = E(c, a, p)`, `w2 = E(a, b, p)`. The pixel is inside if each `w` is `> 0`, or is `== 0` on a **top-left** edge. With this orientation, the edge from `u` to `v` is top-left when `(v.y - u.y < 0) || (v.y == u.y && v.x - u.x > 0)`; `w0` belongs to edge `b → c`, `w1` to `c → a`, `w2` to `a → b`.
4. Depth `z = (w0 a.z + w1 b.z + w2 c.z) / area`. If `z < zbuf[i]`, write `col` and `z`.

The tests split squares and fans into triangles whose edges pass exactly through pixel centers and require that **every pixel is drawn exactly once**: `>= 0` everywhere double-draws shared edges, `> 0` everywhere leaves cracks. They also draw 200,000 small triangles on a 1024×1024 image: without the clipped bounding box that times out.

uint8_t to_byte(float v) {
    if (!(v > 0.0f)) return 0;
    if (v >= 1.0f) return 255;
    return (uint8_t)(v * 255.0f + 0.5f);
}

float srgb_encode(float l) {
    if (!(l > 0.0f)) return 0.0f;
    if (l >= 1.0f) return 1.0f;
    return l <= 0.0031308f ? 12.92f * l : 1.055f * powf(l, 1.0f / 2.4f) - 0.055f;
}

void srgb_lut_init(uint8_t lut[4096]) {
    for (int i = 0; i < 4096; i++) lut[i] = to_byte(srgb_encode(i / 4095.0f));
}

static inline int lut_index(float v) {
    if (!(v > 0.0f)) return 0;
    if (v >= 1.0f) return 4095;
    return (int)(v * 4095.0f + 0.5f);
}

void image_write_ppm_srgb(const Image *im, FILE *f, const uint8_t lut[4096]) {
    fprintf(f, "P3\n%d %d\n255\n", im->w, im->h);
    for (int y = 0; y < im->h; y++) {
        const Color *row = im->px + (size_t)y * im->w;
        for (int x = 0; x < im->w; x++)
            fprintf(f, x ? " %d %d %d" : "%d %d %d", lut[lut_index(row[x].r)], lut[lut_index(row[x].g)],
                    lut[lut_index(row[x].b)]);
        fputc('\n', f);
    }
}

void put_pixel(Image *im, int x, int y, Color c) {
    if (x < 0 || y < 0 || x >= im->w || y >= im->h) return;
    im->px[(size_t)y * im->w + x] = c;
}

void draw_line(Image *im, int x0, int y0, int x1, int y1, Color c) {
    int dx = abs(x1 - x0), sx = x0 < x1 ? 1 : -1;
    int dy = -abs(y1 - y0), sy = y0 < y1 ? 1 : -1;
    int err = dx + dy;
    for (;;) {
        put_pixel(im, x0, y0, c);
        if (x0 == x1 && y0 == y1) break;
        int e2 = 2 * err;
        if (e2 >= dy) { err += dy; x0 += sx; }
        if (e2 <= dx) { err += dx; y0 += sy; }
    }
}

typedef struct { float m[16]; } mat4;

mat4 mat4_identity(void) {
    mat4 r = { { 0 } };
    r.m[0] = r.m[5] = r.m[10] = r.m[15] = 1.0f;

mat4 mat4_mul(mat4 a, mat4 b) {
    mat4 r;
    for (int c = 0; c < 4; c++)
        for (int row = 0; row < 4; row++) {
            float s = 0;
            for (int k = 0; k < 4; k++) s += a.m[k * 4 + row] * b.m[c * 4 + k];
            r.m[c * 4 + row] = s;
        }
    return r;
}

}

mat4 mat4_rotate_axis(vec3 axis, float a) {
    vec3 n = v3_normalize(axis);
    float c = cosf(a), s = sinf(a), t = 1.0f - c;
    float x = n.x, y = n.y, z = n.z;
    mat4 r = mat4_identity();
    r.m[0] = t * x * x + c;     r.m[4] = t * x * y - s * z; r.m[8] = t * x * z + s * y;
    r.m[1] = t * x * y + s * z; r.m[5] = t * y * y + c;     r.m[9] = t * y * z - s * x;
    r.m[2] = t * x * z - s * y; r.m[6] = t * y * z + s * x; r.m[10] = t * z * z + c;
    return r;

mat4 mat4_look_at(vec3 eye, vec3 target, vec3 up) {
    vec3 f = v3_normalize(v3_sub(target, eye));
    vec3 s = v3_normalize(v3_cross(f, up));
    vec3 u = v3_cross(s, f);
    mat4 r = mat4_identity();
    r.m[0] = s.x;  r.m[4] = s.y;  r.m[8] = s.z;
    r.m[1] = u.x;  r.m[5] = u.y;  r.m[9] = u.z;
    r.m[2] = -f.x; r.m[6] = -f.y; r.m[10] = -f.z;
    r.m[12] = -v3_dot(s, eye);
    r.m[13] = -v3_dot(u, eye);
    r.m[14] = v3_dot(f, eye);
    return r;
}

mat4 mat4_perspective(float fovy, float aspect, float znear, float zfar) {
    float f = 1.0f / tanf(fovy * 0.5f);
    mat4 r = { { 0 } };
    r.m[0] = f / aspect;
    r.m[5] = f;
    r.m[10] = zfar / (znear - zfar);
    r.m[11] = -1.0f;
    r.m[14] = znear * zfar / (znear - zfar);
    return r;
}

vec4 to_screen(mat4 mvp, vec3 p, int w, int h) {
    vec4 c = mat4_mul_vec4(mvp, (vec4){ p.x, p.y, p.z, 1.0f });
    if (c.w <= 1e-6f) return (vec4){ 0, 0, -1, c.w };
    float iw = 1.0f / c.w;
    return (vec4){ (c.x * iw * 0.5f + 0.5f) * w, (0.5f - c.y * iw * 0.5f) * h, c.z * iw, c.w };
}

typedef struct { float x, y, z, w; } quat;

quat quat_from_axis_angle(vec3 axis, float angle) {
    vec3 n = v3_normalize(axis);
    float s = sinf(angle * 0.5f);
    return (quat){ n.x * s, n.y * s, n.z * s, cosf(angle * 0.5f) };
}

quat quat_mul(quat a, quat b) {
    return (quat){ a.w * b.x + a.x * b.w + a.y * b.z - a.z * b.y,
                   a.w * b.y - a.x * b.z + a.y * b.w + a.z * b.x,
                   a.w * b.z + a.x * b.y - a.y * b.x + a.z * b.w,
                   a.w * b.w - a.x * b.x - a.y * b.y - a.z * b.z };
}

vec3 quat_rotate(quat q, vec3 v) {
    vec3 u = v3(q.x, q.y, q.z);
    vec3 t = v3_scale(v3_cross(u, v), 2.0f);
    return v3_add(v3_add(v, v3_scale(t, q.w)), v3_cross(u, t));
}

mat4 quat_to_mat4(quat q) {
    float x = q.x, y = q.y, z = q.z, w = q.w;
    mat4 r = mat4_identity();
    r.m[0] = 1 - 2 * (y * y + z * z); r.m[4] = 2 * (x * y - w * z);     r.m[8] = 2 * (x * z + w * y);
    r.m[1] = 2 * (x * y + w * z);     r.m[5] = 1 - 2 * (x * x + z * z); r.m[9] = 2 * (y * z - w * x);
    r.m[2] = 2 * (x * z - w * y);     r.m[6] = 2 * (y * z + w * x);     r.m[10] = 1 - 2 * (x * x + y * y);
    return r;
}

quat quat_slerp(quat a, quat b, float t) {
    float d = a.x * b.x + a.y * b.y + a.z * b.z + a.w * b.w;
    if (d < 0) { b = (quat){ -b.x, -b.y, -b.z, -b.w }; d = -d; }
    float wa, wb;
    if (d > 0.9995f) {
        wa = 1 - t; wb = t;
    } else {
        float th = acosf(d), s = sinf(th);
        wa = sinf((1 - t) * th) / s; wb = sinf(t * th) / s;
    }
    quat r = { wa * a.x + wb * b.x, wa * a.y + wb * b.y, wa * a.z + wb * b.z, wa * a.w + wb * b.w };
    float len = sqrtf(r.x * r.x + r.y * r.y + r.z * r.z + r.w * r.w);
    return (quat){ r.x / len, r.y / len, r.z / len, r.w / len };
}

Mesh mesh_cube(float half) {
    static const int quads[6][4] = { { 0, 4, 6, 2 }, { 1, 3, 7, 5 }, { 0, 1, 5, 4 },
                                     { 2, 6, 7, 3 }, { 0, 2, 3, 1 }, { 4, 5, 7, 6 } };
    Mesh m = mesh_alloc(8, 12);
    if (!m.pos) return m;
    for (int i = 0; i < 8; i++) m.pos[i] = v3(i & 1 ? half : -half, i & 2 ? half : -half, i & 4 ? half : -half);
    int *t = m.idx;
    for (int f = 0; f < 6; f++) {
        const int *q = quads[f];
        *t++ = q[0]; *t++ = q[1]; *t++ = q[2];
        *t++ = q[0]; *t++ = q[2]; *t++ = q[3];
    }
    return m;
}

Mesh mesh_uv_sphere(int slices, int stacks, float r) {
    Mesh m = mesh_alloc((stacks + 1) * (slices + 1), 2 * slices * (stacks - 1));
    if (!m.pos) return m;
    const float PI = 3.14159265f;
    for (int i = 0; i <= stacks; i++) {
        float th = PI * i / stacks, st = sinf(th), ct = cosf(th);
        for (int j = 0; j <= slices; j++) {
            float ph = 2 * PI * j / slices;
            m.pos[i * (slices + 1) + j] = v3(r * st * cosf(ph), r * ct, -r * st * sinf(ph));
        }
    }
    int *t = m.idx;
    for (int i = 0; i < stacks; i++)
        for (int j = 0; j < slices; j++) {
            int a = i * (slices + 1) + j, b = a + slices + 1, c = b + 1, d = a + 1;
            if (i != stacks - 1) { *t++ = a; *t++ = b; *t++ = c; }
            if (i != 0) { *t++ = a; *t++ = c; *t++ = d; }
        }
    return m;
}

Mesh mesh_torus(float R, float r, int nu, int nv) {
    Mesh m = mesh_alloc(nu * nv, 2 * nu * nv);
    if (!m.pos) return m;
    const float TAU = 6.2831853f;
    for (int i = 0; i < nu; i++) {
        float u = TAU * i / nu, cu = cosf(u), su = sinf(u);
        for (int j = 0; j < nv; j++) {
            float v = TAU * j / nv, ring = R + r * cosf(v);
            m.pos[i * nv + j] = v3(ring * cu, r * sinf(v), -ring * su);
        }
    }
    int *t = m.idx;
    for (int i = 0; i < nu; i++) {
        int i1 = (i + 1) % nu;
        for (int j = 0; j < nv; j++) {
            int j1 = (j + 1) % nv;
            int a = i * nv + j, b = i1 * nv + j, c = i1 * nv + j1, d = i * nv + j1;
            *t++ = a; *t++ = b; *t++ = c;
            *t++ = a; *t++ = c; *t++ = d;
        }
    }
    return m;
}

static inline float edge_fn(vec4 a, vec4 b, float px, float py) {
    return (b.x - a.x) * (py - a.y) - (b.y - a.y) * (px - a.x);
}

static inline int top_left(vec4 u, vec4 v) {
    return (v.y - u.y < 0) || (v.y == u.y && v.x - u.x > 0);
}

void fill_triangle(Image *im, float *zbuf, vec4 a, vec4 b, vec4 c, Color col) {
    float area = edge_fn(a, b, c.x, c.y);
    if (area == 0.0f) return;
    if (area < 0) { vec4 t = b; b = c; c = t; area = -area; }
    int x0 = clampi((int)floorf(fminf(a.x, fminf(b.x, c.x))), 0, im->w);
    int x1 = clampi((int)ceilf(fmaxf(a.x, fmaxf(b.x, c.x))), -1, im->w - 1);
    int y0 = clampi((int)floorf(fminf(a.y, fminf(b.y, c.y))), 0, im->h);
    int y1 = clampi((int)ceilf(fmaxf(a.y, fmaxf(b.y, c.y))), -1, im->h - 1);
    int tl0 = top_left(b, c), tl1 = top_left(c, a), tl2 = top_left(a, b);
    float inv = 1.0f / area;
    for (int y = y0; y <= y1; y++) {
        float py = y + 0.5f;
        for (int x = x0; x <= x1; x++) {
            float px = x + 0.5f;
            float w0 = edge_fn(b, c, px, py), w1 = edge_fn(c, a, px, py), w2 = edge_fn(a, b, px, py);
            if (w0 < 0 || w1 < 0 || w2 < 0) continue;
            if ((w0 == 0 && !tl0) || (w1 == 0 && !tl1) || (w2 == 0 && !tl2)) continue;
            float z = (w0 * a.z + w1 * b.z + w2 * c.z) * inv;
            size_t i = (size_t)y * im->w + x;
            if (z < zbuf[i]) {
                zbuf[i] = z;
                im->px[i] = col;
            }
        }
    }
}

Put it all together: `void render_mesh(Image *im, float *zbuf, const Mesh *m, mat4 model, mat4 viewproj, vec3 light_dir, Color base, vec4 *screen)`.

1. `mvp = viewproj * model`, computed **once**. Project every vertex once into `screen` (as in the wireframe).
2. For each triangle `(i0, i1, i2)`: skip it unless all three vertices pass `screen_ok`.
3. **Back-face culling:** with `E` the edge function from the previous step, a triangle that winds counter-clockwise in world space (seen from outside) has `E(s0, s1, s2) < 0` on screen (the y axis flipped). Skip triangles with `E >= 0`.

5. `fill_triangle` with the three screen vertices.

    return v3(m[0] * d.x + m[4] * d.y + m[8] * d.z,
              m[1] * d.x + m[5] * d.y + m[9] * d.z,
              m[2] * d.x + m[6] * d.y + m[10] * d.z);
}

mat4 mat4_translate(vec3 t) {
    mat4 r = mat4_identity();
    r.m[12] = t.x; r.m[13] = t.y; r.m[14] = t.z;
    return r;
}

mat4 mat4_scale(vec3 s) {
    mat4 r = mat4_identity();
    r.m[0] = s.x; r.m[5] = s.y; r.m[10] = s.z;
    return r;
}

mat4 mat4_rotate_x(float a) {
    mat4 r = mat4_identity();
    float c = cosf(a), s = sinf(a);
    r.m[5] = c; r.m[6] = s; r.m[9] = -s; r.m[10] = c;
    return r;
}

mat4 mat4_rotate_y(float a) {
    mat4 r = mat4_identity();
    float c = cosf(a), s = sinf(a);
    r.m[0] = c; r.m[2] = -s; r.m[8] = s; r.m[10] = c;
    return r;
}

mat4 mat4_rotate_z(float a) {
    mat4 r = mat4_identity();
    float c = cosf(a), s = sinf(a);
    r.m[0] = c; r.m[1] = s; r.m[4] = -s; r.m[5] = c;
    return r;
}

mat4 mat4_rotate_axis(vec3 axis, float a) {
    vec3 n = v3_normalize(axis);
    float c = cosf(a), s = sinf(a), t = 1.0f - c;
    float x = n.x, y = n.y, z = n.z;
    mat4 r = mat4_identity();
    r.m[0] = t * x * x + c;     r.m[4] = t * x * y - s * z; r.m[8] = t * x * z + s * y;
    r.m[1] = t * x * y + s * z; r.m[5] = t * y * y + c;     r.m[9] = t * y * z - s * x;
    r.m[2] = t * x * z - s * y; r.m[6] = t * y * z + s * x; r.m[10] = t * z * z + c;
    return r;
}

mat4 mat4_look_at(vec3 eye, vec3 target, vec3 up) {
    vec3 f = v3_normalize(v3_sub(target, eye));
    vec3 s = v3_normalize(v3_cross(f, up));
    vec3 u = v3_cross(s, f);
    mat4 r = mat4_identity();
    r.m[0] = s.x;  r.m[4] = s.y;  r.m[8] = s.z;
    r.m[1] = u.x;  r.m[5] = u.y;  r.m[9] = u.z;
    r.m[2] = -f.x; r.m[6] = -f.y; r.m[10] = -f.z;
    r.m[12] = -v3_dot(s, eye);
    r.m[13] = -v3_dot(u, eye);
    r.m[14] = v3_dot(f, eye);
    return r;
}

mat4 mat4_perspective(float fovy, float aspect, float znear, float zfar) {
    float f = 1.0f / tanf(fovy * 0.5f);
    mat4 r = { { 0 } };
    r.m[0] = f / aspect;
    r.m[5] = f;
    r.m[10] = zfar / (znear - zfar);
    r.m[11] = -1.0f;
    r.m[14] = znear * zfar / (znear - zfar);
    return r;
}

vec4 to_screen(mat4 mvp, vec3 p, int w, int h) {
    vec4 c = mat4_mul_vec4(mvp, (vec4){ p.x, p.y, p.z, 1.0f });
    if (c.w <= 1e-6f) return (vec4){ 0, 0, -1, c.w };
    float iw = 1.0f / c.w;
    return (vec4){ (c.x * iw * 0.5f + 0.5f) * w, (0.5f - c.y * iw * 0.5f) * h, c.z * iw, c.w };
}

typedef struct { float x, y, z, w; } quat;

quat quat_from_axis_angle(vec3 axis, float angle) {
    vec3 n = v3_normalize(axis);
    float s = sinf(angle * 0.5f);
    return (quat){ n.x * s, n.y * s, n.z * s, cosf(angle * 0.5f) };
}

quat quat_mul(quat a, quat b) {
    return (quat){ a.w * b.x + a.x * b.w + a.y * b.z - a.z * b.y,
                   a.w * b.y - a.x * b.z + a.y * b.w + a.z * b.x,
                   a.w * b.z + a.x * b.y - a.y * b.x + a.z * b.w,
                   a.w * b.w - a.x * b.x - a.y * b.y - a.z * b.z };
}

vec3 quat_rotate(quat q, vec3 v) {
    vec3 u = v3(q.x, q.y, q.z);
    vec3 t = v3_scale(v3_cross(u, v), 2.0f);
    return v3_add(v3_add(v, v3_scale(t, q.w)), v3_cross(u, t));
}

mat4 quat_to_mat4(quat q) {
    float x = q.x, y = q.y, z = q.z, w = q.w;
    mat4 r = mat4_identity();
    r.m[0] = 1 - 2 * (y * y + z * z); r.m[4] = 2 * (x * y - w * z);     r.m[8] = 2 * (x * z + w * y);
    r.m[1] = 2 * (x * y + w * z);     r.m[5] = 1 - 2 * (x * x + z * z); r.m[9] = 2 * (y * z - w * x);
    r.m[2] = 2 * (x * z - w * y);     r.m[6] = 2 * (y * z + w * x);     r.m[10] = 1 - 2 * (x * x + y * y);
    return r;
}

quat quat_slerp(quat a, quat b, float t) {
    float d = a.x * b.x + a.y * b.y + a.z * b.z + a.w * b.w;
    if (d < 0) { b = (quat){ -b.x, -b.y, -b.z, -b.w }; d = -d; }
    float wa, wb;
    if (d > 0.9995f) {
        wa = 1 - t; wb = t;
    } else {
        float th = acosf(d), s = sinf(th);
        wa = sinf((1 - t) * th) / s; wb = sinf(t * th) / s;
    }
    quat r = { wa * a.x + wb * b.x, wa * a.y + wb * b.y, wa * a.z + wb * b.z, wa * a.w + wb * b.w };
    float len = sqrtf(r.x * r.x + r.y * r.y + r.z * r.z + r.w * r.w);
    return (quat){ r.x / len, r.y / len, r.z / len, r.w / len };
}

typedef struct { vec3 *pos; int npos; int *idx; int nidx; } Mesh;

static Mesh mesh_alloc(int npos, int ntri) {
    Mesh m = { malloc(sizeof(vec3) * (size_t)npos), npos, malloc(sizeof(int) * 3 * (size_t)ntri), 3 * ntri };
    if (!m.pos || !m.idx) {
        free(m.pos);
        free(m.idx);
        Mesh empty = { 0 };
        return empty;
    }
    return m;
}

void mesh_free(Mesh *m) {
    free(m->pos);
    free(m->idx);
    Mesh empty = { 0 };
    *m = empty;
}

Mesh mesh_cube(float half) {
    static const int quads[6][4] = { { 0, 4, 6, 2 }, { 1, 3, 7, 5 }, { 0, 1, 5, 4 },
                                     { 2, 6, 7, 3 }, { 0, 2, 3, 1 }, { 4, 5, 7, 6 } };
    Mesh m = mesh_alloc(8, 12);
    if (!m.pos) return m;
    for (int i = 0; i < 8; i++) m.pos[i] = v3(i & 1 ? half : -half, i & 2 ? half : -half, i & 4 ? half : -half);
    int *t = m.idx;
    for (int f = 0; f < 6; f++) {
        const int *q = quads[f];
        *t++ = q[0]; *t++ = q[1]; *t++ = q[2];
        *t++ = q[0]; *t++ = q[2]; *t++ = q[3];
    }
    return m;
}

Mesh mesh_uv_sphere(int slices, int stacks, float r) {
    Mesh m = mesh_alloc((stacks + 1) * (slices + 1), 2 * slices * (stacks - 1));
    if (!m.pos) return m;
    const float PI = 3.14159265f;
    for (int i = 0; i <= stacks; i++) {
        float th = PI * i / stacks, st = sinf(th), ct = cosf(th);
        for (int j = 0; j <= slices; j++) {
            float ph = 2 * PI * j / slices;
            m.pos[i * (slices + 1) + j] = v3(r * st * cosf(ph), r * ct, -r * st * sinf(ph));
        }
    }
    int *t = m.idx;
    for (int i = 0; i < stacks; i++)
        for (int j = 0; j < slices; j++) {
            int a = i * (slices + 1) + j, b = a + slices + 1, c = b + 1, d = a + 1;
            if (i != stacks - 1) { *t++ = a; *t++ = b; *t++ = c; }
            if (i != 0) { *t++ = a; *t++ = c; *t++ = d; }
        }
    return m;
}

Mesh mesh_torus(float R, float r, int nu, int nv) {
    Mesh m = mesh_alloc(nu * nv, 2 * nu * nv);
    if (!m.pos) return m;
    const float TAU = 6.2831853f;
    for (int i = 0; i < nu; i++) {
        float u = TAU * i / nu, cu = cosf(u), su = sinf(u);
        for (int j = 0; j < nv; j++) {
            float v = TAU * j / nv, ring = R + r * cosf(v);
            m.pos[i * nv + j] = v3(ring * cu, r * sinf(v), -ring * su);
        }
    }
    int *t = m.idx;
    for (int i = 0; i < nu; i++) {
        int i1 = (i + 1) % nu;
        for (int j = 0; j < nv; j++) {
            int j1 = (j + 1) % nv;
            int a = i * nv + j, b = i1 * nv + j, c = i1 * nv + j1, d = i * nv + j1;
            *t++ = a; *t++ = b; *t++ = c;
            *t++ = a; *t++ = c; *t++ = d;
        }
    }
    return m;
}

int screen_ok(vec4 s, int w, int h) {
    return s.w > 1e-6f && s.z >= 0.0f && s.x > -4.0f * w && s.x < 5.0f * w && s.y > -4.0f * h && s.y < 5.0f * h;
}

void draw_wireframe(Image *im, const Mesh *m, mat4 mvp, Color c, vec4 *screen) {
    for (int i = 0; i < m->npos; i++) screen[i] = to_screen(mvp, m->pos[i], im->w, im->h);
    for (int t = 0; t < m->nidx; t += 3) {
        vec4 a = screen[m->idx[t]], b = screen[m->idx[t + 1]], d = screen[m->idx[t + 2]];
        if (!screen_ok(a, im->w, im->h) || !screen_ok(b, im->w, im->h) || !screen_ok(d, im->w, im->h)) continue;
        int ax = (int)floorf(a.x), ay = (int)floorf(a.y), bx = (int)floorf(b.x), by = (int)floorf(b.y);
        int dx = (int)floorf(d.x), dy = (int)floorf(d.y);
        draw_line(im, ax, ay, bx, by, c);
        draw_line(im, bx, by, dx, dy, c);
        draw_line(im, dx, dy, ax, ay, c);
    }
}

static inline float edge_fn(vec4 a, vec4 b, float px, float py) {
    return (b.x - a.x) * (py - a.y) - (b.y - a.y) * (px - a.x);
}

static inline int top_left(vec4 u, vec4 v) {
    return (v.y - u.y < 0) || (v.y == u.y && v.x - u.x > 0);
}

void fill_triangle(Image *im, float *zbuf, vec4 a, vec4 b, vec4 c, Color col) {
    float area = edge_fn(a, b, c.x, c.y);
    if (area == 0.0f) return;
    if (area < 0) { vec4 t = b; b = c; c = t; area = -area; }
    int x0 = clampi((int)floorf(fminf(a.x, fminf(b.x, c.x))), 0, im->w);
    int x1 = clampi((int)ceilf(fmaxf(a.x, fmaxf(b.x, c.x))), -1, im->w - 1);
    int y0 = clampi((int)floorf(fminf(a.y, fminf(b.y, c.y))), 0, im->h);
    int y1 = clampi((int)ceilf(fmaxf(a.y, fmaxf(b.y, c.y))), -1, im->h - 1);
    int tl0 = top_left(b, c), tl1 = top_left(c, a), tl2 = top_left(a, b);
    float inv = 1.0f / area;
    for (int y = y0; y <= y1; y++) {
        float py = y + 0.5f;
        for (int x = x0; x <= x1; x++) {
            float px = x + 0.5f;
            float w0 = edge_fn(b, c, px, py), w1 = edge_fn(c, a, px, py), w2 = edge_fn(a, b, px, py);
            if (w0 < 0 || w1 < 0 || w2 < 0) continue;
            if ((w0 == 0 && !tl0) || (w1 == 0 && !tl1) || (w2 == 0 && !tl2)) continue;
            float z = (w0 * a.z + w1 * b.z + w2 * c.z) * inv;
            size_t i = (size_t)y * im->w + x;
            if (z < zbuf[i]) {
                zbuf[i] = z;
                im->px[i] = col;
            }
        }
    }
}

void render_mesh(Image *im, float *zbuf, const Mesh *m, mat4 model, mat4 viewproj, vec3 light_dir, Color base, vec4 *screen) {
    mat4 mvp = mat4_mul(viewproj, model);
    vec3 L = v3_normalize(light_dir);
    for (int i = 0; i < m->npos; i++) screen[i] = to_screen(mvp, m->pos[i], im->w, im->h);
    for (int t = 0; t < m->nidx; t += 3) {
        int i0 = m->idx[t], i1 = m->idx[t + 1], i2 = m->idx[t + 2];
        vec4 s0 = screen[i0], s1 = screen[i1], s2 = screen[i2];
        if (!screen_ok(s0, im->w, im->h) || !screen_ok(s1, im->w, im->h) || !screen_ok(s2, im->w, im->h)) continue;
        if (edge_fn(s0, s1, s2.x, s2.y) >= 0) continue;
        vec3 p0 = mat4_mul_point(model, m->pos[i0]), p1 = mat4_mul_point(model, m->pos[i1]), p2 = mat4_mul_point(model, m->pos[i2]);
        vec3 n = v3_normalize(v3_cross(v3_sub(p1, p0), v3_sub(p2, p0)));
        float k = 0.15f + 0.85f * fmaxf(0.0f, -v3_dot(n, L));
        fill_triangle(im, zbuf, s0, s1, s2, color_scale(base, k));
    }
}

The z-buffer fails on those pixels; clear it to `INFINITY` instead of 1.
--- explain
With `>= 0` both triangles claim the shared pixels; with `> 0` neither does. The top-left rule (D3D, Vulkan, WebGPU) breaks the tie consistently.

=== quiz
--- q
Why are quaternions preferred over Euler angles or lerped matrices for animating orientation?
--- choice
They are faster to apply to a vertex than a matrix.
--- answer
Slerp between two unit quaternions gives a constant-speed rotation along the shortest arc, with no gimbal lock, and a unit quaternion is cheap to renormalize.
--- choice
They can represent translation as well as rotation.
--- choice
GPUs only accept quaternions for rotation.
--- explain
Applying a quaternion to many vertices is actually slower than a matrix; engines convert to a matrix once per object. The win is composition and interpolation.

=== quiz
--- q
With the perspective matrix from this chapter (depth 0 at `near`, 1 at `far`), roughly where does a point halfway between `near = 0.1` and `far = 100` land in depth?
--- choice
Near 0.5: depth is linear in distance.
--- answer
Very close to 1 (about 0.999): depth is proportional to `1/distance`, so most of the 0..1 range is spent near the camera.
--- choice
Near 0.001.
--- choice
Exactly 1, because it is beyond the far plane.
--- explain
`depth = far (d - near) / (d (far - near))`; at `d = 50` that is about 0.999. That non-linearity is why a tiny `near` value wrecks depth precision for distant objects.
