## A pointer is an address

Memory is one huge array of bytes, and every byte has a numeric address. A pointer is a variable whose value is an address, plus a *type* that says what lives there. That's all. Everything else about pointers follows from it.

```c
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;         // p holds the address of x. Read "int *p" as "*p is an int".

    printf("%d\n", *p);  // 42: * follows the pointer (dereference)
    *p = 7;              // writes to x through p
    printf("%d\n", x);   // 7

    printf("%p\n", (void *)&x);   // the address, e.g. 0x7ffc8e3a1b4c
    printf("%p\n", (void *)p);    // the same address
    printf("%zu %zu\n", sizeof p, sizeof *p);   // 8 4: an address, and an int
    return 0;
}
```

- `&x` (address-of) gives a pointer to `x`. You can take the address of any variable, array element or struct member, but not of a literal or a temporary like `a + b`.
- `*p` (dereference) *is* the object `p` points to. You can read it and assign to it.
- `%p` prints a pointer. It formally requires a `void *`, hence the cast.

The `*` in a declaration binds to the name, not the type, which leads to a classic trap:

```c
int *a, b;     // a is int *, b is a plain int
int *c, *d;    // two pointers
```

## Out-parameters: C's ref and out

The functions chapter said every argument is copied. A pointer argument is copied too, but the copy holds the same address, so the function can reach the caller's variable through it. This is how C does C#'s `ref` and `out`, and why `scanf` needs `&`:

```c
#include <stdio.h>

void swap(int *a, int *b) {        // C#: void Swap(ref int a, ref int b)
    int t = *a;
    *a = *b;
    *b = t;
}

// Returns 0 on failure; on success writes two results through the pointers.
int divide(int num, int den, int *quot, int *rem) {   // C#: out int quot, out int rem
    if (den == 0) return 0;
    *quot = num / den;
    *rem = num % den;
    return 1;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);
    printf("%d %d\n", x, y);          // 2 1

    int q, r;
    if (divide(17, 5, &q, &r))
        printf("%d r %d\n", q, r);    // 3 r 2
    if (!divide(1, 0, &q, &r))
        puts("division by zero");
    return 0;
}
```

The pattern "return a status, deliver the results through pointers" is everywhere in C APIs, because there are no exceptions and only one return value. Unlike C#, nothing at the call site marks the argument as `ref`; the `&` is the only clue that the callee may change the variable.

## NULL

`NULL` is a null pointer constant, a pointer that points at nothing. A null pointer is false in a condition, so `if (p)` means "if p is not null". Dereferencing `NULL` is undefined behavior; on Linux it usually crashes with a segmentation fault, but there is no `NullReferenceException` to catch.

An *uninitialized* pointer is worse than a null one: it holds a garbage address, and writing through it can silently corrupt anything. Initialize pointers when you declare them, to `NULL` if there is nothing better.

A common idiom is the *optional out-parameter*: the caller passes `NULL` for results it does not want.

```c
#include <stdio.h>

void stats(const int *v, int n, int *sum, int *count_negative) {
    int s = 0, neg = 0;
    for (int i = 0; i < n; i++) {
        s += v[i];
        if (v[i] < 0) neg++;
    }
    if (sum) *sum = s;                        // only if the caller asked
    if (count_negative) *count_negative = neg;
}

int main(void) {
    int data[] = {3, -1, 4, -1, 5};
    int total;
    stats(data, 5, &total, NULL);
    printf("%d\n", total);   // 10
    return 0;
}
```

## Pointer types

An `int *` and a `double *` may hold the same kind of address, but the type decides how many bytes `*p` reads and how they are interpreted. Assigning one to the other is a constraint violation (gcc: "incompatible pointer types"), and accessing an object through the wrong pointer type is undefined behavior (the *strict aliasing* rule, covered later). The exceptions are `void *` (below) and `char *` / `unsigned char *`, which may look at the bytes of any object:

```c
#include <stdio.h>

int main(void) {
    unsigned int value = 0x11223344;
    unsigned char *bytes = (unsigned char *)&value;   // explicit cast needed
    for (size_t i = 0; i < sizeof value; i++)
        printf("%02x ", bytes[i]);   // 44 33 22 11 on x86: little-endian
    printf("\n");
    return 0;
}
```

## Pointer arithmetic

Adding an integer to a pointer moves it by that many *elements*, not bytes: `p + 1` on an `int *` adds `sizeof(int)`, 4, to the address. Subtracting two pointers into the same array gives the number of elements between them, as a `ptrdiff_t` (print with `%td`). And `p[i]` is defined as `*(p + i)`: indexing *is* pointer arithmetic.

```c
#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;                  // an array name converts to a pointer to its first element
    printf("%d %d %d\n", *p, *(p + 2), p[4]);    // 10 30 50

    int *q = &a[3];
    printf("%td\n", q - p);                      // 3 elements apart
    printf("%td\n", (char *)q - (char *)p);      // 12 bytes apart

    for (int *it = a; it < a + 5; it++)          // iterate with a pointer
        printf("%d ", *it);
    printf("\n");

    int *end = a + 5;            // one past the end: fine to compute and compare...
    // printf("%d", *end);       // ...but not to dereference
    while (end > a) printf("%d ", *--end);       // backwards
    printf("\n");
    return 0;
}
```

The rules: arithmetic is only valid within one array, and you may form (but not dereference) the address one past its last element. Anything else, like `a - 1` or `a + 6`, is undefined even if you never dereference it. Comparing pointers with `<` is only meaningful within the same array; `==` and `!=` work for any two pointers.

`*p++` is the most famous C idiom. Postfix `++` binds tighter than `*`, so it means `*(p++)`: read the element, then advance the pointer. `(*p)++` increments the element instead.

```c
#include <stdio.h>

int main(void) {
    const char *s = "hello";
    int len = 0;
    while (*s++) len++;     // walk to the terminating 0 byte
    printf("%d\n", len);    // 5

    int counts[3] = {0, 0, 0};
    int *c = counts;
    (*c)++;                 // counts[0] becomes 1, c does not move
    *c++ = 5;               // counts[0] = 5, then c points at counts[1]
    *c = 9;
    printf("%d %d %d\n", counts[0], counts[1], counts[2]);   // 5 9 0
    return 0;
}
```

## const and pointers: four combinations

A pointer involves two objects: the pointer itself and the thing it points at. `const` can apply to either. Read the declaration **right to left** from the name:

| Declaration | Read as | Change `*p`? | Change `p`? |
|---|---|---|---|
| `int *p` | p is a pointer to int | yes | yes |
| `const int *p` | p is a pointer to an int that is const | no | yes |
| `int *const p` | p is a const pointer to int | yes | no |
| `const int *const p` | p is a const pointer to a const int | no | no |

`int const *p` means the same as `const int *p`: what matters is whether `const` is left or right of the `*`.

```c
#include <stdio.h>

int main(void) {
    int x = 1, y = 2;

    const int *read_only = &x;    // a "view" of x
    // *read_only = 5;            // error: assignment of read-only location
    read_only = &y;               // fine: the pointer itself can move

    int *const fixed = &x;
    *fixed = 5;                   // fine: x is not const
    // fixed = &y;                // error: assignment of read-only variable

    const int *const both = &y;
    printf("%d %d %d\n", *read_only, *fixed, *both);   // 2 5 2
    return 0;
}
```

`const int *` is by far the most important form. In a parameter it is a promise: "this function reads your data but does not modify it". That is why `strlen` takes `const char *` and `memcpy` takes a `const void *` source. Converting `int *` to `const int *` is automatic; the reverse needs a cast, and writing to an object that was *defined* `const` through such a cast is undefined behavior. Use `const` on every pointer parameter you don't write through; it documents the contract and the compiler enforces it.

## Pointers to pointers

A pointer is a variable too, so it has an address. An `int **` points at an `int *`. You need one whenever a function must change the caller's *pointer* (rather than what it points at): the same out-parameter logic, one level up.

```c
#include <stdio.h>

// Advance *cursor past leading spaces. The caller's pointer moves.
void skip_spaces(const char **cursor) {
    while (**cursor == ' ')
        (*cursor)++;
}

int main(void) {
    const char *text = "   indented";
    skip_spaces(&text);
    printf("[%s]\n", text);      // [indented]

    int value = 3;
    int *p = &value;
    int **pp = &p;
    **pp = 4;                    // value = 4
    printf("%d %d %d\n", value, *p, **pp);   // 4 4 4
    return 0;
}
```

`main(int argc, char **argv)` uses one: `argv` points at an array of `char *`, one per command-line argument. Linked-list code uses `node **` to insert or delete without special-casing the head, which you will see in the data structures chapter.

## void *: the generic pointer

`void *` is "a pointer to something, type unknown". Any object pointer converts to `void *` and back implicitly, without a cast (unlike C++). You cannot dereference a `void *` or do arithmetic on it; you must convert it back to a real type first. It is C's substitute for generics and `object`: `malloc` returns one, `memcpy` and `qsort` take them.

```c
#include <stdio.h>
#include <string.h>

// Swap any two objects of the same size, byte by byte.
void swap_any(void *a, void *b, size_t size) {
    unsigned char *x = a, *y = b;     // implicit conversion from void *
    for (size_t i = 0; i < size; i++) {
        unsigned char t = x[i];
        x[i] = y[i];
        y[i] = t;
    }
}

int main(void) {
    double d1 = 1.5, d2 = 2.5;
    swap_any(&d1, &d2, sizeof d1);
    printf("%.1f %.1f\n", d1, d2);   // 2.5 1.5

    char s1[8] = "left", s2[8] = "right";
    swap_any(s1, s2, sizeof s1);
    printf("%s %s\n", s1, s2);       // right left
    return 0;
}
```

The price is type safety: nothing stops you calling `swap_any(&d1, &x, 8)` with a 4-byte `int x`. All the type checking a C# generic would do is now your job.

## Dangling pointers

A local variable dies when its function returns (or its block ends). A pointer to it then *dangles*: it holds the address of memory that will be reused by the next function call. Using it is undefined behavior.

```c
int *make_counter(void) {
    int count = 0;
    return &count;        // gcc: "function returns address of local variable"
}
```

gcc warns, and even replaces the returned address with `NULL` so that the bug crashes early instead of corrupting something. The subtler version, storing the address in a struct or a global, gets no warning; AddressSanitizer reports it at runtime as *stack-use-after-return* or *stack-use-after-scope*. The fixes:

- return the value itself instead of its address (structs can be returned by value);
- let the caller own the storage and pass a pointer to it (the out-parameter pattern);
- use a `static` variable (one shared instance, not reentrant);
- allocate with `malloc` and make the caller `free` it (memory chapter).

## Compared with C# references

| | C# reference | C pointer |
|---|---|---|
| Points to | a managed object | any byte of memory |
| Arithmetic | no | yes |
| Null access | `NullReferenceException` | undefined behavior, usually a crash |
| Lifetime | GC keeps the target alive | nothing does; dangling is possible |
| To a local variable | only `ref`, which can't outlive it | yes, and it can outlive it |
| Reassigning the target object | the GC may move it, transparently | never moves |
| Type check | at runtime on every cast | none after a cast |

C#'s `unsafe` code with `int*` and `fixed` *is* C pointers, borrowed wholesale. A JavaScript object variable is closest to a C# reference. In C, the address is just a number, and every guarantee you had is now a rule you have to keep.

=== exercise divmod
title: Floored division
--- prompt
C's `/` truncates toward zero and `%` takes the sign of the dividend. Python's `//` and `%` instead *floor*: the quotient rounds toward negative infinity and the remainder takes the sign of the divisor. Write the Python version:

`int floor_divmod(int a, int b, int *q, int *r)`

On success store the floored quotient in `*q` and the remainder in `*r`, so that `a == *q * b + *r`, and return 1. If the division is impossible (`b == 0`) or overflows (`a == INT_MIN` and `b == -1`), return 0 and **do not touch** `*q` or `*r`.

| a, b | C `/`, `%` | floored q, r |
|---|---|---|
| 7, 2 | 3, 1 | 3, 1 |
| -7, 2 | -3, -1 | -4, 1 |
| 7, -2 | -3, 1 | -4, -1 |
| -7, -2 | 3, -1 | 3, -1 |
--- starter
int floor_divmod(int a, int b, int *q, int *r) {
    return 0;
}
--- solution
#include <limits.h>

int floor_divmod(int a, int b, int *q, int *r) {
    if (b == 0 || (a == INT_MIN && b == -1)) return 0;
    int quot = a / b, rem = a % b;
    if (rem != 0 && ((rem < 0) != (b < 0))) {
        quot--;
        rem += b;
    }
    *q = quot;
    *r = rem;
    return 1;
}
--- harness

static int fdm(int a, int b) { q_ = 111; r_ = 222; return floor_divmod(a, b, &q_, &r_); }

    CHECK_INT(fdm(7, -2), 1);  CHECK_INT(q_, -4); CHECK_INT(r_, -1);

title: Optional out-parameters

Write `void min_max(const int *v, int n, int *min, int *max)` that stores the smallest and largest of the `n` values starting at `v` (`n` is at least 1).

--- starter

void min_max(const int *v, int n, int *min, int *max) {
    int lo = v[0], hi = v[0];
    for (const int *p = v + 1; p < v + n; p++) {
        if (*p < lo) lo = *p;
        if (*p > hi) hi = *p;
    }
    if (min) *min = lo;
    if (max) *max = hi;
}

Then write `int count_in_range(const int *begin, const int *end, int lo, int hi)` returning how many elements `x` satisfy `lo <= x && x <= hi`.
--- starter
long long sum_range(const int *begin, const int *end) {
    return 0;
}

int count_in_range(const int *begin, const int *end, int lo, int hi) {
    return 0;
}
--- solution
long long sum_range(const int *begin, const int *end) {
    long long total = 0;
    for (const int *p = begin; p != end; p++)
        total += *p;
    return total;
}

int count_in_range(const int *begin, const int *end, int lo, int hi) {
    int count = 0;
    while (begin != end) {
        int x = *begin++;
        if (lo <= x && x <= hi) count++;
    }
    return count;
}

}

--- solution
#include <stddef.h>

int *find_int(int *v, int n, int value) {
    for (int *p = v; p < v + n; p++)
        if (*p == value) return p;
    return NULL;
}

int *find_last(int *v, int n, int value) {
    for (int *p = v + n; p > v; ) {
        p--;
        if (*p == value) return p;
    }
    return NULL;
}

Loop a pointer from `v` while `p < v + n`, and `return p;` on a match.
--- hint
Going backwards, don't compute `v - 1` (pointing before an array is undefined). Start at `v + n` and decrement *before* each dereference, stopping when the pointer reaches `v`.

=== exercise sort3
title: Sort three in place
--- prompt
Write `void sort3(int *a, int *b, int *c)` that rearranges the three values so that `*a <= *b <= *c`.

Write a small `static` helper that swaps two values through pointers if they are out of order, and call it three times.
--- starter
void sort3(int *a, int *b, int *c) {
}
--- solution
static void order(int *x, int *y) {
    if (*x > *y) {
        int t = *x;
        *x = *y;
        *y = t;
    }
}

void sort3(int *a, int *b, int *c) {
    order(a, b);
    order(b, c);
    order(a, b);
}
--- harness
#include <limits.h>
static int ok3(int x, int y, int z, int e1, int e2, int e3) {
    sort3(&x, &y, &z);
    return x == e1 && y == e2 && z == e3;
}
int main(void) {
    CHECK(ok3(1, 2, 3, 1, 2, 3));
    CHECK(ok3(1, 3, 2, 1, 2, 3));
    CHECK(ok3(2, 1, 3, 1, 2, 3));
    CHECK(ok3(2, 3, 1, 1, 2, 3));
    CHECK(ok3(3, 1, 2, 1, 2, 3));
    CHECK(ok3(3, 2, 1, 1, 2, 3));
    CHECK(ok3(5, 5, 5, 5, 5, 5));
    CHECK(ok3(2, 1, 1, 1, 1, 2));
    CHECK(ok3(1, 2, 1, 1, 1, 2));
    CHECK(ok3(0, -1, -2, -2, -1, 0));
    CHECK(ok3(INT_MAX, INT_MIN, 0, INT_MIN, 0, INT_MAX));
    return TEST_END();
}
--- hint
Three compare-and-swaps in the order (a, b), (b, c), (a, b) form a sorting network: after the first two the largest is in `c`, and the last one fixes `a` and `b`.

=== exercise takeint
title: A parsing cursor
--- prompt
A parser often keeps a *cursor*, a `const char *` to the next unread character, and helper functions advance it. Since they must change the caller's pointer, they take a pointer to it: a `const char **`.

Write `int take_int(const char **s, int *out)`:

1. Skip any spaces (`' '`) at `*s`.
2. Accept an optional `+` or `-`, then one or more digits `0`-`9`.
3. On success: store the value in `*out`, advance `*s` to the first character after the last digit, and return 1.
4. On failure (no digits, or a value outside `int`'s range): return 0 and leave **both** `*s` and `*out` unchanged.

`"-2147483648"` is valid; `"2147483648"` is not. For example, after `take_int(&s, &v)` with `s = "  -42abc"`, `v` is -42 and `s` points at `"abc"`. Don't use library parsing functions.
--- starter
int take_int(const char **s, int *out) {
    return 0;
}
--- solution
int take_int(const char **s, int *out) {
    const char *p = *s;
    while (*p == ' ') p++;
    int negative = 0;
    if (*p == '+' || *p == '-') {
        negative = (*p == '-');
        p++;
    }
    if (*p < '0' || *p > '9') return 0;
    long long value = 0;
    while (*p >= '0' && *p <= '9') {
        value = value * 10 + (*p - '0');
        if (value > 2147483648LL) return 0;   // too big even for a negative int
        p++;
    }
    if (negative) value = -value;
    if (value > 2147483647LL) return 0;
    *out = (int)value;
    *s = p;
    return 1;
}
--- harness
#include <limits.h>
int main(void) {
    const char *s = "  42 rest";
    int v = 0;
    CHECK_INT(take_int(&s, &v), 1);
    CHECK_INT(v, 42);
    CHECK_STR(s, " rest");

    s = "  -42abc";
    CHECK_INT(take_int(&s, &v), 1);
    CHECK_INT(v, -42);
    CHECK_STR(s, "abc");

    const char *list = "10 -20 +30";
    int sum = 0, n = 0;
    while (take_int(&list, &v)) { sum += v; n++; }
    CHECK_INT(n, 3);
    CHECK_INT(sum, 20);
    CHECK_STR(list, "");

    s = "007x";
    CHECK_INT(take_int(&s, &v), 1);
    CHECK_INT(v, 7);
    CHECK_STR(s, "x");

    s = "0";
    CHECK_INT(take_int(&s, &v), 1);
    CHECK_INT(v, 0);
    CHECK_STR(s, "");

    s = "2147483647";
    CHECK_INT(take_int(&s, &v), 1);
    CHECK_INT(v, INT_MAX);
    s = "-2147483648!";
    CHECK_INT(take_int(&s, &v), 1);
    CHECK_INT(v, INT_MIN);
    CHECK_STR(s, "!");

    const char *bad[] = {"", "   ", "abc", "  -", "+", "+-3", "- 3", "2147483648",
                         "-2147483649", "99999999999999999999999", "  x12"};
    for (int i = 0; i < (int)(sizeof bad / sizeof bad[0]); i++) {
        const char *start = bad[i];
        const char *cur = start;
        v = 1234;
        CHECK_INT(take_int(&cur, &v), 0);
        CHECK(cur == start);
        CHECK_INT(v, 1234);
    }
    return TEST_END();
}
--- hint
Work on a local copy `const char *p = *s;` and only write back `*s = p;` once you know the parse succeeded. That makes "leave it unchanged on failure" automatic.
--- hint
Accumulate in a `long long` and bail out as soon as the magnitude exceeds 2147483648, so even a very long digit string can't overflow the accumulator.
--- hint
The magnitude 2147483648 is fine only with a minus sign. Apply the sign, then check the upper bound.

=== exercise reverse
title: Print it backwards
--- prompt
Read up to 1000 integers from stdin (until end of input) into an array, then print them in reverse order on one line, separated by single spaces. With no input, print an empty line.

Do the reverse printing with a **pointer** that starts one past the last element and walks down to the first, rather than with an index.
--- starter

int main(void) {
    int values[1000];

        n++;
    // print backwards using a pointer

--- solution
#include <stdio.h>

int main(void) {
    int values[1000];
    int n = 0;
    while (n < 1000 && scanf("%d", &values[n]) == 1)
        n++;
    for (int *p = values + n; p > values; ) {
        p--;
        printf("%d", *p);
        if (p > values) putchar(' ');
    }
    printf("\n");
    return 0;
}
