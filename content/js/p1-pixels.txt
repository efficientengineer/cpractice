## Why start on the CPU

Every procedural texture is, in the end, a function from a pixel position to a color, evaluated a few hundred thousand times. Before you push that work onto the GPU (the WebGPU track does), you want the math and the data layout right on the CPU, where you can test each function at sample points, step through it in a debugger and measure it. This chapter builds the small image toolkit the next two chapters (noise and procedural textures) render with: pixel packing, color spaces, palettes, shapes, blending, filters and dithering. The project at the end of the chapter animates a glowing neon scene at full resolution, entirely on the CPU, without allocating a single object per frame.

Everything here runs on `canvas`, a 512×512 `OffscreenCanvas` (code that mentions `canvas` gets one; tests use a smaller one, so always read `canvas.width`).

## ImageData: bytes in a row

`ImageData` is a width, a height and a `Uint8ClampedArray` called `data`: 4 bytes per pixel, R, G, B, A, rows top to bottom, no padding. Pixel `(x, y)` starts at byte `(y * width + x) * 4`. You fill it, then hand it to the canvas with **one** `putImageData` call.

```js
const w = canvas.width, h = canvas.height;
const image = new ImageData(w, h);           // all zeros: transparent black
const d = image.data;                        // Uint8ClampedArray, length w * h * 4
for (let y = 0; y < h; y++) {
  for (let x = 0; x < w; x++) {
    const i = (y * w + x) * 4;
    d[i] = x * 255 / w;                      // red ramps left to right (clamped and rounded on write)
    d[i + 1] = y * 255 / h;                  // green ramps top to bottom
    d[i + 2] = 128;
    d[i + 3] = 255;                          // alpha: forget it and you see nothing
  }
}
canvas.getContext('2d').putImageData(image, 0, 0);
console.log(d.length, d.constructor.name, d[0], d[3]);
```

`Uint8ClampedArray` rounds and clamps on write (`300` becomes 255, `-4` becomes 0, `127.5` rounds to even, 128), so you can write float math straight into it. A plain `Uint8Array` would wrap 300 to 44.

> **Performance:** the three rules for CPU pixel work: allocate the `ImageData` (and every other buffer) once, outside the frame loop; never call `getImageData` inside a loop (it copies the whole canvas back from the compositor, sometimes from the GPU); and call `putImageData` exactly once per frame. Do not create a `{ r, g, b }` object or a `[r, g, b]` array per pixel: at 512×512 that is 262,144 allocations per frame and the garbage collector will show up as stutter.

## One write per pixel: a Uint32Array view

Typed arrays can share a buffer. A `Uint32Array` over `image.data.buffer` sees each pixel as one 32-bit integer, so filling or copying a pixel is one store instead of four:

```js
const w = canvas.width, h = canvas.height;
const image = new ImageData(w, h);
const px = new Uint32Array(image.data.buffer);       // length w * h, same memory

const little = new Uint8Array(new Uint32Array([0x11223344]).buffer)[0] === 0x44;
console.log('little-endian:', little);

// On a little-endian CPU byte 0 (R) is the *lowest* byte of the integer, so the integer is 0xAABBGGRR.
const pack = (r, g, b, a = 255) => ((a << 24) | (b << 16) | (g << 8) | r) >>> 0;
const orange = pack(255, 140, 0);
console.log(orange.toString(16));                    // ff008cff: A=ff, B=00, G=8c, R=ff
px.fill(pack(20, 20, 30));
for (let y = 100; y < 200; y++) px.fill(orange, y * w + 50, y * w + 300);   // a row at a time
canvas.getContext('2d').putImageData(image, 0, 0);
console.log(Array.from(image.data.subarray((150 * w + 60) * 4, (150 * w + 60) * 4 + 4)));
```

Every machine you will run this on (x86, ARM phones, Apple silicon) is little-endian, so this "ABGR" integer layout is safe in practice; check once at startup if you are paranoid, as above. `TypedArray.fill(value, start, end)` and `set(source, offset)` run as native memory fills and copies: use them for spans instead of JavaScript loops.

The `>>> 0` matters: `(255 << 24)` is negative in JavaScript's signed 32-bit bitwise math. Storing a negative number into a `Uint32Array` wraps correctly anyway, but comparing packed colors with `===` only works if you always produce the same (unsigned) representation.

## Float buffers and linear light

Bytes are a storage format, not a working format. Image math (blending, blurring, lighting, adding glow) wants **floats in linear light**: values proportional to the number of photons. The bytes in an image are not linear: they are **sRGB encoded**, a curve close to a 2.2 power that spends more of the 256 codes on dark tones, where the eye is sensitive. Code 128 is not half the light of 255; it is about 22%.

The standard sRGB transfer functions (IEC 61966-2-1):

```text
linear = c <= 0.04045   ? c / 12.92  : ((c + 0.055) / 1.055) ^ 2.4       (decode, sRGB -> linear)
srgb   = l <= 0.0031308 ? l * 12.92  : 1.055 * l ^ (1 / 2.4) - 0.055      (encode, linear -> sRGB)
```

So the pipeline is: work in a `Float32Array` of linear RGB (3 floats per pixel, `w * h * 3`), and convert to sRGB bytes once, at the end, for display. Averaging two pixels in sRGB bytes (what naive code does) makes blurs and anti-aliased edges too dark, and makes a red/green blend muddy brown:

```js
const toLin = c => c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
const toSrgb = l => l <= 0.0031308 ? l * 12.92 : 1.055 * Math.pow(l, 1 / 2.4) - 0.055;
// The average of a black and a white pixel:
console.log('sRGB-space average:', 128, ' linear-light average:', Math.round(255 * toSrgb((toLin(0) + toLin(1)) / 2)));
// Mixing pure red and pure green 50/50:
const g = Math.round(255 * toSrgb(0.5));
console.log('naive', [128, 128, 0], ' linear', [g, g, 0]);
```

The linear average of black and white displays as 188, not 128. A 1-pixel checkerboard of black and white, seen from across the room, looks like 188 gray: that is physics, and linear math reproduces it.

> **Performance:** `Math.pow` per channel per pixel (786,432 calls for a 512×512 frame) is the slow part of encoding. Precompute a **lookup table** once: 4096 entries mapping linear values to sRGB bytes is accurate to within one code everywhere. Decoding bytes to linear is a 256-entry `Float32Array`. Tables like these are the CPU version of what the GPU does for free with an `rgba8unorm-srgb` texture format.

## Color spaces: HSV, HSL, OKLab

RGB is how displays work, not how people pick colors. **HSV** (hue, saturation, value) and **HSL** (hue, saturation, lightness) are cylindrical remappings of the RGB cube (Alvy Ray Smith, 1978): hue is an angle around the gray axis, which makes "rotate the hue" and "random saturated color" one-liners. The standard conversion splits the hue circle into six sectors; within a sector one channel is at `v`, one at `v(1 - s)`, and one ramps between them.

HSV is not *perceptual*: pure yellow and pure blue have the same `v = 1` but yellow looks far brighter, so a gradient that interpolates RGB or HSV values has bright and dark bands and muddy midpoints. **OKLab** (Björn Ottosson, 2020) is a modern perceptual space: `L` is perceived lightness, `a` is green to red, `b` is blue to yellow, and equal steps look roughly equal. It is built from linear sRGB with a 3×3 matrix (to an LMS cone response), a cube root (the eye's compressive response), and another 3×3 matrix. Interpolate there and convert back, and gradients stay even:

```js
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}
const lab = new Float64Array(3);
console.log('white ', Array.from(linearToOklab(1, 1, 1, lab), v => +v.toFixed(4)));
console.log('yellow', Array.from(linearToOklab(1, 1, 0, lab), v => +v.toFixed(4)));
console.log('blue  ', Array.from(linearToOklab(0, 0, 1, lab), v => +v.toFixed(4)));
```

Yellow has `L` near 0.97 and blue near 0.45: the lightness difference RGB hides. The inverse is the same three steps backwards (matrix, cube, matrix); you will write it in the exercises. Note the `out` parameter: converting a color returns into a caller-owned array instead of allocating a new one, which matters as soon as you convert per pixel.

## Palettes: lookup tables and cosine palettes

A palette maps a scalar `t` in [0, 1] (a noise value, a height, a distance) to a color. Two classic forms:

- **Gradient stops**: a list of `(t, color)` pairs, interpolated (ideally in OKLab).
- **Cosine palettes** (Inigo Quilez, "palettes" article): `color(t) = a + b · cos(2π(c·t + d))` per channel, with four RGB vectors. Twelve numbers give smooth, endlessly tweakable rainbows, fire, ice and sunsets, and the formula is cheap enough to evaluate in a shader.

Either way, for the CPU you **bake** the palette into a lookup table: 256 packed `Uint32` colors, computed once, and color a pixel with `px[i] = lut[(t * 255) | 0]`.

```js
const w = canvas.width, h = canvas.height, image = new ImageData(w, h), px = new Uint32Array(image.data.buffer);
const pal = (t, a, b, c, d, k) => a[k] + b[k] * Math.cos(6.283185307 * (c[k] * t + d[k]));
const presets = [
  [[0.5, 0.5, 0.5], [0.5, 0.5, 0.5], [1, 1, 1], [0, 0.33, 0.67]],
  [[0.5, 0.5, 0.5], [0.5, 0.5, 0.5], [1, 0.7, 0.4], [0, 0.15, 0.2]],
  [[0.8, 0.5, 0.4], [0.2, 0.4, 0.2], [2, 1, 1], [0, 0.25, 0.25]],
];
const luts = presets.map(([a, b, c, d]) => {
  const lut = new Uint32Array(256);
  for (let i = 0; i < 256; i++) {
    const ch = k => Math.max(0, Math.min(255, Math.round(255 * pal(i / 255, a, b, c, d, k))));
    lut[i] = (255 << 24 | ch(2) << 16 | ch(1) << 8 | ch(0)) >>> 0;
  }
  return lut;
});
for (let y = 0; y < h; y++) {
  const lut = luts[Math.floor(y * 3 / h)];
  for (let x = 0; x < w; x++) {
    const t = 0.5 + 0.5 * Math.sin(x * 0.02 + Math.sin(y * 0.03) * 2);   // any scalar field
    px[y * w + x] = lut[(t * 255) | 0];
  }
}
canvas.getContext('2d').putImageData(image, 0, 0);
```

## Shapes as functions: signed distance and anti-aliasing

Procedural images do not draw shapes by walking their outline; they ask, at every pixel, "how far am I from the shape?" A **signed distance function** (SDF) returns that distance, negative inside. Inigo Quilez's "2D distance functions" article is the reference catalog; three you will use constantly:

```text
circle:   length(p - c) - r
box:      q = abs(p - c) - halfSize;  length(max(q, 0)) + min(max(q.x, q.y), 0)
segment:  h = clamp(dot(p - a, b - a) / dot(b - a, b - a), 0, 1);  length(p - a - (b - a) * h)
          (subtract a radius from the segment distance and you have a capsule: a thick line)
```

With the distance in pixels, **anti-aliasing is one line**: a pixel whose center is exactly on the edge is about half covered, one a pixel inside is fully covered, so coverage is `1 - smoothstep(-0.5, 0.5, d)`. Sample at pixel *centers* (`x + 0.5, y + 0.5`). The result is a soft, correct edge with no supersampling. SDFs also combine: `min(d1, d2)` is a union, `max(d1, -d2)` a subtraction, `abs(d) - t` an outline of thickness `2t`.

```js
const w = canvas.width, h = canvas.height, image = new ImageData(w, h), px = new Uint32Array(image.data.buffer);
const smoothstep = (a, b, x) => { const t = Math.min(1, Math.max(0, (x - a) / (b - a))); return t * t * (3 - 2 * t); };
const sdCircle = (px, py, cx, cy, r) => Math.sqrt((px - cx) ** 2 + (py - cy) ** 2) - r;
const sdBox = (px, py, cx, cy, hx, hy) => {
  const qx = Math.abs(px - cx) - hx, qy = Math.abs(py - cy) - hy;
  return Math.hypot(Math.max(qx, 0), Math.max(qy, 0)) + Math.min(Math.max(qx, qy), 0);
};
for (let y = 0; y < h; y++) {
  for (let x = 0; x < w; x++) {
    const X = x + 0.5, Y = y + 0.5;
    const ring = Math.abs(sdCircle(X, Y, w * 0.35, h * 0.5, w * 0.2)) - 6;    // outline of a circle
    const box = sdBox(X, Y, w * 0.68, h * 0.5, w * 0.16, h * 0.1) - 12;       // rounded box: subtract a radius
    const d = Math.min(ring, Math.max(box, -sdCircle(X, Y, w * 0.68, h * 0.5, 20)));  // union, with a hole
    const a = 1 - smoothstep(-0.5, 0.5, d);
    const v = Math.round(255 * a);
    px[y * w + x] = (255 << 24 | 40 << 16 | v << 8 | v) >>> 0;
  }
}
canvas.getContext('2d').putImageData(image, 0, 0);
```

> **Performance:** the full-screen loop above is right for a background or a texture, where every pixel needs the function anyway. For *drawing many small shapes* it is the classic mistake: 3,000 circles over a 1024×1024 image is three billion distance evaluations. A shape only affects pixels within its **bounding box** (plus a pixel for the anti-aliased rim), so loop over that box, clipped to the image. Same result, a thousand times less work. (`Math.hypot` is also several times slower than `Math.sqrt(dx*dx + dy*dy)` in hot code.)

## Blending

With coverage `a` and a shape color `c`, painting is a lerp: `dst = dst + (c - dst) * a`. That is the "normal" blend mode with straight (non-premultiplied) alpha. Image editors add **blend modes**, each a function `B(dst, src)` per channel, lerped in by opacity:

| Mode | `B(d, s)` | Use |
|---|---|---|
| normal | `s` | paint over |
| multiply | `d · s` | shadows, dirt, ambient occlusion layers (only darkens) |
| screen | `d + s - d·s` | glows, haze (only lightens, never above 1) |
| add | `d + s` | light: fire, sparks, bloom (can exceed 1 in a float buffer) |

When layers carry their own alpha and are composited repeatedly, use **premultiplied alpha**: store `(r·a, g·a, b·a, a)`. Porter and Duff's "over" (1984) is then `dst = src + dst · (1 - src.a)` for all four channels, with no division, and filtering (blur, mipmaps) of premultiplied colors does not bleed dark fringes from transparent pixels. GPUs blend premultiplied colors natively; it is the format to standardize on.

## Blur: separable, with a sliding window

A **box blur** of radius `r` replaces each pixel by the mean of the `(2r+1)²` pixels around it. Done literally that is `(2r+1)²` reads per pixel: at `r = 20` on a 1024×1024 RGB image, five billion reads. Two observations fix it:

1. The box kernel is **separable**: blurring every row horizontally and then every column vertically gives exactly the 2D result. That is `2(2r+1)` reads per pixel.
2. Along a row, consecutive windows differ by one pixel in and one pixel out. Keep a **running sum**: `sum += in[x + r + 1] - in[x - r]`. Now the cost per pixel is constant, **independent of the radius**.

Three box blurs in a row approximate a Gaussian closely (the central limit theorem: a box convolved with itself three times is a smooth bell; see Wojciech Jarosz's "Fast Image Convolutions" and Ivan Kutskir's fast Gaussian write-up). Edges need a policy: here we **clamp** coordinates to the image, so the edge pixel is repeated. For tileable textures you will **wrap** instead.

```js
// Blur one row of floats with a sliding window, clamped at the ends.
function blurRow(src, dst, n, r) {
  const last = n - 1, inv = 1 / (2 * r + 1);
  let sum = 0;
  for (let k = -r; k <= r; k++) sum += src[Math.min(last, Math.max(0, k))];
  for (let x = 0; x < n; x++) {
    dst[x] = sum * inv;
    sum += src[Math.min(last, x + r + 1)] - src[Math.max(0, x - r)];
  }
}
const row = new Float32Array([0, 0, 0, 0, 9, 0, 0, 0, 0, 0]), out = new Float32Array(10);
blurRow(row, out, 10, 1);
console.log(Array.from(out));
const big = new Float32Array(1 << 20).map((_, i) => i % 7), dst = new Float32Array(1 << 20);
for (const r of [2, 50, 500]) {
  const t0 = performance.now();
  blurRow(big, dst, big.length, r);
  console.log(`r=${r}: ${(performance.now() - t0).toFixed(1)} ms`);   // about the same for every radius
}
```

The vertical pass walks memory with a stride of a whole row, which is less cache friendly than the horizontal one. Production code often transposes the image, blurs rows again, and transposes back; at the sizes in this course the direct version is fine.

## Image kernels

Many filters are a **3×3 convolution**: each output is a weighted sum of the 9 input pixels around it.

| Kernel | Weights (row by row) | Effect |
|---|---|---|
| identity | `0 0 0 / 0 1 0 / 0 0 0` | copy |
| box | all `1/9` | blur |
| sharpen | `0 -1 0 / -1 5 -1 / 0 -1 0` | original plus (original minus blur): boosts edges |
| Sobel x | `-1 0 1 / -2 0 2 / -1 0 1` | horizontal gradient (finds vertical edges) |
| Sobel y | `-1 -2 -1 / 0 0 0 / 1 2 1` | vertical gradient |

Weights that sum to 1 preserve brightness; derivative kernels sum to 0, so flat areas go to 0. The **Sobel** operator (Sobel and Feldman, 1968) computes both gradients and the edge strength `sqrt(gx² + gy²)`. You will use exactly this in the textures chapter to turn a height map into a **normal map**.

> **Performance:** compute the clamped neighbor offsets once per row (`ym`, `y0`, `yp`) and once per column (`xm`, `xp`) instead of clamping 9 coordinates per pixel; keep the 9 weights in locals or a small typed array. A general `n×n` convolution with a function call per tap is the slow, allocation-prone way. Large kernels should be separable (like blur) or done on the GPU.

## Dithering

Quantizing a smooth gradient to few levels (8-bit output, a 4-color palette, a 1-bit e-ink look) makes visible **bands**. Dithering trades bands for fine noise the eye averages out.

- **Ordered dithering** adds a per-pixel threshold from a tiled **Bayer matrix** before rounding down. The Bayer matrix (Bryce Bayer, 1973) orders thresholds so that nearby pixels get very different ones, giving a regular cross-hatch. It is built recursively: from `M` (n×n) the 2n×2n matrix is `[[4M, 4M+2], [4M+3, 4M+1]]`, starting from `[0]`. Each pixel is independent, so it is trivially parallel: the GPU-friendly choice.
- **Error diffusion** (Floyd and Steinberg, 1976) quantizes pixels in order and pushes each pixel's rounding error to unprocessed neighbors: 7/16 to the right, 3/16 below-left, 5/16 below, 1/16 below-right. The average brightness is preserved exactly (up to the edges), and the result looks organic. It is inherently sequential.

```text
Bayer 4x4 (thresholds are (value + 0.5) / 16):     Floyd-Steinberg weights:
   0  8  2 10                                               *   7
  12  4 14  6                                           3   5   1     (/16)
   3 11  1  9
  15  7 13  5
```

Even plain 8-bit output bands visibly in dark gradients (a night sky, fog). Adding a tiny ordered-dither offset (±0.5 of a code) before the final rounding removes it at no cost; games and film grain do this all the time.

Start the toolkit with the two pixel primitives everything else writes through.

- `packRGBA(r, g, b, a = 255)`: pack four 8-bit channels into one **unsigned** 32-bit integer whose bytes in memory (on a little-endian machine) are R, G, B, A. The fast way to fill a span is `u32.fill(color, start, end)`, one native call per row. The bug to avoid: clipping only `y`. If `x1` runs past the right edge, the index `y * w + x` silently wraps onto the next row.

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// Run: a checkerboard with a few clipped rectangles, written as packed 32-bit pixels.
function demo() {

  const image = new ImageData(w, h);
  const px = new Uint32Array(image.data.buffer);       // same bytes, one element per pixel
  const s = w / 16;
  const dark = packRGBA(40, 44, 52), light = packRGBA(70, 76, 90);

Add the sRGB transfer functions and the fast float-to-pixels conversion every later step displays through.

Why a table: the conversion runs on every channel of every pixel of every frame, and `Math.pow` is the expensive part. 4097 entries is fine-grained enough that the result is within one code of the exact `Math.round(255 * linearToSrgb(v))` everywhere. The bad habit is calling `linearToSrgb` (two `pow`s' worth of work) per channel in the frame loop, or building the table inside `floatToRGBA` on every call: build it once and pass it in.

Clamp with comparisons, `v > 0 ? (v < 1 ? v : 1) : 0`: every comparison with NaN is false, so NaN falls through to 0. `Math.min(1, Math.max(0, NaN))` is NaN, and `NaN | 0` is 0 only by accident.

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

--- prompt
Add the two quickest ways to get good-looking color from a single number.

- `hsvToRgb(h, s, v, out)`: `h` in **turns** (1 = 360°, wrapping: `1.25` and `-0.75` both mean `0.25`), `s` and `v` in [0, 1]. Write R, G, B (0..1) into `out` and return `out`. Notice the `out` parameter: the color functions are called per pixel, so they must not return a fresh array each time. Allocate one small `Float64Array(3)` outside the loop and reuse it. The LUT is the bigger win: 12 cosines per pixel become one array read.

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

--- prompt
Add perceptual color mixing.

- `linearToOklab(r, g, b, out)`: as in the chapter (linear sRGB in, `[L, a, b]` out).
- `oklabToLinear(L, a, b, out)`: the inverse. From Ottosson's reference:

```text
l_ = L + 0.3963377774 a + 0.2158037573 b        l = l_^3   (likewise m, s)
m_ = L - 0.1055613458 a - 0.0638541728 b
s_ = L - 0.0894841775 a - 1.2914855480 b
R =  4.0767416621 l - 3.3077115913 m + 0.2309699292 s
G = -1.2684380046 l + 2.6097574011 m - 0.3413193965 s
B = -0.0041960863 l - 0.7034186147 m + 1.7076147010 s
```

- `mixOklab(c0, c1, t, out)`: `c0`, `c1` are linear RGB triples; convert both, lerp `L`, `a`, `b` by `t`, convert back into `out`, return `out`.
- `fillGradientOklab(img, w, h, c0, c1)`: fill a linear float RGB image with a **vertical** gradient: every pixel of row `y` is `mixOklab(c0, c1, y / (h - 1))` (row 0 is `c0`; use `t = 0` if `h` is 1).

Performance: the gradient only changes per row, so convert **once per row** (`h` conversions, each with three cube roots), not once per pixel, then fill the row. And `mixOklab` should not allocate: keep its two scratch `[L, a, b]` arrays at the top level, created once.

A nice check of what "perceptual" means: the OKLab midpoint of black and white has `L = 0.5`, which is linear `0.5³ = 0.125`, which displays as sRGB 0.39: perceived middle gray, darker than the linear average.

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

// ---- OKLab (Bjorn Ottosson, 2020) ----
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}

function oklabToLinear(L, a, b, out) {
  const l = L + 0.3963377774 * a + 0.2158037573 * b;
  const m = L - 0.1055613458 * a - 0.0638541728 * b;
  const s = L - 0.0894841775 * a - 1.2914855480 * b;
  const l3 = l * l * l, m3 = m * m * m, s3 = s * s * s;
  out[0] = 4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3;
  out[1] = -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3;
  out[2] = -0.0041960863 * l3 - 0.7034186147 * m3 + 1.7076147010 * s3;
  return out;
}

// Scratch space allocated once, reused by every call.
const labA_ = new Float64Array(3), labB_ = new Float64Array(3);

// Mixes two *linear* RGB colors through OKLab.
function mixOklab(c0, c1, t, out) {
  linearToOklab(c0[0], c0[1], c0[2], labA_);
  linearToOklab(c1[0], c1[1], c1[2], labB_);
  return oklabToLinear(
    labA_[0] + (labB_[0] - labA_[0]) * t,
    labA_[1] + (labB_[1] - labA_[1]) * t,
    labA_[2] + (labB_[2] - labA_[2]) * t, out);
}

// Vertical gradient: row y gets mixOklab(c0, c1, y / (h - 1)). One conversion per row.
function fillGradientOklab(img, w, h, c0, c1) {
  const col = new Float64Array(3);
  for (let y = 0; y < h; y++) {
    mixOklab(c0, c1, h > 1 ? y / (h - 1) : 0, col);
    const r = col[0], g = col[1], b = col[2];
    for (let i = y * w * 3, end = i + w * 3; i < end; i += 3) { img[i] = r; img[i + 1] = g; img[i + 2] = b; }
  }
}

    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

// ---- OKLab (Bjorn Ottosson, 2020) ----
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}

function oklabToLinear(L, a, b, out) {
  const l = L + 0.3963377774 * a + 0.2158037573 * b;
  const m = L - 0.1055613458 * a - 0.0638541728 * b;
  const s = L - 0.0894841775 * a - 1.2914855480 * b;
  const l3 = l * l * l, m3 = m * m * m, s3 = s * s * s;
  out[0] = 4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3;
  out[1] = -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3;
  out[2] = -0.0041960863 * l3 - 0.7034186147 * m3 + 1.7076147010 * s3;
  return out;
}

// Scratch space allocated once, reused by every call.
const labA_ = new Float64Array(3), labB_ = new Float64Array(3);

// Mixes two *linear* RGB colors through OKLab.
function mixOklab(c0, c1, t, out) {
  linearToOklab(c0[0], c0[1], c0[2], labA_);
  linearToOklab(c1[0], c1[1], c1[2], labB_);
  return oklabToLinear(
    labA_[0] + (labB_[0] - labA_[0]) * t,
    labA_[1] + (labB_[1] - labA_[1]) * t,
    labA_[2] + (labB_[2] - labA_[2]) * t, out);
}

// Vertical gradient: row y gets mixOklab(c0, c1, y / (h - 1)). One conversion per row.
function fillGradientOklab(img, w, h, c0, c1) {
  const col = new Float64Array(3);
  for (let y = 0; y < h; y++) {
    mixOklab(c0, c1, h > 1 ? y / (h - 1) : 0, col);
    const r = col[0], g = col[1], b = col[2];
    for (let i = y * w * 3, end = i + w * 3; i < end; i += 3) { img[i] = r; img[i + 1] = g; img[i + 2] = b; }
  }
}

// ---- signed distance shapes, anti-aliased ----
function smoothstep(e0, e1, x) {
  let t = (x - e0) / (e1 - e0);
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  return t * t * (3 - 2 * t);
}

function sdCircle(px, py, cx, cy, r) {
  const dx = px - cx, dy = py - cy;
  return Math.sqrt(dx * dx + dy * dy) - r;
}

// Box centered at (cx, cy) with half sizes hx, hy (Quilez's sdBox).
function sdBox(px, py, cx, cy, hx, hy) {
  const qx = Math.abs(px - cx) - hx, qy = Math.abs(py - cy) - hy;
  const ox = qx > 0 ? qx : 0, oy = qy > 0 ? qy : 0;
  return Math.sqrt(ox * ox + oy * oy) + Math.min(Math.max(qx, qy), 0);
}

// Distance to the segment a-b (subtract a radius for a capsule).
function sdSegment(px, py, ax, ay, bx, by) {
  const pax = px - ax, pay = py - ay, bax = bx - ax, bay = by - ay;
  const len2 = bax * bax + bay * bay;
  let t = len2 > 0 ? (pax * bax + pay * bay) / len2 : 0;
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  const dx = pax - bax * t, dy = pay - bay * t;
  return Math.sqrt(dx * dx + dy * dy);
}

// Distance in pixels -> fraction of the pixel covered (1 inside, 0 outside, a 1 px ramp).
function coverage(d) {
  return 1 - smoothstep(-0.5, 0.5, d);
}

// Only the bounding box is visited. Pixel centers are at (x + 0.5, y + 0.5).
function drawCircle(img, w, h, cx, cy, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(cx - r - 1)), x1 = Math.min(w - 1, Math.ceil(cx + r + 1));
  const y0 = Math.max(0, Math.floor(cy - r - 1)), y1 = Math.min(h - 1, Math.ceil(cy + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdCircle(x + 0.5, y + 0.5, cx, cy, r)) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

function drawCapsule(img, w, h, ax, ay, bx, by, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(Math.min(ax, bx) - r - 1)), x1 = Math.min(w - 1, Math.ceil(Math.max(ax, bx) + r + 1));
  const y0 = Math.max(0, Math.floor(Math.min(ay, by) - r - 1)), y1 = Math.min(h - 1, Math.ceil(Math.max(ay, by) + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdSegment(x + 0.5, y + 0.5, ax, ay, bx, by) - r) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

const labA_ = new Float64Array(3), labB_ = new Float64Array(3);

// Mixes two *linear* RGB colors through OKLab.
function mixOklab(c0, c1, t, out) {
  linearToOklab(c0[0], c0[1], c0[2], labA_);
  linearToOklab(c1[0], c1[1], c1[2], labB_);
  return oklabToLinear(
    labA_[0] + (labB_[0] - labA_[0]) * t,
    labA_[1] + (labB_[1] - labA_[1]) * t,
    labA_[2] + (labB_[2] - labA_[2]) * t, out);
}

// Vertical gradient: row y gets mixOklab(c0, c1, y / (h - 1)). One conversion per row.
function fillGradientOklab(img, w, h, c0, c1) {
  const col = new Float64Array(3);
  for (let y = 0; y < h; y++) {
    mixOklab(c0, c1, h > 1 ? y / (h - 1) : 0, col);
    const r = col[0], g = col[1], b = col[2];
    for (let i = y * w * 3, end = i + w * 3; i < end; i += 3) { img[i] = r; img[i + 1] = g; img[i + 2] = b; }
  }
}

// ---- signed distance shapes, anti-aliased ----
function smoothstep(e0, e1, x) {
  let t = (x - e0) / (e1 - e0);
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  return t * t * (3 - 2 * t);
}

function sdCircle(px, py, cx, cy, r) {
  const dx = px - cx, dy = py - cy;
  return Math.sqrt(dx * dx + dy * dy) - r;
}

// Box centered at (cx, cy) with half sizes hx, hy (Quilez's sdBox).
function sdBox(px, py, cx, cy, hx, hy) {
  const qx = Math.abs(px - cx) - hx, qy = Math.abs(py - cy) - hy;
  const ox = qx > 0 ? qx : 0, oy = qy > 0 ? qy : 0;
  return Math.sqrt(ox * ox + oy * oy) + Math.min(Math.max(qx, qy), 0);
}

// Distance to the segment a-b (subtract a radius for a capsule).
function sdSegment(px, py, ax, ay, bx, by) {
  const pax = px - ax, pay = py - ay, bax = bx - ax, bay = by - ay;
  const len2 = bax * bax + bay * bay;
  let t = len2 > 0 ? (pax * bax + pay * bay) / len2 : 0;
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  const dx = pax - bax * t, dy = pay - bay * t;
  return Math.sqrt(dx * dx + dy * dy);
}

// Distance in pixels -> fraction of the pixel covered (1 inside, 0 outside, a 1 px ramp).
function coverage(d) {
  return 1 - smoothstep(-0.5, 0.5, d);
}

// Only the bounding box is visited. Pixel centers are at (x + 0.5, y + 0.5).
function drawCircle(img, w, h, cx, cy, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(cx - r - 1)), x1 = Math.min(w - 1, Math.ceil(cx + r + 1));
  const y0 = Math.max(0, Math.floor(cy - r - 1)), y1 = Math.min(h - 1, Math.ceil(cy + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdCircle(x + 0.5, y + 0.5, cx, cy, r)) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

function drawCapsule(img, w, h, ax, ay, bx, by, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(Math.min(ax, bx) - r - 1)), x1 = Math.min(w - 1, Math.ceil(Math.max(ax, bx) + r + 1));
  const y0 = Math.max(0, Math.floor(Math.min(ay, by) - r - 1)), y1 = Math.min(h - 1, Math.ceil(Math.max(ay, by) + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdSegment(x + 0.5, y + 0.5, ax, ay, bx, by) - r) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

// ---- blending ----
const BLEND_NORMAL = 0, BLEND_MULTIPLY = 1, BLEND_SCREEN = 2, BLEND_ADD = 3;

// dst, src: linear RGB (3 floats per pixel). mask: one float per pixel, or null for all 1s.
// dst = lerp(dst, blendMode(dst, src), mask * opacity)
function blendLayer(dst, src, mask, n, mode, opacity) {
  for (let p = 0, i = 0; p < n; p++, i += 3) {
    const a = mask ? mask[p] * opacity : opacity;
    if (a === 0) continue;
    for (let c = i; c < i + 3; c++) {
      const d = dst[c], s = src[c];
      const b = mode === BLEND_MULTIPLY ? d * s : mode === BLEND_SCREEN ? d + s - d * s : mode === BLEND_ADD ? d + s : s;
      dst[c] = d + (b - d) * a;
    }
  }
}

// Porter-Duff "over" for premultiplied RGBA (4 floats per pixel): dst = src + dst * (1 - src.a).
function overPremul(dst, src, n) {
  for (let j = 0, end = n * 4; j < end; j += 4) {
    const k = 1 - src[j + 3];
    dst[j] = src[j] + dst[j] * k;
    dst[j + 1] = src[j + 1] + dst[j + 1] * k;
    dst[j + 2] = src[j + 2] + dst[j + 2] * k;
    dst[j + 3] = src[j + 3] + dst[j + 3] * k;
  }
}

--- prompt
Add a blur whose cost does not depend on its radius.

- `blurH(src, dst, w, h, ch, r)`: horizontal box blur of an image with `ch` floats per pixel (interleaved). Each output is the mean of the `2r + 1` inputs from `x - r` to `x + r` in its row, with coordinates **clamped** to `[0, w - 1]` (so the edge pixel repeats). Use a running sum per row and channel: initialize it with the window around `x = 0`, then for each `x` write `sum / (2r + 1)` and update `sum += src[clamp(x + r + 1)] - src[clamp(x - r)]`.
- `blurV(src, dst, w, h, ch, r)`: the same down each column.

The test blurs a 1024×1024 RGB image with radius 100 in under 1.2 seconds. A sliding window does that in well under 0.3 s. Summing the window for every output pixel (even separably) is 201 reads per pixel per pass and takes several seconds; the full 2D window takes minutes. Radius larger than the image must still work (clamping handles it).

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

// ---- OKLab (Bjorn Ottosson, 2020) ----
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}

function oklabToLinear(L, a, b, out) {
  const l = L + 0.3963377774 * a + 0.2158037573 * b;
  const m = L - 0.1055613458 * a - 0.0638541728 * b;
  const s = L - 0.0894841775 * a - 1.2914855480 * b;
  const l3 = l * l * l, m3 = m * m * m, s3 = s * s * s;
  out[0] = 4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3;
  out[1] = -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3;
  out[2] = -0.0041960863 * l3 - 0.7034186147 * m3 + 1.7076147010 * s3;
  return out;
}

}

function drawCapsule(img, w, h, ax, ay, bx, by, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(Math.min(ax, bx) - r - 1)), x1 = Math.min(w - 1, Math.ceil(Math.max(ax, bx) + r + 1));
  const y0 = Math.max(0, Math.floor(Math.min(ay, by) - r - 1)), y1 = Math.min(h - 1, Math.ceil(Math.max(ay, by) + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdSegment(x + 0.5, y + 0.5, ax, ay, bx, by) - r) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

// ---- blending ----
const BLEND_NORMAL = 0, BLEND_MULTIPLY = 1, BLEND_SCREEN = 2, BLEND_ADD = 3;

// dst, src: linear RGB (3 floats per pixel). mask: one float per pixel, or null for all 1s.
// dst = lerp(dst, blendMode(dst, src), mask * opacity)
function blendLayer(dst, src, mask, n, mode, opacity) {
  for (let p = 0, i = 0; p < n; p++, i += 3) {
    const a = mask ? mask[p] * opacity : opacity;
    if (a === 0) continue;
    for (let c = i; c < i + 3; c++) {
      const d = dst[c], s = src[c];
      const b = mode === BLEND_MULTIPLY ? d * s : mode === BLEND_SCREEN ? d + s - d * s : mode === BLEND_ADD ? d + s : s;
      dst[c] = d + (b - d) * a;
    }
  }
}

// Porter-Duff "over" for premultiplied RGBA (4 floats per pixel): dst = src + dst * (1 - src.a).
function overPremul(dst, src, n) {
  for (let j = 0, end = n * 4; j < end; j += 4) {
    const k = 1 - src[j + 3];
    dst[j] = src[j] + dst[j] * k;
    dst[j + 1] = src[j + 1] + dst[j + 1] * k;
    dst[j + 2] = src[j + 2] + dst[j + 2] * k;
    dst[j + 3] = src[j + 3] + dst[j + 3] * k;
  }
}

// ---- separable box blur with a sliding window ----
// Horizontal pass: each output is the mean of 2r+1 inputs, edges clamped.
// The running sum adds the pixel entering the window and drops the one leaving: O(1) per pixel.
function blurH(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = w - 1;
  for (let y = 0; y < h; y++) {
    const row = y * w;
    for (let c = 0; c < ch; c++) {
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(row + (k < 0 ? 0 : k > last ? last : k)) * ch + c];
      for (let x = 0; x < w; x++) {
        dst[(row + x) * ch + c] = sum * inv;
        const xa = x + r + 1, xr = x - r;
        sum += src[(row + (xa > last ? last : xa)) * ch + c] - src[(row + (xr < 0 ? 0 : xr)) * ch + c];
      }
    }
  }
}

function blurV(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = h - 1, stride = w * ch;
  for (let x = 0; x < w; x++) {
    for (let c = 0; c < ch; c++) {
      const col = x * ch + c;
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(k < 0 ? 0 : k > last ? last : k) * stride + col];
      for (let y = 0; y < h; y++) {
        dst[y * stride + col] = sum * inv;
        const ya = y + r + 1, yr = y - r;
        sum += src[(ya > last ? last : ya) * stride + col] - src[(yr < 0 ? 0 : yr) * stride + col];
      }
    }
  }
}

// In place on img, using tmp (same size) as scratch.
function boxBlur(img, tmp, w, h, ch, r) {
  if (r <= 0) return;
  blurH(img, tmp, w, h, ch, r);
  blurV(tmp, img, w, h, ch, r);
}

--- solution
// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

// ---- OKLab (Bjorn Ottosson, 2020) ----
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}

function oklabToLinear(L, a, b, out) {
  const l = L + 0.3963377774 * a + 0.2158037573 * b;
  const m = L - 0.1055613458 * a - 0.0638541728 * b;
  const s = L - 0.0894841775 * a - 1.2914855480 * b;
  const l3 = l * l * l, m3 = m * m * m, s3 = s * s * s;
  out[0] = 4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3;
  out[1] = -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3;
  out[2] = -0.0041960863 * l3 - 0.7034186147 * m3 + 1.7076147010 * s3;
  return out;
}

// Scratch space allocated once, reused by every call.
const labA_ = new Float64Array(3), labB_ = new Float64Array(3);

// Mixes two *linear* RGB colors through OKLab.
function mixOklab(c0, c1, t, out) {
  linearToOklab(c0[0], c0[1], c0[2], labA_);
  linearToOklab(c1[0], c1[1], c1[2], labB_);
  return oklabToLinear(
    labA_[0] + (labB_[0] - labA_[0]) * t,
    labA_[1] + (labB_[1] - labA_[1]) * t,
    labA_[2] + (labB_[2] - labA_[2]) * t, out);
}

// Vertical gradient: row y gets mixOklab(c0, c1, y / (h - 1)). One conversion per row.
function fillGradientOklab(img, w, h, c0, c1) {
  const col = new Float64Array(3);
  for (let y = 0; y < h; y++) {
    mixOklab(c0, c1, h > 1 ? y / (h - 1) : 0, col);
    const r = col[0], g = col[1], b = col[2];
    for (let i = y * w * 3, end = i + w * 3; i < end; i += 3) { img[i] = r; img[i + 1] = g; img[i + 2] = b; }
  }
}

// ---- signed distance shapes, anti-aliased ----
function smoothstep(e0, e1, x) {
  let t = (x - e0) / (e1 - e0);
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  return t * t * (3 - 2 * t);
}

function sdCircle(px, py, cx, cy, r) {
  const dx = px - cx, dy = py - cy;
  return Math.sqrt(dx * dx + dy * dy) - r;
}

// Box centered at (cx, cy) with half sizes hx, hy (Quilez's sdBox).
function sdBox(px, py, cx, cy, hx, hy) {
  const qx = Math.abs(px - cx) - hx, qy = Math.abs(py - cy) - hy;
  const ox = qx > 0 ? qx : 0, oy = qy > 0 ? qy : 0;
  return Math.sqrt(ox * ox + oy * oy) + Math.min(Math.max(qx, qy), 0);
}

// Distance to the segment a-b (subtract a radius for a capsule).
function sdSegment(px, py, ax, ay, bx, by) {
  const pax = px - ax, pay = py - ay, bax = bx - ax, bay = by - ay;
  const len2 = bax * bax + bay * bay;
  let t = len2 > 0 ? (pax * bax + pay * bay) / len2 : 0;
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  const dx = pax - bax * t, dy = pay - bay * t;
  return Math.sqrt(dx * dx + dy * dy);
}

// Distance in pixels -> fraction of the pixel covered (1 inside, 0 outside, a 1 px ramp).
function coverage(d) {
  return 1 - smoothstep(-0.5, 0.5, d);
}

// Only the bounding box is visited. Pixel centers are at (x + 0.5, y + 0.5).
function drawCircle(img, w, h, cx, cy, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(cx - r - 1)), x1 = Math.min(w - 1, Math.ceil(cx + r + 1));
  const y0 = Math.max(0, Math.floor(cy - r - 1)), y1 = Math.min(h - 1, Math.ceil(cy + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdCircle(x + 0.5, y + 0.5, cx, cy, r)) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

function drawCapsule(img, w, h, ax, ay, bx, by, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(Math.min(ax, bx) - r - 1)), x1 = Math.min(w - 1, Math.ceil(Math.max(ax, bx) + r + 1));
  const y0 = Math.max(0, Math.floor(Math.min(ay, by) - r - 1)), y1 = Math.min(h - 1, Math.ceil(Math.max(ay, by) + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdSegment(x + 0.5, y + 0.5, ax, ay, bx, by) - r) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

// ---- blending ----
const BLEND_NORMAL = 0, BLEND_MULTIPLY = 1, BLEND_SCREEN = 2, BLEND_ADD = 3;

// dst, src: linear RGB (3 floats per pixel). mask: one float per pixel, or null for all 1s.
// dst = lerp(dst, blendMode(dst, src), mask * opacity)
function blendLayer(dst, src, mask, n, mode, opacity) {
  for (let p = 0, i = 0; p < n; p++, i += 3) {
    const a = mask ? mask[p] * opacity : opacity;
    if (a === 0) continue;
    for (let c = i; c < i + 3; c++) {
      const d = dst[c], s = src[c];
      const b = mode === BLEND_MULTIPLY ? d * s : mode === BLEND_SCREEN ? d + s - d * s : mode === BLEND_ADD ? d + s : s;
      dst[c] = d + (b - d) * a;
    }
  }
}

// Porter-Duff "over" for premultiplied RGBA (4 floats per pixel): dst = src + dst * (1 - src.a).
function overPremul(dst, src, n) {
  for (let j = 0, end = n * 4; j < end; j += 4) {
    const k = 1 - src[j + 3];
    dst[j] = src[j] + dst[j] * k;
    dst[j + 1] = src[j + 1] + dst[j + 1] * k;
    dst[j + 2] = src[j + 2] + dst[j + 2] * k;
    dst[j + 3] = src[j + 3] + dst[j + 3] * k;
  }
}

// ---- separable box blur with a sliding window ----
// Horizontal pass: each output is the mean of 2r+1 inputs, edges clamped.
// The running sum adds the pixel entering the window and drops the one leaving: O(1) per pixel.
function blurH(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = w - 1;
  for (let y = 0; y < h; y++) {
    const row = y * w;
    for (let c = 0; c < ch; c++) {
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(row + (k < 0 ? 0 : k > last ? last : k)) * ch + c];
      for (let x = 0; x < w; x++) {
        dst[(row + x) * ch + c] = sum * inv;
        const xa = x + r + 1, xr = x - r;
        sum += src[(row + (xa > last ? last : xa)) * ch + c] - src[(row + (xr < 0 ? 0 : xr)) * ch + c];
      }
    }
  }
}

function blurV(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = h - 1, stride = w * ch;
  for (let x = 0; x < w; x++) {
    for (let c = 0; c < ch; c++) {
      const col = x * ch + c;
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(k < 0 ? 0 : k > last ? last : k) * stride + col];
      for (let y = 0; y < h; y++) {
        dst[y * stride + col] = sum * inv;
        const ya = y + r + 1, yr = y - r;
        sum += src[(ya > last ? last : ya) * stride + col] - src[(yr < 0 ? 0 : yr) * stride + col];
      }
    }
  }
}

// In place on img, using tmp (same size) as scratch.
function boxBlur(img, tmp, w, h, ch, r) {
  if (r <= 0) return;
  blurH(img, tmp, w, h, ch, r);
  blurV(tmp, img, w, h, ch, r);
}

// ---- 3x3 convolution and Sobel ----
const SHARPEN = new Float32Array([0, -1, 0, -1, 5, -1, 0, -1, 0]);

// k: 9 weights, row-major. Edges clamped. Neighbor offsets computed once per row and column.
function convolve3x3(src, dst, w, h, ch, k) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      for (let c = 0; c < ch; c++) {
        dst[(y0 + x) * ch + c] =
          k[0] * src[(ym + xm) * ch + c] + k[1] * src[(ym + x) * ch + c] + k[2] * src[(ym + xp) * ch + c] +
          k[3] * src[(y0 + xm) * ch + c] + k[4] * src[(y0 + x) * ch + c] + k[5] * src[(y0 + xp) * ch + c] +
          k[6] * src[(yp + xm) * ch + c] + k[7] * src[(yp + x) * ch + c] + k[8] * src[(yp + xp) * ch + c];
      }
    }
  }
}

// Gradient magnitude of a one-channel image, edges clamped.
function sobel(src, dst, w, h) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      const gx = (src[ym + xp] + 2 * src[y0 + xp] + src[yp + xp]) - (src[ym + xm] + 2 * src[y0 + xm] + src[yp + xm]);
      const gy = (src[yp + xm] + 2 * src[yp + x] + src[yp + xp]) - (src[ym + xm] + 2 * src[ym + x] + src[ym + xp]);
      dst[y0 + x] = Math.sqrt(gx * gx + gy * gy);
    }
  }
}

--- prompt
Add Bayer dithering.

- `bayerMatrix(n)`: for `n` a power of two (1, 2, 4, 8, ...), a `Float32Array` of `n * n` thresholds, row-major. Build the integer matrix recursively: start from `[0]`; from an `s × s` matrix `M` build the `2s × 2s` one with quadrants `4M` (top left), `4M + 2` (top right), `4M + 3` (bottom left), `4M + 1` (bottom right). Then map each integer `v` to `(v + 0.5) / n²`. So `bayerMatrix(2)` is `[0.125, 0.625, 0.875, 0.375]`.
- `ditherOrdered(gray, out, w, h, levels, M, n)`: `gray` holds values in [0, 1]; write level indices `0..levels-1` to `out` (a `Uint8Array`): `q = floor(gray * (levels - 1) + M[(y mod n) * n + (x mod n)])`, clamped to the valid range.

Since `n` is a power of two, `x mod n` is `x & (n - 1)`. Each pixel depends only on itself and its position, so this is the dithering you can run in a fragment shader: remember that when you get to the GPU.

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

// ---- OKLab (Bjorn Ottosson, 2020) ----
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}

function oklabToLinear(L, a, b, out) {
  const l = L + 0.3963377774 * a + 0.2158037573 * b;
  const m = L - 0.1055613458 * a - 0.0638541728 * b;
  const s = L - 0.0894841775 * a - 1.2914855480 * b;
  const l3 = l * l * l, m3 = m * m * m, s3 = s * s * s;
  out[0] = 4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3;
  out[1] = -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3;
  out[2] = -0.0041960863 * l3 - 0.7034186147 * m3 + 1.7076147010 * s3;
  return out;
}

// Scratch space allocated once, reused by every call.
const labA_ = new Float64Array(3), labB_ = new Float64Array(3);

// Mixes two *linear* RGB colors through OKLab.
function mixOklab(c0, c1, t, out) {
  linearToOklab(c0[0], c0[1], c0[2], labA_);
  linearToOklab(c1[0], c1[1], c1[2], labB_);
  return oklabToLinear(
    labA_[0] + (labB_[0] - labA_[0]) * t,
    labA_[1] + (labB_[1] - labA_[1]) * t,
    labA_[2] + (labB_[2] - labA_[2]) * t, out);
}

// Vertical gradient: row y gets mixOklab(c0, c1, y / (h - 1)). One conversion per row.
function fillGradientOklab(img, w, h, c0, c1) {
  const col = new Float64Array(3);
  for (let y = 0; y < h; y++) {
    mixOklab(c0, c1, h > 1 ? y / (h - 1) : 0, col);
    const r = col[0], g = col[1], b = col[2];
    for (let i = y * w * 3, end = i + w * 3; i < end; i += 3) { img[i] = r; img[i + 1] = g; img[i + 2] = b; }
  }
}

// ---- signed distance shapes, anti-aliased ----
function smoothstep(e0, e1, x) {
  let t = (x - e0) / (e1 - e0);
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  return t * t * (3 - 2 * t);
}

function sdCircle(px, py, cx, cy, r) {
  const dx = px - cx, dy = py - cy;
  return Math.sqrt(dx * dx + dy * dy) - r;
}

// Box centered at (cx, cy) with half sizes hx, hy (Quilez's sdBox).
function sdBox(px, py, cx, cy, hx, hy) {
  const qx = Math.abs(px - cx) - hx, qy = Math.abs(py - cy) - hy;
  const ox = qx > 0 ? qx : 0, oy = qy > 0 ? qy : 0;
  return Math.sqrt(ox * ox + oy * oy) + Math.min(Math.max(qx, qy), 0);
}

// Distance to the segment a-b (subtract a radius for a capsule).
function sdSegment(px, py, ax, ay, bx, by) {
  const pax = px - ax, pay = py - ay, bax = bx - ax, bay = by - ay;
  const len2 = bax * bax + bay * bay;
  let t = len2 > 0 ? (pax * bax + pay * bay) / len2 : 0;
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  const dx = pax - bax * t, dy = pay - bay * t;
  return Math.sqrt(dx * dx + dy * dy);
}

// Distance in pixels -> fraction of the pixel covered (1 inside, 0 outside, a 1 px ramp).
function coverage(d) {
  return 1 - smoothstep(-0.5, 0.5, d);
}

// Only the bounding box is visited. Pixel centers are at (x + 0.5, y + 0.5).
function drawCircle(img, w, h, cx, cy, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(cx - r - 1)), x1 = Math.min(w - 1, Math.ceil(cx + r + 1));
  const y0 = Math.max(0, Math.floor(cy - r - 1)), y1 = Math.min(h - 1, Math.ceil(cy + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdCircle(x + 0.5, y + 0.5, cx, cy, r)) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

function drawCapsule(img, w, h, ax, ay, bx, by, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(Math.min(ax, bx) - r - 1)), x1 = Math.min(w - 1, Math.ceil(Math.max(ax, bx) + r + 1));
  const y0 = Math.max(0, Math.floor(Math.min(ay, by) - r - 1)), y1 = Math.min(h - 1, Math.ceil(Math.max(ay, by) + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdSegment(x + 0.5, y + 0.5, ax, ay, bx, by) - r) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

// ---- blending ----
const BLEND_NORMAL = 0, BLEND_MULTIPLY = 1, BLEND_SCREEN = 2, BLEND_ADD = 3;

// dst, src: linear RGB (3 floats per pixel). mask: one float per pixel, or null for all 1s.
// dst = lerp(dst, blendMode(dst, src), mask * opacity)
function blendLayer(dst, src, mask, n, mode, opacity) {
  for (let p = 0, i = 0; p < n; p++, i += 3) {
    const a = mask ? mask[p] * opacity : opacity;
    if (a === 0) continue;
    for (let c = i; c < i + 3; c++) {
      const d = dst[c], s = src[c];
      const b = mode === BLEND_MULTIPLY ? d * s : mode === BLEND_SCREEN ? d + s - d * s : mode === BLEND_ADD ? d + s : s;
      dst[c] = d + (b - d) * a;
    }
  }
}

// Porter-Duff "over" for premultiplied RGBA (4 floats per pixel): dst = src + dst * (1 - src.a).
function overPremul(dst, src, n) {
  for (let j = 0, end = n * 4; j < end; j += 4) {
    const k = 1 - src[j + 3];
    dst[j] = src[j] + dst[j] * k;
    dst[j + 1] = src[j + 1] + dst[j + 1] * k;
    dst[j + 2] = src[j + 2] + dst[j + 2] * k;
    dst[j + 3] = src[j + 3] + dst[j + 3] * k;
  }
}

// ---- separable box blur with a sliding window ----
// Horizontal pass: each output is the mean of 2r+1 inputs, edges clamped.
// The running sum adds the pixel entering the window and drops the one leaving: O(1) per pixel.
function blurH(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = w - 1;
  for (let y = 0; y < h; y++) {
    const row = y * w;
    for (let c = 0; c < ch; c++) {
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(row + (k < 0 ? 0 : k > last ? last : k)) * ch + c];
      for (let x = 0; x < w; x++) {
        dst[(row + x) * ch + c] = sum * inv;
        const xa = x + r + 1, xr = x - r;
        sum += src[(row + (xa > last ? last : xa)) * ch + c] - src[(row + (xr < 0 ? 0 : xr)) * ch + c];
      }
    }
  }
}

function blurV(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = h - 1, stride = w * ch;
  for (let x = 0; x < w; x++) {
    for (let c = 0; c < ch; c++) {
      const col = x * ch + c;
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(k < 0 ? 0 : k > last ? last : k) * stride + col];
      for (let y = 0; y < h; y++) {
        dst[y * stride + col] = sum * inv;
        const ya = y + r + 1, yr = y - r;
        sum += src[(ya > last ? last : ya) * stride + col] - src[(yr < 0 ? 0 : yr) * stride + col];
      }
    }
  }
}

// In place on img, using tmp (same size) as scratch.
function boxBlur(img, tmp, w, h, ch, r) {
  if (r <= 0) return;
  blurH(img, tmp, w, h, ch, r);
  blurV(tmp, img, w, h, ch, r);
}

const SHARPEN = new Float32Array([0, -1, 0, -1, 5, -1, 0, -1, 0]);

// k: 9 weights, row-major. Edges clamped. Neighbor offsets computed once per row and column.
function convolve3x3(src, dst, w, h, ch, k) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      for (let c = 0; c < ch; c++) {
        dst[(y0 + x) * ch + c] =
          k[0] * src[(ym + xm) * ch + c] + k[1] * src[(ym + x) * ch + c] + k[2] * src[(ym + xp) * ch + c] +
          k[3] * src[(y0 + xm) * ch + c] + k[4] * src[(y0 + x) * ch + c] + k[5] * src[(y0 + xp) * ch + c] +
          k[6] * src[(yp + xm) * ch + c] + k[7] * src[(yp + x) * ch + c] + k[8] * src[(yp + xp) * ch + c];
      }
    }
  }
}

// Gradient magnitude of a one-channel image, edges clamped.
function sobel(src, dst, w, h) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      const gx = (src[ym + xp] + 2 * src[y0 + xp] + src[yp + xp]) - (src[ym + xm] + 2 * src[y0 + xm] + src[yp + xm]);
      const gy = (src[yp + xm] + 2 * src[yp + x] + src[yp + xp]) - (src[ym + xm] + 2 * src[ym + x] + src[ym + xp]);
      dst[y0 + x] = Math.sqrt(gx * gx + gy * gy);
    }
  }
}

// ---- ordered dithering ----
// n x n Bayer thresholds (n a power of two), as (index + 0.5) / n^2 in (0, 1).
function bayerMatrix(n) {
  let m = new Float32Array([0]), size = 1;
  while (size < n) {
    const s2 = size * 2, next = new Float32Array(s2 * s2);
    for (let y = 0; y < size; y++) for (let x = 0; x < size; x++) {
      const v = 4 * m[y * size + x];
      next[y * s2 + x] = v;
      next[y * s2 + x + size] = v + 2;
      next[(y + size) * s2 + x] = v + 3;
      next[(y + size) * s2 + x + size] = v + 1;
    }
    m = next; size = s2;
  }
  const inv = 1 / (n * n);
  for (let i = 0; i < m.length; i++) m[i] = (m[i] + 0.5) * inv;
  return m;
}

// gray in [0, 1] -> level index 0..levels-1: floor(v * (levels - 1) + threshold).
function ditherOrdered(gray, out, w, h, levels, M, n) {
  const L = levels - 1, mask = n - 1;
  for (let y = 0; y < h; y++) {
    const mrow = (y & mask) * n;
    for (let x = 0; x < w; x++) {
      const q = Math.floor(gray[y * w + x] * L + M[mrow + (x & mask)]);
      out[y * w + x] = q < 0 ? 0 : q > L ? L : q;
    }
  }
}

--- prompt
Add error diffusion.

`ditherFS(gray, out, w, h, levels)`: visit pixels row by row, left to right. For each pixel with (error-adjusted) value `v`: `q = clamp(round(v * (levels - 1)), 0, levels - 1)`, write `q` to `out`, compute the error `e = v - q / (levels - 1)` and add it to the unvisited neighbors in `gray` (which is modified in place: it is the error buffer):

```text
          (x+1, y): e * 7/16
(x-1, y+1): e * 3/16    (x, y+1): e * 5/16    (x+1, y+1): e * 1/16
```

Neighbors outside the image get nothing (that error is lost). Use `Math.round`.

Error diffusion preserves average brightness, so a large flat 25% gray comes out with almost exactly 25% of its pixels on, but without the regular cross-hatch of Bayer. The price is that every pixel depends on the ones before it, so it is sequential: fine on the CPU for a texture you bake once, not something to run per pixel in a shader.

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

// ---- OKLab (Bjorn Ottosson, 2020) ----
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}

function oklabToLinear(L, a, b, out) {
  const l = L + 0.3963377774 * a + 0.2158037573 * b;
  const m = L - 0.1055613458 * a - 0.0638541728 * b;
  const s = L - 0.0894841775 * a - 1.2914855480 * b;
  const l3 = l * l * l, m3 = m * m * m, s3 = s * s * s;
  out[0] = 4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3;
  out[1] = -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3;
  out[2] = -0.0041960863 * l3 - 0.7034186147 * m3 + 1.7076147010 * s3;
  return out;
}

// Scratch space allocated once, reused by every call.
const labA_ = new Float64Array(3), labB_ = new Float64Array(3);

// Mixes two *linear* RGB colors through OKLab.
function mixOklab(c0, c1, t, out) {
  linearToOklab(c0[0], c0[1], c0[2], labA_);
  linearToOklab(c1[0], c1[1], c1[2], labB_);
  return oklabToLinear(
    labA_[0] + (labB_[0] - labA_[0]) * t,
    labA_[1] + (labB_[1] - labA_[1]) * t,
    labA_[2] + (labB_[2] - labA_[2]) * t, out);
}

// Vertical gradient: row y gets mixOklab(c0, c1, y / (h - 1)). One conversion per row.
function fillGradientOklab(img, w, h, c0, c1) {
  const col = new Float64Array(3);
  for (let y = 0; y < h; y++) {
    mixOklab(c0, c1, h > 1 ? y / (h - 1) : 0, col);
    const r = col[0], g = col[1], b = col[2];
    for (let i = y * w * 3, end = i + w * 3; i < end; i += 3) { img[i] = r; img[i + 1] = g; img[i + 2] = b; }
  }
}

// ---- signed distance shapes, anti-aliased ----
function smoothstep(e0, e1, x) {
  let t = (x - e0) / (e1 - e0);
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  return t * t * (3 - 2 * t);
}

function sdCircle(px, py, cx, cy, r) {
  const dx = px - cx, dy = py - cy;
  return Math.sqrt(dx * dx + dy * dy) - r;
}

// Box centered at (cx, cy) with half sizes hx, hy (Quilez's sdBox).
function sdBox(px, py, cx, cy, hx, hy) {
  const qx = Math.abs(px - cx) - hx, qy = Math.abs(py - cy) - hy;
  const ox = qx > 0 ? qx : 0, oy = qy > 0 ? qy : 0;
  return Math.sqrt(ox * ox + oy * oy) + Math.min(Math.max(qx, qy), 0);
}

// Distance to the segment a-b (subtract a radius for a capsule).
function sdSegment(px, py, ax, ay, bx, by) {
  const pax = px - ax, pay = py - ay, bax = bx - ax, bay = by - ay;
  const len2 = bax * bax + bay * bay;
  let t = len2 > 0 ? (pax * bax + pay * bay) / len2 : 0;
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  const dx = pax - bax * t, dy = pay - bay * t;
  return Math.sqrt(dx * dx + dy * dy);
}

// Distance in pixels -> fraction of the pixel covered (1 inside, 0 outside, a 1 px ramp).
function coverage(d) {
  return 1 - smoothstep(-0.5, 0.5, d);
}

// Only the bounding box is visited. Pixel centers are at (x + 0.5, y + 0.5).
function drawCircle(img, w, h, cx, cy, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(cx - r - 1)), x1 = Math.min(w - 1, Math.ceil(cx + r + 1));
  const y0 = Math.max(0, Math.floor(cy - r - 1)), y1 = Math.min(h - 1, Math.ceil(cy + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdCircle(x + 0.5, y + 0.5, cx, cy, r)) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

function drawCapsule(img, w, h, ax, ay, bx, by, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(Math.min(ax, bx) - r - 1)), x1 = Math.min(w - 1, Math.ceil(Math.max(ax, bx) + r + 1));
  const y0 = Math.max(0, Math.floor(Math.min(ay, by) - r - 1)), y1 = Math.min(h - 1, Math.ceil(Math.max(ay, by) + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdSegment(x + 0.5, y + 0.5, ax, ay, bx, by) - r) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

// ---- blending ----
const BLEND_NORMAL = 0, BLEND_MULTIPLY = 1, BLEND_SCREEN = 2, BLEND_ADD = 3;

// dst, src: linear RGB (3 floats per pixel). mask: one float per pixel, or null for all 1s.
// dst = lerp(dst, blendMode(dst, src), mask * opacity)
function blendLayer(dst, src, mask, n, mode, opacity) {
  for (let p = 0, i = 0; p < n; p++, i += 3) {
    const a = mask ? mask[p] * opacity : opacity;
    if (a === 0) continue;
    for (let c = i; c < i + 3; c++) {
      const d = dst[c], s = src[c];
      const b = mode === BLEND_MULTIPLY ? d * s : mode === BLEND_SCREEN ? d + s - d * s : mode === BLEND_ADD ? d + s : s;
      dst[c] = d + (b - d) * a;
    }
  }
}

// Porter-Duff "over" for premultiplied RGBA (4 floats per pixel): dst = src + dst * (1 - src.a).
function overPremul(dst, src, n) {
  for (let j = 0, end = n * 4; j < end; j += 4) {
    const k = 1 - src[j + 3];
    dst[j] = src[j] + dst[j] * k;
    dst[j + 1] = src[j + 1] + dst[j + 1] * k;
    dst[j + 2] = src[j + 2] + dst[j + 2] * k;
    dst[j + 3] = src[j + 3] + dst[j + 3] * k;
  }
}

// ---- separable box blur with a sliding window ----
// Horizontal pass: each output is the mean of 2r+1 inputs, edges clamped.
// The running sum adds the pixel entering the window and drops the one leaving: O(1) per pixel.
function blurH(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = w - 1;
  for (let y = 0; y < h; y++) {
    const row = y * w;
    for (let c = 0; c < ch; c++) {
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(row + (k < 0 ? 0 : k > last ? last : k)) * ch + c];
      for (let x = 0; x < w; x++) {
        dst[(row + x) * ch + c] = sum * inv;
        const xa = x + r + 1, xr = x - r;
        sum += src[(row + (xa > last ? last : xa)) * ch + c] - src[(row + (xr < 0 ? 0 : xr)) * ch + c];
      }
    }
  }
}

function blurV(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = h - 1, stride = w * ch;
  for (let x = 0; x < w; x++) {
    for (let c = 0; c < ch; c++) {
      const col = x * ch + c;
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(k < 0 ? 0 : k > last ? last : k) * stride + col];
      for (let y = 0; y < h; y++) {
        dst[y * stride + col] = sum * inv;
        const ya = y + r + 1, yr = y - r;
        sum += src[(ya > last ? last : ya) * stride + col] - src[(yr < 0 ? 0 : yr) * stride + col];
      }
    }
  }
}

// In place on img, using tmp (same size) as scratch.
function boxBlur(img, tmp, w, h, ch, r) {
  if (r <= 0) return;
  blurH(img, tmp, w, h, ch, r);
  blurV(tmp, img, w, h, ch, r);
}

// ---- 3x3 convolution and Sobel ----
const SHARPEN = new Float32Array([0, -1, 0, -1, 5, -1, 0, -1, 0]);

// k: 9 weights, row-major. Edges clamped. Neighbor offsets computed once per row and column.
function convolve3x3(src, dst, w, h, ch, k) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      for (let c = 0; c < ch; c++) {
        dst[(y0 + x) * ch + c] =
          k[0] * src[(ym + xm) * ch + c] + k[1] * src[(ym + x) * ch + c] + k[2] * src[(ym + xp) * ch + c] +
          k[3] * src[(y0 + xm) * ch + c] + k[4] * src[(y0 + x) * ch + c] + k[5] * src[(y0 + xp) * ch + c] +
          k[6] * src[(yp + xm) * ch + c] + k[7] * src[(yp + x) * ch + c] + k[8] * src[(yp + xp) * ch + c];
      }
    }
  }
}

// Gradient magnitude of a one-channel image, edges clamped.
function sobel(src, dst, w, h) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      const gx = (src[ym + xp] + 2 * src[y0 + xp] + src[yp + xp]) - (src[ym + xm] + 2 * src[y0 + xm] + src[yp + xm]);
      const gy = (src[yp + xm] + 2 * src[yp + x] + src[yp + xp]) - (src[ym + xm] + 2 * src[ym + x] + src[ym + xp]);
      dst[y0 + x] = Math.sqrt(gx * gx + gy * gy);
    }
  }
}

// ---- ordered dithering ----
// n x n Bayer thresholds (n a power of two), as (index + 0.5) / n^2 in (0, 1).
function bayerMatrix(n) {
  let m = new Float32Array([0]), size = 1;
  while (size < n) {
    const s2 = size * 2, next = new Float32Array(s2 * s2);
    for (let y = 0; y < size; y++) for (let x = 0; x < size; x++) {
      const v = 4 * m[y * size + x];
      next[y * s2 + x] = v;
      next[y * s2 + x + size] = v + 2;
      next[(y + size) * s2 + x] = v + 3;
      next[(y + size) * s2 + x + size] = v + 1;
    }
    m = next; size = s2;
  }
  const inv = 1 / (n * n);
  for (let i = 0; i < m.length; i++) m[i] = (m[i] + 0.5) * inv;
  return m;
}

// gray in [0, 1] -> level index 0..levels-1: floor(v * (levels - 1) + threshold).
function ditherOrdered(gray, out, w, h, levels, M, n) {
  const L = levels - 1, mask = n - 1;
  for (let y = 0; y < h; y++) {
    const mrow = (y & mask) * n;
    for (let x = 0; x < w; x++) {
      const q = Math.floor(gray[y * w + x] * L + M[mrow + (x & mask)]);
      out[y * w + x] = q < 0 ? 0 : q > L ? L : q;
    }
  }
}

// ---- Floyd-Steinberg error diffusion ----
// Quantizes gray (modified in place: it accumulates the diffused error) to levels 0..levels-1.
function ditherFS(gray, out, w, h, levels) {
  const L = levels - 1;
  for (let y = 0; y < h; y++) {
    for (let x = 0; x < w; x++) {
      const i = y * w + x, v = gray[i];
      let q = Math.round(v * L);
      q = q < 0 ? 0 : q > L ? L : q;
      out[i] = q;
      const e = v - q / L;
      if (x + 1 < w) gray[i + 1] += e * (7 / 16);
      if (y + 1 < h) {
        if (x > 0) gray[i + w - 1] += e * (3 / 16);
        gray[i + w] += e * (5 / 16);
        if (x + 1 < w) gray[i + w + 1] += e * (1 / 16);
      }
    }
  }
}

// ---- packed pixels ----
// One 32-bit write per pixel. Bytes in memory are R, G, B, A on a little-endian
// machine, so the integer reads 0xAABBGGRR.
function packRGBA(r, g, b, a = 255) {
  return ((a & 255) << 24 | (b & 255) << 16 | (g & 255) << 8 | (r & 255)) >>> 0;
}

// Fills the half-open rectangle [x0, x1) x [y0, y1), clipped to the image, one row at a time.
function fillRect(u32, w, h, x0, y0, x1, y1, color) {
  x0 = Math.max(0, Math.floor(x0)); y0 = Math.max(0, Math.floor(y0));
  x1 = Math.min(w, Math.floor(x1)); y1 = Math.min(h, Math.floor(y1));
  if (x1 <= x0 || y1 <= y0) return;
  for (let y = y0; y < y1; y++) u32.fill(color, y * w + x0, y * w + x1);
}

// ---- sRGB transfer function ----
function srgbToLinear(c) {
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function linearToSrgb(c) {
  return c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
}

// 4097 entries: index i holds the sRGB byte for linear value i / 4096. Built once.
function makeSrgbLUT() {
  const lut = new Uint8Array(4097);
  for (let i = 0; i <= 4096; i++) lut[i] = Math.round(255 * linearToSrgb(i / 4096));
  return lut;
}

// Linear float RGB (3 floats per pixel) -> packed opaque sRGB pixels, no Math.pow per pixel.
function floatToRGBA(src, dst, n, lut) {
  for (let i = 0, j = 0; i < n; i++, j += 3) {
    let r = src[j], g = src[j + 1], b = src[j + 2];
    r = r > 0 ? (r < 1 ? r : 1) : 0;          // clamp; the comparison form also maps NaN to 0
    g = g > 0 ? (g < 1 ? g : 1) : 0;
    b = b > 0 ? (b < 1 ? b : 1) : 0;
    dst[i] = (0xFF000000 | lut[(b * 4096 + 0.5) | 0] << 16 | lut[(g * 4096 + 0.5) | 0] << 8 | lut[(r * 4096 + 0.5) | 0]) >>> 0;
  }
}

// ---- HSV and cosine palettes ----
// h in turns (wraps), s and v in [0, 1]. Writes into out, allocates nothing.
function hsvToRgb(h, s, v, out) {
  h = (h - Math.floor(h)) * 6;
  const i = Math.floor(h), f = h - i;
  const p = v * (1 - s), q = v * (1 - s * f), t = v * (1 - s * (1 - f));
  switch (i) {
    case 0: out[0] = v; out[1] = t; out[2] = p; break;
    case 1: out[0] = q; out[1] = v; out[2] = p; break;
    case 2: out[0] = p; out[1] = v; out[2] = t; break;
    case 3: out[0] = p; out[1] = q; out[2] = v; break;
    case 4: out[0] = t; out[1] = p; out[2] = v; break;
    default: out[0] = v; out[1] = p; out[2] = q; break;
  }
  return out;
}

// Inigo Quilez: color(t) = a + b * cos(2 pi (c t + d)), per channel.
function cosinePalette(t, a, b, c, d, out) {
  const TAU = 6.283185307179586;
  out[0] = a[0] + b[0] * Math.cos(TAU * (c[0] * t + d[0]));
  out[1] = a[1] + b[1] * Math.cos(TAU * (c[1] * t + d[1]));
  out[2] = a[2] + b[2] * Math.cos(TAU * (c[2] * t + d[2]));
  return out;
}

// n packed colors for t = i / (n - 1), clamped to [0, 1] and treated as sRGB.
function makePaletteLUT(n, a, b, c, d) {
  const lut = new Uint32Array(n), col = new Float64Array(3);
  for (let i = 0; i < n; i++) {
    cosinePalette(n > 1 ? i / (n - 1) : 0, a, b, c, d, col);
    const r = Math.round(255 * Math.min(1, Math.max(0, col[0])));
    const g = Math.round(255 * Math.min(1, Math.max(0, col[1])));
    const bl = Math.round(255 * Math.min(1, Math.max(0, col[2])));
    lut[i] = packRGBA(r, g, bl, 255);
  }
  return lut;
}

// ---- OKLab (Bjorn Ottosson, 2020) ----
function linearToOklab(r, g, b, out) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  out[0] = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s;
  out[1] = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s;
  out[2] = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s;
  return out;
}

function oklabToLinear(L, a, b, out) {
  const l = L + 0.3963377774 * a + 0.2158037573 * b;
  const m = L - 0.1055613458 * a - 0.0638541728 * b;
  const s = L - 0.0894841775 * a - 1.2914855480 * b;
  const l3 = l * l * l, m3 = m * m * m, s3 = s * s * s;
  out[0] = 4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3;
  out[1] = -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3;
  out[2] = -0.0041960863 * l3 - 0.7034186147 * m3 + 1.7076147010 * s3;
  return out;
}

// Scratch space allocated once, reused by every call.
const labA_ = new Float64Array(3), labB_ = new Float64Array(3);

// Mixes two *linear* RGB colors through OKLab.
function mixOklab(c0, c1, t, out) {
  linearToOklab(c0[0], c0[1], c0[2], labA_);
  linearToOklab(c1[0], c1[1], c1[2], labB_);
  return oklabToLinear(
    labA_[0] + (labB_[0] - labA_[0]) * t,
    labA_[1] + (labB_[1] - labA_[1]) * t,
    labA_[2] + (labB_[2] - labA_[2]) * t, out);
}

// Vertical gradient: row y gets mixOklab(c0, c1, y / (h - 1)). One conversion per row.
function fillGradientOklab(img, w, h, c0, c1) {
  const col = new Float64Array(3);
  for (let y = 0; y < h; y++) {
    mixOklab(c0, c1, h > 1 ? y / (h - 1) : 0, col);
    const r = col[0], g = col[1], b = col[2];
    for (let i = y * w * 3, end = i + w * 3; i < end; i += 3) { img[i] = r; img[i + 1] = g; img[i + 2] = b; }
  }
}

// ---- signed distance shapes, anti-aliased ----
function smoothstep(e0, e1, x) {
  let t = (x - e0) / (e1 - e0);
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  return t * t * (3 - 2 * t);
}

function sdCircle(px, py, cx, cy, r) {
  const dx = px - cx, dy = py - cy;
  return Math.sqrt(dx * dx + dy * dy) - r;
}

// Box centered at (cx, cy) with half sizes hx, hy (Quilez's sdBox).
function sdBox(px, py, cx, cy, hx, hy) {
  const qx = Math.abs(px - cx) - hx, qy = Math.abs(py - cy) - hy;
  const ox = qx > 0 ? qx : 0, oy = qy > 0 ? qy : 0;
  return Math.sqrt(ox * ox + oy * oy) + Math.min(Math.max(qx, qy), 0);
}

// Distance to the segment a-b (subtract a radius for a capsule).
function sdSegment(px, py, ax, ay, bx, by) {
  const pax = px - ax, pay = py - ay, bax = bx - ax, bay = by - ay;
  const len2 = bax * bax + bay * bay;
  let t = len2 > 0 ? (pax * bax + pay * bay) / len2 : 0;
  t = t < 0 ? 0 : t > 1 ? 1 : t;
  const dx = pax - bax * t, dy = pay - bay * t;
  return Math.sqrt(dx * dx + dy * dy);
}

// Distance in pixels -> fraction of the pixel covered (1 inside, 0 outside, a 1 px ramp).
function coverage(d) {
  return 1 - smoothstep(-0.5, 0.5, d);
}

// Only the bounding box is visited. Pixel centers are at (x + 0.5, y + 0.5).
function drawCircle(img, w, h, cx, cy, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(cx - r - 1)), x1 = Math.min(w - 1, Math.ceil(cx + r + 1));
  const y0 = Math.max(0, Math.floor(cy - r - 1)), y1 = Math.min(h - 1, Math.ceil(cy + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdCircle(x + 0.5, y + 0.5, cx, cy, r)) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

function drawCapsule(img, w, h, ax, ay, bx, by, r, color, alpha = 1) {
  const x0 = Math.max(0, Math.floor(Math.min(ax, bx) - r - 1)), x1 = Math.min(w - 1, Math.ceil(Math.max(ax, bx) + r + 1));
  const y0 = Math.max(0, Math.floor(Math.min(ay, by) - r - 1)), y1 = Math.min(h - 1, Math.ceil(Math.max(ay, by) + r + 1));
  const cr = color[0], cg = color[1], cb = color[2];
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      const a = coverage(sdSegment(x + 0.5, y + 0.5, ax, ay, bx, by) - r) * alpha;
      if (a <= 0) continue;
      const i = (y * w + x) * 3;
      img[i] += (cr - img[i]) * a; img[i + 1] += (cg - img[i + 1]) * a; img[i + 2] += (cb - img[i + 2]) * a;
    }
  }
}

// ---- blending ----
const BLEND_NORMAL = 0, BLEND_MULTIPLY = 1, BLEND_SCREEN = 2, BLEND_ADD = 3;

// dst, src: linear RGB (3 floats per pixel). mask: one float per pixel, or null for all 1s.
// dst = lerp(dst, blendMode(dst, src), mask * opacity)
function blendLayer(dst, src, mask, n, mode, opacity) {
  for (let p = 0, i = 0; p < n; p++, i += 3) {
    const a = mask ? mask[p] * opacity : opacity;
    if (a === 0) continue;
    for (let c = i; c < i + 3; c++) {
      const d = dst[c], s = src[c];
      const b = mode === BLEND_MULTIPLY ? d * s : mode === BLEND_SCREEN ? d + s - d * s : mode === BLEND_ADD ? d + s : s;
      dst[c] = d + (b - d) * a;
    }
  }
}

// Porter-Duff "over" for premultiplied RGBA (4 floats per pixel): dst = src + dst * (1 - src.a).
function overPremul(dst, src, n) {
  for (let j = 0, end = n * 4; j < end; j += 4) {
    const k = 1 - src[j + 3];
    dst[j] = src[j] + dst[j] * k;
    dst[j + 1] = src[j + 1] + dst[j + 1] * k;
    dst[j + 2] = src[j + 2] + dst[j + 2] * k;
    dst[j + 3] = src[j + 3] + dst[j + 3] * k;
  }
}

// ---- separable box blur with a sliding window ----
// Horizontal pass: each output is the mean of 2r+1 inputs, edges clamped.
// The running sum adds the pixel entering the window and drops the one leaving: O(1) per pixel.
function blurH(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = w - 1;
  for (let y = 0; y < h; y++) {
    const row = y * w;
    for (let c = 0; c < ch; c++) {
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(row + (k < 0 ? 0 : k > last ? last : k)) * ch + c];
      for (let x = 0; x < w; x++) {
        dst[(row + x) * ch + c] = sum * inv;
        const xa = x + r + 1, xr = x - r;
        sum += src[(row + (xa > last ? last : xa)) * ch + c] - src[(row + (xr < 0 ? 0 : xr)) * ch + c];
      }
    }
  }
}

function blurV(src, dst, w, h, ch, r) {
  const inv = 1 / (2 * r + 1), last = h - 1, stride = w * ch;
  for (let x = 0; x < w; x++) {
    for (let c = 0; c < ch; c++) {
      const col = x * ch + c;
      let sum = 0;
      for (let k = -r; k <= r; k++) sum += src[(k < 0 ? 0 : k > last ? last : k) * stride + col];
      for (let y = 0; y < h; y++) {
        dst[y * stride + col] = sum * inv;
        const ya = y + r + 1, yr = y - r;
        sum += src[(ya > last ? last : ya) * stride + col] - src[(yr < 0 ? 0 : yr) * stride + col];
      }
    }
  }
}

// In place on img, using tmp (same size) as scratch.
function boxBlur(img, tmp, w, h, ch, r) {
  if (r <= 0) return;
  blurH(img, tmp, w, h, ch, r);
  blurV(tmp, img, w, h, ch, r);
}

// ---- 3x3 convolution and Sobel ----
const SHARPEN = new Float32Array([0, -1, 0, -1, 5, -1, 0, -1, 0]);

// k: 9 weights, row-major. Edges clamped. Neighbor offsets computed once per row and column.
function convolve3x3(src, dst, w, h, ch, k) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      for (let c = 0; c < ch; c++) {
        dst[(y0 + x) * ch + c] =
          k[0] * src[(ym + xm) * ch + c] + k[1] * src[(ym + x) * ch + c] + k[2] * src[(ym + xp) * ch + c] +
          k[3] * src[(y0 + xm) * ch + c] + k[4] * src[(y0 + x) * ch + c] + k[5] * src[(y0 + xp) * ch + c] +
          k[6] * src[(yp + xm) * ch + c] + k[7] * src[(yp + x) * ch + c] + k[8] * src[(yp + xp) * ch + c];
      }
    }
  }
}

// Gradient magnitude of a one-channel image, edges clamped.
function sobel(src, dst, w, h) {
  for (let y = 0; y < h; y++) {
    const ym = (y > 0 ? y - 1 : 0) * w, y0 = y * w, yp = (y < h - 1 ? y + 1 : h - 1) * w;
    for (let x = 0; x < w; x++) {
      const xm = x > 0 ? x - 1 : 0, xp = x < w - 1 ? x + 1 : w - 1;
      const gx = (src[ym + xp] + 2 * src[y0 + xp] + src[yp + xp]) - (src[ym + xm] + 2 * src[y0 + xm] + src[yp + xm]);
      const gy = (src[yp + xm] + 2 * src[yp + x] + src[yp + xp]) - (src[ym + xm] + 2 * src[ym + x] + src[ym + xp]);
      dst[y0 + x] = Math.sqrt(gx * gx + gy * gy);
    }
  }
}

// ---- ordered dithering ----
// n x n Bayer thresholds (n a power of two), as (index + 0.5) / n^2 in (0, 1).
function bayerMatrix(n) {
  let m = new Float32Array([0]), size = 1;
  while (size < n) {
    const s2 = size * 2, next = new Float32Array(s2 * s2);
    for (let y = 0; y < size; y++) for (let x = 0; x < size; x++) {
      const v = 4 * m[y * size + x];
      next[y * s2 + x] = v;
      next[y * s2 + x + size] = v + 2;
      next[(y + size) * s2 + x] = v + 3;
      next[(y + size) * s2 + x + size] = v + 1;
    }
    m = next; size = s2;
  }
  const inv = 1 / (n * n);
  for (let i = 0; i < m.length; i++) m[i] = (m[i] + 0.5) * inv;
  return m;
}

// gray in [0, 1] -> level index 0..levels-1: floor(v * (levels - 1) + threshold).
function ditherOrdered(gray, out, w, h, levels, M, n) {
  const L = levels - 1, mask = n - 1;
  for (let y = 0; y < h; y++) {
    const mrow = (y & mask) * n;
    for (let x = 0; x < w; x++) {
      const q = Math.floor(gray[y * w + x] * L + M[mrow + (x & mask)]);
      out[y * w + x] = q < 0 ? 0 : q > L ? L : q;
    }
  }
}

// ---- Floyd-Steinberg error diffusion ----
// Quantizes gray (modified in place: it accumulates the diffused error) to levels 0..levels-1.
function ditherFS(gray, out, w, h, levels) {
  const L = levels - 1;
  for (let y = 0; y < h; y++) {
    for (let x = 0; x < w; x++) {
      const i = y * w + x, v = gray[i];
      let q = Math.round(v * L);
      q = q < 0 ? 0 : q > L ? L : q;
      out[i] = q;
      const e = v - q / L;
      if (x + 1 < w) gray[i + 1] += e * (7 / 16);
      if (y + 1 < h) {
        if (x > 0) gray[i + w - 1] += e * (3 / 16);
        gray[i + w] += e * (5 / 16);
        if (x + 1 < w) gray[i + w + 1] += e * (1 / 16);
      }
    }
  }
}

// ---- bloom ----
// bright = max(img - threshold, 0); blur it with three box passes; img += strength * bright.
// bright and tmp are caller-owned scratch buffers the size of img: nothing is allocated per frame.
function bloom(img, bright, tmp, w, h, threshold, r, strength) {
  const n = w * h * 3;
  for (let i = 0; i < n; i++) { const v = img[i] - threshold; bright[i] = v > 0 ? v : 0; }
  boxBlur(bright, tmp, w, h, 3, r);
  boxBlur(bright, tmp, w, h, 3, r);
  boxBlur(bright, tmp, w, h, 3, r);
  for (let i = 0; i < n; i++) img[i] += strength * bright[i];
}
