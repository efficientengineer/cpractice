=== chapter projects
title: Projects
blurb: Capstone projects for procedural graphics tooling: a seeded random number library, a texture formula compiler, a texture cache, a node-graph compositor and an easing library. Built in steps.
--- body
## How these projects work

Each project is a small library you would actually want in a procedural graphics toolkit, built in steps. A step marked as continuing an earlier one starts from **your own solution** to that step plus stubs for the new functions, exactly like growing a real codebase: you will live with your earlier design decisions, so make them clean. The tests are thorough, include edge cases, and several have time limits that a naive approach fails. Everything here is deterministic: the same inputs and seeds always give the same outputs, which is what makes procedural content testable and shareable.

These are the tools *around* generation. The procedural generation track builds the generators themselves (noise, textures, terrain, L-systems, meshes); these libraries are what those generators run on.

## 1. A seeded random number library

Chapter 10 built `xorshift32` and FNV-1a. A production procedural toolkit wants more: a generator with better statistical quality (xorshift32 fails several standard tests), string seeds ("world name" seeds), helpers that are easy to get subtly wrong (unbiased shuffles, weighted choice), state you can save and restore, and **stateless hashing** of coordinates so any tile or chunk of an infinite world can be generated independently, in any order, on any thread, with identical results.

> **Performance:** a generator is called millions of times per texture. It must not allocate: keep its state in local variables of a closure (or a small `Uint32Array`), return plain numbers, and use `Math.imul`, `| 0` and `>>> 0` so the engine keeps everything in 32-bit integer registers. Weighted choice over many items must be logarithmic (binary search over cumulative weights), not a linear scan.

## 2. A texture formula compiler

Procedural texture tools let users type formulas: `smoothstep(0.3, 0.7, fract(u * 8)) * (sin(v * tau) * 0.5 + 0.5)`. You will tokenize and parse such formulas into an abstract syntax tree (using the sticky-regex technique from chapter 08 and a recursive descent parser), evaluate the tree, and finally **compile** it into a tree of closures with constant folding, which runs a full-resolution texture about twenty times faster than walking the tree per pixel.

> **Performance:** the bad habit here is doing per pixel what can be done once: re-parsing the formula, looking variables up by name in an object, allocating an environment object per pixel, or re-evaluating subexpressions that do not depend on the pixel. Parse once, resolve names to slots once, fold constants once, then run a tight loop that writes into a `Float32Array`.

## 3. An LRU texture cache

Generated textures are expensive to make and big to keep: a 2048 by 2048 RGBA8 texture is 16 MiB. A cache keeps the most recently used ones under a memory budget, evicts the least recently used when it is over, and tells you which ones it evicted so you can release their GPU memory (`texture.destroy()` in WebGPU). It must also deduplicate concurrent requests: if two materials ask for the same texture while it is being generated, it must be generated once.

> **Performance:** every operation must be O(1). A JavaScript `Map` iterates in insertion order, so deleting and re-inserting a key moves it to the "most recent" end, and the first key is always the least recent: a complete LRU with no linked list. The naive version (`array.indexOf` plus `splice` to reorder) is O(n) per access and collapses at a few thousand entries.

## 4. A node-graph texture compositor

Substance Designer, Blender's shader editor and Houdini all present procedural textures as a **graph**: nodes (generators and filters) connected by edges. Evaluating it means sorting the nodes topologically, detecting cycles, evaluating each needed node exactly once into its own buffer, and, when the user tweaks one slider, re-evaluating **only** the nodes downstream of that change.

> **Performance:** each node's output is a `Float32Array` that is allocated once and overwritten on recompute, never reallocated. Recomputing the whole graph when one parameter changes is the classic bad habit; dirty tracking turns a multi-second rebuild into a few milliseconds when only the last node changed.

## 5. Easing curves

Tweening camera moves, blending parameters over time and animating procedural values all need easing functions, including the designer-friendly `cubic-bezier(x1, y1, x2, y2)` curves from CSS, which require solving a cubic numerically for every sample.

> **Performance:** a bezier easing is evaluated per frame per animated value, so it must not allocate; Newton's method usually converges in three or four iterations, with bisection as a safe fallback. Sampling a long keyframe track should use binary search to find the active segment.

=== exercise prng1
title: Random library, step 1: the generator
--- prompt
Write `createRng(seed)` returning a generator object. The starter contains `fnv1a` from chapter 10.

**Seeding.** `seed` is a number (use `seed >>> 0`) or a string (use `fnv1a(seed)`); anything else (or a non-finite number) throws a `TypeError`. Expand the 32-bit seed into four state words `a, b, c, d` with four calls to **splitmix32**, then discard the first **12** outputs of the generator (warm-up).

**Generator: sfc32.** The two algorithms, with all arithmetic 32-bit:

```text
splitmix32 (state s):              sfc32 next() (state a, b, c, d):
  s = (s + 0x9E3779B9) | 0           t = (((a + b) | 0) + d) | 0
  z = s                              d = (d + 1) | 0
  z = imul(z ^ (z >>> 16), 0x85EBCA6B)   a = b ^ (b >>> 9)
  z = imul(z ^ (z >>> 13), 0xC2B2AE35)   b = (c + (c << 3)) | 0
  return (z ^ (z >>> 16)) >>> 0      c = (c << 21) | (c >>> 11)
                                     c = (c + t) | 0
                                     return t >>> 0
```

**Methods:**

- `next()`: the next unsigned 32-bit integer.
- `float()`: `next() / 2^32`, in [0, 1).
- `int(lo, hi)`: an integer in `[lo, hi]` inclusive: `lo + Math.floor(float() * (hi - lo + 1))`. Throws a `RangeError` unless both are integers and `lo <= hi`.
- `range(lo, hi)`: `lo + float() * (hi - lo)`.
- `bool(p = 0.5)`: `float() < p`.
- `getState()`: a new array `[a, b, c, d]` of unsigned values; `setState(arr)` restores it, so a generator can be saved and resumed exactly.

Each method uses exactly one `next()` call. For seed `1`, the first three `next()` values are `1828152527, 3394835397, 2967886022`. The harness generates five million floats under a time limit, so no allocation per call.

function createRng(seed) {
  if (typeof seed === 'string') seed = fnv1a(seed);
  else if (typeof seed !== 'number' || !Number.isFinite(seed)) throw new TypeError('seed must be a number or string');
  let sm = seed >>> 0;
  const split = () => {
    sm = (sm + 0x9E3779B9) | 0;
    let z = sm;
    z = Math.imul(z ^ (z >>> 16), 0x85EBCA6B);
    z = Math.imul(z ^ (z >>> 13), 0xC2B2AE35);
    return (z ^ (z >>> 16)) >>> 0;
  };
  let a = split(), b = split(), c = split(), d = split();
  const rng = {
    next() {
      const t = (((a + b) | 0) + d) | 0;
      d = (d + 1) | 0;
      a = b ^ (b >>> 9);
      b = (c + (c << 3)) | 0;
      c = (c << 21) | (c >>> 11);
      c = (c + t) | 0;
      return t >>> 0;
    },
    float() { return rng.next() / 4294967296; },

    range(lo, hi) { return lo + rng.float() * (hi - lo); },
    bool(p = 0.5) { return rng.float() < p; },
    getState() { return [a >>> 0, b >>> 0, c >>> 0, d >>> 0]; },
    setState(s) { [a, b, c, d] = s.map(x => x | 0); },
  };
  for (let i = 0; i < 12; i++) rng.next();
  return rng;
}

=== exercise prng2
title: Random library, step 2: shuffles, weights and coordinate hashing
continues: prng1
--- prompt
Add helpers on top of your generator. All of them take the generator as a parameter so they work with any `createRng` instance.

- `pick(rng, arr)`: `arr[rng.int(0, arr.length - 1)]`. For an empty array return `undefined` **without** consuming a random number.
- `shuffle(rng, arr)`: shuffles `arr` **in place** with Fisher-Yates and returns it: for `i` from `arr.length - 1` down to `1`, `j = rng.int(0, i)`, swap `arr[i]` and `arr[j]`. (The popular `arr.sort(() => rng.float() - 0.5)` is biased and slow; never use it.)
- `weightedPicker(weights)`: validates the weights (each finite and `>= 0`, total `> 0`, otherwise `RangeError`), precomputes **cumulative** sums once, and returns a function `rng => index`. The function draws `x = rng.float() * total` and returns the first index whose cumulative sum is **greater than** `x`, found by binary search. Zero-weight items are never chosen.
- `hash2(seed, x, y)`: a stateless 32-bit hash of integer coordinates (negative ones too), unsigned: start with `h = seed ^ imul(x, 0x27D4EB2D) ^ imul(y, 0x165667B1)`, then apply the murmur3 finalizer: `h ^= h >>> 16; h = imul(h, 0x85EBCA6B); h ^= h >>> 13; h = imul(h, 0xC2B2AE35); h ^= h >>> 16`, and return `h >>> 0`.
- `tileRng(seed, tx, ty)`: `createRng(hash2(seed, tx, ty))`, a generator for one tile of an infinite world, independent of the order in which tiles are generated.

The harness picks a million times from ten thousand weights under a time limit.

function pick(rng, arr) {
  return arr.length ? arr[rng.int(0, arr.length - 1)] : undefined;
}

function shuffle(rng, arr) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = rng.int(0, i);
    const tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
  }
  return arr;
}

function weightedPicker(weights) {
  const cum = new Float64Array(weights.length);
  let total = 0;
  weights.forEach((w, i) => {
    if (!(Number.isFinite(w) && w >= 0)) throw new RangeError(`bad weight at ${i}: ${w}`);
    total += w;
    cum[i] = total;
  });
  if (!(total > 0)) throw new RangeError('weights must sum to more than 0');
  return rng => {
    const x = rng.float() * total;
    let lo = 0, hi = cum.length - 1;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (cum[mid] > x) hi = mid; else lo = mid + 1;
    }
    return lo;
  };
}

function hash2(seed, x, y) {
  let h = (seed ^ Math.imul(x, 0x27D4EB2D) ^ Math.imul(y, 0x165667B1)) | 0;
  h ^= h >>> 16;
  h = Math.imul(h, 0x85EBCA6B);
  h ^= h >>> 13;
  h = Math.imul(h, 0xC2B2AE35);
  h ^= h >>> 16;
  return h >>> 0;
}

function tileRng(seed, tx, ty) {
  return createRng(hash2(seed, tx, ty));
}

=== exercise expr1
title: Formula compiler, step 1: tokenize and parse
--- prompt
Write `parse(src)` that turns a texture formula into an abstract syntax tree. Node shapes:

| node | shape |
|---|---|
| number | `{ type: 'num', value }` |
| variable | `{ type: 'var', name }` |
| negation | `{ type: 'unary', op: '-', arg }` |
| binary | `{ type: 'bin', op, left, right }` |
| call | `{ type: 'call', name, args: [...] }` |
| conditional | `{ type: 'cond', test, then, else }` |

Grammar, from lowest to highest precedence:

1. `test ? a : b` (right associative: `a ? b : c ? d : e` is `a ? b : (c ? d : e)`)
2. comparisons `<` `>` `<=` `>=` `==` `!=` (left associative)
3. `+` `-` (left associative)
4. `*` `/` `%` (left associative)
5. unary `-` (may repeat: `--u`)
6. `^` power, **right** associative, binding tighter than unary minus on its left but allowing one on its right: `-2^2` is `-(2^2)`, `2^3^2` is `2^(3^2)`, `2^-1` is `2^(-1)`
7. numbers (`3`, `0.5`, `.5`, `1e-3`), identifiers (`[A-Za-z_]\w*`), calls `name(arg, arg, ...)` (zero or more arguments), and parentheses

Whitespace is ignored. Any error (an unexpected character or token, a missing `)` or `:`, a trailing comma, unexpected end of input, leftover tokens) throws a `SyntaxError` whose message ends with `at N`, where `N` is the 0-based character position of the offending token (the input length for end of input). Chapter 08's sticky-regex tokenizer is a good start; a recursive descent parser with one function per precedence level is the standard technique.
--- starter

--- solution
const TOKEN_RE_ = /(?<ws>\s+)|(?<num>(?:\d+\.?\d*|\.\d+)(?:[eE][+-]?\d+)?)|(?<id>[A-Za-z_]\w*)|(?<op><=|>=|==|!=|[-+*\/%^(),?:<>])/y;

function tokenize(src) {
  const out = [];
  TOKEN_RE_.lastIndex = 0;
  while (TOKEN_RE_.lastIndex < src.length) {
    const pos = TOKEN_RE_.lastIndex;
    const m = TOKEN_RE_.exec(src);
    if (!m) throw new SyntaxError(`Unexpected '${src[pos]}' at ${pos}`);
    const g = m.groups;
    if (g.num) out.push({ type: 'num', value: Number(g.num), pos });
    else if (g.id) out.push({ type: 'id', value: g.id, pos });
    else if (g.op) out.push({ type: 'op', value: g.op, pos });
  }
  out.push({ type: 'eof', value: '', pos: src.length });
  return out;
}

function parse(src) {
  const toks = tokenize(src);
  let i = 0;
  const peek = () => toks[i];
  const isOp = (...ops) => peek().type === 'op' && ops.includes(peek().value);
  const fail = msg => { throw new SyntaxError(`${msg} at ${peek().pos}`); };
  const expect = op => { if (!isOp(op)) fail(`Expected '${op}'`); i++; };

  function conditional() {
    const test = comparison();
    if (!isOp('?')) return test;
    i++;
    const then = conditional();
    expect(':');
    const otherwise = conditional();
    return { type: 'cond', test, then, else: otherwise };
  }
  function binaryLevel(next, ops) {
    return () => {
      let left = next();
      while (isOp(...ops)) {
        const op = toks[i++].value;
        left = { type: 'bin', op, left, right: next() };
      }
      return left;
    };
  }
  function unary() {
    if (isOp('-')) { i++; return { type: 'unary', op: '-', arg: unary() }; }
    return power();
  }
  function power() {
    const base = primary();
    if (isOp('^')) { i++; return { type: 'bin', op: '^', left: base, right: unary() }; }
    return base;
  }
  function primary() {

function tokenize(src) {
  const out = [];
  TOKEN_RE_.lastIndex = 0;
  while (TOKEN_RE_.lastIndex < src.length) {
    const pos = TOKEN_RE_.lastIndex;
    const m = TOKEN_RE_.exec(src);
    if (!m) throw new SyntaxError(`Unexpected '${src[pos]}' at ${pos}`);
    const g = m.groups;
    if (g.num) out.push({ type: 'num', value: Number(g.num), pos });
    else if (g.id) out.push({ type: 'id', value: g.id, pos });
    else if (g.op) out.push({ type: 'op', value: g.op, pos });
  }
  out.push({ type: 'eof', value: '', pos: src.length });
  return out;

function evaluate(ast, env = {}) {
  switch (ast.type) {
    case 'num': return ast.value;
    case 'var':
      if (Object.hasOwn(env, ast.name)) return env[ast.name];
      if (Object.hasOwn(CONSTANTS_, ast.name)) return CONSTANTS_[ast.name];
      throw new ReferenceError(`unknown variable: ${ast.name}`);
    case 'unary': return -evaluate(ast.arg, env);
    case 'bin': return BINOPS_[ast.op](evaluate(ast.left, env), evaluate(ast.right, env));
    case 'cond': return evaluate(ast.test, env) !== 0 ? evaluate(ast.then, env) : evaluate(ast.else, env);
    case 'call': {
      if (!Object.hasOwn(FUNCTIONS_, ast.name)) throw new ReferenceError(`unknown function: ${ast.name}`);
      const f = FUNCTIONS_[ast.name];
      if (ast.args.length !== f.length) throw new TypeError(`${ast.name} takes ${f.length} arguments`);
      return f(...ast.args.map(a => evaluate(a, env)));
    }
  }
  throw new TypeError(`bad node: ${ast.type}`);
}

      }
      case 'bin': {
        const op = BINOPS_[n.op], l = gen(n.left), r = gen(n.right);
        if (isConst(l) && isConst(r)) return konst(op(l.constant, r.constant));
        switch (n.op) {                       // inline the common ones
          case '+': return () => l() + r();
          case '-': return () => l() - r();
          case '*': return () => l() * r();
          case '/': return () => l() / r();
          default: return () => op(l(), r());
        }
      }
      case 'cond': {
        const t = gen(n.test), a = gen(n.then), b = gen(n.else);
        if (isConst(t)) return t.constant !== 0 ? a : b;
        return () => (t() !== 0 ? a() : b());
      }
      case 'call': {
        if (!Object.hasOwn(funcs, n.name)) throw new ReferenceError(`unknown function: ${n.name}`);
        const f = funcs[n.name];
        if (n.args.length !== f.length) throw new TypeError(`${n.name} takes ${f.length} arguments`);
        const as = n.args.map(gen);
        if (as.every(isConst)) return konst(f(...as.map(a => a.constant)));
        if (as.length === 1) { const [a] = as; return () => f(a()); }
        if (as.length === 2) { const [a, b] = as; return () => f(a(), b()); }
        if (as.length === 3) { const [a, b, c] = as; return () => f(a(), b(), c()); }
        return () => f(...as.map(a => a()));
      }
    }
    throw new TypeError(`bad node: ${n.type}`);
  }
  const body = gen(parse(src));
  return (...xs) => {
    for (let i = 0; i < args.length; i++) args[i] = xs[i];
    return body();
  };
}

function bakeFormula(src, width, height) {
  const f = compile(src, ['u', 'v']);
  const out = new Float32Array(width * height);
  for (let y = 0, i = 0; y < height; y++) {
    const v = (y + 0.5) / height;
    for (let x = 0; x < width; x++, i++) out[i] = f((x + 0.5) / width, v);
  }
  return out;
}

class LRUCache {
  constructor({ maxEntries = Infinity, onEvict = null } = {}) {
    this.max = maxEntries;
    this.onEvict = onEvict;
    this.entries = [];             // [key, value] pairs, least recent first
  }

  #find(key) { return this.entries.findIndex(e => e[0] === key); }

class LRUCache {
  #map = new Map();                  // insertion order = recency order, least recent first
  #max;
  #onEvict;
  constructor({ maxEntries = Infinity, onEvict = null } = {}) {
    if (!(maxEntries >= 1)) throw new RangeError('maxEntries must be at least 1');
    this.#max = maxEntries;
    this.#onEvict = onEvict;
  }
  get size() { return this.#map.size; }
  has(key) { return this.#map.has(key); }
  peek(key) { return this.#map.get(key); }
  get(key) {
    if (!this.#map.has(key)) return undefined;
    const v = this.#map.get(key);
    this.#map.delete(key);
    this.#map.set(key, v);
    return v;
  }
  set(key, value) {
    if (this.#map.has(key)) {
      const old = this.#map.get(key);
      this.#map.delete(key);
      if (old !== value && this.#onEvict) this.#onEvict(key, old);
    }
    this.#map.set(key, value);
    while (this.#map.size > this.#max) {
      const [k, v] = this.#map.entries().next().value;
      this.#map.delete(k);
      if (this.#onEvict) this.#onEvict(k, v);
    }
    return this;
  }
  delete(key) { return this.#map.delete(key); }
  clear() { this.#map.clear(); }
  keys() { return [...this.#map.keys()]; }
}

class TextureCache {
  #lru = new LRUCache();
  #loading = new Map();
  #pins = new Map();
  #bytes = 0;
  #hits = 0;
  #misses = 0;
  constructor({ maxBytes, load, onEvict = () => {} }) {
    this.maxBytes = maxBytes;
    this.load = load;
    this.onEvict = onEvict;
  }
  get(key) {
    if (this.#lru.has(key)) { this.#hits++; return Promise.resolve(this.#lru.get(key)); }
    if (this.#loading.has(key)) { this.#hits++; return this.#loading.get(key); }
    this.#misses++;
    const p = Promise.resolve()
      .then(() => this.load(key))
      .then(tex => {
        this.#loading.delete(key);
        this.#lru.set(key, tex);
        this.#bytes += tex.bytes;
        this.#evict(key);
        return tex;
      }, err => {
        this.#loading.delete(key);
        throw err;
      });
    this.#loading.set(key, p);
    return p;
  }
  #evict(keep) {
    for (const k of this.#lru.keys()) {
      if (this.#bytes <= this.maxBytes) break;
      if (k === keep || this.#pins.get(k) > 0) continue;
      const tex = this.#lru.peek(k);
      this.#lru.delete(k);
      this.#bytes -= tex.bytes;
      this.onEvict(k, tex);
    }
  }
  pin(key) { this.#pins.set(key, (this.#pins.get(key) ?? 0) + 1); }
  unpin(key) {
    const n = (this.#pins.get(key) ?? 0) - 1;
    if (n > 0) this.#pins.set(key, n); else this.#pins.delete(key);
    this.#evict(null);
  }
  has(key) { return this.#lru.has(key); }
  stats() { return { hits: this.#hits, misses: this.#misses, bytes: this.#bytes, count: this.#lru.size }; }
}

title: Node graph, step 1: order and evaluate
--- prompt
A texture graph is an object mapping node ids to `{ op, inputs = [], params = {} }`, where `inputs` lists the ids of the nodes feeding it, in order. Every node produces a `size` by `size` grayscale image stored as a `Float32Array` (row by row). Pixel centres are at `u = (x + 0.5) / size`, `v = (y + 0.5) / size`.

Write a top-level object `OPS` with these operations. Each is a function `(out, inputs, params, size)` that **writes into** the preallocated `out` (and returns nothing); `inputs` are the input nodes' output arrays.

| op | inputs | params | pixel value |
|---|---|---|---|
| `const` | 0 | `value` | `value` |
| `gradient` | 0 | `axis` (`'u'` or `'v'`) | `u` or `v` |
| `checker` | 0 | `n` | `(floor(u * n) + floor(v * n)) & 1` |
| `add`, `mul` | 2 | | `a + b`, `a * b` |
| `mix` | 3 | | `a + (b - a) * t` |
| `invert` | 1 | | `1 - a` |

const OPS = {
  const: (out, ins, p) => { out.fill(p.value); },
  gradient: (out, ins, p, size) => {
    for (let y = 0, i = 0; y < size; y++)
      for (let x = 0; x < size; x++, i++) out[i] = ((p.axis === 'v' ? y : x) + 0.5) / size;
  },
  checker: (out, ins, p, size) => {
    for (let y = 0, i = 0; y < size; y++)
      for (let x = 0; x < size; x++, i++) out[i] = (Math.floor((x + 0.5) / size * p.n) + Math.floor((y + 0.5) / size * p.n)) & 1;
  },
  add: (out, [a, b]) => { for (let i = 0; i < out.length; i++) out[i] = a[i] + b[i]; },
  mul: (out, [a, b]) => { for (let i = 0; i < out.length; i++) out[i] = a[i] * b[i]; },
  mix: (out, [a, b, t]) => { for (let i = 0; i < out.length; i++) out[i] = a[i] + (b[i] - a[i]) * t[i]; },
  invert: (out, [a]) => { for (let i = 0; i < out.length; i++) out[i] = 1 - a[i]; },
  threshold: (out, [a], p) => { for (let i = 0; i < out.length; i++) out[i] = a[i] >= p.t ? 1 : 0; },
};

function topoOrder(nodes, outputId) {
  const order = [], state = new Map();          // id -> 'visiting' | 'done'
  const visit = id => {
    if (!Object.hasOwn(nodes, id)) throw new ReferenceError(`missing node: ${id}`);
    const s = state.get(id);
    if (s === 'done') return;
    if (s === 'visiting') throw new Error(`cycle through node ${id}`);
    state.set(id, 'visiting');
    for (const src of nodes[id].inputs ?? []) visit(src);
    state.set(id, 'done');
    order.push(id);
  };
  visit(outputId);
  return order;
}

function evaluateGraph(nodes, outputId, size, customOps = {}) {
  const ops = { ...OPS, ...customOps };
  const buffers = new Map();
  for (const id of topoOrder(nodes, outputId)) {
    const node = nodes[id];
    if (!Object.hasOwn(ops, node.op)) throw new TypeError(`unknown op: ${node.op}`);
    const out = new Float32Array(size * size);
    ops[node.op](out, (node.inputs ?? []).map(src => buffers.get(src)), node.params ?? {}, size);
    buffers.set(id, out);
  }
  return buffers.get(outputId);

--- prompt
In an editor the user drags one slider at a time; recomputing the whole graph for every change is wasteful. Write `class Compositor`:

- `constructor(nodes, size, customOps = {})`: takes a **copy** of the graph (copy each node's `inputs` array and `params` object; the caller's objects must never be modified). Initially every node is dirty.
- `output(id)`: returns the node's image, recomputing only the **dirty** nodes it depends on, in topological order. Each node has **one** `Float32Array` that is allocated the first time it is computed and then overwritten in place on every recompute, so `output(id)` returns the same array object every time.
- `setParam(id, key, value)`: changes a parameter. If the value is the same (`Object.is`), nothing happens. Otherwise the node and everything downstream of it become dirty.
- `connect(id, index, srcId)`: sets `inputs[index]` of node `id` to `srcId` and marks `id` and its downstream dirty. If that would create a cycle, throw an `Error` (message containing `cycle`) and leave the graph exactly as it was. Missing node ids throw a `ReferenceError`.
- `evaluations`: a public counter of how many times an op has been run.

const OPS = {
  const: (out, ins, p) => { out.fill(p.value); },
  gradient: (out, ins, p, size) => {
    for (let y = 0, i = 0; y < size; y++)
      for (let x = 0; x < size; x++, i++) out[i] = ((p.axis === 'v' ? y : x) + 0.5) / size;
  },
  checker: (out, ins, p, size) => {
    for (let y = 0, i = 0; y < size; y++)
      for (let x = 0; x < size; x++, i++) out[i] = (Math.floor((x + 0.5) / size * p.n) + Math.floor((y + 0.5) / size * p.n)) & 1;
  },
  add: (out, [a, b]) => { for (let i = 0; i < out.length; i++) out[i] = a[i] + b[i]; },
  mul: (out, [a, b]) => { for (let i = 0; i < out.length; i++) out[i] = a[i] * b[i]; },
  mix: (out, [a, b, t]) => { for (let i = 0; i < out.length; i++) out[i] = a[i] + (b[i] - a[i]) * t[i]; },
  invert: (out, [a]) => { for (let i = 0; i < out.length; i++) out[i] = 1 - a[i]; },
  threshold: (out, [a], p) => { for (let i = 0; i < out.length; i++) out[i] = a[i] >= p.t ? 1 : 0; },
};

function topoOrder(nodes, outputId) {
  const order = [], state = new Map();          // id -> 'visiting' | 'done'
  const visit = id => {
    if (!Object.hasOwn(nodes, id)) throw new ReferenceError(`missing node: ${id}`);
    const s = state.get(id);
    if (s === 'done') return;
    if (s === 'visiting') throw new Error(`cycle through node ${id}`);
    state.set(id, 'visiting');
    for (const src of nodes[id].inputs ?? []) visit(src);
    state.set(id, 'done');
    order.push(id);
  };
  visit(outputId);
  return order;
}

function evaluateGraph(nodes, outputId, size, customOps = {}) {
  const ops = { ...OPS, ...customOps };
  const buffers = new Map();
  for (const id of topoOrder(nodes, outputId)) {
    const node = nodes[id];
    if (!Object.hasOwn(ops, node.op)) throw new TypeError(`unknown op: ${node.op}`);
    const out = new Float32Array(size * size);
    ops[node.op](out, (node.inputs ?? []).map(src => buffers.get(src)), node.params ?? {}, size);
    buffers.set(id, out);
  }
  return buffers.get(outputId);
}
class Compositor {
  constructor(nodes, size, customOps = {}) {
    this.nodes = {};
    for (const [id, n] of Object.entries(nodes)) {
      this.nodes[id] = { op: n.op, inputs: [...(n.inputs ?? [])], params: { ...(n.params ?? {}) } };
    }
    this.size = size;
    this.ops = { ...OPS, ...customOps };
    this.buffers = new Map();      // id -> Float32Array, reused across recomputes
    this.dirty = new Set(Object.keys(this.nodes));
    this.evaluations = 0;
  }
  #markDirty(id) {
    const stack = [id];
    while (stack.length) {
      const cur = stack.pop();
      if (this.dirty.has(cur) && cur !== id) continue;
      this.dirty.add(cur);
      for (const [other, n] of Object.entries(this.nodes)) if (n.inputs.includes(cur) && !this.dirty.has(other)) stack.push(other);
    }
  }
  output(id) {
    for (const nid of topoOrder(this.nodes, id)) {
      if (!this.dirty.has(nid)) continue;
      const node = this.nodes[nid];
      if (!Object.hasOwn(this.ops, node.op)) throw new TypeError(`unknown op: ${node.op}`);
      let out = this.buffers.get(nid);
      if (!out) this.buffers.set(nid, out = new Float32Array(this.size * this.size));
      this.ops[node.op](out, node.inputs.map(src => this.buffers.get(src)), node.params, this.size);
      this.evaluations++;
      this.dirty.delete(nid);
    }
    return this.buffers.get(id);
  }
  setParam(id, key, value) {
    if (!Object.hasOwn(this.nodes, id)) throw new ReferenceError(`missing node: ${id}`);
    const p = this.nodes[id].params;
    if (Object.is(p[key], value)) return;
    p[key] = value;
    this.#markDirty(id);
  }
  connect(id, index, srcId) {
    if (!Object.hasOwn(this.nodes, id)) throw new ReferenceError(`missing node: ${id}`);
    if (!Object.hasOwn(this.nodes, srcId)) throw new ReferenceError(`missing node: ${srcId}`);
    const inputs = this.nodes[id].inputs, old = inputs[index];
    inputs[index] = srcId;
    try {
      topoOrder(this.nodes, id);
    } catch (e) {
      inputs[index] = old;
      throw e;
    }
    this.#markDirty(id);
  }
}

--- hint

--- prompt
Write an easing library.

**`easings`**, an object of functions on `t` in [0, 1] (each maps 0 to 0 and 1 to 1):

| name | formula |
|---|---|
| `linear` | `t` |
| `quadIn` / `quadOut` | `t * t` / `t * (2 - t)` |
| `quadInOut` | `t < 0.5 ? 2t² : 1 - 2(1 - t)²` |
| `cubicInOut` | `t < 0.5 ? 4t³ : 1 - 4(1 - t)³` |
| `smoothstep` | `t * t * (3 - 2t)` |
| `backOut` | `1 + 2.70158 (t - 1)³ + 1.70158 (t - 1)²` (overshoots 1) |

**`cubicBezier(x1, y1, x2, y2)`** returns an easing function like CSS `cubic-bezier()`: the curve goes from (0, 0) to (1, 1) with control points (x1, y1) and (x2, y2). For input `t`, find the curve parameter `s` with `x(s) = t` (Newton's method on the cubic, falling back to bisection when the derivative is tiny or Newton does not converge), and return `y(s)`. Accuracy: within `1e-6`. Inputs `<= 0` give 0 and `>= 1` give 1. `x1` or `x2` outside [0, 1] throws a `RangeError` (then `x(s)` would not be monotonic). The y values may be outside [0, 1].

**`sampleTrack(keys, time)`**: `keys` is a non-empty array of `{ t, value, ease }` sorted by `t`. Before the first key return its value, after the last key the last value. Otherwise find the segment `keys[i].t <= time < keys[i + 1].t` by **binary search** and interpolate the values with the starting key's `ease`, which is a name from `easings`, a function, or missing (linear). An unknown easing name throws a `RangeError`; an empty track too.

The harness samples a 10,000-key track a million times and a bezier a million times under time limits, and nothing may allocate per sample.

const easings = {
  linear: t => t,
  quadIn: t => t * t,
  quadOut: t => t * (2 - t),
  quadInOut: t => (t < 0.5 ? 2 * t * t : 1 - 2 * (1 - t) * (1 - t)),
  cubicInOut: t => (t < 0.5 ? 4 * t * t * t : 1 - 4 * (1 - t) ** 3),
  smoothstep: t => t * t * (3 - 2 * t),
  backOut: t => 1 + 2.70158 * (t - 1) ** 3 + 1.70158 * (t - 1) ** 2,
};

function cubicBezier(x1, y1, x2, y2) {
  if (!(x1 >= 0 && x1 <= 1 && x2 >= 0 && x2 <= 1)) throw new RangeError('x control points must be in [0, 1]');
  const cx = 3 * x1, bx = 3 * (x2 - x1) - cx, ax = 1 - cx - bx;
  const cy = 3 * y1, by = 3 * (y2 - y1) - cy, ay = 1 - cy - by;
  const X = s => ((ax * s + bx) * s + cx) * s;
  const Y = s => ((ay * s + by) * s + cy) * s;
  const dX = s => (3 * ax * s + 2 * bx) * s + cx;
  return t => {
    if (t <= 0) return 0;
    if (t >= 1) return 1;
    let s = t;
    for (let i = 0; i < 8; i++) {                   // Newton's method
      const err = X(s) - t, d = dX(s);
      if (Math.abs(err) < 1e-9) return Y(s);
      if (Math.abs(d) < 1e-9) break;
      s -= err / d;
    }
    let lo = 0, hi = 1;                             // bisection fallback
    s = t;
    for (let i = 0; i < 60; i++) {
      const x = X(s);
      if (Math.abs(x - t) < 1e-9) break;
      if (x < t) lo = s; else hi = s;
      s = (lo + hi) / 2;
    }
    return Y(s);
  };
}

function sampleTrack(keys, time) {
  if (!keys.length) throw new RangeError('empty track');
  if (time <= keys[0].t) return keys[0].value;
  const last = keys[keys.length - 1];
  if (time >= last.t) return last.value;
  let lo = 0, hi = keys.length - 1;                 // find segment with binary search
  while (hi - lo > 1) {
    const mid = (lo + hi) >> 1;
    if (keys[mid].t <= time) lo = mid; else hi = mid;
  }
  const a = keys[lo], b = keys[hi];
  const ease = typeof a.ease === 'function' ? a.ease : easings[a.ease ?? 'linear'];
  if (!ease) throw new RangeError(`unknown easing: ${a.ease}`);
  const k = ease((time - a.t) / (b.t - a.t));
  return a.value + (b.value - a.value) * k;
}

  eq(sampleTrack([{ t: 2, value: 7 }], 1), 7, 'single key');
  eq(sampleTrack([{ t: 2, value: 7 }], 3), 7);
  throws(() => sampleTrack([], 0), 'empty track');
  throws(() => sampleTrack([{ t: 0, value: 0, ease: 'wobble' }, { t: 1, value: 1 }], 0.5), 'unknown easing');
  {
    const N = 10000;
    const keys = Array.from({ length: N }, (_, i) => ({ t: i, value: i % 2 ? 1 : 0, ease: i % 3 ? 'smoothstep' : 'linear' }));
    const t0 = performance.now();
    let s = 0;
    for (let i = 0; i < 1e6; i++) s += sampleTrack(keys, (i * 0.0099991) % N);
    const ms = performance.now() - t0;
    check(s > 0, 'samples computed');
    near(sampleTrack(keys, 5000.5), 0.5, 1e-12, 'middle of a smoothstep segment');
    check(ms < 1500, 'a million track samples took ' + Math.round(ms) + 'ms');
  }
}
