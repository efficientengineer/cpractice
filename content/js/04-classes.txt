## this is decided at the call site

In C#, `this` inside a method is always the instance. In JavaScript, `this` inside a regular `function` is a hidden parameter set by **how the function is called**, not where it was defined. Four rules, in priority order:

| Call form | `this` |
|---|---|
| `new Foo()` | the newly created object |
| `fn.call(obj, ...)`, `fn.apply(obj, [...])`, or a function from `fn.bind(obj)` | `obj` |
| `obj.method()` | `obj` (whatever is left of the dot at call time) |
| plain `fn()` | `undefined` in strict mode; the global object in sloppy mode |

Arrow functions ignore all four: they have no `this` of their own and use the `this` of the scope they were written in.

```js
function whoAmI() { return this?.label ?? String(this === globalThis ? 'global object' : this); }
const cube = { label: 'cube', whoAmI };
const sphere = { label: 'sphere' };

console.log(cube.whoAmI());              // method call: cube
console.log(whoAmI.call(sphere));        // explicit: sphere
const detached = cube.whoAmI;
console.log(detached());                 // plain call: global object (sloppy) / undefined (strict)
const bound = whoAmI.bind(sphere);
console.log(bound(), bound.call(cube));  // bind wins over call
```

`call` and `apply` differ only in how arguments are passed (`apply` takes an array; with spread syntax you rarely need it). `bind` returns a new function with `this` (and optionally leading arguments) fixed permanently.

### Losing this in callbacks

The single most common `this` bug: passing a method as a callback. The callee calls it as a plain function, so `this` is gone. Class bodies are always strict, so inside a class method that means `this === undefined` and a `TypeError`.

```js
class MeshBuilder {
  constructor() { this.vertices = []; }
  addVertex(v) { this.vertices.push(v); return this.vertices.length; }
}
const mb = new MeshBuilder();
try {
  [[0, 0, 0], [1, 0, 0]].forEach(mb.addVertex);     // passes the function, not the binding
} catch (e) { console.log(e.name + ': ' + e.message); }

[[0, 0, 0]].forEach(v => mb.addVertex(v));        // fix 1: wrap in an arrow
[[1, 0, 0]].forEach(mb.addVertex.bind(mb));       // fix 2: bind
[[0, 1, 0]].forEach(mb.addVertex, mb);            // fix 3: many array methods take a thisArg
console.log(mb.vertices.length);
```

Fix 4 is to define the method as an arrow-valued class field (`addVertex = (v) => {...}`), shown below, which has a cost.

### Arrows capture this

Arrows are the fix for the pre-2015 `var self = this` dance: a callback written inside a method sees the method's `this`.

```js
const terrain = {
  label: 'island',
  heights: [0.25, 0.5, 0.875],
  max: 1,
  raise(amount) {
    // arrow: this is terrain, from raise's call
    this.heights = this.heights.map(h => Math.min(this.max, h + amount));
    return this.heights;
  },
  broken: () => typeof this,   // arrow at object level: this from the enclosing scope, not the object
};
console.log(terrain.raise(0.25), terrain.broken());
```

Don't use arrows as object methods (the `broken` case): an object literal doesn't create a scope, so `this` is whatever it was outside.

## Prototypes

Every object has a hidden link to another object, its **prototype** (`Object.getPrototypeOf(obj)`, historically `obj.__proto__`). Reading a property that isn't on the object itself walks up the chain: object, its prototype, the prototype's prototype, until `null`. Writing always goes to the object itself (shadowing, not modifying, the prototype's copy).

```js
const materialProto = {
  describe() { return `${this.kind}, roughness ${this.roughness}`; },
  roughness: 0.5,                           // a shared default
};
const stone = Object.create(materialProto);
stone.kind = 'stone';
const chrome = Object.create(materialProto);
chrome.kind = 'chrome';
chrome.roughness = 0.05;                    // own property shadows the prototype's

console.log(stone.describe(), '|', chrome.describe());
console.log(Object.hasOwn(stone, 'roughness'), 'roughness' in stone, Object.keys(stone));
console.log(Object.getPrototypeOf(stone) === materialProto, Object.getPrototypeOf(materialProto) === Object.prototype);
```

That's the whole object model. Methods live once on a shared prototype; instances hold only their data. A C# class does the same thing internally (instance fields per object, methods in the type's method table); JavaScript makes the table an ordinary object you can see and modify.

**Never put mutable shared state on a prototype.** An array default on the prototype is one array shared by every instance, and `stone.layers.push(...)` mutates it for all of them (reading `layers` finds the prototype's array; `push` mutates it rather than assigning).

### Constructor functions: what classes compile to

```js
function Vec(x, y) { this.x = x; this.y = y; }       // called with new
Vec.prototype.len = function () { return Math.hypot(this.x, this.y); };

const v = new Vec(3, 4);
console.log(v.len(), v instanceof Vec, Object.getPrototypeOf(v) === Vec.prototype, v.constructor === Vec);
```

`new Vec(3, 4)` does four things: create an object whose prototype is `Vec.prototype`; call `Vec` with `this` set to it; if `Vec` returns an object, use that instead; otherwise return the new object. `a instanceof B` walks `a`'s prototype chain looking for `B.prototype`. You'll implement both in the exercises.

## Classes

`class` is cleaner syntax for the same prototype machinery, with a few real additions: private fields, static blocks, and enforced `new` (calling a class without `new` throws). Class bodies are always strict mode.

```js
class Texture {
  static #nextId = 1;            // private static
  static count = 0;              // public static, lives on the class itself

  id = Texture.#nextId++;        // public instance field, initialized per instance
  #data;                         // private instance field

  constructor(width, height) {
    this.width = width;
    this.height = height;
    this.#data = new Uint8ClampedArray(width * height * 4);   // RGBA bytes
    Texture.count++;
  }

  get byteLength() { return this.#data.length; }               // accessor on the prototype
  get pixelCount() { return this.width * this.height; }

  setPixel(x, y, r, g, b, a = 255) {                           // method on the prototype
    const i = (y * this.width + x) * 4;
    this.#data[i] = r; this.#data[i + 1] = g; this.#data[i + 2] = b; this.#data[i + 3] = a;
    return this;                                               // enables chaining
  }
  getPixel(x, y) {
    const i = (y * this.width + x) * 4;
    return [this.#data[i], this.#data[i + 1], this.#data[i + 2], this.#data[i + 3]];
  }

  static compareSize(a, b) { return a.pixelCount - b.pixelCount; }
  toString() { return `Texture#${this.id} ${this.width}x${this.height}`; }
}

const a = new Texture(4, 4), b = new Texture(2, 2);
a.setPixel(1, 2, 255, 128, 300).setPixel(0, 0, -5, 0, 0);    // Uint8ClampedArray clamps to 0..255
console.log(`${a}`, a.byteLength, a.getPixel(1, 2), a.getPixel(0, 0), Texture.count);
console.log(a, Object.keys(a));                // #data isn't a property: invisible to keys and JSON
console.log([a, b].toSorted(Texture.compareSize).map(String));
a.byteLength = 0;                              // getter only: ignored in sloppy code like this, a TypeError in strict code
console.log(a.byteLength);
try { Texture(1, 1); } catch (e) { console.log(e.message); }
```

Notes for C# eyes:

- **Fields** are per-instance and initialized in declaration order, before the constructor body runs (in a subclass: right after `super()` returns).
- **`#private`** is hard privacy, enforced by the engine: `obj.#data` from outside the class is a syntax error, and there's no reflection to get around it. `#data in obj` is a brand check ("was this object constructed by my class?"). The older convention `_data` is just a name.
- **`static`** members live on the constructor function. Statics are inherited: `class HdrTexture extends Texture` gets `HdrTexture.compareSize`.
- **No overloading**, no `protected`, no interfaces, no abstract keyword. Duck typing fills the gap: anything with a `sample(u, v)` method is a texture source. Simulate `abstract` by throwing in the base method.
- Methods aren't `virtual` or non-virtual: every call is dynamic dispatch through the prototype chain.

> **Performance:** look at what `getPixel` returns: a fresh 4-element array per call. Calling it for every pixel of a 2048x2048 texture allocates 4 million arrays. Hot APIs avoid that by returning one channel (`getChannel(x, y, c)`), writing into a caller-provided `out` array, or simply exposing the underlying typed array so the caller loops over it directly. Convenience methods are for tests and tools; bulk work goes straight at the buffer.

### Getters, setters, and validation

```js
class Exposure {
  #stops = 0;
  constructor(min, max) { this.min = min; this.max = max; }
  get stops() { return this.#stops; }
  set stops(v) { this.#stops = Math.min(this.max, Math.max(this.min, v)); }   // clamp on write
  get multiplier() { return 2 ** this.#stops; }                               // derived value
}
const ev = new Exposure(-4, 4);
ev.stops = 10;
ev.stops -= 2;
console.log(ev.stops, ev.multiplier);
```

### Arrow fields: auto-bound but per instance

```js
class Slider {
  changes = 0;
  onInput = () => { this.changes++; };   // a new function per instance, this bound to it
  nudge() { this.changes++; }            // one function on the prototype, shared
}
const s = new Slider();
const handler = s.onInput;
handler(); handler();
console.log(s.changes, Object.keys(s), new Slider().onInput === s.onInput, new Slider().nudge === s.nudge);
```

> **Performance:** an arrow field is a closure allocated for every instance and stored on it. For a UI with ten sliders, who cares. For 100,000 scattered instances of a `Pebble` class, that's 100,000 extra function objects per method, and bigger objects. Keep methods on the prototype for anything you create in bulk; bind only where a callback is actually needed. Equally, initialize **every** field in the constructor or as a field declaration, so all instances share one shape. Adding a property later to some instances (`if (wet) p.gloss = 1`) splits them into different shapes and makes every call site that touches them slower.

## Inheritance and super

```js
class Light {
  constructor(name, intensity) { this.name = name; this.intensity = intensity; }
  // irradiance at distance d (inverse square)
  at(d) { return this.intensity / (d * d); }
  describe() { return `${this.name} (${this.intensity})`; }
}

class SpotLight extends Light {
  constructor(name, intensity, coneDeg) {
    super(name, intensity);          // must run before touching this
    this.cosCone = Math.cos(coneDeg * Math.PI / 180);
  }
  at(d, cosAngle = 1) {              // override
    return cosAngle < this.cosCone ? 0 : super.at(d);   // call the base version
  }
  describe() { return `${super.describe()} [spot]`; }
}

const spot = new SpotLight('key', 100, 30);
console.log(spot.at(2), spot.at(2, 0.5), spot.describe());
console.log(spot instanceof SpotLight, spot instanceof Light, Object.getPrototypeOf(SpotLight.prototype) === Light.prototype);
```

- A derived constructor **must** call `super(...)` before using `this` (a `ReferenceError` otherwise), and if it has no constructor, one that forwards all arguments is generated.
- `super.method()` calls the parent's version, like C#'s `base.Method()`.
- There's one gotcha C# also has: a base constructor that calls an overridden method runs the derived override **before** the derived class's fields are initialized. Avoid calling overridable methods from constructors.
- You can extend built-ins: `class Palette extends Array`, `class ShaderError extends Error`. Custom errors should set `this.name`.

```js
class ShaderError extends Error {
  constructor(message, line) { super(message); this.name = 'ShaderError'; this.line = line; }
}
try { throw new ShaderError('unknown identifier "nrm"', 42); } catch (e) {
  console.log(e instanceof ShaderError, e instanceof Error, e.name, e.line, String(e));
}
```

### instanceof and its limits

`x instanceof C` checks whether `C.prototype` is on `x`'s chain. It fails across realms (an array from another iframe or worker isn't `instanceof` your `Array`; use `Array.isArray`), and it says nothing about objects that merely have the right shape. For duck typing, check for the method: `typeof src.sample === 'function'`.

## Composition and mixins

Deep inheritance hierarchies (`Node > Mesh > SkinnedMesh > InstancedSkinnedMesh`) age badly; most engines moved towards composition. JavaScript has two lightweight options.

**Mixins**: a function from a class to a subclass. Since `extends` takes any expression, you can stack them:

```js
const Positioned = Base => class extends Base {
  x = 0; y = 0; z = 0;
  translate(dx, dy, dz) { this.x += dx; this.y += dy; this.z += dz; return this; }
};
const Tinted = Base => class extends Base {
  color = [1, 1, 1];
  tint(r, g, b) { this.color = [this.color[0] * r, this.color[1] * g, this.color[2] * b]; return this; }
};
class SceneNode {}
class Billboard extends Tinted(Positioned(SceneNode)) {
  describe() { return `billboard at ${this.x},${this.y},${this.z}`; }
}
const bb = new Billboard().translate(3, 4, 0).tint(1, 0.5, 0.5);
console.log(bb, bb.describe());
```

**Composition**: a scene node *has* components (plain objects), and systems loop over the nodes that have the components they need. That's the start of an entity-component-system.

```js
const nodes = [
  { id: 1, transform: { x: 0, y: 0 }, spin: { speed: 1 } },
  { id: 2, transform: { x: 5, y: 5 } },                             // static: no spin
  { id: 3, transform: { x: 0, y: 0 }, spin: { speed: 2 }, mesh: { tris: 12 } },
];
function spinSystem(list, dt) {
  for (const n of list) if (n.spin) n.transform.angle = (n.transform.angle ?? 0) + n.spin.speed * dt;
}
spinSystem(nodes, 0.5);
console.log(nodes.map(n => n.transform));
```

(That `angle` added on the fly to some transforms is exactly the shape instability the performance notes warn about; a real system would initialize it everywhere.)

## C# classes versus JavaScript classes

| C# | JavaScript |
|---|---|
| `private byte[] data;` | `#data;` (hard private) or `_data` (convention only) |
| `protected` | no equivalent (convention, or symbols) |
| `public int Width { get; private set; }` | `#width` plus `get width()` |
| `static` | `static` (inherited by subclasses) |
| `base.M()` | `super.m()` |
| `abstract` / `interface` | duck typing; throw in a base method; TypeScript for checking |
| overloads | one function that inspects its arguments, or options objects |
| `virtual` / `override` | every method is overridable |
| `struct` value types (`Vector3`) | no equivalent; objects are always references |
| `sealed` | no equivalent (`Object.freeze` on the prototype, rarely) |
| extension methods | adding to a prototype: possible, but don't patch built-ins |
| `this` always bound | depends on the call: see the start of this chapter |

> **Performance:** there are no value-type structs, so `new Vec3(x, y, z)` per operation is a heap allocation. A math library where `a.add(b)` returns a new vector is pleasant and fine at setup time, but in a per-vertex loop it makes garbage proportional to vertex count. Real libraries (gl-matrix is the classic) provide out-parameter functions like `vec3.add(out, a, b)` writing into preallocated vectors, reuse scratch vectors, and store bulk data in `Float32Array`s rather than in objects at all.

=== exercise vec2
title: Vec2
--- prompt
Write a `class Vec2` for 2D graphics math.

- `constructor(x = 0, y = 0)` storing public fields `x`, `y`.
- `add(v)`, `sub(v)`, `scale(s)`: return **new** vectors.
- `get length()`: the Euclidean length.
- `normalized()`: a new unit vector in the same direction; the zero vector normalizes to `(0, 0)` (not `NaN`).
- `dot(v)`.
- `equals(v, eps = 1e-9)`: component-wise within `eps`.
- `static fromAngle(rad, len = 1)`: `(cos·len, sin·len)`.
- In-place variants for hot loops, which **mutate `this` and return `this`** (so they chain and allocate nothing): `addScaledInPlace(v, s)` (adds `v * s`, the classic `pos += vel * dt` of a particle step) and `set(x, y)`.
- `toString()` returning `Vec2(x, y)`, e.g. `Vec2(1, -2.5)`.
--- starter
class Vec2 {
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }
}
--- solution
class Vec2 {
  constructor(x = 0, y = 0) {
    this.x = x;
    this.y = y;
  }
  add(v) { return new Vec2(this.x + v.x, this.y + v.y); }
  sub(v) { return new Vec2(this.x - v.x, this.y - v.y); }
  scale(s) { return new Vec2(this.x * s, this.y * s); }
  get length() { return Math.hypot(this.x, this.y); }
  normalized() {
    const len = this.length;
    return len === 0 ? new Vec2(0, 0) : new Vec2(this.x / len, this.y / len);
  }
  dot(v) { return this.x * v.x + this.y * v.y; }
  equals(v, eps = 1e-9) { return Math.abs(this.x - v.x) <= eps && Math.abs(this.y - v.y) <= eps; }
  static fromAngle(rad, len = 1) { return new Vec2(Math.cos(rad) * len, Math.sin(rad) * len); }
  addScaledInPlace(v, s) { this.x += v.x * s; this.y += v.y * s; return this; }
  set(x, y) { this.x = x; this.y = y; return this; }
  toString() { return `Vec2(${this.x}, ${this.y})`; }
}
--- hint
`get length() { ... }` defines an accessor: callers write `v.length`, no parentheses.
--- hint
In-place methods end with `return this;`. `static fromAngle` is called as `Vec2.fromAngle(...)`.
--- harness
{
  const a = new Vec2(3, 4), b = new Vec2(1, -2);
  eq(a.add(b), new Vec2(4, 2));
  eq(a.sub(b), new Vec2(2, 6));
  eq(a.scale(2), new Vec2(6, 8));
  eq(a, new Vec2(3, 4), 'add/sub/scale do not mutate');
  check(a.add(b) instanceof Vec2, 'returns Vec2 instances');
  eq(a.length, 5);
  eq(new Vec2().length, 0);
  eq([new Vec2().x, new Vec2().y], [0, 0], 'defaults');
  check(a.normalized().equals(new Vec2(0.6, 0.8)), 'normalized');
  eq(new Vec2(0, 0).normalized(), new Vec2(0, 0), 'zero vector');
  eq(a.dot(b), -5);
  check(Vec2.fromAngle(Math.PI / 2, 2).equals(new Vec2(0, 2)), 'fromAngle');
  check(Vec2.fromAngle(0).equals(new Vec2(1, 0)), 'fromAngle default len');
  check(!a.equals(new Vec2(3, 4.001)), 'equals eps');
  check(a.equals(new Vec2(3, 4.001), 0.01), 'equals custom eps');

  check(r === p, 'in-place returns this');
  eq([p.x, p.y], [11, 8]);
  eq(p.set(1, 2).addScaledInPlace(new Vec2(1, 1), 3), new Vec2(4, 5), 'chaining');
  eq(String(new Vec2(1, -2.5)), 'Vec2(1, -2.5)');
  eq(`${new Vec2()}`, 'Vec2(0, 0)');

}

=== exercise emitter
title: Event emitter
--- prompt
A long-running generator reports what it's doing through events: `'progress'`, `'tile'` (a tile of the texture finished), `'done'`. Write `class Emitter` with:

- `on(event, handler)`: subscribe; returns a function that unsubscribes this handler.
- `off(event, handler)`: unsubscribe (removes one registration; no-op if absent).
- `once(event, handler)`: subscribe for a single emit. `off(event, handler)` with the original handler must also cancel a pending `once`.
- `emit(event, ...args)`: call the event's handlers in subscription order with the args, and return how many were called.

Edge cases that real emitters get wrong, all tested:

- A handler that unsubscribes itself (or another handler) during `emit` must not cause handlers to be skipped in that emit. Handlers added during an emit are not called until the next one.
- The same handler subscribed twice is called twice.
- Handlers are called with `this` set to the emitter.
- Different events and different emitters are independent.
--- starter
class Emitter {
  handlers = {};
  on(event, handler) {
    this.handlers[event] = handler;
  }
  emit(event, ...args) {
    this.handlers[event](...args);
  }
}
--- solution
class Emitter {
  #map = new Map();

  on(event, handler) {
    return this.#add(event, { handler, fn: handler });
  }

  once(event, handler) {
    const entry = { handler, fn: null };
    entry.fn = (...args) => {
      this.#remove(event, entry);
      return handler.apply(this, args);
    };
    return this.#add(event, entry);
  }

  off(event, handler) {
    const list = this.#map.get(event);
    if (!list) return;
    const i = list.findIndex(e => e.handler === handler);
    if (i >= 0) this.#remove(event, list[i]);
  }

  emit(event, ...args) {
    const list = this.#map.get(event);
    if (!list) return 0;
    const snapshot = list.slice();
    let called = 0;
    for (const entry of snapshot) {
      if (!entry.removed) {
        called++;
        entry.fn.apply(this, args);
      }
    }
    return called;
  }

  #add(event, entry) {
    if (!this.#map.has(event)) this.#map.set(event, []);
    this.#map.get(event).push(entry);
    return () => this.#remove(event, entry);
  }

  #remove(event, entry) {
    const list = this.#map.get(event);
    const i = list ? list.indexOf(entry) : -1;
    if (i >= 0) { list.splice(i, 1); entry.removed = true; }
  }
}
--- hint
Store an entry object per registration (`{ handler, fn }`) rather than bare functions, so `once` wrappers can be found by their original handler and duplicates stay distinct.
--- hint
In `emit`, iterate over a copy of the list so removals don't shift indexes under you. But a handler removed during the emit, before its turn, should not be called: mark entries as removed and skip them.
--- harness
{
  const em = new Emitter();
  const log = [];
  const a = (x) => log.push('a' + x), b = (x) => log.push('b' + x);
  const unA = em.on('hit', a);
  em.on('hit', b);
  eq(em.emit('hit', 1), 2);
  eq(log, ['a1', 'b1']);
  unA();
  eq(em.emit('hit', 2), 1);
  eq(log, ['a1', 'b1', 'b2']);
  em.off('hit', b);
  eq(em.emit('hit', 3), 0);
  eq(em.emit('nothing'), 0, 'unknown event');
  em.off('nothing', a);

  const em2 = new Emitter();
  let n = 0;
  em2.once('go', () => n++);
  eq([em2.emit('go'), em2.emit('go')], [1, 0]);
  eq(n, 1, 'once fires once');
  const h = () => n++;
  em2.once('go', h);
  em2.off('go', h);
  eq(em2.emit('go'), 0, 'off cancels once');

  const em3 = new Emitter(), order = [];
  const self = () => { order.push('self'); em3.off('t', self); };
  const next = () => order.push('next');
  em3.on('t', self); em3.on('t', next);
  eq(em3.emit('t'), 2, 'self-removal does not skip the next handler');
  eq(order, ['self', 'next']);
  eq(em3.emit('t'), 1);

  const em4 = new Emitter(), seen = [];
  const second = () => seen.push('second');
  em4.on('t', () => { seen.push('first'); em4.off('t', second); });
  em4.on('t', second);
  eq(em4.emit('t'), 1, 'handler removed before its turn is not called');
  eq(seen, ['first']);

  const em5 = new Emitter(), adds = [];
  em5.on('t', () => { adds.push('outer'); em5.on('t', () => adds.push('inner')); });
  em5.emit('t');
  eq(adds, ['outer'], 'added during emit not called yet');

  const em6 = new Emitter();
  let dup = 0;
  const d = () => dup++;
  em6.on('t', d); em6.on('t', d);
  em6.emit('t');
  eq(dup, 2, 'duplicates called twice');
  em6.off('t', d);
  em6.emit('t');
  eq(dup, 3, 'off removes one registration');

  const em7 = new Emitter();
  let who = null;
  em7.on('t', function () { who = this; });
  em7.emit('t');
  check(who === em7, 'this is the emitter');
  let args = null;
  em7.once('u', function (...a) { args = [this === em7, ...a]; });
  em7.emit('u', 1, 2);
  eq(args, [true, 1, 2], 'once passes this and args');

  const x1 = new Emitter(), x2 = new Emitter();
  let c = 0;
  x1.on('t', () => c++);
  x2.emit('t');
  eq(c, 0, 'emitters independent');
}

=== exercise shapes
title: A signed distance shape hierarchy
--- prompt
A **signed distance function** (SDF) returns, for a point, the distance to a shape's surface: negative inside, zero on the edge, positive outside. SDFs are the backbone of procedural 2D graphics (crisp vector shapes in shaders) and of ray-marched 3D scenes. Write a small class hierarchy:

**`Shape`**: `constructor(name)`. The name is **private** (`#name`) with a read-only getter `name`. `distance(x, y)` throws an `Error` (it's "abstract"). `contains(x, y)` is `distance(x, y) <= 0`. `toString()` returns `` `${name} area=${area.toFixed(2)}` `` using the subclass's `area` getter. A static `Shape.created` counts all shapes ever constructed, including subclasses.

**`Circle extends Shape`**: `constructor(cx, cy, r, name = 'circle')`. Distance: `hypot(x - cx, y - cy) - r`. `get area()`: `π r²`.

**`Box extends Shape`**: `constructor(cx, cy, hw, hh)` (half width and height), name `'box'`. The exact box SDF:

```text
dx = |x - cx| - hw,  dy = |y - cy| - hh
distance = hypot(max(dx, 0), max(dy, 0)) + min(max(dx, dy), 0)
```

`get area()`: `4 · hw · hh`.

**`Ring extends Circle`**: `constructor(cx, cy, r, thickness)`, name `'ring'`. Distance: `|circle distance| - thickness / 2` (the classic "onion" operation, reusing the parent via `super`). `get area()`: `2π r · thickness`.
--- starter
class Shape {
  constructor(name) { this.name = name; }
}
class Circle extends Shape {}
class Box extends Shape {}
class Ring extends Circle {}
--- solution
class Shape {
  static created = 0;
  #name;
  constructor(name) {
    this.#name = name;
    Shape.created++;
  }
  get name() { return this.#name; }
  distance(x, y) { throw new Error('distance is abstract'); }
  contains(x, y) { return this.distance(x, y) <= 0; }
  toString() { return `${this.#name} area=${this.area.toFixed(2)}`; }
}

class Circle extends Shape {
  constructor(cx, cy, r, name = 'circle') {
    super(name);
    this.cx = cx; this.cy = cy; this.r = r;
  }
  distance(x, y) { return Math.hypot(x - this.cx, y - this.cy) - this.r; }
  get area() { return Math.PI * this.r * this.r; }
}

class Box extends Shape {
  constructor(cx, cy, hw, hh) {
    super('box');
    this.cx = cx; this.cy = cy; this.hw = hw; this.hh = hh;
  }
  distance(x, y) {
    const dx = Math.abs(x - this.cx) - this.hw, dy = Math.abs(y - this.cy) - this.hh;
    return Math.hypot(Math.max(dx, 0), Math.max(dy, 0)) + Math.min(Math.max(dx, dy), 0);
  }
  get area() { return 4 * this.hw * this.hh; }
}

class Ring extends Circle {
  constructor(cx, cy, r, thickness) {
    super(cx, cy, r, 'ring');
    this.thickness = thickness;
  }
  distance(x, y) { return Math.abs(super.distance(x, y)) - this.thickness / 2; }
  get area() { return 2 * Math.PI * this.r * this.thickness; }
}
--- hint
`Shape` can't know the area, but `toString` can still read `this.area`: the getter is looked up on the actual object's prototype chain, so the subclass's getter runs.
--- hint
In `Ring`, `super.distance(x, y)` calls `Circle`'s version with `this` still being the ring.
--- hint
Count with `Shape.created++` in `Shape`'s constructor. `this.constructor.created++` would create a separate counter on each subclass the first time it runs.
--- harness
{
  const before = Shape.created;
  const c = new Circle(0, 0, 2);
  near(c.distance(3, 4), 3);
  near(c.distance(0, 0), -2);
  check(c.contains(1, 1) && !c.contains(2, 2), 'contains');
  check(c.contains(2, 0), 'edge counts as inside');
  near(c.area, Math.PI * 4);
  eq(c.name, 'circle');
  try { c.name = 'x'; } catch {}
  eq(c.name, 'circle', 'name is read-only');
  check(!Object.keys(c).includes('name'), 'name is private, not an own property');
  eq(String(c), 'circle area=12.57');

  const b = new Box(1, 1, 2, 1);
  near(b.distance(1, 1), -1, 1e-9, 'centre: nearest edge is 1 away');
  near(b.distance(4, 1), 1, 1e-9, 'right of box');
  near(b.distance(1, 3.5), 1.5, 1e-9, 'above box');
  near(b.distance(6, 6), 5, 1e-9, 'corner region: hypot(3, 4)');
  near(b.distance(2.5, 1.2), -0.5, 1e-9, 'inside near right edge');
  eq(b.area, 8);
  eq(`${b}`, 'box area=8.00');

=== exercise mixins
title: Mixins
--- prompt
Write two mixins, functions that take a base class and return a subclass:

- `Transformable(Base)`: adds fields `x = 0`, `y = 0`, `z = 0`, `scale = 1`, and methods `translate(dx, dy, dz)` and `scaleBy(s)` (multiplies `scale`), both returning `this`.
- `Colored(Base)`: adds a field `color`, a **new** array copied from a static `defaultColor` on the **final** class (`this.constructor.defaultColor`, or `[1, 1, 1]` if the class doesn't define one), plus `tint(r, g, b)` (multiplies each channel, returns `this`) and `get luminance()`: `0.2126 r + 0.7152 g + 0.0722 b`.

Then define `class Sprite extends Colored(Transformable(Object))` with `static defaultColor = [1, 0.5, 0]` and a `name` set from its constructor's argument.

Mixins must not interfere with a base class's constructor arguments: `Colored(Transformable(Named))` where `Named`'s constructor takes `(name)` must still receive it. Tinting one object must never change another's color or the class default.
--- starter
const Transformable = Base => Base;
const Colored = Base => Base;
class Sprite {}
--- solution
const Transformable = Base => class extends Base {
  x = 0; y = 0; z = 0; scale = 1;
  translate(dx, dy, dz) { this.x += dx; this.y += dy; this.z += dz; return this; }
  scaleBy(s) { this.scale *= s; return this; }
};

const Colored = Base => class extends Base {
  color = [...(this.constructor.defaultColor ?? [1, 1, 1])];
  tint(r, g, b) { this.color[0] *= r; this.color[1] *= g; this.color[2] *= b; return this; }
  get luminance() { const [r, g, b] = this.color; return 0.2126 * r + 0.7152 * g + 0.0722 * b; }
};

class Sprite extends Colored(Transformable(Object)) {
  static defaultColor = [1, 0.5, 0];
  constructor(name) {
    super();
    this.name = name;
  }
}
--- hint
`const Transformable = Base => class extends Base { ... }`. Without an explicit constructor, the generated one forwards all arguments to `Base`.
--- hint
A field initializer can read `this.constructor`: it runs during construction, after the base constructors, with `this` being the final object. Copy the default with spread, or every object would share (and tint) one array.
--- harness
{
  const s = new Sprite('spark');
  eq([s.name, s.x, s.y, s.z, s.scale], ['spark', 0, 0, 0, 1]);
  eq(s.color, [1, 0.5, 0]);
  check(s.translate(1, 2, 3) === s && s.scaleBy(2) === s, 'chaining returns this');
  eq([s.x, s.y, s.z, s.scale], [1, 2, 3, 2]);
  s.translate(-1, 0, 1).scaleBy(0.25);
  eq([s.x, s.z, s.scale], [0, 4, 0.5]);
  s.tint(0.5, 0.5, 1);
  eq(s.color, [0.5, 0.25, 0]);
  eq(Sprite.defaultColor, [1, 0.5, 0], 'class default untouched');
  eq(new Sprite('b').color, [1, 0.5, 0], 'other sprites untouched');
  near(new Sprite('c').luminance, 0.2126 + 0.7152 * 0.5);

  class Named { constructor(name) { this.name = name; } }
  class Marker extends Colored(Transformable(Named)) {}
  const m = new Marker('pin');
  eq([m.name, m.color], ['pin', [1, 1, 1]], 'base args forwarded, default white');
  near(m.luminance, 1);
  check(m instanceof Named, 'instanceof base');
  class Red extends Colored(Object) { static defaultColor = [1, 0, 0]; }
  eq(new Red().color, [1, 0, 0]);
  check(!Object.hasOwn(m, 'translate') && !Object.hasOwn(m, 'tint'), 'methods on prototypes, not instances');
}

=== exercise pool
title: Object pool
--- prompt
Particles live for a fraction of a second. Creating and discarding thousands per second feeds the garbage collector; a pool recycles them instead. Write `class Pool`:

- `constructor(create, reset)`: `create()` makes a new object; `reset(obj)` prepares a recycled one.
- `acquire()`: returns a free object if there is one (after calling `reset` on it), otherwise a new one from `create()`.
- `release(obj)`: returns `obj` to the pool. Releasing an object that isn't currently in use (released twice, or never acquired from this pool) throws an `Error`.
- `get inUse()` and `get free()`: counts.
- `prewarm(n)`: creates objects until at least `n` are free.

`acquire` and `release` must be O(1) (tested with 200,000 objects, so no `indexOf`/`includes` scans over arrays). Hint: a `Set` gives O(1) membership.
--- starter
class Pool {
  constructor(create, reset) {
    this.create = create;
  }
  acquire() { return this.create(); }
  release(obj) {}
}
--- solution
class Pool {
  #create; #reset;
  #free = [];
  #used = new Set();

  constructor(create, reset) {
    this.#create = create;
    this.#reset = reset;
  }

  acquire() {
    let obj;
    if (this.#free.length) {
      obj = this.#free.pop();
      this.#reset(obj);
    } else {
      obj = this.#create();
    }
    this.#used.add(obj);
    return obj;
  }

  release(obj) {
    if (!this.#used.delete(obj)) throw new Error('object not in use');
    this.#free.push(obj);
  }

  prewarm(n) {
    while (this.#free.length < n) this.#free.push(this.#create());
  }

  get inUse() { return this.#used.size; }
  get free() { return this.#free.length; }
}
--- hint
Keep free objects in an array used as a stack (`push`/`pop` are O(1)) and the in-use ones in a `Set`.
--- hint
`set.delete(obj)` returns `false` when `obj` wasn't there: that's your double-release check in one O(1) call.
--- harness
{
  let made = 0, resets = 0;
  const pool = new Pool(() => ({ id: made++, x: 0, alive: true }), b => { resets++; b.x = 0; b.alive = true; });
  const a = pool.acquire(), b = pool.acquire();
  eq([made, pool.inUse, pool.free], [2, 2, 0]);
  a.x = 50; a.alive = false;
  pool.release(a);
  eq([pool.inUse, pool.free], [1, 1]);
  const c = pool.acquire();
  check(c === a, 'recycled the same object');
  eq([c.x, c.alive, resets, made], [0, true, 1, 2], 'reset was called, nothing new created');
  throws(() => { pool.release(b); pool.release(b); }, 'double release throws');
  throws(() => pool.release({}), 'foreign object throws');
  eq([pool.inUse, pool.free], [1, 1]);
  pool.prewarm(10);
  eq([pool.free, made], [10, 11]);
  pool.prewarm(5);
  eq(pool.free, 10, 'prewarm is "at least"');

  const big = new Pool(() => ({}), () => {});
  const N = 200000, objs = new Array(N);
  const t = performance.now();
  for (let i = 0; i < N; i++) objs[i] = big.acquire();
  for (let i = 0; i < N; i++) big.release(objs[i]);
  for (let i = 0; i < N; i++) objs[i] = big.acquire();
  const ms = performance.now() - t;
  eq([big.inUse, big.free], [N, 0]);
  check(ms < 500, `200k acquire/release took ${ms.toFixed(0)} ms (want < 500)`);
}

=== exercise protoMagic
title: new and instanceof by hand
--- prompt
Implement the two operators yourself, using only `Object.create`, `Object.getPrototypeOf` and function calls:

- `construct(Ctor, ...args)`: behaves like `new Ctor(...args)` for **constructor functions** (not classes, which refuse to be called without `new`). Create an object whose prototype is `Ctor.prototype`, call `Ctor` with it as `this`, and return the constructor's return value if that is an object (or function), otherwise the new object.
- `isInstance(obj, Ctor)`: like `obj instanceof Ctor`. Primitives (and `null`/`undefined`) are never instances. Walk the prototype chain of `obj` looking for `Ctor.prototype`.
--- starter
function construct(Ctor, ...args) {
  return Ctor(...args);
}

function isInstance(obj, Ctor) {
  return obj.constructor === Ctor;
}
--- solution
function construct(Ctor, ...args) {
  const obj = Object.create(Ctor.prototype);
  const result = Ctor.apply(obj, args);
  return (result !== null && typeof result === 'object') || typeof result === 'function' ? result : obj;
}

function isInstance(obj, Ctor) {
  if (obj === null || (typeof obj !== 'object' && typeof obj !== 'function')) return false;
  let p = Object.getPrototypeOf(obj);
  while (p !== null) {
    if (p === Ctor.prototype) return true;
    p = Object.getPrototypeOf(p);
  }
  return false;
}
--- hint
`Ctor.apply(obj, args)` calls the constructor with `this = obj`.
--- hint
`obj.constructor` can be overwritten and isn't how `instanceof` works. Loop `p = Object.getPrototypeOf(p)` until `null`.
--- harness
{
  function Shape3D(kind, hp) { this.kind = kind; this.hp = hp; }
  Shape3D.prototype.label = function () { return this.kind + '!'; };
  function Sphere(hp) { Shape3D.call(this, 'sphere', hp); }
  Sphere.prototype = Object.create(Shape3D.prototype);
  Sphere.prototype.constructor = Sphere;

  const m = construct(Shape3D, 'cube', 5);
  eq([m.kind, m.hp, m.label()], ['cube', 5, 'cube!']);
  check(Object.getPrototypeOf(m) === Shape3D.prototype, 'prototype set');
  const d = construct(Sphere, 50);
  eq(d.label(), 'sphere!');
  check(isInstance(d, Sphere) && isInstance(d, Shape3D) && isInstance(d, Object), 'chain');
  check(!isInstance(m, Sphere), 'not a sphere');
  check(isInstance(m, Shape3D) === (m instanceof Shape3D), 'agrees with instanceof');

  function ReturnsObj() { this.a = 1; return { b: 2 }; }
  eq(construct(ReturnsObj), { b: 2 }, 'returned object wins');
  function ReturnsPrim() { this.a = 1; return 42; }
  eq(construct(ReturnsPrim).a, 1, 'returned primitive ignored');
  function ReturnsNull() { this.a = 1; return null; }
  eq(construct(ReturnsNull).a, 1, 'returned null ignored');
  const fn = () => 1;
  function ReturnsFn() { return fn; }
  check(construct(ReturnsFn) === fn, 'returned function wins');

  check(!isInstance(5, Number), 'primitives are not instances');
  check(!isInstance(null, Object) && !isInstance(undefined, Object), 'null/undefined');
  check(isInstance([], Array) && isInstance([], Object), 'arrays');
  check(isInstance(fn, Function), 'functions are objects');
  check(!isInstance(Object.create(null), Object), 'null prototype');
  const fake = { constructor: Shape3D };
  check(!isInstance(fake, Shape3D), 'constructor property is not proof');
  class Real {}
  check(isInstance(new Real(), Real), 'works with class instances');
}
