## Putting it together

The exercises in this chapter are the unglamorous core of a game engine: the pieces that sit underneath rendering and gameplay and that every frame leans on. They are larger than earlier exercises. Expect to spend an hour or more on some, to write helper functions, and to run your code many times. Several are **multi-step**: a later step starts from your solution to the earlier one and extends it, the way real code grows.

The tests are thorough. Some feed hostile input, and several are **performance tests**: they push hundreds of thousands of items through your code, and an O(n²) solution will time out even though it gives the right answers. That is deliberate. In a game, a correct answer that takes 40 ms is a bug, because the whole frame budget is 16.6 ms at 60 fps.

(The separate game development track covers tile maps, physics, entities, procedural generation, pathfinding and whole games. This chapter builds the infrastructure those things sit on.)

General advice:

- **Design the data first.** Decide what structs you need, which arrays are contiguous, and who owns each allocation, before writing logic.
- **Write small `static` helpers.** A 200-line function is as hard to debug in C as anywhere else.
- **Test incrementally**: the playground's stdin box for programs, or your own `main` for function exercises (it is renamed out of the way when the tests run).
- **Keep the sanitizers on.** Every one of these has a natural off-by-one or leak waiting to happen.

> **Performance:** the recurring theme is *no allocation in the hot path*. Each structure here allocates rarely (geometric growth, or once up front) and then reuses its memory. Allocation in a frame loop costs time, fragments the heap, and makes frame times jittery; keep it out.

## The projects

### String builder (2 steps)

C# has `StringBuilder`; JavaScript has `array.join`. In C you build one: a heap buffer with a length and a capacity that grows geometrically, so `n` appends cost O(n) in total rather than O(n²). A game uses one for the HUD, the debug overlay and the console log, *cleared and reused every frame*: once it has grown to the size of a typical frame's text, it never allocates again. Step 2 adds formatted appends (measure with `vsnprintf(NULL, 0, ...)` first), insertion, and aliasing: appending a builder's contents to itself must work even though growing may move the buffer.

### Asset-name interning

Games refer to assets by name (`"tex/rock_03.png"`), but comparing and hashing strings every frame is waste. An **interning table** maps each distinct string to a small integer id, once, at load time; after that the engine passes `uint32_t`s around and compares them with `==`. You will build it on an open-addressing hash table, with all the name bytes stored back to back in one buffer instead of one `malloc` per name.

### Timed event queue (2 steps)

"Respawn this enemy in 300 ticks", "this grenade explodes in 90 ticks": games schedule work for the future. A **binary min-heap** in a plain array gives O(log n) insert and pop-earliest, with no per-event allocation. Events at the same tick must fire in the order they were scheduled, or replays and networked games desynchronize. Step 2 adds cancellation (the enemy died before its respawn timer fired) using *lazy deletion*.

### Particle pool

Particles, bullets and sound voices are created and destroyed constantly. A **pool** hands out fixed-size blocks from one preallocated buffer in O(1), with an *intrusive free list*: a free block's own first bytes store the pointer to the next free block, so the allocator needs no memory of its own.

### Level-data compression

Rows of tiles are full of runs: `"..........####......"`. **Run-length encoding** turns that into `"10.4#6."`. Encoding is easy; decoding robustly is the real work, because a decoder must reject malformed input without overrunning, leaking, or allocating gigabytes because a corrupt file said `999999999999x`.

### Debug-console calculator

Every engine has a console where you type `spawn_count * 2 + 1`. Its core is a **recursive-descent parser**: one function per grammar rule, each calling the rules it contains. The grammar encodes precedence. Evaluate while parsing; no tree is needed.

```text
expr    := term (('+' | '-') term)*
term    := unary (('*' | '/' | '%') unary)*
unary   := ('-' | '+') unary | power
power   := primary ('^' unary)?
primary := NUMBER | '(' expr ')'
```

### Scripting VM (2 steps)

Lua, the scripting language in countless games, runs on a bytecode VM: an array of instructions, a program counter, a value stack, and a `switch` in a loop. You will write a two-pass assembler (labels can be used before they are defined) and the interpreter, with errors that name the source line. Step 2 gives scripts variables.

> **Performance:** an interpreter's inner loop runs millions of times per second, so do all the expensive work (parsing text, looking up labels) *once*, at load time, and leave the loop with nothing but array indexing and a `switch`.

### Settings file parser

`settings.ini` holds resolution, volume and key bindings. Line-oriented parsing, trimming, case-folding, override semantics and sorted output, with precise error reporting.

=== exercise strbuf
title: String builder, step 1: growth and reuse
--- prompt
Implement the core of a growable string builder for HUD and console text:

```c
typedef struct { char *data; size_t len; size_t cap; } StrBuf;
```

`data` is either `NULL` (nothing allocated yet, `len == cap == 0`) or a heap buffer of `cap` bytes holding `len` characters followed by `'\0'`.

- `void sb_init(StrBuf *sb)`: empty, no allocation.
- `bool sb_append_n(StrBuf *sb, const char *s, size_t n)`: append `n` bytes from `s`; `false` (builder unchanged) if allocation fails.
- `bool sb_append(StrBuf *sb, const char *s)`, `bool sb_append_char(StrBuf *sb, char c)`.
- `void sb_clear(StrBuf *sb)`: make it empty **but keep the buffer**, so next frame's text reuses it.
- `const char *sb_cstr(const StrBuf *sb)`: the contents, `""` when nothing is allocated.
- `void sb_free(StrBuf *sb)`: free and reset to empty.

**Growth:** when more room is needed, the new capacity is at least double the old one (minimum 16). The tests append two million characters one at a time and allow at most 25 reallocations; growing by a fixed amount copies the buffer over and over and times out. They also simulate frames: after the first frame, clearing and rebuilding text of the same size must not reallocate at all.

--- solution
#include <stdarg.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char *data;
    size_t len;
    size_t cap;
} StrBuf;

void sb_init(StrBuf *sb) {
    sb->data = NULL;
    sb->len = sb->cap = 0;
}

/* Make room for `extra` more characters plus the terminator. */
static bool sb_reserve(StrBuf *sb, size_t extra) {
    if (extra > SIZE_MAX - sb->len - 1) return false;
    size_t need = sb->len + extra + 1;
    if (need <= sb->cap) return true;
    size_t ncap = sb->cap ? sb->cap : 16;
    while (ncap < need) {
        if (ncap > SIZE_MAX / 2) { ncap = need; break; }
        ncap *= 2;
    }
    char *p = realloc(sb->data, ncap);
    if (!p) return false;
    if (!sb->data) p[0] = '\0';
    sb->data = p;
    sb->cap = ncap;
    return true;
}

bool sb_append_n(StrBuf *sb, const char *s, size_t n) {
    if (!sb_reserve(sb, n)) return false;
    memcpy(sb->data + sb->len, s, n);
    sb->len += n;
    sb->data[sb->len] = '\0';
    return true;
}

bool sb_append(StrBuf *sb, const char *s) {
    return sb_append_n(sb, s, strlen(s));
}

bool sb_append_char(StrBuf *sb, char c) {
    return sb_append_n(sb, &c, 1);
}

void sb_clear(StrBuf *sb) {
    sb->len = 0;
    if (sb->data) sb->data[0] = '\0';
}

const char *sb_cstr(const StrBuf *sb) {
    return sb->data ? sb->data : "";
}

void sb_free(StrBuf *sb) {
    free(sb->data);
    sb_init(sb);
}
--- hint
Write one private `sb_reserve(sb, extra)` that ensures `len + extra + 1 <= cap`, doubling `cap` until it fits. Every append goes through it.
--- hint
`sb_clear` only sets `len = 0` and writes the terminator. Freeing there would defeat the purpose: next frame would allocate again.
--- harness
int main(void) {
    StrBuf sb;
    sb_init(&sb);
    CHECK_STR(sb_cstr(&sb), "");
    sb_clear(&sb);
    CHECK(sb.data == NULL);
    CHECK(sb_append(&sb, "HP: "));
    CHECK(sb_append_char(&sb, '9'));
    CHECK(sb_append(&sb, "7/100"));
    CHECK_STR(sb_cstr(&sb), "HP: 97/100");
    CHECK_INT(sb.len, 10);
    CHECK(sb.cap >= 11);
    CHECK(sb_append_n(&sb, " | AMMO 12 junk", 10));
    CHECK_STR(sb_cstr(&sb), "HP: 97/100 | AMMO 12");
    CHECK(sb_append(&sb, ""));
    CHECK_INT(sb.len, 20);
    sb_free(&sb);
    CHECK(sb.data == NULL);
    CHECK_INT(sb.len, 0);
    CHECK_INT(sb.cap, 0);
    sb_free(&sb);

    /* two million single-character appends: geometric growth only */
    sb_init(&sb);
    size_t last_cap = sb.cap;
    int reallocs = 0, ok = 1;
    for (int i = 0; i < 2000000; i++) {
        ok &= sb_append_char(&sb, (char)('a' + i % 26));
        if (sb.cap != last_cap) { reallocs++; last_cap = sb.cap; }
    }
    CHECK(ok);
    CHECK_INT(sb.len, 2000000);
    CHECK(reallocs <= 25);
    CHECK(sb.cap > sb.len);
    CHECK_INT(sb.data[1999999], 'a' + 1999999 % 26);
    CHECK_INT(sb.data[2000000], 0);
    sb_free(&sb);

    /* frames: build, clear, rebuild. After frame 0 there must be no reallocation. */
    sb_init(&sb);
    char *first_buffer = NULL;
    int stable = 1;
    for (int frame = 0; frame < 100; frame++) {
        sb_clear(&sb);
        CHECK_INT(sb.len, 0);
        for (int line = 0; line < 20; line++) {
            sb_append(&sb, "entity ");
            sb_append_char(&sb, (char)('A' + line));
            sb_append(&sb, " pos=(12,34) vel=(0,-1)\n");
        }
        if (frame == 0) first_buffer = sb.data;
        else stable &= sb.data == first_buffer;
    }
    CHECK(stable);
    CHECK_INT(sb.len, 20 * 32);
    CHECK(strncmp(sb_cstr(&sb), "entity A pos", 12) == 0);
    sb_clear(&sb);
    CHECK_STR(sb_cstr(&sb), "");
    sb_free(&sb);
    return TEST_END();
}

=== exercise strbuf_fmt
title: String builder, step 2: formatting, insertion, aliasing
continues: strbuf
--- prompt
Extend your string builder from step 1.

- `bool sb_appendf(StrBuf *sb, const char *fmt, ...)`: append `printf`-style formatted text.
- `bool sb_insert(StrBuf *sb, size_t pos, const char *s)`: insert at position `pos` (`0..len`); `false` if `pos > len`.
- `char *sb_detach(StrBuf *sb)`: hand the caller the heap string (never `NULL` unless allocation fails; `""` for an empty builder) and reset the builder to empty, without copying. The caller frees it.

And make `sb_append_n` (so also `sb_append`) and `sb_insert` safe when `s` points **into the builder's own buffer**: `sb_append(&sb, sb.data)` must double the string, and `sb_insert(&sb, 0, sb.data + 3)` must work. Your step 1 `sb_append_n` probably reads freed memory in that case when the buffer moves; ASan will tell you.

> **Performance:** `sb_appendf` should format straight into the builder's buffer. Formatting into a temporary `malloc`ed string and then appending it doubles the work and allocates on every call.

#include <stdarg.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char *data;
    size_t len;
    size_t cap;
} StrBuf;

void sb_init(StrBuf *sb) {
    sb->data = NULL;
    sb->len = sb->cap = 0;
}

/* Make room for `extra` more characters plus the terminator. */
static bool sb_reserve(StrBuf *sb, size_t extra) {
    if (extra > SIZE_MAX - sb->len - 1) return false;
    size_t need = sb->len + extra + 1;
    if (need <= sb->cap) return true;
    size_t ncap = sb->cap ? sb->cap : 16;
    while (ncap < need) {
        if (ncap > SIZE_MAX / 2) { ncap = need; break; }
        ncap *= 2;
    }
    char *p = realloc(sb->data, ncap);
    if (!p) return false;
    if (!sb->data) p[0] = '\0';
    sb->data = p;
    sb->cap = ncap;
    return true;
}

/* Does s point into the builder's buffer? Compare as integers: relational
   comparison of pointers into different objects is undefined. */
static bool aliases(const StrBuf *sb, const char *s) {
    uintptr_t b = (uintptr_t)sb->data, p = (uintptr_t)s;
    return sb->data && p >= b && p < b + sb->cap;
}

bool sb_append_n(StrBuf *sb, const char *s, size_t n) {
    size_t offset = aliases(sb, s) ? (size_t)(s - sb->data) : SIZE_MAX;
    if (!sb_reserve(sb, n)) return false;
    if (offset != SIZE_MAX) s = sb->data + offset;   /* the buffer may have moved */
    memmove(sb->data + sb->len, s, n);
    sb->len += n;
    sb->data[sb->len] = '\0';
    return true;
}

bool sb_append(StrBuf *sb, const char *s) {
    return sb_append_n(sb, s, strlen(s));
}

bool sb_append_char(StrBuf *sb, char c) {
    return sb_append_n(sb, &c, 1);
}

void sb_clear(StrBuf *sb) {
    sb->len = 0;
    if (sb->data) sb->data[0] = '\0';
}

const char *sb_cstr(const StrBuf *sb) {
    return sb->data ? sb->data : "";
}

void sb_free(StrBuf *sb) {
    free(sb->data);
    sb_init(sb);
}

bool sb_appendf(StrBuf *sb, const char *fmt, ...) {
    va_list ap, ap2;
    va_start(ap, fmt);
    va_copy(ap2, ap);
    int n = vsnprintf(NULL, 0, fmt, ap);
    va_end(ap);
    bool ok = n >= 0 && sb_reserve(sb, (size_t)n);
    if (ok) {
        vsnprintf(sb->data + sb->len, (size_t)n + 1, fmt, ap2);
        sb->len += (size_t)n;
    }
    va_end(ap2);
    return ok;
}

bool sb_insert(StrBuf *sb, size_t pos, const char *s) {
    if (pos > sb->len) return false;
    size_t n = strlen(s);
    char *copy = NULL;
    if (aliases(sb, s)) {          /* the shift below would overwrite the source */
        copy = malloc(n + 1);
        if (!copy) return false;
        memcpy(copy, s, n + 1);
        s = copy;
    }
    bool ok = sb_reserve(sb, n);
    if (ok) {
        memmove(sb->data + pos + n, sb->data + pos, sb->len - pos + 1);
        memcpy(sb->data + pos, s, n);
        sb->len += n;
    }
    free(copy);
    return ok;
}

char *sb_detach(StrBuf *sb) {
    char *out = sb->data;
    if (!out) {
        out = malloc(1);
        if (!out) return NULL;
        out[0] = '\0';
    }
    sb_init(sb);
    return out;
}
--- hint
`vsnprintf(NULL, 0, fmt, ap)` returns the length the text needs. A `va_list` can only be walked once, so `va_copy` it before measuring, reserve, then format directly into `data + len`.
--- hint
For aliasing in append: if `s` points into `data`, remember the *offset* `s - data` before growing and recompute `s = data + offset` after. Use `memmove`, since source and destination may overlap. For insert, the simplest correct approach is to copy the source first.

=== exercise intern
title: Interning asset names
--- prompt
Build a string-interning table that gives every distinct asset name a dense integer id: the first new name gets `0`, the next `1`, and so on. Interning a name that is already present returns its existing id.

```c
void intern_init(Interner *in);
uint32_t intern(Interner *in, const char *name);       /* id; UINT32_MAX if allocation fails */
uint32_t intern_find(const Interner *in, const char *name);  /* id, or UINT32_MAX if absent */
const char *intern_name(const Interner *in, uint32_t id);    /* NULL for an unknown id */
uint32_t intern_count(const Interner *in);
void intern_free(Interner *in);                        /* frees everything, leaves it empty */
```

You design `Interner`. The table copies the names (the caller's buffer may change afterwards). A pointer from `intern_name` may be invalidated by a later `intern` call, like a pointer into a growing array.

The tests intern 150000 distinct names and look them up again. A linear search through all names takes minutes; you need a hash table.

> **Performance:** don't `malloc` each name separately. Store all the characters back to back in one growable `char` buffer and keep each name's *offset* (an offset survives `realloc`; a pointer doesn't). Use open addressing (one flat `uint32_t` slot array, linear probing, kept under 3/4 full) rather than chained nodes: probing walks adjacent memory, which the cache loves, while a chain is a pointer chase per step.

--- solution
#include <stdbool.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char *chars;          /* every name, each followed by '\0', back to back */
    size_t chars_len, chars_cap;
    uint32_t *offsets;    /* id -> offset of its name in chars */
    uint32_t count, offsets_cap;
    uint32_t *slots;      /* open addressing: 0 = empty, otherwise id + 1 */
    uint32_t nslots;      /* power of two */
} Interner;

void intern_init(Interner *in) {
    memset(in, 0, sizeof *in);
}

static uint32_t hash_str(const char *s) {   /* FNV-1a, 32-bit */
    uint32_t h = 2166136261u;
    for (; *s; s++) {
        h ^= (unsigned char)*s;
        h *= 16777619u;
    }
    return h;
}

/* Index of the slot holding `name`, or of the empty slot where it would go. */
static uint32_t find_slot(const Interner *in, const char *name, uint32_t h) {
    uint32_t mask = in->nslots - 1;
    for (uint32_t i = h & mask;; i = (i + 1) & mask) {
        uint32_t v = in->slots[i];
        if (v == 0 || strcmp(in->chars + in->offsets[v - 1], name) == 0) return i;
    }
}

static bool rehash(Interner *in) {
    uint32_t n = in->nslots ? in->nslots * 2 : 64;
    uint32_t *slots = calloc(n, sizeof *slots);
    if (!slots) return false;
    free(in->slots);
    in->slots = slots;
    in->nslots = n;
    for (uint32_t id = 0; id < in->count; id++) {
        uint32_t i = hash_str(in->chars + in->offsets[id]) & (n - 1);
        while (slots[i]) i = (i + 1) & (n - 1);
        slots[i] = id + 1;
    }
    return true;
}

uint32_t intern_find(const Interner *in, const char *name) {
    if (in->count == 0) return UINT32_MAX;
    uint32_t v = in->slots[find_slot(in, name, hash_str(name))];
    return v ? v - 1 : UINT32_MAX;
}

uint32_t intern(Interner *in, const char *name) {
    if ((in->count + 1) * 4 > in->nslots * 3 && !rehash(in)) return UINT32_MAX;  /* load <= 3/4 */
    uint32_t h = hash_str(name);
    uint32_t slot = find_slot(in, name, h);
    if (in->slots[slot]) return in->slots[slot] - 1;
    size_t n = strlen(name) + 1;
    if (in->chars_len + n > in->chars_cap) {
        size_t cap = in->chars_cap ? in->chars_cap : 1024;
        while (cap < in->chars_len + n) cap *= 2;
        char *p = realloc(in->chars, cap);
        if (!p) return UINT32_MAX;
        in->chars = p;
        in->chars_cap = cap;
    }
    if (in->count == in->offsets_cap) {
        uint32_t cap = in->offsets_cap ? in->offsets_cap * 2 : 64;
        uint32_t *p = realloc(in->offsets, cap * sizeof *p);
        if (!p) return UINT32_MAX;
        in->offsets = p;
        in->offsets_cap = cap;
    }
    memcpy(in->chars + in->chars_len, name, n);
    in->offsets[in->count] = (uint32_t)in->chars_len;
    in->chars_len += n;
    in->slots[slot] = in->count + 1;
    return in->count++;
}

const char *intern_name(const Interner *in, uint32_t id) {

#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    uint32_t time;     /* game tick when it fires */
    int type;
    int entity;
    uint32_t id;       /* push order: 0, 1, 2, ... */
} Event;

typedef struct {
    Event *heap;       /* binary min-heap on (time, id) */
    size_t len, cap;
    uint32_t next_id;
} EventQueue;

void eq_init(EventQueue *q) {
    q->heap = NULL;
    q->len = q->cap = 0;
    q->next_id = 0;
}

static bool before(const Event *a, const Event *b) {
    return a->time != b->time ? a->time < b->time : a->id < b->id;
}

static void sift_up(Event *h, size_t i) {
    Event e = h[i];
    while (i > 0) {
        size_t parent = (i - 1) / 2;
        if (!before(&e, &h[parent])) break;
        h[i] = h[parent];
        i = parent;
    }
    h[i] = e;
}

static void sift_down(Event *h, size_t len, size_t i) {
    Event e = h[i];
    for (;;) {
        size_t child = 2 * i + 1;
        if (child >= len) break;
        if (child + 1 < len && before(&h[child + 1], &h[child])) child++;
        if (!before(&h[child], &e)) break;
        h[i] = h[child];
        i = child;
    }
    h[i] = e;
}

uint32_t eq_push(EventQueue *q, uint32_t time, int type, int entity) {
    if (q->len == q->cap) {
        size_t cap = q->cap ? q->cap * 2 : 64;
        Event *p = realloc(q->heap, cap * sizeof *p);
        if (!p) return UINT32_MAX;
        q->heap = p;
        q->cap = cap;
    }
    Event e = {time, type, entity, q->next_id++};
    q->heap[q->len] = e;
    sift_up(q->heap, q->len++);
    return e.id;
}

bool eq_pop_due(EventQueue *q, uint32_t now, Event *out) {
    if (q->len == 0 || q->heap[0].time > now) return false;
    *out = q->heap[0];
    q->heap[0] = q->heap[--q->len];
    if (q->len > 0) sift_down(q->heap, q->len, 0);
    return true;
}

size_t eq_size(const EventQueue *q) {
    return q->len;
}

void eq_free(EventQueue *q) {
    free(q->heap);
    eq_init(q);
}
--- hint
Order events by `(time, id)`: compare times, and if they are equal compare ids. Since ids increase with every push, that makes equal-time events come out in push order. A heap alone is not stable; the id tie-break is what makes it so.
--- hint
Push: append at the end, then *sift up*, swapping with the parent `(i - 1) / 2` while it is larger. Pop: take `heap[0]`, move the last element to the root, then *sift down*, swapping with the smaller child while that child is smaller.
--- hint
`eq_pop_due` only has to look at `heap[0]`: if the earliest event is not due, nothing is.
--- harness

    rng_state ^= rng_state << 13;
    rng_state ^= rng_state >> 17;
    rng_state ^= rng_state << 5;
    return rng_state;
}

=== exercise events_cancel
title: Event queue, step 2: cancellation
continues: events
--- prompt
Add cancellation to your event queue:

```c
bool eq_cancel(EventQueue *q, uint32_t id);
```

It returns `true` if event `id` was pending and is now cancelled; `false` if no such event was ever pushed, or it was already popped or cancelled. A cancelled event is never returned by `eq_pop_due`, and `eq_size` counts only events that are still pending.

The tests schedule 300000 timers and cancel a third of them. Searching the heap for the event to remove is O(n) per cancel and times out.

> **Performance:** use **lazy deletion**. Don't remove a cancelled event from the heap; just mark its id as dead (ids are dense, so a byte array indexed by id is a perfect O(1) lookup). When a dead event reaches the top of the heap, `eq_pop_due` discards it and looks again. Each event is still pushed and popped exactly once, so everything stays O(log n).
--- stubs

    return false;
}

#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    uint32_t time;     /* game tick when it fires */
    int type;
    int entity;
    uint32_t id;       /* push order: 0, 1, 2, ... */
} Event;

typedef struct {
    Event *heap;       /* binary min-heap on (time, id) */
    size_t len, cap;
    uint32_t next_id;
    unsigned char *state;   /* per id: PENDING, DONE (popped or cancelled) */
    size_t state_cap;
    size_t live;            /* pending events not cancelled */
} EventQueue;

enum { PENDING = 0, DONE = 1 };

void eq_init(EventQueue *q) {
    q->heap = NULL;
    q->len = q->cap = 0;
    q->next_id = 0;
    q->state = NULL;
    q->state_cap = 0;
    q->live = 0;
}

static bool before(const Event *a, const Event *b) {
    return a->time != b->time ? a->time < b->time : a->id < b->id;
}

static void sift_up(Event *h, size_t i) {
    Event e = h[i];
    while (i > 0) {
        size_t parent = (i - 1) / 2;
        if (!before(&e, &h[parent])) break;
        h[i] = h[parent];
        i = parent;
    }

}

static void sift_down(Event *h, size_t len, size_t i) {
    Event e = h[i];
    for (;;) {
        size_t child = 2 * i + 1;
        if (child >= len) break;
        if (child + 1 < len && before(&h[child + 1], &h[child])) child++;
        if (!before(&h[child], &e)) break;
        h[i] = h[child];
        i = child;
    }
    h[i] = e;
}

uint32_t eq_push(EventQueue *q, uint32_t time, int type, int entity) {
    if (q->len == q->cap) {
        size_t cap = q->cap ? q->cap * 2 : 64;
        Event *p = realloc(q->heap, cap * sizeof *p);
        if (!p) return UINT32_MAX;
        q->heap = p;
        q->cap = cap;
    }
    if (q->next_id == q->state_cap) {
        size_t cap = q->state_cap ? q->state_cap * 2 : 64;
        unsigned char *p = realloc(q->state, cap);
        if (!p) return UINT32_MAX;
        q->state = p;
        q->state_cap = cap;
    }
    Event e = {time, type, entity, q->next_id++};
    q->state[e.id] = PENDING;
    q->heap[q->len] = e;
    sift_up(q->heap, q->len++);
    q->live++;
    return e.id;
}

static void remove_top(EventQueue *q) {
    q->heap[0] = q->heap[--q->len];
    if (q->len > 0) sift_down(q->heap, q->len, 0);
}

bool eq_pop_due(EventQueue *q, uint32_t now, Event *out) {
    /* lazy deletion: cancelled events stay in the heap until they reach the top */
    while (q->len > 0 && q->state[q->heap[0].id] == DONE) remove_top(q);
    if (q->len == 0 || q->heap[0].time > now) return false;
    *out = q->heap[0];
    q->state[out->id] = DONE;
    q->live--;
    remove_top(q);
    return true;
}

bool eq_cancel(EventQueue *q, uint32_t id) {
    if (id >= q->next_id || q->state[id] == DONE) return false;
    q->state[id] = DONE;
    q->live--;
    return true;
}

size_t eq_size(const EventQueue *q) {
    return q->live;
}

void eq_free(EventQueue *q) {
    free(q->heap);
    free(q->state);
    eq_init(q);
}

Track the number of live events in a separate counter: the heap's length now includes dead entries.

Particles, bullets and sound voices are created and destroyed by the thousand every second. Implement a pool allocator that carves fixed-size blocks out of a buffer the caller provides, with O(1) allocate and free and no memory of its own beyond the `Pool` struct.

#include <stdalign.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <string.h>

typedef struct {
    unsigned char *start;
    size_t block_size;
    size_t nblocks;
    void *free_list;
    size_t available;
} Pool;

/* The free list lives inside the blocks. memcpy avoids any alignment or aliasing doubts. */
static void *next_of(void *block) {
    void *next;
    memcpy(&next, block, sizeof next);
    return next;
}

static void set_next(void *block, void *next) {
    memcpy(block, &next, sizeof next);
}

size_t pool_init(Pool *p, void *mem, size_t mem_size, size_t block_size) {
    const size_t a = 16;  /* alignof(max_align_t) on x86-64 Linux; fixed so every platform gets the same layout */
    if (block_size < a) block_size = a;
    block_size = (block_size + a - 1) & ~(a - 1);
    uintptr_t m = (uintptr_t)mem;
    size_t skip = (size_t)(((m + a - 1) & ~(uintptr_t)(a - 1)) - m);
    size_t n = mem_size > skip ? (mem_size - skip) / block_size : 0;
    p->start = (unsigned char *)mem + skip;
    p->block_size = block_size;
    p->nblocks = n;
    p->available = n;
    p->free_list = n ? p->start : NULL;
    for (size_t i = 0; i < n; i++)
        set_next(p->start + i * block_size, i + 1 < n ? p->start + (i + 1) * block_size : NULL);
    return n;
}

void *pool_alloc(Pool *p) {
    void *b = p->free_list;
    if (!b) return NULL;
    p->free_list = next_of(b);
    p->available--;
    return b;
}

bool pool_free(Pool *p, void *block) {
    if (!block || p->nblocks == 0) return false;
    uintptr_t s = (uintptr_t)p->start, b = (uintptr_t)block;
    if (b < s || b >= s + p->nblocks * p->block_size || (b - s) % p->block_size != 0) return false;
    set_next(block, p->free_list);
    p->free_list = block;
    p->available++;
    return true;
}

size_t pool_available(const Pool *p) {
    return p->available;
}
--- hint
In `pool_init`, link block `i` to block `i + 1` (the last to `NULL`) and point `free_list` at block 0. Alloc pops the head; free pushes onto the head. That gives LIFO reuse.
--- hint
Align the start address like the arena did: `((uintptr_t)mem + a - 1) & ~(uintptr_t)(a - 1)`. Remember to subtract the skipped bytes from the usable size.
--- hint
To check ownership, convert to `uintptr_t` (comparing unrelated pointers with `<` is undefined), then check the range and that the offset is a multiple of `block_size`.
--- harness

int main(void) {
    Pool p;
    CHECK_INT(pool_init(&p, mem, 1000, 24), 31);

=== exercise rle
title: Compressing level rows
--- prompt
Level rows are long runs of the same tile: `"..........####......"`. Implement run-length encoding of text, in which each run of identical characters becomes its length in decimal followed by the character: `"aaabcc"` becomes `"3a1b2c"`, and twelve `x`s become `"12x"`, so that row is `"10.4#6."`.

- `char *rle_encode(const char *s)`: return the encoding as a new heap string (`""` for `""`). Since counts are digits, input containing a digit `0-9` cannot be encoded: return `NULL`.
- `char *rle_decode(const char *s)`: return the decoded heap string, or `NULL` if the input is malformed. Valid input is a sequence of zero or more pairs: a count of one or more digits with no leading zero, between 1 and 1000000 inclusive, then one non-digit character. Anything else is malformed: `"a"`, `"0a"`, `"03a"`, `"3"`, `"3a2"`, `"1000001a"`.

The caller frees the results. Neither function may leak on any path, and the decoder must validate the whole input before allocating, so `"999999999999x"` must not trigger a huge allocation.

The tests include a two-million-character level. Building the output with `strcat` (which rescans the whole string every call) or growing it with a `realloc` per run is O(n²) and times out.

> **Performance:** compute the output size first and allocate exactly once, then write through a moving pointer. That pattern (measure, allocate, fill) is how you keep serialization code out of the profiler.
--- starter

--- solution
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

static bool is_digit(char c) { return c >= '0' && c <= '9'; }

char *rle_encode(const char *s) {
    size_t n = strlen(s);
    for (size_t i = 0; i < n; i++)
        if (is_digit(s[i])) return NULL;
    char *out = malloc(2 * n + 1);   /* worst case: every run has length 1 */
    if (!out) return NULL;
    char *w = out;
    for (size_t i = 0; i < n;) {
        size_t run = 1;
        while (i + run < n && s[i + run] == s[i]) run++;
        char digits[24];
        int k = 0;
        for (size_t r = run; r; r /= 10) digits[k++] = (char)('0' + r % 10);
        while (k) *w++ = digits[--k];
        *w++ = s[i];
        i += run;
    }
    *w = '\0';
    return out;
}

/* Parses one count at *p. Returns 0 if malformed. */
static long parse_count(const char **p) {
    const char *s = *p;
    if (!is_digit(*s) || *s == '0') return 0;
    long v = 0;
    while (is_digit(*s)) {
        v = v * 10 + (*s++ - '0');
        if (v > 1000000) return 0;
    }
    *p = s;
    return v;
}

char *rle_decode(const char *s) {
    size_t total = 0;
    for (const char *p = s; *p;) {      /* pass 1: validate and measure */
        long count = parse_count(&p);
        if (count == 0 || *p == '\0') return NULL;
        p++;                            /* the character (cannot be a digit here) */
        total += (size_t)count;
    }
    char *out = malloc(total + 1);
    if (!out) return NULL;
    char *w = out;
    for (const char *p = s; *p;) {      /* pass 2: fill */
        long count = parse_count(&p);
        memset(w, *p++, (size_t)count);
        w += count;
    }
    *w = '\0';
    return out;
}
--- hint
Encoding: the output is never longer than `2 * strlen(s)` (a run of length 1 costs 2 characters, longer runs cost less per character), so one allocation is enough. Write the count's digits into a small buffer backwards, then copy them forwards.
--- hint
Decoding in two passes: the first only parses and adds up the lengths, returning `NULL` at the first problem (nothing allocated yet, so nothing to leak). The second allocates once and fills with `memset`.
--- hint
Reject the count as soon as it exceeds 1000000, while reading digits, so a 50-digit count cannot overflow your accumulator.
--- harness

title: Debug-console calculator
--- prompt
Write the evaluator behind a game's debug console: it reads expressions from stdin, one per line, and prints each result on its own line. Blank lines (empty or only spaces/tabs) produce no output. Lines are at most 1000 characters.

**Syntax.** Integer literals are non-negative decimal numbers. Operators are `+ - * / % ^`, plus unary `-` and `+`, and parentheses. Spaces and tabs may appear between tokens. From loosest to tightest:

| Level | Operators | Associativity |
|---|---|---|
| additive | `+` `-` | left |
| multiplicative | `*` `/` `%` | left |
| unary | `-x` `+x` | prefix |
| power | `^` | right, and its right operand may be unary: `2^-1` |

So `-2^2` is `-4`, `2^3^2` is `512`, and `10 - 4 - 3` is `3`. All arithmetic is on `long long`; `/` and `%` truncate as in C. `0^0` is 1.

**Errors.** If the line is not a valid expression, print `error: syntax`. Otherwise, if evaluation goes wrong, print the *first* problem in left-to-right evaluation order:

- `error: division by zero` for `/` or `%` by zero;
- `error: overflow` if any literal or intermediate result does not fit in a `long long` (so `-9223372036854775808` is an overflow, because the literal is; write `-9223372036854775807 - 1`);
- `error: negative exponent`.

```text
-7 / 2
2 ^ 10
1 +
10 / (5 - 5)
```

prints

```text

```

--- solution
#include <stdio.h>
#include <string.h>
#include <stdbool.h>

typedef struct {
    const char *p;      /* current position in the line */
    bool syntax_error;
    const char *error;  /* first evaluation error, or NULL */
} Parser;

static void skip_spaces(Parser *ps) {
    while (*ps->p == ' ' || *ps->p == '\t') ps->p++;
}

static void fail(Parser *ps, const char *msg) {
    if (!ps->error) ps->error = msg;
}

static long long expr(Parser *ps);
static long long unary(Parser *ps);

static long long primary(Parser *ps) {
    skip_spaces(ps);
    if (*ps->p == '(') {
        ps->p++;
        long long v = expr(ps);
        skip_spaces(ps);
        if (*ps->p != ')') { ps->syntax_error = true; return 0; }
        ps->p++;
        return v;
    }
    if (*ps->p < '0' || *ps->p > '9') { ps->syntax_error = true; return 0; }
    long long v = 0;
    bool over = false;
    while (*ps->p >= '0' && *ps->p <= '9') {
        int d = *ps->p++ - '0';
        if (!over && (__builtin_mul_overflow(v, 10, &v) || __builtin_add_overflow(v, d, &v))) over = true;
    }
    if (over) { fail(ps, "overflow"); return 0; }
    return v;
}

static long long ipow(Parser *ps, long long base, long long e) {
    if (e < 0) { fail(ps, "negative exponent"); return 0; }
    if (base == 0) return e == 0 ? 1 : 0;
    if (base == 1) return 1;
    if (base == -1) return e % 2 == 0 ? 1 : -1;
    long long r = 1;   /* |base| >= 2, so this overflows within 64 steps */
    while (e-- > 0)
        if (__builtin_mul_overflow(r, base, &r)) { fail(ps, "overflow"); return 0; }
    return r;
}

/* power := primary ('^' unary)?   right associative, binds tighter than unary minus */
static long long power(Parser *ps) {
    long long base = primary(ps);
    skip_spaces(ps);
    if (*ps->p != '^') return base;
    ps->p++;
    long long e = unary(ps);
    return ipow(ps, base, e);
}

/* unary := ('-' | '+') unary | power */
static long long unary(Parser *ps) {
    skip_spaces(ps);
    if (*ps->p == '-') {
        ps->p++;
        long long v = unary(ps), r;
        if (__builtin_sub_overflow(0LL, v, &r)) { fail(ps, "overflow"); return 0; }
        return r;
    }
    if (*ps->p == '+') {
        ps->p++;
        return unary(ps);
    }
    return power(ps);
}

/* term := unary (('*' | '/' | '%') unary)* */
static long long term(Parser *ps) {
    long long v = unary(ps);
    for (;;) {
        skip_spaces(ps);
        char op = *ps->p;
        if (op != '*' && op != '/' && op != '%') return v;
        ps->p++;
        long long rhs = unary(ps);
        if (op == '*') {
            if (__builtin_mul_overflow(v, rhs, &v)) { fail(ps, "overflow"); v = 0; }
        } else if (rhs == 0) {
            fail(ps, "division by zero");
            v = 0;
        } else if (rhs == -1) {
            /* LLONG_MIN / -1 overflows; x % -1 is always 0 */
            if (op == '%') v = 0;
            else if (__builtin_sub_overflow(0LL, v, &v)) { fail(ps, "overflow"); v = 0; }
        } else {
            v = op == '/' ? v / rhs : v % rhs;
        }
    }
}

/* expr := term (('+' | '-') term)* */
static long long expr(Parser *ps) {
    long long v = term(ps);
    for (;;) {
        skip_spaces(ps);
        char op = *ps->p;
        if (op != '+' && op != '-') return v;
        ps->p++;
        long long rhs = term(ps);
        bool over = op == '+' ? __builtin_add_overflow(v, rhs, &v) : __builtin_sub_overflow(v, rhs, &v);
        if (over) { fail(ps, "overflow"); v = 0; }
    }
}

int main(void) {
    char line[1024];
    while (fgets(line, sizeof line, stdin)) {
        line[strcspn(line, "\r\n")] = '\0';
        Parser ps = {line, false, NULL};
        skip_spaces(&ps);
        if (*ps.p == '\0') continue;
        long long v = expr(&ps);
        skip_spaces(&ps);
        if (*ps.p != '\0') ps.syntax_error = true;
        if (ps.syntax_error) puts("error: syntax");
        else if (ps.error) printf("error: %s\n", ps.error);
        else printf("%lld\n", v);
    }
    return 0;
}
--- hint

=== exercise vm
title: Scripting VM, step 1: assembler and interpreter
--- prompt
Write an assembler and interpreter for a small stack machine, the kind of VM that runs game scripts (enemy behaviors, cutscenes, quest logic). The script text comes from stdin, one instruction per line. A `;` starts a comment that runs to the end of the line; blank lines are ignored. A line `name:` defines a label (letters, digits and `_`, not starting with a digit, at most 31 characters) for the next instruction. Lines are at most 255 characters; programs have at most 1000 instructions.

The machine has a stack of up to 256 `long long` values and a separate call stack of up to 256 return addresses. Instructions (in the descriptions, `b` is the top of the stack and `a` the one below it):

| Instruction | Effect |
|---|---|
| `push N` | push the decimal integer N (must fit in a `long long`) |
| `pop`, `dup` | discard the top; push a copy of the top |
| `swap`, `over` | `a b` to `b a`; `a b` to `a b a` |
| `rot` | `x a b` to `a b x` (the third item moves to the top) |
| `add`, `sub`, `mul` | pop `a` and `b`, push `a + b`, `a - b`, `a * b`, wrapping around on overflow (two's complement) |
| `div`, `mod` | push `a / b`, `a % b` as in C; `LLONG_MIN / -1` wraps to `LLONG_MIN`, and `x % -1` is `0` |
| `neg` | negate the top (wrapping) |
| `eq`, `lt`, `gt` | pop `a` and `b`, push `1` if `a == b` / `a < b` / `a > b`, else `0` |
| `print` | pop and print the value on its own line |
| `jmp L` | jump to label L |
| `jz L`, `jnz L` | pop; jump if the value is zero / non-zero |
| `call L`, `ret` | push the address of the next instruction on the call stack and jump; pop it and jump there |
| `halt` | stop. Running past the last instruction also stops. |

**Assembly** happens before anything runs. Report the first problem in source order and exit with code 1, executing nothing:

- `error: line N: unknown instruction 'X'`
- `error: line N: wrong number of operands`
- `error: line N: bad number 'X'`
- `error: line N: bad label` (a malformed label name, in a definition or an operand)
- `error: line N: duplicate label 'X'`
- `error: line N: unknown label 'X'` (checked after the whole program is read, reported for the first instruction that uses it)

**Runtime errors** stop execution with exit code 1, after any output already printed: `error: line N: stack underflow` (not enough values for the instruction), `stack overflow` (more than 256 values), `division by zero`, `return without call` and `call stack overflow`, each prefixed with `error: line N: ` where `N` is the source line of the failing instruction.

Line numbers count every input line, including blank and comment lines, starting at 1.

static const char *const op_names[] = {

typedef struct {

    char label[32];         /* jump label before linking */

#define MAX_CODE 1000

static int find_label(const char *name) {
    for (int i = 0; i < nlabels; i++)
        if (strcmp(labels[i].name, name) == 0) return labels[i].addr;
    return -1;

static int is_ident(const char *s) {
    if (!*s || !(isalpha((unsigned char)*s) || *s == '_')) return 0;
    for (; *s; s++)
        if (!(isalnum((unsigned char)*s) || *s == '_')) return 0;
    return 1;
}

/* Assemble one source line. Returns 0 on success, prints an error and returns -1 otherwise. */
static int assemble_line(char *s, int lineno) {
    char *semi = strchr(s, ';');
    if (semi) *semi = '\0';
    char a[64] = "", b[64] = "", extra[2] = "";
    int n = sscanf(s, "%63s %63s %1s", a, b, extra);
    if (n <= 0) return 0;                       /* blank or comment */
    size_t alen = strlen(a);

            return -1;
        }
        if (find_label(a) >= 0) {
            printf("error: line %d: duplicate label '%s'\n", lineno, a);
            return -1;
        }
        strcpy(labels[nlabels].name, a);
        labels[nlabels++].addr = ncode;
        return 0;
    }
    int op = -1;
    for (int i = 0; i < NOPS; i++)
        if (strcmp(a, op_names[i]) == 0) op = i;
    if (op < 0) {
        printf("error: line %d: unknown instruction '%s'\n", lineno, a);
        return -1;
    }
    int wants_arg = op == OP_PUSH || op == OP_JMP || op == OP_JZ || op == OP_JNZ || op == OP_CALL;
    if (n != (wants_arg ? 2 : 1)) {
        printf("error: line %d: wrong number of operands\n", lineno);
        return -1;
    }
    if (ncode == MAX_CODE) {
        printf("error: line %d: program too long\n", lineno);
        return -1;
    }
    Instr *in = &code[ncode];
    in->op = (enum op)op;
    in->line = lineno;
    in->arg = 0;
    in->label[0] = '\0';
    if (op == OP_PUSH) {
        char *end;
        errno = 0;
        in->arg = strtoll(b, &end, 10);
        if (*end != '\0' || errno == ERANGE) {
            printf("error: line %d: bad number '%s'\n", lineno, b);
            return -1;
        }
    } else if (wants_arg) {
        if (!is_ident(b) || strlen(b) > 31) {
            printf("error: line %d: bad label\n", lineno);
            return -1;
        }
        strcpy(in->label, b);
    }
    ncode++;
    return 0;
}

static int link_labels(void) {
    for (int i = 0; i < ncode; i++) {
        if (!code[i].label[0]) continue;
        int addr = find_label(code[i].label);
        if (addr < 0) {
            printf("error: line %d: unknown label '%s'\n", code[i].line, code[i].label);
            return -1;
        }
        code[i].arg = addr;

    return 0;

static int run(void) {
    long long stack[STACK_MAX];
    int calls[STACK_MAX];
    int sp = 0, csp = 0, pc = 0;
    while (pc < ncode) {
        Instr *in = &code[pc++];
        static const signed char pops[OP_COUNT] = {
            [OP_POP] = 1, [OP_DUP] = 1, [OP_SWAP] = 2, [OP_OVER] = 2, [OP_ROT] = 3,
            [OP_ADD] = 2, [OP_SUB] = 2, [OP_MUL] = 2, [OP_DIV] = 2, [OP_MOD] = 2, [OP_NEG] = 1,
            [OP_EQ] = 2, [OP_LT] = 2, [OP_GT] = 2, [OP_PRINT] = 1, [OP_JZ] = 1, [OP_JNZ] = 1,
        };
        static const signed char pushes[OP_COUNT] = {
            [OP_PUSH] = 1, [OP_DUP] = 2, [OP_SWAP] = 2, [OP_OVER] = 3, [OP_ROT] = 3,
            [OP_ADD] = 1, [OP_SUB] = 1, [OP_MUL] = 1, [OP_DIV] = 1, [OP_MOD] = 1, [OP_NEG] = 1,
            [OP_EQ] = 1, [OP_LT] = 1, [OP_GT] = 1,
        };
        if (sp < pops[in->op]) {
            printf("error: line %d: stack underflow\n", in->line);
            return -1;
        }
        if (sp - pops[in->op] + pushes[in->op] > STACK_MAX) {
            printf("error: line %d: stack overflow\n", in->line);
            return -1;
        }
        long long a = sp >= 2 ? stack[sp - 2] : 0, b = sp >= 1 ? stack[sp - 1] : 0;
        unsigned long long ua = (unsigned long long)a, ub = (unsigned long long)b;
        switch (in->op) {
        case OP_PUSH: stack[sp++] = in->arg; break;
        case OP_POP: sp--; break;
        case OP_DUP: stack[sp++] = b; break;
        case OP_SWAP: stack[sp - 2] = b; stack[sp - 1] = a; break;
        case OP_OVER: stack[sp++] = a; break;
        case OP_ROT: {   /* x a b -> a b x */
            long long x = stack[sp - 3];
            stack[sp - 3] = a; stack[sp - 2] = b; stack[sp - 1] = x;
            break;
        }
        case OP_ADD: stack[--sp - 1] = (long long)(ua + ub); break;
        case OP_SUB: stack[--sp - 1] = (long long)(ua - ub); break;
        case OP_MUL: stack[--sp - 1] = (long long)(ua * ub); break;
        case OP_DIV:
        case OP_MOD:
            if (b == 0) {
                printf("error: line %d: division by zero\n", in->line);
                return -1;
            }
            if (b == -1) stack[--sp - 1] = in->op == OP_DIV ? (long long)(0 - ua) : 0;
            else stack[--sp - 1] = in->op == OP_DIV ? a / b : a % b;
            break;
        case OP_NEG: stack[sp - 1] = (long long)(0 - ub); break;
        case OP_EQ: stack[--sp - 1] = a == b; break;
        case OP_LT: stack[--sp - 1] = a < b; break;
        case OP_GT: stack[--sp - 1] = a > b; break;
        case OP_PRINT: printf("%lld\n", stack[--sp]); break;
        case OP_JMP: pc = (int)in->arg; break;
        case OP_JZ: if (stack[--sp] == 0) pc = (int)in->arg; break;
        case OP_JNZ: if (stack[--sp] != 0) pc = (int)in->arg; break;
        case OP_CALL:
            if (csp == STACK_MAX) {
                printf("error: line %d: call stack overflow\n", in->line);
                return -1;
            }
            calls[csp++] = pc;
            pc = (int)in->arg;
            break;
        case OP_RET:
            if (csp == 0) {
                printf("error: line %d: return without call\n", in->line);
                return -1;
            }
            pc = calls[--csp];
            break;
        case OP_HALT: return 0;
        case OP_COUNT: break;
        }
    }
    return 0;
}

        lineno++;
        if (assemble_line(line, lineno) != 0) return 1;

}

=== exercise vm_vars
title: Scripting VM, step 2: variables
continues: vm
--- prompt
Scripts need state: a door's open flag, a boss's phase, a counter. Extend your VM from step 1 with 16 variable slots, numbered `0` to `15`, all starting at `0`:

| Instruction | Effect |
|---|---|
| `load N` | push the value of slot N |
| `store N` | pop a value into slot N |

The operand must be a decimal number from `0` to `15`; anything else is an assembly error `error: line N: bad slot 'X'`. A missing or extra operand is `wrong number of operands`, as before, and `store` with an empty stack is a `stack underflow`.

One test runs a loop of a million iterations (about ten million instructions); it should take well under a second.

> **Performance:** variables are an array indexed by a number fixed at assembly time, never a lookup by name at run time. Real VMs (Lua's included) compile local variable names to slot numbers for exactly this reason.

enum op {

    OP_JMP, OP_JZ, OP_JNZ, OP_CALL, OP_RET, OP_HALT,

static int is_ident(const char *s) {
    if (!*s || !(isalpha((unsigned char)*s) || *s == '_')) return 0;
    for (; *s; s++)

            return -1;

        labels[nlabels++].addr = ncode;
        return 0;

    int op = -1;
    for (int i = 0; i < NOPS; i++)
        if (strcmp(a, op_names[i]) == 0) op = i;
    if (op < 0) {
        printf("error: line %d: unknown instruction '%s'\n", lineno, a);
        return -1;
    }
    int wants_arg = op == OP_PUSH || op == OP_LOAD || op == OP_STORE || op == OP_JMP || op == OP_JZ || op == OP_JNZ || op == OP_CALL;
    if (n != (wants_arg ? 2 : 1)) {
        printf("error: line %d: wrong number of operands\n", lineno);
        return -1;
    }
    if (ncode == MAX_CODE) {
        printf("error: line %d: program too long\n", lineno);
        return -1;

    in->op = (enum op)op;
    in->line = lineno;

        }

--- solution
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

typedef struct {
    char *name;    /* "section.key" or "key", lowercased */
    char *value;
} Entry;

static Entry *entries;
static size_t count, cap;

static char *dup_range(const char *s, size_t n) {
    char *p = malloc(n + 1);
    if (!p) exit(2);
    memcpy(p, s, n);
    p[n] = '\0';
    return p;
}

/* Trim spaces and tabs in place; returns the start and sets *len. */
static const char *trim(const char *s, size_t *len) {
    const char *e = s + strlen(s);
    while (*s == ' ' || *s == '\t') s++;
    while (e > s && (e[-1] == ' ' || e[-1] == '\t')) e--;
    *len = (size_t)(e - s);
    return s;
}

static int valid_name(const char *s, size_t n) {
    if (n == 0) return 0;
    for (size_t i = 0; i < n; i++)
        if (!(isalnum((unsigned char)s[i]) || s[i] == '_' || s[i] == '-')) return 0;
    return 1;
}

static void set(char *name, char *value) {
    for (size_t i = 0; i < count; i++)
        if (strcmp(entries[i].name, name) == 0) {
            free(entries[i].value);
            free(name);
            entries[i].value = value;
            return;
        }
    if (count == cap) {
        cap = cap ? cap * 2 : 16;
        Entry *p = realloc(entries, cap * sizeof *p);
        if (!p) exit(2);
        entries = p;
    }
    entries[count].name = name;
    entries[count].value = value;
    count++;
}

static int by_name(const void *a, const void *b) {
    return strcmp(((const Entry *)a)->name, ((const Entry *)b)->name);
}

static void free_all(void) {
    for (size_t i = 0; i < count; i++) {
        free(entries[i].name);
        free(entries[i].value);
    }
    free(entries);
}

int main(void) {
    char line[1024];
    char section[256] = "";
    int lineno = 0;
    while (fgets(line, sizeof line, stdin)) {
        lineno++;
        line[strcspn(line, "\r\n")] = '\0';
        size_t n;
        const char *s = trim(line, &n);
        if (n == 0 || *s == ';' || *s == '#') continue;
        if (*s == '[') {
            if (s[n - 1] != ']') goto bad;
            char inner[256];
            if (n - 2 >= sizeof inner) goto bad;
            memcpy(inner, s + 1, n - 2);
            inner[n - 2] = '\0';
            size_t m;
            const char *name = trim(inner, &m);
            if (!valid_name(name, m)) goto bad;
            for (size_t i = 0; i < m; i++) section[i] = (char)tolower((unsigned char)name[i]);
            section[m] = '\0';
            continue;
        }
        const char *eq = strchr(s, '=');
        if (!eq) goto bad;
        char keybuf[1024];
        memcpy(keybuf, s, (size_t)(eq - s));
        keybuf[eq - s] = '\0';
        size_t klen;
        const char *key = trim(keybuf, &klen);
        if (!valid_name(key, klen)) goto bad;
        size_t vlen;
        const char *val = trim(eq + 1, &vlen);
        if (vlen > 0 && *val == '"') {
            if (vlen < 2 || val[vlen - 1] != '"') goto bad;
            val++;
            vlen -= 2;
            if (memchr(val, '"', vlen)) goto bad;
        }
        size_t slen = strlen(section);
        char *full = malloc(slen + 1 + klen + 1);
        if (!full) return 2;
        char *w = full;
        if (slen) {
            memcpy(w, section, slen);
            w += slen;
            *w++ = '.';
        }
        for (size_t i = 0; i < klen; i++) *w++ = (char)tolower((unsigned char)key[i]);
        *w = '\0';
        set(full, dup_range(val, vlen));
    }
    if (count > 0) qsort(entries, count, sizeof *entries, by_name);
    for (size_t i = 0; i < count; i++) printf("%s=%s\n", entries[i].name, entries[i].value);
    free_all();
    return 0;
bad:
    printf("error: line %d\n", lineno);
    free_all();
    return 1;
}

--- q
A string builder grows its buffer by a fixed 64 bytes whenever it is full. What is the total cost of appending `n` characters one at a time?
--- choice
O(n), the same as doubling
--- answer
O(n²), because each regrowth may copy everything so far, and there are n/64 regrowths
--- choice
O(n log n)
--- choice
O(1) per append, because realloc never copies
--- explain
With a fixed increment there are about n/64 reallocations, each of which may copy the whole current buffer: 64 + 128 + ... + n, which is O(n²). Multiplying the capacity (by 2, or 1.5) makes the copies form a geometric series whose sum is O(n): amortized O(1) per append. `realloc` *can* sometimes extend in place, but you cannot rely on it.

--- answer
Because the rule for a lower-precedence operator is built from the rule for the higher one, so `*` groups first

--- explain
In `1 + 2 * 3`, `expr` asks `term` for its operands; `term` consumes `2 * 3` as a unit before `expr` ever sees the `+`. Each precedence level is one function, from loosest at the top to tightest at the bottom.

static size_t round_block(size_t n) {
    if (n < 16) n = 16;
    return (n + 15) & ~(size_t)15;
}

int main(void) {

`(n + 15) & ~15` rounds up to the next multiple of 16 (leaving multiples alone). The minimum of 16 guarantees room for the free-list pointer and keeps every block aligned like `malloc`'s.

--- choice

--- answer

With the root at index 0, the children of `i` are `2i + 1` and `2i + 2`, and the parent is `(i - 1) / 2`. The whole tree is implicit in the indices, so the heap needs no pointers and sits in one contiguous block of memory.

--- q
Your event queue uses lazy deletion: cancelled events stay in the heap and are discarded when they reach the top. What is the main cost?
--- choice
Popping becomes O(n)
--- answer
The heap can hold dead entries, so memory use is bounded by events pushed rather than events pending
--- choice
Events at the same tick come out in the wrong order
--- choice
Cancelling becomes O(log n)
--- explain
Every event is still pushed once and popped once, so the total work stays O(log n) per event and cancelling is O(1). The price is memory: if you cancel far more than you pop, dead entries pile up. Real engines rebuild the heap when the dead fraction gets large.
