## Plants as string rewriting

In 1968 the biologist Aristid Lindenmayer modeled the growth of algae as **parallel string rewriting**: start with a string (the *axiom*), and in each generation replace *every* symbol at once by its successor (its *production rule*). Przemysław Prusinkiewicz turned this into a graphics tool by interpreting the result with a **turtle**, and the book he wrote with Lindenmayer, *The Algorithmic Beauty of Plants* (1990, free on algorithmicbotany.org, "ABOP" below), is still the reference. Most of what follows is from its first three chapters.

Lindenmayer's algae:

```text
axiom:  A
rules:  A -> AB,  B -> A

gen 0:  A
gen 1:  AB
gen 2:  ABA
gen 3:  ABAAB
gen 4:  ABAABABA
```

The lengths are the Fibonacci numbers. That is the first thing to internalize: **L-system strings grow exponentially**. A rule with 5 symbols applied 10 times gives about 10 million symbols. Every piece of code in this chapter has to be written for that.

Symbols without a rule are copied unchanged (`+`, `-`, `[`, `]` usually have none).

## Generating strings without quadratic traps

The naive implementation appends successor after successor with `strcat`, or grows the output with `realloc` for every symbol. `strcat` must find the end of the string first, so building a string of length `n` that way is O(n²): for 10 million symbols, 50 trillion byte reads. Do this instead:

1. **Compute the final length first.** Length is linear: `len_g(c)`, the length that symbol `c` becomes after `g` generations, is 1 for `g = 0` and the sum of `len_{g-1}` over the successor's symbols after that. That is a dynamic program over the ~100 symbols, independent of the string, and it costs microseconds even for 1000 generations (where the string itself would not fit in the universe).
2. **Allocate once**, two buffers big enough for the largest generation, and ping-pong between them.
3. **Write with a cursor**: `memcpy(out + len, succ, succ_len); len += succ_len;` with the successor lengths precomputed once per run, not `strlen` per symbol.

```c
#include <stdio.h>
#include <stdint.h>

int main(void) {
    /* length of the algae system after g generations, without building any string */
    uint64_t a = 1, b = 1;                     /* len_g(A), len_g(B) */
    for (int g = 1; g <= 90; g++) {
        uint64_t na = a + b, nb = a;           /* A -> AB, B -> A */
        a = na; b = nb;
        if (g % 15 == 0) printf("gen %2d: %llu symbols\n", g, (unsigned long long)a);
    }
    return 0;
}
```

> **Performance:** "count, allocate once, fill" is the pattern for every generator whose output size can be known: L-systems, meshes, text exports, particle bursts. When the size cannot be known in advance (stochastic rules), the next best is: run the generator twice with the same seed, once counting and once writing, or grow geometrically (double the capacity), never by a constant.

## The turtle

Interpret the string left to right as commands to a pen-carrying turtle with a position and a heading:

| symbol | action |
|---|---|
| `F`, `G` | move forward one step, drawing a line |
| `f` | move forward without drawing |
| `+` / `-` | turn left / right by the angle δ |
| `\|` | turn around (180°) |
| `[` | push the turtle state (position, heading) on a stack |
| `]` | pop it: jump back to where the branch started |

Brackets are what make plants: `F[+F]F` draws a stem with a side branch. The stack is a fixed-size array of states, not a linked list and not recursion; real plants nest a few dozen levels deep at most, so 64 entries is plenty, and overflowing it is an error you report, not a crash.

> **Performance:** a turn by the same δ happens millions of times, so compute `cos δ` and `sin δ` once and rotate the heading *vector* `(dx, dy)` by them, instead of keeping an angle and calling `cosf`/`sinf` for every `F`. Rounding drift over millions of rotations is real but tiny in `float` for drawings; brackets reset it anyway, since a pop restores the saved vector.

The classic curves are all one-liners (δ is the turn angle):

| curve | axiom | rules | δ |
|---|---|---|---|
| Koch snowflake | `F--F--F` | `F -> F+F--F+F` | 60° |
| Dragon curve (Heighway) | `FX` | `X -> X+YF+`, `Y -> -FX-Y` | 90° |
| Hilbert curve | `A` | `A -> +BF-AFA-FB+`, `B -> -AF+BFB+FA-` | 90° |
| Sierpinski arrowhead | `F` | `F -> G-F-G`, `G -> F+G+F` | 60° |
| Fractal plant (ABOP 1.24) | `X` | `X -> F+[[X]-X]-F[-FX]+X`, `F -> FF` | 25° |

`X`, `Y`, `A`, `B` draw nothing; they only exist to be rewritten. A complete program that rewrites and draws the plant (it uses `strcat`, which is fine at this size, and exactly the habit to drop for the exercises):

```c
#include <stdio.h>
#include <string.h>
#include <math.h>

enum { W = 128, H = 128, MAXLEN = 200000 };
static char a[MAXLEN], b[MAXLEN];
static unsigned char img[H][W];

int main(void) {
    strcpy(a, "X");
    for (int g = 0; g < 5; g++) {                       /* rewrite 5 times */
        size_t n = 0;
        for (const char *p = a; *p; p++) {
            const char *s = *p == 'X' ? "F+[[X]-X]-F[-FX]+X" : *p == 'F' ? "FF" : NULL;
            size_t k = s ? strlen(s) : 1;
            memcpy(b + n, s ? s : p, k);
            n += k;
        }
        b[n] = '\0';
        memcpy(a, b, n + 1);
    }
    float x = 40, y = 127, dx = 0, dy = -1.6f, c = cosf(25 * 3.14159265f / 180), s = sinf(25 * 3.14159265f / 180);
    float stack[64][4];
    int sp = 0;
    for (const char *p = a; *p; p++) {
        switch (*p) {
        case 'F':
            for (int k = 0; k < 4; k++) {               /* 4 dots per step */
                int px = (int)(x + dx * k * 0.25f), py = (int)(y + dy * k * 0.25f);
                if (px >= 0 && px < W && py >= 0 && py < H) img[py][px] = 1;
            }
            x += dx; y += dy;
            break;
        case '+': { float t = dx * c - dy * s; dy = dx * s + dy * c; dx = t; break; }
        case '-': { float t = dx * c + dy * s; dy = -dx * s + dy * c; dx = t; break; }
        case '[': stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++; break;
        case ']': sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3]; break;
        }
    }
    printf("P2\n%d %d\n1\n", W, H);
    for (int i = 0; i < H; i++)
        for (int j = 0; j < W; j++) printf("%d%c", !img[i][j], j == W - 1 ? '\n' : ' ');
    return 0;
}
```

## Stochastic L-systems

Every plant from a deterministic L-system is an exact clone. ABOP's fix (section 1.7): give a symbol several successors with probabilities, and pick one *per symbol occurrence* per generation:

```text
F -> F[+F]F[-F]F    (weight 1)
F -> F[+F]F         (weight 1)
F -> F[-F]F         (weight 1)
```

Use a seeded PRNG, consumed in a fixed order (left to right, generation by generation), so a seed always gives the same plant: you can store a forest as a list of seeds. The length is no longer known in advance, but because the PRNG is deterministic you can **replay** it: run a generation once with a copy of the PRNG state to count, size the buffer, then run it again with the real state to write.

## Parametric L-systems

Strings of characters cannot say "this branch is 70% as long as its parent". **Parametric L-systems** (ABOP chapter 1.10) attach numbers to symbols: modules like `F(1.0)`, `+(30)`, `!(0.5)`, and productions compute the successors' parameters from the predecessor's:

```text
A(l) -> F(l) [ +(30) A(l * 0.7) ] [ -(25) A(l * 0.6) ]
```

The right representation in C is an array of `struct { char sym; float p; }`, not text with parentheses: no parsing, no number formatting, constant size per module, and the generation loop is the same "count, allocate, fill" as before. (Full parametric L-systems also have *conditions*, `A(l) : l > 0.1 -> ...`; we leave them out so that lengths stay computable up front.)

## The 3D turtle

In 3D the turtle carries a frame of three unit vectors: **H** (heading), **L** (left) and **U** (up), with `H × L = U`. Rotations turn two of them around the third:

| symbol | rotation | around |
|---|---|---|
| `+` / `-` | turn left / right (yaw) | U |
| `&` / `^` | pitch down / up | L |
| `\` / `/` | roll left / right | H |
| `\|` | turn around | U, 180° |

A branch segment is a cylinder along H; L and U are exactly the two vectors you need to place its ring of vertices, so the turtle's frame doubles as the cylinder's local coordinate system and the rings never twist. ABOP's trees also use `!(w)` to set the branch width, which lets old trunk segments thicken as the tree grows.

> **Performance:** a tree of a few thousand segments becomes tens of thousands of triangles. Count segments and leaves first (just count `F` and `L` modules in the final string), allocate the vertex and index arrays once, and write them with cursors, exactly as for the terrain mesh. Game engines go further: they generate a few tree variants once at load time, bake them into vertex buffers, and draw thousands of instances.

=== exercise ls_length
title: L-systems 1: length without the string
--- prompt
Implement `uint64_t ls_length(const LSystem *ls, const char *axiom, int n)`: the length of the string after `n` generations, **without building it**.

Keep an array `len[128]`, where `len[c]` is how long symbol `c` becomes after the current number of generations. Initially (0 generations) every symbol has length 1. One generation later, a symbol with rule `s` has length `len_next[c] = sum of len[s[i]]` over the characters of its successor, and a symbol without a rule stays 1. After `n` rounds, the answer is the sum of `len[c]` over the axiom's characters.

Lengths can exceed 64 bits (the algae system passes `2^64` around generation 92). **Saturate**: if any sum would overflow, use `UINT64_MAX` instead, and keep it there.

The tests ask for generation 1000 of several systems. Expanding the string is impossible; the dynamic program takes `n × (total rule length)` steps.

Symbols are 7-bit ASCII (`ls->rule[(unsigned char)c]`).

Vec3 v3(float x, float y, float z) { Vec3 r = {x, y, z}; return r; }
Vec3 v3_add(Vec3 a, Vec3 b) { return v3(a.x + b.x, a.y + b.y, a.z + b.z); }
Vec3 v3_sub(Vec3 a, Vec3 b) { return v3(a.x - b.x, a.y - b.y, a.z - b.z); }
Vec3 v3_scale(Vec3 a, float s) { return v3(a.x * s, a.y * s, a.z * s); }

Vec3 v3_cross(Vec3 a, Vec3 b) { return v3(a.y * b.z - a.z * b.y, a.z * b.x - a.x * b.z, a.x * b.y - a.y * b.x); }

Vec3 v3_norm(Vec3 a) { float l = v3_len(a); return l > 0 ? v3_scale(a, 1.0f / l) : a; }

    return x;
}

typedef struct { int w, h; unsigned char *px; } Image;      /* RGB, 3 bytes per pixel, row-major */
Image img_new(int w, int h) { Image im = {w, h, calloc((size_t)w * h * 3, 1)}; return im; }
void img_free(Image *im) { free(im->px); im->px = NULL; }
void img_fill(Image *im, int r, int g, int b) {
    for (size_t i = 0, n = (size_t)im->w * im->h; i < n; i++) {
        im->px[3 * i] = (unsigned char)r; im->px[3 * i + 1] = (unsigned char)g; im->px[3 * i + 2] = (unsigned char)b;
    }
}
void img_set(Image *im, int x, int y, int r, int g, int b) {   /* ignores pixels outside the image */
    if (x < 0 || y < 0 || x >= im->w || y >= im->h) return;
    unsigned char *p = im->px + ((size_t)y * im->w + x) * 3;

}

        if (e2 <= dx) { err += dx; y0 += sy; }

}

/* ===== This chapter: an L-system is one successor string per symbol (NULL: the symbol stays) ===== */

typedef struct { const char *rule[128]; } LSystem;

uint64_t sat_add(uint64_t a, uint64_t b) { return a > UINT64_MAX - b ? UINT64_MAX : a + b; }

uint64_t ls_length(const LSystem *ls, const char *axiom, int n) {
    uint64_t len[128], next[128];
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < n; g++) {
        for (int c = 0; c < 128; c++) {
            const char *r = ls->rule[c];
            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

int main(void) {
    LSystem algae = {.rule = {['A'] = "AB", ['B'] = "A"}};
    LSystem plant = {.rule = {['X'] = "F+[[X]-X]-F[-FX]+X", ['F'] = "FF"}};
    for (int g = 0; g <= 100; g += 10)
        printf("gen %3d: algae %20llu   plant %20llu\n", g,
               (unsigned long long)ls_length(&algae, "A", g), (unsigned long long)ls_length(&plant, "X", g));
    return 0;

--- prompt
Implement `char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len)`: the string after `n` generations, in a heap buffer the caller frees, with its length in `*out_len`.

- Use `ls_length` for generations `0..n` to find the **largest** length any generation reaches (rules can erase symbols, so it is not always the last one). If it is above `1u << 28`, return `NULL`.
- Allocate **two** buffers of that size + 1, once. Copy the axiom into one; each generation reads one buffer and writes the other with a write cursor, then swap. Free the buffer you do not return.
- Precompute each rule's successor length once (`size_t rlen[128]`) instead of calling `strlen` per symbol.

The large test expands the algae system to generation 33: 9.2 million symbols. With a write cursor and `memcpy` that takes a fraction of a second even under the sanitizers. With `strcat` (which rescans the output from the start on every call), or with `strlen(out)` in a loop condition, it takes hours.

--- stubs
char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {
    (void)ls; (void)n;
    char *s = malloc(strlen(axiom) + 1);
    strcpy(s, axiom);
    *out_len = strlen(s);

/* ===== This chapter: an L-system is one successor string per symbol (NULL: the symbol stays) ===== */

typedef struct { const char *rule[128]; } LSystem;

uint64_t sat_add(uint64_t a, uint64_t b) { return a > UINT64_MAX - b ? UINT64_MAX : a + b; }

uint64_t ls_length(const LSystem *ls, const char *axiom, int n) {
    uint64_t len[128], next[128];
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < n; g++) {
        for (int c = 0; c < 128; c++) {
            const char *r = ls->rule[c];
            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {
    uint64_t maxlen = 0;
    for (int g = 0; g <= n; g++) {
        uint64_t l = ls_length(ls, axiom, g);
        if (l > maxlen) maxlen = l;
    }
    if (maxlen > (1u << 28)) return NULL;
    size_t rlen[128];
    for (int c = 0; c < 128; c++) rlen[c] = ls->rule[c] ? strlen(ls->rule[c]) : 0;
    char *cur = malloc(maxlen + 1), *nxt = malloc(maxlen + 1);
    size_t len = strlen(axiom);
    memcpy(cur, axiom, len + 1);
    for (int g = 0; g < n; g++) {
        size_t w = 0;
        for (size_t i = 0; i < len; i++) {
            unsigned char c = (unsigned char)cur[i];
            const char *r = ls->rule[c];
            if (r) { memcpy(nxt + w, r, rlen[c]); w += rlen[c]; }
            else nxt[w++] = (char)c;
        }
        nxt[w] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        len = w;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

Interpret a string as turtle commands and output line segments:

```c
typedef struct { float x0, y0, x1, y1; int depth; } Seg;
```

The turtle starts at `(0, 0)` facing `heading_deg` (0 is +x, 90 is +y; y points **up** here). Symbols:

- `F`, `G`: move `step` forward and emit a segment from the old to the new position, with `depth` = the current bracket nesting depth;

typedef struct { float x0, y0, x1, y1; int depth; } Seg;

#define TURTLE_STACK 64

int turtle2d(const char *s, float step, float angle_deg, float heading_deg, Seg *out, int cap) {
    const float rad = 3.14159265358979f / 180;
    float c = cosf(angle_deg * rad), sn = sinf(angle_deg * rad);
    float x = 0, y = 0, dx = cosf(heading_deg * rad), dy = sinf(heading_deg * rad);
    float stack[TURTLE_STACK][4];
    int sp = 0, count = 0;
    for (const char *p = s; *p; p++) {
        float t;
        switch (*p) {
        case 'F': case 'G':
            if (count < cap) {
                Seg sg = {x, y, x + dx * step, y + dy * step, sp};
                out[count] = sg;
            }
            count++;
            x += dx * step; y += dy * step;
            break;
        case 'f': x += dx * step; y += dy * step; break;
        case '+': t = dx * c - dy * sn; dy = dx * sn + dy * c; dx = t; break;
        case '-': t = dx * c + dy * sn; dy = -dx * sn + dy * c; dx = t; break;
        case '|': dx = -dx; dy = -dy; break;
        case '[':
            if (sp == TURTLE_STACK) return -1;
            stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++;
            break;
        case ']':
            if (sp == 0) return -1;
            sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3];
            break;
        default: break;
        }
    }
    return count;
}

```text
aw = W - 1 - 2*margin,  ah = H - 1 - 2*margin,  bw = maxx - minx,  bh = maxy - miny
scale = min(aw / bw, ah / bh)       (a zero extent does not limit: use the other ratio; both zero: scale = 1)
ox = margin + (aw - bw * scale) / 2,  oy = margin + (ah - bh * scale) / 2
pixel x = (int)floorf(ox + (x - minx) * scale + 0.5f)
pixel y = H - 1 - (int)floorf(oy + (y - miny) * scale + 0.5f)
```

and draws each segment with the starter's `img_line`. When you click **Run** you get the classic curves from the table in the chapter text: Koch snowflake, dragon, Hilbert and Sierpinski arrowhead.

The tests also check the curves' known properties through your whole pipeline: the Hilbert curve of order 4 visits every point of a 16 × 16 grid exactly once, the dragon curve never draws the same unit edge twice.

typedef struct { const char *rule[128]; } LSystem;

uint64_t sat_add(uint64_t a, uint64_t b) { return a > UINT64_MAX - b ? UINT64_MAX : a + b; }

uint64_t ls_length(const LSystem *ls, const char *axiom, int n) {
    uint64_t len[128], next[128];
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < n; g++) {
        for (int c = 0; c < 128; c++) {
            const char *r = ls->rule[c];
            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {
    uint64_t maxlen = 0;
    for (int g = 0; g <= n; g++) {
        uint64_t l = ls_length(ls, axiom, g);
        if (l > maxlen) maxlen = l;
    }
    if (maxlen > (1u << 28)) return NULL;
    size_t rlen[128];
    for (int c = 0; c < 128; c++) rlen[c] = ls->rule[c] ? strlen(ls->rule[c]) : 0;
    char *cur = malloc(maxlen + 1), *nxt = malloc(maxlen + 1);
    size_t len = strlen(axiom);
    memcpy(cur, axiom, len + 1);
    for (int g = 0; g < n; g++) {
        size_t w = 0;
        for (size_t i = 0; i < len; i++) {
            unsigned char c = (unsigned char)cur[i];
            const char *r = ls->rule[c];
            if (r) { memcpy(nxt + w, r, rlen[c]); w += rlen[c]; }
            else nxt[w++] = (char)c;
        }
        nxt[w] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        len = w;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { float x0, y0, x1, y1; int depth; } Seg;

#define TURTLE_STACK 64

int turtle2d(const char *s, float step, float angle_deg, float heading_deg, Seg *out, int cap) {
    const float rad = 3.14159265358979f / 180;
    float c = cosf(angle_deg * rad), sn = sinf(angle_deg * rad);
    float x = 0, y = 0, dx = cosf(heading_deg * rad), dy = sinf(heading_deg * rad);
    float stack[TURTLE_STACK][4];
    int sp = 0, count = 0;
    for (const char *p = s; *p; p++) {
        float t;
        switch (*p) {
        case 'F': case 'G':
            if (count < cap) {
                Seg sg = {x, y, x + dx * step, y + dy * step, sp};
                out[count] = sg;
            }
            count++;
            x += dx * step; y += dy * step;
            break;
        case 'f': x += dx * step; y += dy * step; break;
        case '+': t = dx * c - dy * sn; dy = dx * sn + dy * c; dx = t; break;
        case '-': t = dx * c + dy * sn; dy = -dx * sn + dy * c; dx = t; break;
        case '|': dx = -dx; dy = -dy; break;
        case '[':
            if (sp == TURTLE_STACK) return -1;
            stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++;
            break;
        case ']':
            if (sp == 0) return -1;
            sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3];
            break;
        default: break;
        }
    }
    return count;
}

void seg_bounds(const Seg *s, int n, float *minx, float *miny, float *maxx, float *maxy) {
    if (n <= 0) { *minx = *miny = *maxx = *maxy = 0; return; }
    float a = s[0].x0, b = s[0].y0, c = s[0].x0, d = s[0].y0;
    for (int i = 0; i < n; i++) {
        a = fminf(a, fminf(s[i].x0, s[i].x1)); c = fmaxf(c, fmaxf(s[i].x0, s[i].x1));
        b = fminf(b, fminf(s[i].y0, s[i].y1)); d = fmaxf(d, fmaxf(s[i].y0, s[i].y1));
    }
    *minx = a; *miny = b; *maxx = c; *maxy = d;
}

void draw_segments(Image *im, const Seg *s, int n, int margin, int r, int g, int b) {
    float minx, miny, maxx, maxy;
    seg_bounds(s, n, &minx, &miny, &maxx, &maxy);
    float aw = (float)(im->w - 1 - 2 * margin), ah = (float)(im->h - 1 - 2 * margin);
    float bw = maxx - minx, bh = maxy - miny, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = margin + (aw - bw * scale) / 2, oy = margin + (ah - bh * scale) / 2;
    for (int i = 0; i < n; i++) {
        int x0 = (int)floorf(ox + (s[i].x0 - minx) * scale + 0.5f);
        int y0 = im->h - 1 - (int)floorf(oy + (s[i].y0 - miny) * scale + 0.5f);
        int x1 = (int)floorf(ox + (s[i].x1 - minx) * scale + 0.5f);
        int y1 = im->h - 1 - (int)floorf(oy + (s[i].y1 - miny) * scale + 0.5f);
        img_line(im, x0, y0, x1, y1, r, g, b);
    }
}

void draw_curve(Image *out, int ox, int oy, const LSystem *ls, const char *axiom, int gens, float angle, int r, int g, int b) {
    size_t n;
    char *s = ls_expand(ls, axiom, gens, &n);
    int count = turtle2d(s, 1, angle, 0, NULL, 0);
    Seg *segs = malloc(sizeof(Seg) * count);
    turtle2d(s, 1, angle, 0, segs, count);
    Image tile = img_new(64, 64);
    img_fill(&tile, 250, 248, 240);
    draw_segments(&tile, segs, count, 3, r, g, b);
    for (int y = 0; y < 64; y++) memcpy(out->px + 3 * ((size_t)(oy + y) * out->w + ox), tile.px + 3 * (size_t)y * 64, 64 * 3);
    img_free(&tile); free(segs); free(s);
}

=== exercise ls_stochastic
title: L-systems 5: stochastic rules
continues: ls_draw
--- prompt
Give symbols several weighted successors so every seed grows a different plant:

```c
typedef struct { const char *succ; int weight; } Choice;
typedef struct { Choice choice[128][4]; int count[128]; } StochLSystem;    /* count[c] == 0: no rule */
uint32_t rng_next(uint32_t *state);
char *ls_expand_stochastic(const StochLSystem *ls, const char *axiom, int n, uint32_t seed, size_t *out_len);
```

`rng_next` is given in the stubs (an LCG step followed by the starter's `hash32`; every 32-bit state is valid, including 0). The state starts at `seed` and continues across generations.

Each generation goes through the current string left to right. For a symbol `c`:

- `count[c] == 0`: copy it;
- `count[c] == 1`: write its only successor, **without** touching the PRNG;
- `count[c] >= 2`: `r = rng_next(&state) % total_weight`; pick the first successor whose running weight sum is `> r`.

The final length now depends on the choices, so `ls_length` cannot size the buffers. Do it in two passes per generation: copy the PRNG state and run the generation once **counting** only; grow the output buffer if needed (to at least that length + 1, and at least double its old capacity); then run it again with the real state, **writing**. Because the PRNG is deterministic, both passes make the same choices. Return the final string (heap, caller frees) and its length.

The large test grows a weed to about 6 million symbols; per-symbol `realloc`, `strcat` or `strlen` will not finish.

            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {

#define TURTLE_STACK 64

int turtle2d(const char *s, float step, float angle_deg, float heading_deg, Seg *out, int cap) {
    const float rad = 3.14159265358979f / 180;
    float c = cosf(angle_deg * rad), sn = sinf(angle_deg * rad);
    float x = 0, y = 0, dx = cosf(heading_deg * rad), dy = sinf(heading_deg * rad);
    float stack[TURTLE_STACK][4];
    int sp = 0, count = 0;
    for (const char *p = s; *p; p++) {
        float t;
        switch (*p) {
        case 'F': case 'G':
            if (count < cap) {
                Seg sg = {x, y, x + dx * step, y + dy * step, sp};
                out[count] = sg;
            }
            count++;
            x += dx * step; y += dy * step;
            break;
        case 'f': x += dx * step; y += dy * step; break;
        case '+': t = dx * c - dy * sn; dy = dx * sn + dy * c; dx = t; break;
        case '-': t = dx * c + dy * sn; dy = -dx * sn + dy * c; dx = t; break;
        case '|': dx = -dx; dy = -dy; break;
        case '[':
            if (sp == TURTLE_STACK) return -1;
            stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++;
            break;
        case ']':
            if (sp == 0) return -1;
            sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3];
            break;
        default: break;
        }
    }
    return count;
}

void seg_bounds(const Seg *s, int n, float *minx, float *miny, float *maxx, float *maxy) {
    if (n <= 0) { *minx = *miny = *maxx = *maxy = 0; return; }
    float a = s[0].x0, b = s[0].y0, c = s[0].x0, d = s[0].y0;
    for (int i = 0; i < n; i++) {
        a = fminf(a, fminf(s[i].x0, s[i].x1)); c = fmaxf(c, fmaxf(s[i].x0, s[i].x1));
        b = fminf(b, fminf(s[i].y0, s[i].y1)); d = fmaxf(d, fmaxf(s[i].y0, s[i].y1));
    }
    *minx = a; *miny = b; *maxx = c; *maxy = d;
}

void draw_segments(Image *im, const Seg *s, int n, int margin, int r, int g, int b) {
    float minx, miny, maxx, maxy;
    seg_bounds(s, n, &minx, &miny, &maxx, &maxy);
    float aw = (float)(im->w - 1 - 2 * margin), ah = (float)(im->h - 1 - 2 * margin);
    float bw = maxx - minx, bh = maxy - miny, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = margin + (aw - bw * scale) / 2, oy = margin + (ah - bh * scale) / 2;
    for (int i = 0; i < n; i++) {
        int x0 = (int)floorf(ox + (s[i].x0 - minx) * scale + 0.5f);
        int y0 = im->h - 1 - (int)floorf(oy + (s[i].y0 - miny) * scale + 0.5f);
        int x1 = (int)floorf(ox + (s[i].x1 - minx) * scale + 0.5f);
        int y1 = im->h - 1 - (int)floorf(oy + (s[i].y1 - miny) * scale + 0.5f);
        img_line(im, x0, y0, x1, y1, r, g, b);
    }
}

typedef struct { const char *succ; int weight; } Choice;
typedef struct { Choice choice[128][4]; int count[128]; } StochLSystem;

/* one generation; out == NULL only counts. Returns the new length. */
size_t stoch_pass(const StochLSystem *ls, const size_t rlen[128][4], const int total[128],
                  const char *cur, size_t len, uint32_t *state, char *out) {
    size_t w = 0;
    for (size_t i = 0; i < len; i++) {
        unsigned char c = (unsigned char)cur[i];
        int k = 0;
        if (ls->count[c] == 0) {
            if (out) out[w] = (char)c;
            w++;
            continue;
        }
        if (ls->count[c] >= 2) {
            int r = (int)(rng_next(state) % (uint32_t)total[c]), acc = 0;
            for (k = 0; k < ls->count[c] - 1; k++) {
                acc += ls->choice[c][k].weight;
                if (acc > r) break;
            }
        }
        if (out) memcpy(out + w, ls->choice[c][k].succ, rlen[c][k]);
        w += rlen[c][k];
    }
    return w;
}

char *ls_expand_stochastic(const StochLSystem *ls, const char *axiom, int n, uint32_t seed, size_t *out_len) {
    size_t rlen[128][4];
    int total[128];
    for (int c = 0; c < 128; c++) {
        total[c] = 0;
        for (int k = 0; k < ls->count[c]; k++) {
            rlen[c][k] = strlen(ls->choice[c][k].succ);
            total[c] += ls->choice[c][k].weight;
        }
    }
    size_t len = strlen(axiom), cap_cur = len + 1, cap_nxt = len + 1;
    char *cur = malloc(cap_cur), *nxt = malloc(cap_nxt);
    memcpy(cur, axiom, len + 1);
    uint32_t state = seed;
    for (int g = 0; g < n; g++) {
        uint32_t probe = state;
        size_t need = stoch_pass(ls, rlen, total, cur, len, &probe, NULL);
        if (need + 1 > cap_nxt) {
            size_t nc = cap_nxt * 2 > need + 1 ? cap_nxt * 2 : need + 1;
            free(nxt);
            nxt = malloc(nc);
            cap_nxt = nc;
        }
        len = stoch_pass(ls, rlen, total, cur, len, &state, nxt);
        nxt[len] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        size_t tc = cap_cur; cap_cur = cap_nxt; cap_nxt = tc;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

    for (int i = 0; i < n; i++) {
        a = fminf(a, fminf(s[i].x0, s[i].x1)); c = fmaxf(c, fmaxf(s[i].x0, s[i].x1));
        b = fminf(b, fminf(s[i].y0, s[i].y1)); d = fmaxf(d, fmaxf(s[i].y0, s[i].y1));
    }
    *minx = a; *miny = b; *maxx = c; *maxy = d;
}

void draw_segments(Image *im, const Seg *s, int n, int margin, int r, int g, int b) {
    float minx, miny, maxx, maxy;
    seg_bounds(s, n, &minx, &miny, &maxx, &maxy);
    float aw = (float)(im->w - 1 - 2 * margin), ah = (float)(im->h - 1 - 2 * margin);
    float bw = maxx - minx, bh = maxy - miny, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = margin + (aw - bw * scale) / 2, oy = margin + (ah - bh * scale) / 2;
    for (int i = 0; i < n; i++) {
        int x0 = (int)floorf(ox + (s[i].x0 - minx) * scale + 0.5f);
        int y0 = im->h - 1 - (int)floorf(oy + (s[i].y0 - miny) * scale + 0.5f);
        int x1 = (int)floorf(ox + (s[i].x1 - minx) * scale + 0.5f);
        int y1 = im->h - 1 - (int)floorf(oy + (s[i].y1 - miny) * scale + 0.5f);
        img_line(im, x0, y0, x1, y1, r, g, b);
    }
}

uint32_t rng_next(uint32_t *state) {
    *state = *state * 1664525u + 1013904223u;
    return hash32(*state);
}

typedef struct { const char *succ; int weight; } Choice;
typedef struct { Choice choice[128][4]; int count[128]; } StochLSystem;

/* one generation; out == NULL only counts. Returns the new length. */
size_t stoch_pass(const StochLSystem *ls, const size_t rlen[128][4], const int total[128],
                  const char *cur, size_t len, uint32_t *state, char *out) {
    size_t w = 0;
    for (size_t i = 0; i < len; i++) {
        unsigned char c = (unsigned char)cur[i];
        int k = 0;
        if (ls->count[c] == 0) {
            if (out) out[w] = (char)c;
            w++;
            continue;
        }
        if (ls->count[c] >= 2) {
            int r = (int)(rng_next(state) % (uint32_t)total[c]), acc = 0;
            for (k = 0; k < ls->count[c] - 1; k++) {
                acc += ls->choice[c][k].weight;
                if (acc > r) break;
            }
        }
        if (out) memcpy(out + w, ls->choice[c][k].succ, rlen[c][k]);
        w += rlen[c][k];
    }
    return w;
}

char *ls_expand_stochastic(const StochLSystem *ls, const char *axiom, int n, uint32_t seed, size_t *out_len) {
    size_t rlen[128][4];
    int total[128];
    for (int c = 0; c < 128; c++) {
        total[c] = 0;
        for (int k = 0; k < ls->count[c]; k++) {
            rlen[c][k] = strlen(ls->choice[c][k].succ);
            total[c] += ls->choice[c][k].weight;
        }
    }
    size_t len = strlen(axiom), cap_cur = len + 1, cap_nxt = len + 1;
    char *cur = malloc(cap_cur), *nxt = malloc(cap_nxt);
    memcpy(cur, axiom, len + 1);
    uint32_t state = seed;
    for (int g = 0; g < n; g++) {
        uint32_t probe = state;
        size_t need = stoch_pass(ls, rlen, total, cur, len, &probe, NULL);
        if (need + 1 > cap_nxt) {
            size_t nc = cap_nxt * 2 > need + 1 ? cap_nxt * 2 : need + 1;
            free(nxt);
            nxt = malloc(nc);
            cap_nxt = nc;
        }
        len = stoch_pass(ls, rlen, total, cur, len, &state, nxt);
        nxt[len] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        size_t tc = cap_cur; cap_cur = cap_nxt; cap_nxt = tc;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { char sym; float p; } Module;
typedef struct { char sym; float mul, add; } PSucc;
typedef struct { const PSucc *succ[128]; int n[128]; } PLSystem;

int pls_expand(const PLSystem *ls, const Module *axiom, int na, int iterations, Module **out) {
    *out = NULL;
    uint64_t len[128], next[128], maxlen = (uint64_t)na;
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < iterations; g++) {
        for (int c = 0; c < 128; c++) {
            if (ls->n[c] == 0) { next[c] = 1; continue; }
            uint64_t s = 0;
            for (int k = 0; k < ls->n[c]; k++) s = sat_add(s, len[(unsigned char)ls->succ[c][k].sym]);
            next[c] = s;
        }
        memcpy(len, next, sizeof len);
        uint64_t total = 0;
        for (int i = 0; i < na; i++) total = sat_add(total, len[(unsigned char)axiom[i].sym]);
        if (total > maxlen) maxlen = total;
    }
    if (maxlen > (1u << 24)) return -1;
    Module *cur = malloc(sizeof(Module) * (maxlen ? maxlen : 1)), *nxt = malloc(sizeof(Module) * (maxlen ? maxlen : 1));
    memcpy(cur, axiom, sizeof(Module) * na);
    size_t count = (size_t)na;
    for (int g = 0; g < iterations; g++) {
        size_t w = 0;
        for (size_t i = 0; i < count; i++) {
            unsigned char c = (unsigned char)cur[i].sym;
            if (ls->n[c] == 0) { nxt[w++] = cur[i]; continue; }
            for (int k = 0; k < ls->n[c]; k++) {
                const PSucc *ps = &ls->succ[c][k];
                nxt[w].sym = ps->sym;
                nxt[w].p = cur[i].p * ps->mul + ps->add;
                w++;
            }
        }
        Module *t = cur; cur = nxt; nxt = t;
        count = w;
    }
    free(nxt);
    *out = cur;
    return (int)count;
}

--- prompt
Interpret modules in 3D. The turtle has a position `P`, a frame `H, L, U` (heading, left, up; `H × L = U`) and a width `w`.

```c
typedef struct { Vec3 a, b, h, l, u; float r; int depth; } Branch;   /* cylinder from a to b, radius r */
typedef struct { Vec3 pos, h, l, u; float size; } Leaf;
void turtle3d_count(const Module *m, int n, int *nbranches, int *nleaves);
int turtle3d(const Module *m, int n, float width0, Branch *br, Leaf *lf);
```

`turtle3d_count` counts `F` and `L` modules (that is all it takes to size the arrays). `turtle3d` starts at `P = (0,0,0)`, `H = (0,0,1)` (up the z axis), `L = (-1,0,0)`, `U = (0,-1,0)`, `w = width0`, and processes the modules (angles in degrees, `a` is the module's parameter, `c = cos a`, `s = sin a`):

| module | effect |
|---|---|
| `F(l)` | branch from `P` to `P + l H`, with the current `H, L, U`, `r = w / 2`, `depth` = bracket depth; then move `P` there |
| `f(l)` | move without a branch |
| `+(a)` / `-(a)` | yaw: `H' = H c + L s`, `L' = L c - H s` (`-` uses `-a`) |
| `&(a)` / `^(a)` | pitch: `H' = H c - U s`, `U' = U c + H s` (`^` uses `-a`) |
| `\(a)` / `/(a)` | roll: `L' = L c - U s`, `U' = U c + L s` (`/` uses `-a`) |
| `\|` | `H = -H`, `L = -L` |
| `!(x)` | `w = x` |
| `L(s)` | leaf at `P` with the current frame and `size = s` |
| `[` / `]` | push / pop `P, H, L, U, w` (64 deep) |

Return 0, or `-1` on stack overflow or an unmatched `]`. Store branches and leaves in order of appearance.

Each rotation keeps the frame orthonormal in exact arithmetic; in `float` it drifts slowly, which the tests tolerate for trees of realistic depth. (Long-lived turtles re-orthonormalize: `H = normalize(H)`, `L = normalize(U × H)`, `U = H × L`.)

**Run** shows ABOP's ternary tree (figure 2.8) projected onto the x-z plane, drawn with step 4's `draw_segments`.

/* ===== This chapter: an L-system is one successor string per symbol (NULL: the symbol stays) ===== */

typedef struct { const char *rule[128]; } LSystem;

uint64_t sat_add(uint64_t a, uint64_t b) { return a > UINT64_MAX - b ? UINT64_MAX : a + b; }

uint64_t ls_length(const LSystem *ls, const char *axiom, int n) {
    uint64_t len[128], next[128];
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < n; g++) {
        for (int c = 0; c < 128; c++) {
            const char *r = ls->rule[c];
            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {
    uint64_t maxlen = 0;
    for (int g = 0; g <= n; g++) {
        uint64_t l = ls_length(ls, axiom, g);
        if (l > maxlen) maxlen = l;
    }
    if (maxlen > (1u << 28)) return NULL;
    size_t rlen[128];
    for (int c = 0; c < 128; c++) rlen[c] = ls->rule[c] ? strlen(ls->rule[c]) : 0;
    char *cur = malloc(maxlen + 1), *nxt = malloc(maxlen + 1);

    memcpy(cur, axiom, len + 1);

        len = w;
    }

    *out_len = len;

}

typedef struct { float x0, y0, x1, y1; int depth; } Seg;

#define TURTLE_STACK 64

int turtle2d(const char *s, float step, float angle_deg, float heading_deg, Seg *out, int cap) {
    const float rad = 3.14159265358979f / 180;
    float c = cosf(angle_deg * rad), sn = sinf(angle_deg * rad);
    float x = 0, y = 0, dx = cosf(heading_deg * rad), dy = sinf(heading_deg * rad);
    float stack[TURTLE_STACK][4];
    int sp = 0, count = 0;
    for (const char *p = s; *p; p++) {
        float t;
        switch (*p) {
        case 'F': case 'G':
            if (count < cap) {
                Seg sg = {x, y, x + dx * step, y + dy * step, sp};
                out[count] = sg;
            }
            count++;
            x += dx * step; y += dy * step;
            break;
        case 'f': x += dx * step; y += dy * step; break;
        case '+': t = dx * c - dy * sn; dy = dx * sn + dy * c; dx = t; break;
        case '-': t = dx * c + dy * sn; dy = -dx * sn + dy * c; dx = t; break;
        case '|': dx = -dx; dy = -dy; break;
        case '[':
            if (sp == TURTLE_STACK) return -1;
            stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++;
            break;
        case ']':
            if (sp == 0) return -1;
            sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3];
            break;
        default: break;
        }
    }
    return count;
}

void seg_bounds(const Seg *s, int n, float *minx, float *miny, float *maxx, float *maxy) {
    if (n <= 0) { *minx = *miny = *maxx = *maxy = 0; return; }
    float a = s[0].x0, b = s[0].y0, c = s[0].x0, d = s[0].y0;
    for (int i = 0; i < n; i++) {
        a = fminf(a, fminf(s[i].x0, s[i].x1)); c = fmaxf(c, fmaxf(s[i].x0, s[i].x1));
        b = fminf(b, fminf(s[i].y0, s[i].y1)); d = fmaxf(d, fmaxf(s[i].y0, s[i].y1));
    }
    *minx = a; *miny = b; *maxx = c; *maxy = d;
}

void draw_segments(Image *im, const Seg *s, int n, int margin, int r, int g, int b) {
    float minx, miny, maxx, maxy;
    seg_bounds(s, n, &minx, &miny, &maxx, &maxy);
    float aw = (float)(im->w - 1 - 2 * margin), ah = (float)(im->h - 1 - 2 * margin);
    float bw = maxx - minx, bh = maxy - miny, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = margin + (aw - bw * scale) / 2, oy = margin + (ah - bh * scale) / 2;
    for (int i = 0; i < n; i++) {
        int x0 = (int)floorf(ox + (s[i].x0 - minx) * scale + 0.5f);
        int y0 = im->h - 1 - (int)floorf(oy + (s[i].y0 - miny) * scale + 0.5f);
        int x1 = (int)floorf(ox + (s[i].x1 - minx) * scale + 0.5f);
        int y1 = im->h - 1 - (int)floorf(oy + (s[i].y1 - miny) * scale + 0.5f);
        img_line(im, x0, y0, x1, y1, r, g, b);
    }
}

uint32_t rng_next(uint32_t *state) {
    *state = *state * 1664525u + 1013904223u;
    return hash32(*state);
}

typedef struct { const char *succ; int weight; } Choice;
typedef struct { Choice choice[128][4]; int count[128]; } StochLSystem;

/* one generation; out == NULL only counts. Returns the new length. */
size_t stoch_pass(const StochLSystem *ls, const size_t rlen[128][4], const int total[128],
                  const char *cur, size_t len, uint32_t *state, char *out) {
    size_t w = 0;
    for (size_t i = 0; i < len; i++) {
        unsigned char c = (unsigned char)cur[i];
        int k = 0;
        if (ls->count[c] == 0) {
            if (out) out[w] = (char)c;
            w++;
            continue;
        }
        if (ls->count[c] >= 2) {
            int r = (int)(rng_next(state) % (uint32_t)total[c]), acc = 0;
            for (k = 0; k < ls->count[c] - 1; k++) {
                acc += ls->choice[c][k].weight;
                if (acc > r) break;
            }
        }
        if (out) memcpy(out + w, ls->choice[c][k].succ, rlen[c][k]);
        w += rlen[c][k];
    }
    return w;
}

char *ls_expand_stochastic(const StochLSystem *ls, const char *axiom, int n, uint32_t seed, size_t *out_len) {
    size_t rlen[128][4];
    int total[128];
    for (int c = 0; c < 128; c++) {
        total[c] = 0;
        for (int k = 0; k < ls->count[c]; k++) {
            rlen[c][k] = strlen(ls->choice[c][k].succ);
            total[c] += ls->choice[c][k].weight;
        }
    }
    size_t len = strlen(axiom), cap_cur = len + 1, cap_nxt = len + 1;
    char *cur = malloc(cap_cur), *nxt = malloc(cap_nxt);
    memcpy(cur, axiom, len + 1);
    uint32_t state = seed;
    for (int g = 0; g < n; g++) {
        uint32_t probe = state;
        size_t need = stoch_pass(ls, rlen, total, cur, len, &probe, NULL);
        if (need + 1 > cap_nxt) {
            size_t nc = cap_nxt * 2 > need + 1 ? cap_nxt * 2 : need + 1;
            free(nxt);
            nxt = malloc(nc);
            cap_nxt = nc;
        }
        len = stoch_pass(ls, rlen, total, cur, len, &state, nxt);
        nxt[len] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        size_t tc = cap_cur; cap_cur = cap_nxt; cap_nxt = tc;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { char sym; float p; } Module;
typedef struct { char sym; float mul, add; } PSucc;
typedef struct { const PSucc *succ[128]; int n[128]; } PLSystem;

int pls_expand(const PLSystem *ls, const Module *axiom, int na, int iterations, Module **out) {
    *out = NULL;
    uint64_t len[128], next[128], maxlen = (uint64_t)na;
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < iterations; g++) {
        for (int c = 0; c < 128; c++) {
            if (ls->n[c] == 0) { next[c] = 1; continue; }
            uint64_t s = 0;
            for (int k = 0; k < ls->n[c]; k++) s = sat_add(s, len[(unsigned char)ls->succ[c][k].sym]);
            next[c] = s;
        }
        memcpy(len, next, sizeof len);
        uint64_t total = 0;
        for (int i = 0; i < na; i++) total = sat_add(total, len[(unsigned char)axiom[i].sym]);
        if (total > maxlen) maxlen = total;
    }
    if (maxlen > (1u << 24)) return -1;
    Module *cur = malloc(sizeof(Module) * (maxlen ? maxlen : 1)), *nxt = malloc(sizeof(Module) * (maxlen ? maxlen : 1));
    memcpy(cur, axiom, sizeof(Module) * na);
    size_t count = (size_t)na;
    for (int g = 0; g < iterations; g++) {
        size_t w = 0;
        for (size_t i = 0; i < count; i++) {
            unsigned char c = (unsigned char)cur[i].sym;
            if (ls->n[c] == 0) { nxt[w++] = cur[i]; continue; }
            for (int k = 0; k < ls->n[c]; k++) {
                const PSucc *ps = &ls->succ[c][k];
                nxt[w].sym = ps->sym;
                nxt[w].p = cur[i].p * ps->mul + ps->add;
                w++;
            }
        }
        Module *t = cur; cur = nxt; nxt = t;
        count = w;
    }
    free(nxt);
    *out = cur;
    return (int)count;
}

typedef struct { Vec3 a, b, h, l, u; float r; int depth; } Branch;
typedef struct { Vec3 pos, h, l, u; float size; } Leaf;

void turtle3d_count(const Module *m, int n, int *nbranches, int *nleaves) {

typedef struct { Vec3 p, h, l, u; float w; } Turtle3;

/* rotate the pair (x, y) by angle a: x' = x c + y s, y' = y c - x s */
void rot_pair(Vec3 *x, Vec3 *y, float a_deg) {
    float a = a_deg * 3.14159265358979f / 180, c = cosf(a), s = sinf(a);
    Vec3 nx = v3_add(v3_scale(*x, c), v3_scale(*y, s));
    Vec3 ny = v3_sub(v3_scale(*y, c), v3_scale(*x, s));
    *x = nx; *y = ny;
}

int turtle3d(const Module *m, int n, float width0, Branch *br, Leaf *lf) {
    Turtle3 t = {v3(0, 0, 0), v3(0, 0, 1), v3(-1, 0, 0), v3(0, -1, 0), width0}, stack[64];
    int sp = 0, nb = 0, nl = 0;
    for (int i = 0; i < n; i++) {
        float a = m[i].p;
        Vec3 nu;
        switch (m[i].sym) {
        case 'F': {
            Vec3 end = v3_add(t.p, v3_scale(t.h, a));
            Branch b = {t.p, end, t.h, t.l, t.u, t.w / 2, sp};
            br[nb++] = b;
            t.p = end;
            break;
        }
        case 'f': t.p = v3_add(t.p, v3_scale(t.h, a)); break;
        case '+': rot_pair(&t.h, &t.l, a); break;
        case '-': rot_pair(&t.h, &t.l, -a); break;
        case '&': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, a); t.u = v3_scale(nu, -1); break;
        case '^': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '\\': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, a); t.u = v3_scale(nu, -1); break;
        case '/': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '|': t.h = v3_scale(t.h, -1); t.l = v3_scale(t.l, -1); break;
        case '!': t.w = a; break;
        case 'L': {
            Leaf l = {t.p, t.h, t.l, t.u, a};
            lf[nl++] = l;
            break;
        }
        case '[':
            if (sp == 64) return -1;
            stack[sp++] = t;
            break;
        case ']':
            if (sp == 0) return -1;
            t = stack[--sp];
            break;
        default: break;
        }
    }
    return 0;
}

--- prompt
Turn each branch into a cylinder: a ring of `sides` vertices around `a` and another around `b`, joined by quads.

```c
typedef struct { int nverts, ntris; float *pos, *nrm; unsigned char *col; uint32_t *idx; } Mesh;
int mesh_alloc(Mesh *m, int nverts, int ntris);     /* one allocation per array; sets the counts */
void mesh_free(Mesh *m);
int branch_mesh(const Branch *br, int n, int sides, Mesh *out);
```

`mesh_alloc` allocates `pos` and `nrm` (3 floats per vertex), `col` (3 bytes per vertex) and `idx` (3 per triangle), returns 1, or 0 if any allocation failed (freeing the others). `mesh_free` frees and zeroes.

`branch_mesh` (`sides >= 3`) allocates exactly `2 * sides * n` vertices and `2 * sides * n` triangles, and for branch `k`, ring vertex `j` (`θ = 2π j / sides`, `d = L cos θ + U sin θ` using the branch's frame):

- vertex `2 * sides * k + j` = `a + r d` and vertex `2 * sides * k + sides + j` = `b + r d`, both with normal `d`, color (110, 80, 50);
- quad `j` (with `j1 = (j + 1) % sides`, `p = 2 * sides * k`, `q = p + sides`) is the triangles `(p + j, p + j1, q + j1)` and `(p + j, q + j1, q + j)`, stored at triangle index `2 * sides * k + 2 * j` and `+ 1`.

That winding faces outward (counter-clockwise seen from outside). The cylinder's frame comes from the turtle, so neighboring rings line up and never twist.

> **Performance:** a cylinder per branch is the naive approach used here; production tree generators (SpeedTree, ProcTree, Blender's Sapling) share rings between consecutive segments of a limb and drop the side count with distance. The sizes are still computed before the loop, which is the habit that matters.

void img_line(Image *im, int x0, int y0, int x1, int y1, int r, int g, int b) {   /* Bresenham */
    int dx = abs(x1 - x0), sx = x0 < x1 ? 1 : -1, dy = -abs(y1 - y0), sy = y0 < y1 ? 1 : -1, err = dx + dy;
    for (;;) {
        img_set(im, x0, y0, r, g, b);
        if (x0 == x1 && y0 == y1) break;
        int e2 = 2 * err;
        if (e2 >= dy) { err += dy; x0 += sx; }
        if (e2 <= dx) { err += dx; y0 += sy; }
    }

/* ===== This chapter: an L-system is one successor string per symbol (NULL: the symbol stays) ===== */

typedef struct { const char *rule[128]; } LSystem;

uint64_t sat_add(uint64_t a, uint64_t b) { return a > UINT64_MAX - b ? UINT64_MAX : a + b; }

uint64_t ls_length(const LSystem *ls, const char *axiom, int n) {
    uint64_t len[128], next[128];
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < n; g++) {
        for (int c = 0; c < 128; c++) {
            const char *r = ls->rule[c];
            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {
    uint64_t maxlen = 0;
    for (int g = 0; g <= n; g++) {
        uint64_t l = ls_length(ls, axiom, g);
        if (l > maxlen) maxlen = l;
    }
    if (maxlen > (1u << 28)) return NULL;
    size_t rlen[128];
    for (int c = 0; c < 128; c++) rlen[c] = ls->rule[c] ? strlen(ls->rule[c]) : 0;
    char *cur = malloc(maxlen + 1), *nxt = malloc(maxlen + 1);
    size_t len = strlen(axiom);
    memcpy(cur, axiom, len + 1);
    for (int g = 0; g < n; g++) {
        size_t w = 0;
        for (size_t i = 0; i < len; i++) {
            unsigned char c = (unsigned char)cur[i];
            const char *r = ls->rule[c];
            if (r) { memcpy(nxt + w, r, rlen[c]); w += rlen[c]; }
            else nxt[w++] = (char)c;
        }
        nxt[w] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        len = w;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { float x0, y0, x1, y1; int depth; } Seg;

#define TURTLE_STACK 64

int turtle2d(const char *s, float step, float angle_deg, float heading_deg, Seg *out, int cap) {
    const float rad = 3.14159265358979f / 180;
    float c = cosf(angle_deg * rad), sn = sinf(angle_deg * rad);
    float x = 0, y = 0, dx = cosf(heading_deg * rad), dy = sinf(heading_deg * rad);
    float stack[TURTLE_STACK][4];
    int sp = 0, count = 0;
    for (const char *p = s; *p; p++) {
        float t;
        switch (*p) {
        case 'F': case 'G':
            if (count < cap) {
                Seg sg = {x, y, x + dx * step, y + dy * step, sp};
                out[count] = sg;
            }
            count++;
            x += dx * step; y += dy * step;
            break;
        case 'f': x += dx * step; y += dy * step; break;
        case '+': t = dx * c - dy * sn; dy = dx * sn + dy * c; dx = t; break;
        case '-': t = dx * c + dy * sn; dy = -dx * sn + dy * c; dx = t; break;
        case '|': dx = -dx; dy = -dy; break;
        case '[':
            if (sp == TURTLE_STACK) return -1;
            stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++;
            break;
        case ']':
            if (sp == 0) return -1;
            sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3];
            break;
        default: break;
        }
    }
    return count;
}

void seg_bounds(const Seg *s, int n, float *minx, float *miny, float *maxx, float *maxy) {
    if (n <= 0) { *minx = *miny = *maxx = *maxy = 0; return; }
    float a = s[0].x0, b = s[0].y0, c = s[0].x0, d = s[0].y0;
    for (int i = 0; i < n; i++) {
        a = fminf(a, fminf(s[i].x0, s[i].x1)); c = fmaxf(c, fmaxf(s[i].x0, s[i].x1));
        b = fminf(b, fminf(s[i].y0, s[i].y1)); d = fmaxf(d, fmaxf(s[i].y0, s[i].y1));
    }
    *minx = a; *miny = b; *maxx = c; *maxy = d;
}

void draw_segments(Image *im, const Seg *s, int n, int margin, int r, int g, int b) {
    float minx, miny, maxx, maxy;
    seg_bounds(s, n, &minx, &miny, &maxx, &maxy);
    float aw = (float)(im->w - 1 - 2 * margin), ah = (float)(im->h - 1 - 2 * margin);
    float bw = maxx - minx, bh = maxy - miny, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = margin + (aw - bw * scale) / 2, oy = margin + (ah - bh * scale) / 2;
    for (int i = 0; i < n; i++) {
        int x0 = (int)floorf(ox + (s[i].x0 - minx) * scale + 0.5f);
        int y0 = im->h - 1 - (int)floorf(oy + (s[i].y0 - miny) * scale + 0.5f);
        int x1 = (int)floorf(ox + (s[i].x1 - minx) * scale + 0.5f);
        int y1 = im->h - 1 - (int)floorf(oy + (s[i].y1 - miny) * scale + 0.5f);
        img_line(im, x0, y0, x1, y1, r, g, b);
    }
}

uint32_t rng_next(uint32_t *state) {
    *state = *state * 1664525u + 1013904223u;
    return hash32(*state);
}

typedef struct { const char *succ; int weight; } Choice;
typedef struct { Choice choice[128][4]; int count[128]; } StochLSystem;

/* one generation; out == NULL only counts. Returns the new length. */
size_t stoch_pass(const StochLSystem *ls, const size_t rlen[128][4], const int total[128],
                  const char *cur, size_t len, uint32_t *state, char *out) {
    size_t w = 0;
    for (size_t i = 0; i < len; i++) {
        unsigned char c = (unsigned char)cur[i];
        int k = 0;
        if (ls->count[c] == 0) {
            if (out) out[w] = (char)c;
            w++;
            continue;
        }
        if (ls->count[c] >= 2) {
            int r = (int)(rng_next(state) % (uint32_t)total[c]), acc = 0;
            for (k = 0; k < ls->count[c] - 1; k++) {
                acc += ls->choice[c][k].weight;
                if (acc > r) break;
            }
        }
        if (out) memcpy(out + w, ls->choice[c][k].succ, rlen[c][k]);
        w += rlen[c][k];
    }
    return w;
}

char *ls_expand_stochastic(const StochLSystem *ls, const char *axiom, int n, uint32_t seed, size_t *out_len) {
    size_t rlen[128][4];
    int total[128];
    for (int c = 0; c < 128; c++) {
        total[c] = 0;
        for (int k = 0; k < ls->count[c]; k++) {
            rlen[c][k] = strlen(ls->choice[c][k].succ);
            total[c] += ls->choice[c][k].weight;
        }
    }
    size_t len = strlen(axiom), cap_cur = len + 1, cap_nxt = len + 1;
    char *cur = malloc(cap_cur), *nxt = malloc(cap_nxt);
    memcpy(cur, axiom, len + 1);
    uint32_t state = seed;
    for (int g = 0; g < n; g++) {
        uint32_t probe = state;
        size_t need = stoch_pass(ls, rlen, total, cur, len, &probe, NULL);
        if (need + 1 > cap_nxt) {
            size_t nc = cap_nxt * 2 > need + 1 ? cap_nxt * 2 : need + 1;
            free(nxt);
            nxt = malloc(nc);
            cap_nxt = nc;
        }
        len = stoch_pass(ls, rlen, total, cur, len, &state, nxt);
        nxt[len] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        size_t tc = cap_cur; cap_cur = cap_nxt; cap_nxt = tc;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { char sym; float p; } Module;
typedef struct { char sym; float mul, add; } PSucc;
typedef struct { const PSucc *succ[128]; int n[128]; } PLSystem;

int pls_expand(const PLSystem *ls, const Module *axiom, int na, int iterations, Module **out) {
    *out = NULL;
    uint64_t len[128], next[128], maxlen = (uint64_t)na;
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < iterations; g++) {
        for (int c = 0; c < 128; c++) {
            if (ls->n[c] == 0) { next[c] = 1; continue; }
            uint64_t s = 0;
            for (int k = 0; k < ls->n[c]; k++) s = sat_add(s, len[(unsigned char)ls->succ[c][k].sym]);
            next[c] = s;
        }
        memcpy(len, next, sizeof len);
        uint64_t total = 0;
        for (int i = 0; i < na; i++) total = sat_add(total, len[(unsigned char)axiom[i].sym]);
        if (total > maxlen) maxlen = total;
    }
    if (maxlen > (1u << 24)) return -1;
    Module *cur = malloc(sizeof(Module) * (maxlen ? maxlen : 1)), *nxt = malloc(sizeof(Module) * (maxlen ? maxlen : 1));
    memcpy(cur, axiom, sizeof(Module) * na);
    size_t count = (size_t)na;
    for (int g = 0; g < iterations; g++) {
        size_t w = 0;
        for (size_t i = 0; i < count; i++) {
            unsigned char c = (unsigned char)cur[i].sym;
            if (ls->n[c] == 0) { nxt[w++] = cur[i]; continue; }
            for (int k = 0; k < ls->n[c]; k++) {
                const PSucc *ps = &ls->succ[c][k];
                nxt[w].sym = ps->sym;
                nxt[w].p = cur[i].p * ps->mul + ps->add;
                w++;
            }
        }
        Module *t = cur; cur = nxt; nxt = t;
        count = w;
    }
    free(nxt);
    *out = cur;
    return (int)count;
}

typedef struct { Vec3 a, b, h, l, u; float r; int depth; } Branch;
typedef struct { Vec3 pos, h, l, u; float size; } Leaf;

void turtle3d_count(const Module *m, int n, int *nbranches, int *nleaves) {
    int b = 0, l = 0;
    for (int i = 0; i < n; i++) { b += m[i].sym == 'F'; l += m[i].sym == 'L'; }
    *nbranches = b; *nleaves = l;
}

typedef struct { Vec3 p, h, l, u; float w; } Turtle3;

/* rotate the pair (x, y) by angle a: x' = x c + y s, y' = y c - x s */
void rot_pair(Vec3 *x, Vec3 *y, float a_deg) {
    float a = a_deg * 3.14159265358979f / 180, c = cosf(a), s = sinf(a);
    Vec3 nx = v3_add(v3_scale(*x, c), v3_scale(*y, s));
    Vec3 ny = v3_sub(v3_scale(*y, c), v3_scale(*x, s));
    *x = nx; *y = ny;
}

int turtle3d(const Module *m, int n, float width0, Branch *br, Leaf *lf) {
    Turtle3 t = {v3(0, 0, 0), v3(0, 0, 1), v3(-1, 0, 0), v3(0, -1, 0), width0}, stack[64];
    int sp = 0, nb = 0, nl = 0;
    for (int i = 0; i < n; i++) {
        float a = m[i].p;
        Vec3 nu;
        switch (m[i].sym) {
        case 'F': {
            Vec3 end = v3_add(t.p, v3_scale(t.h, a));
            Branch b = {t.p, end, t.h, t.l, t.u, t.w / 2, sp};
            br[nb++] = b;
            t.p = end;
            break;
        }
        case 'f': t.p = v3_add(t.p, v3_scale(t.h, a)); break;
        case '+': rot_pair(&t.h, &t.l, a); break;
        case '-': rot_pair(&t.h, &t.l, -a); break;
        case '&': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, a); t.u = v3_scale(nu, -1); break;
        case '^': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '\\': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, a); t.u = v3_scale(nu, -1); break;
        case '/': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '|': t.h = v3_scale(t.h, -1); t.l = v3_scale(t.l, -1); break;
        case '!': t.w = a; break;
        case 'L': {
            Leaf l = {t.p, t.h, t.l, t.u, a};
            lf[nl++] = l;
            break;
        }
        case '[':
            if (sp == 64) return -1;
            stack[sp++] = t;
            break;
        case ']':
            if (sp == 0) return -1;
            t = stack[--sp];
            break;
        default: break;
        }
    }
    return 0;
}

typedef struct { int nverts, ntris; float *pos, *nrm; unsigned char *col; uint32_t *idx; } Mesh;

int mesh_alloc(Mesh *m, int nverts, int ntris) {
    m->nverts = nverts; m->ntris = ntris;
    m->pos = malloc(sizeof(float) * 3 * (size_t)(nverts ? nverts : 1));
    m->nrm = malloc(sizeof(float) * 3 * (size_t)(nverts ? nverts : 1));
    m->col = malloc(3 * (size_t)(nverts ? nverts : 1));
    m->idx = malloc(sizeof(uint32_t) * 3 * (size_t)(ntris ? ntris : 1));
    if (!m->pos || !m->nrm || !m->col || !m->idx) {
        free(m->pos); free(m->nrm); free(m->col); free(m->idx);
        memset(m, 0, sizeof *m);
        return 0;
    }
    return 1;
}

void mesh_free(Mesh *m) {
    free(m->pos); free(m->nrm); free(m->col); free(m->idx);
    memset(m, 0, sizeof *m);
}

void mesh_set_vertex(Mesh *m, int v, Vec3 p, Vec3 n, int r, int g, int b) {
    m->pos[3 * v] = p.x; m->pos[3 * v + 1] = p.y; m->pos[3 * v + 2] = p.z;
    m->nrm[3 * v] = n.x; m->nrm[3 * v + 1] = n.y; m->nrm[3 * v + 2] = n.z;
    m->col[3 * v] = (unsigned char)r; m->col[3 * v + 1] = (unsigned char)g; m->col[3 * v + 2] = (unsigned char)b;
}

/* writes branches starting at vertex 0 / triangle 0 of an already allocated mesh */
void branch_mesh_into(const Branch *br, int n, int sides, Mesh *out) {
    for (int k = 0; k < n; k++) {
        int p = 2 * sides * k, q = p + sides;
        for (int j = 0; j < sides; j++) {
            float th = 6.28318530718f * j / sides;
            Vec3 d = v3_add(v3_scale(br[k].l, cosf(th)), v3_scale(br[k].u, sinf(th)));
            mesh_set_vertex(out, p + j, v3_add(br[k].a, v3_scale(d, br[k].r)), d, 110, 80, 50);
            mesh_set_vertex(out, q + j, v3_add(br[k].b, v3_scale(d, br[k].r)), d, 110, 80, 50);
            int j1 = (j + 1) % sides;
            uint32_t *t = out->idx + 3 * (size_t)(2 * sides * k + 2 * j);
            t[0] = (uint32_t)(p + j); t[1] = (uint32_t)(p + j1); t[2] = (uint32_t)(q + j1);
            t[3] = (uint32_t)(p + j); t[4] = (uint32_t)(q + j1); t[5] = (uint32_t)(q + j);
        }
    }
}

int branch_mesh(const Branch *br, int n, int sides, Mesh *out) {
    if (!mesh_alloc(out, 2 * sides * n, 2 * sides * n)) return 0;
    branch_mesh_into(br, n, sides, out);
    return 1;
}

typedef struct { const char *rule[128]; } LSystem;

uint64_t sat_add(uint64_t a, uint64_t b) { return a > UINT64_MAX - b ? UINT64_MAX : a + b; }

uint64_t ls_length(const LSystem *ls, const char *axiom, int n) {
    uint64_t len[128], next[128];
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < n; g++) {
        for (int c = 0; c < 128; c++) {
            const char *r = ls->rule[c];
            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {
    uint64_t maxlen = 0;
    for (int g = 0; g <= n; g++) {
        uint64_t l = ls_length(ls, axiom, g);
        if (l > maxlen) maxlen = l;

    if (maxlen > (1u << 28)) return NULL;
    size_t rlen[128];
    for (int c = 0; c < 128; c++) rlen[c] = ls->rule[c] ? strlen(ls->rule[c]) : 0;
    char *cur = malloc(maxlen + 1), *nxt = malloc(maxlen + 1);
    size_t len = strlen(axiom);
    memcpy(cur, axiom, len + 1);
    for (int g = 0; g < n; g++) {
        size_t w = 0;

            unsigned char c = (unsigned char)cur[i];

typedef struct { float x0, y0, x1, y1; int depth; } Seg;

#define TURTLE_STACK 64

int turtle2d(const char *s, float step, float angle_deg, float heading_deg, Seg *out, int cap) {
    const float rad = 3.14159265358979f / 180;
    float c = cosf(angle_deg * rad), sn = sinf(angle_deg * rad);
    float x = 0, y = 0, dx = cosf(heading_deg * rad), dy = sinf(heading_deg * rad);
    float stack[TURTLE_STACK][4];
    int sp = 0, count = 0;
    for (const char *p = s; *p; p++) {
        float t;
        switch (*p) {
        case 'F': case 'G':
            if (count < cap) {
                Seg sg = {x, y, x + dx * step, y + dy * step, sp};
                out[count] = sg;
            }
            count++;
            x += dx * step; y += dy * step;
            break;
        case 'f': x += dx * step; y += dy * step; break;
        case '+': t = dx * c - dy * sn; dy = dx * sn + dy * c; dx = t; break;
        case '-': t = dx * c + dy * sn; dy = -dx * sn + dy * c; dx = t; break;
        case '|': dx = -dx; dy = -dy; break;
        case '[':
            if (sp == TURTLE_STACK) return -1;
            stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++;
            break;
        case ']':
            if (sp == 0) return -1;
            sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3];
            break;
        default: break;
        }
    }
    return count;
}

void seg_bounds(const Seg *s, int n, float *minx, float *miny, float *maxx, float *maxy) {
    if (n <= 0) { *minx = *miny = *maxx = *maxy = 0; return; }
    float a = s[0].x0, b = s[0].y0, c = s[0].x0, d = s[0].y0;
    for (int i = 0; i < n; i++) {
        a = fminf(a, fminf(s[i].x0, s[i].x1)); c = fmaxf(c, fmaxf(s[i].x0, s[i].x1));
        b = fminf(b, fminf(s[i].y0, s[i].y1)); d = fmaxf(d, fmaxf(s[i].y0, s[i].y1));
    }
    *minx = a; *miny = b; *maxx = c; *maxy = d;
}

void draw_segments(Image *im, const Seg *s, int n, int margin, int r, int g, int b) {
    float minx, miny, maxx, maxy;
    seg_bounds(s, n, &minx, &miny, &maxx, &maxy);
    float aw = (float)(im->w - 1 - 2 * margin), ah = (float)(im->h - 1 - 2 * margin);
    float bw = maxx - minx, bh = maxy - miny, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = margin + (aw - bw * scale) / 2, oy = margin + (ah - bh * scale) / 2;
    for (int i = 0; i < n; i++) {
        int x0 = (int)floorf(ox + (s[i].x0 - minx) * scale + 0.5f);
        int y0 = im->h - 1 - (int)floorf(oy + (s[i].y0 - miny) * scale + 0.5f);
        int x1 = (int)floorf(ox + (s[i].x1 - minx) * scale + 0.5f);
        int y1 = im->h - 1 - (int)floorf(oy + (s[i].y1 - miny) * scale + 0.5f);
        img_line(im, x0, y0, x1, y1, r, g, b);
    }
}

uint32_t rng_next(uint32_t *state) {
    *state = *state * 1664525u + 1013904223u;
    return hash32(*state);
}

typedef struct { const char *succ; int weight; } Choice;
typedef struct { Choice choice[128][4]; int count[128]; } StochLSystem;

/* one generation; out == NULL only counts. Returns the new length. */
size_t stoch_pass(const StochLSystem *ls, const size_t rlen[128][4], const int total[128],
                  const char *cur, size_t len, uint32_t *state, char *out) {
    size_t w = 0;
    for (size_t i = 0; i < len; i++) {
        unsigned char c = (unsigned char)cur[i];
        int k = 0;
        if (ls->count[c] == 0) {
            if (out) out[w] = (char)c;
            w++;
            continue;
        }
        if (ls->count[c] >= 2) {
            int r = (int)(rng_next(state) % (uint32_t)total[c]), acc = 0;
            for (k = 0; k < ls->count[c] - 1; k++) {
                acc += ls->choice[c][k].weight;
                if (acc > r) break;
            }
        }
        if (out) memcpy(out + w, ls->choice[c][k].succ, rlen[c][k]);
        w += rlen[c][k];
    }
    return w;
}

char *ls_expand_stochastic(const StochLSystem *ls, const char *axiom, int n, uint32_t seed, size_t *out_len) {
    size_t rlen[128][4];
    int total[128];
    for (int c = 0; c < 128; c++) {
        total[c] = 0;
        for (int k = 0; k < ls->count[c]; k++) {
            rlen[c][k] = strlen(ls->choice[c][k].succ);
            total[c] += ls->choice[c][k].weight;
        }
    }
    size_t len = strlen(axiom), cap_cur = len + 1, cap_nxt = len + 1;
    char *cur = malloc(cap_cur), *nxt = malloc(cap_nxt);
    memcpy(cur, axiom, len + 1);
    uint32_t state = seed;
    for (int g = 0; g < n; g++) {
        uint32_t probe = state;
        size_t need = stoch_pass(ls, rlen, total, cur, len, &probe, NULL);
        if (need + 1 > cap_nxt) {
            size_t nc = cap_nxt * 2 > need + 1 ? cap_nxt * 2 : need + 1;
            free(nxt);
            nxt = malloc(nc);
            cap_nxt = nc;
        }
        len = stoch_pass(ls, rlen, total, cur, len, &state, nxt);
        nxt[len] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        size_t tc = cap_cur; cap_cur = cap_nxt; cap_nxt = tc;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { char sym; float p; } Module;
typedef struct { char sym; float mul, add; } PSucc;
typedef struct { const PSucc *succ[128]; int n[128]; } PLSystem;

int pls_expand(const PLSystem *ls, const Module *axiom, int na, int iterations, Module **out) {
    *out = NULL;
    uint64_t len[128], next[128], maxlen = (uint64_t)na;
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < iterations; g++) {
        for (int c = 0; c < 128; c++) {
            if (ls->n[c] == 0) { next[c] = 1; continue; }
            uint64_t s = 0;
            for (int k = 0; k < ls->n[c]; k++) s = sat_add(s, len[(unsigned char)ls->succ[c][k].sym]);
            next[c] = s;
        }
        memcpy(len, next, sizeof len);
        uint64_t total = 0;
        for (int i = 0; i < na; i++) total = sat_add(total, len[(unsigned char)axiom[i].sym]);
        if (total > maxlen) maxlen = total;
    }
    if (maxlen > (1u << 24)) return -1;
    Module *cur = malloc(sizeof(Module) * (maxlen ? maxlen : 1)), *nxt = malloc(sizeof(Module) * (maxlen ? maxlen : 1));
    memcpy(cur, axiom, sizeof(Module) * na);
    size_t count = (size_t)na;
    for (int g = 0; g < iterations; g++) {
        size_t w = 0;
        for (size_t i = 0; i < count; i++) {
            unsigned char c = (unsigned char)cur[i].sym;
            if (ls->n[c] == 0) { nxt[w++] = cur[i]; continue; }
            for (int k = 0; k < ls->n[c]; k++) {
                const PSucc *ps = &ls->succ[c][k];
                nxt[w].sym = ps->sym;
                nxt[w].p = cur[i].p * ps->mul + ps->add;
                w++;
            }
        }
        Module *t = cur; cur = nxt; nxt = t;
        count = w;
    }
    free(nxt);
    *out = cur;
    return (int)count;
}

typedef struct { Vec3 p, h, l, u; float w; } Turtle3;

/* rotate the pair (x, y) by angle a: x' = x c + y s, y' = y c - x s */
void rot_pair(Vec3 *x, Vec3 *y, float a_deg) {
    float a = a_deg * 3.14159265358979f / 180, c = cosf(a), s = sinf(a);
    Vec3 nx = v3_add(v3_scale(*x, c), v3_scale(*y, s));
    Vec3 ny = v3_sub(v3_scale(*y, c), v3_scale(*x, s));
    *x = nx; *y = ny;
}

int turtle3d(const Module *m, int n, float width0, Branch *br, Leaf *lf) {
    Turtle3 t = {v3(0, 0, 0), v3(0, 0, 1), v3(-1, 0, 0), v3(0, -1, 0), width0}, stack[64];
    int sp = 0, nb = 0, nl = 0;
    for (int i = 0; i < n; i++) {
        float a = m[i].p;
        Vec3 nu;
        switch (m[i].sym) {
        case 'F': {
            Vec3 end = v3_add(t.p, v3_scale(t.h, a));
            Branch b = {t.p, end, t.h, t.l, t.u, t.w / 2, sp};
            br[nb++] = b;
            t.p = end;
            break;
        }
        case 'f': t.p = v3_add(t.p, v3_scale(t.h, a)); break;
        case '+': rot_pair(&t.h, &t.l, a); break;
        case '-': rot_pair(&t.h, &t.l, -a); break;
        case '&': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, a); t.u = v3_scale(nu, -1); break;
        case '^': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '\\': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, a); t.u = v3_scale(nu, -1); break;
        case '/': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '|': t.h = v3_scale(t.h, -1); t.l = v3_scale(t.l, -1); break;
        case '!': t.w = a; break;
        case 'L': {
            Leaf l = {t.p, t.h, t.l, t.u, a};
            lf[nl++] = l;
            break;
        }
        case '[':
            if (sp == 64) return -1;
            stack[sp++] = t;
            break;
        case ']':
            if (sp == 0) return -1;
            t = stack[--sp];
            break;
        default: break;
        }
    }
    return 0;
}

int branch_mesh(const Branch *br, int n, int sides, Mesh *out) {
    if (!mesh_alloc(out, 2 * sides * n, 2 * sides * n)) return 0;
    branch_mesh_into(br, n, sides, out);
    return 1;
}

int tree_mesh(const Branch *br, int nb, const Leaf *lf, int nl, int sides, Mesh *out) {
    int bv = 2 * sides * nb;
    if (!mesh_alloc(out, bv + 4 * nl, bv + 2 * nl)) return 0;
    branch_mesh_into(br, nb, sides, out);
    for (int i = 0; i < nl; i++) {
        int v = bv + 4 * i;
        float s = lf[i].size;
        uint32_t h = hash32((uint32_t)i) % 2000;
        int r = 60 + (int)(h % 40), g = 130 + (int)(h / 40 % 50), b = 40;
        Vec3 mid = v3_add(lf[i].pos, v3_scale(lf[i].h, 0.5f * s)), side = v3_scale(lf[i].l, 0.3f * s);
        mesh_set_vertex(out, v, lf[i].pos, lf[i].u, r, g, b);
        mesh_set_vertex(out, v + 1, v3_add(mid, side), lf[i].u, r, g, b);
        mesh_set_vertex(out, v + 2, v3_add(lf[i].pos, v3_scale(lf[i].h, s)), lf[i].u, r, g, b);
        mesh_set_vertex(out, v + 3, v3_sub(mid, side), lf[i].u, r, g, b);
        uint32_t *t = out->idx + 3 * (size_t)(bv + 2 * i);
        t[0] = (uint32_t)v; t[1] = (uint32_t)(v + 3); t[2] = (uint32_t)(v + 2);
        t[3] = (uint32_t)v; t[4] = (uint32_t)(v + 2); t[5] = (uint32_t)(v + 1);
    }
    return 1;
}

--- prompt
Draw the mesh with a z-buffer. The view is orthographic, from the front, after spinning the tree by `yaw` degrees around the vertical axis:

```c
void render_mesh(const Mesh *me, float yaw_deg, Image *im);
```

1. Transform every vertex once into a temporary array (allocate one array for the whole call, not per triangle): `x' = x cos(yaw) - y sin(yaw)`, `depth = x sin(yaw) + y cos(yaw)`, `z' = z`. Rotate the normals the same way (`nz` unchanged).
2. Fit like step 4: bounds of `(x', z')` over all vertices, `margin = 2`, `aw = W - 1 - 2 margin`, `ah = H - 1 - 2 margin`, `scale = min(aw / bw, ah / bh)` (with the same zero-extent rules), `ox = margin + (aw - bw scale) / 2`, `oy = margin + (ah - bh scale) / 2`; screen `sx = ox + (x' - minx) scale`, `sy = H - 1 - (oy + (z' - minz) scale)` (floats, no rounding).
3. Clear the image to (235, 240, 245) and a `float` z-buffer to `FLT_MAX` (or `INFINITY`).
4. For each triangle, loop over the pixels of its screen bounding box (clamped to the image); a pixel `(px, py)` is covered if its center `(px + 0.5, py + 0.5)` has **edge functions** all `>= 0` or all `<= 0` (either winding: the tree is seen from both sides). Interpolate the depth with the barycentric weights; draw if it is **smaller** than the z-buffer value (smaller depth = nearer the viewer), and store it.
5. Color: average the triangle's 3 rotated vertex normals, normalize, `lit = 0.35 + 0.65 * |n · L|` with `L = normalize(-0.4, -0.6, 0.7)` (two-sided lighting), times the first vertex's color, `(int)(c * lit + 0.5f)`.

Skip degenerate triangles (zero area on screen). This is the core of every software rasterizer and of what GPUs do in hardware: bounding box, edge functions, barycentric interpolation, depth test.

**Run** renders the leafy tree. It is the end of this chapter's project: string rewriting to a lit 3D model in a few hundred lines of C.

typedef struct { int w, h; unsigned char *px; } Image;      /* RGB, 3 bytes per pixel, row-major */
Image img_new(int w, int h) { Image im = {w, h, calloc((size_t)w * h * 3, 1)}; return im; }

void img_fill(Image *im, int r, int g, int b) {
    for (size_t i = 0, n = (size_t)im->w * im->h; i < n; i++) {
        im->px[3 * i] = (unsigned char)r; im->px[3 * i + 1] = (unsigned char)g; im->px[3 * i + 2] = (unsigned char)b;
    }

void img_set(Image *im, int x, int y, int r, int g, int b) {   /* ignores pixels outside the image */
    if (x < 0 || y < 0 || x >= im->w || y >= im->h) return;
    unsigned char *p = im->px + ((size_t)y * im->w + x) * 3;
    p[0] = (unsigned char)r; p[1] = (unsigned char)g; p[2] = (unsigned char)b;
}
void img_line(Image *im, int x0, int y0, int x1, int y1, int r, int g, int b) {   /* Bresenham */
    int dx = abs(x1 - x0), sx = x0 < x1 ? 1 : -1, dy = -abs(y1 - y0), sy = y0 < y1 ? 1 : -1, err = dx + dy;
    for (;;) {
        img_set(im, x0, y0, r, g, b);
        if (x0 == x1 && y0 == y1) break;
        int e2 = 2 * err;
        if (e2 >= dy) { err += dy; x0 += sx; }
        if (e2 <= dx) { err += dx; y0 += sy; }
    }
}

/* ===== This chapter: an L-system is one successor string per symbol (NULL: the symbol stays) ===== */

typedef struct { const char *rule[128]; } LSystem;

uint64_t sat_add(uint64_t a, uint64_t b) { return a > UINT64_MAX - b ? UINT64_MAX : a + b; }

uint64_t ls_length(const LSystem *ls, const char *axiom, int n) {
    uint64_t len[128], next[128];
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < n; g++) {
        for (int c = 0; c < 128; c++) {
            const char *r = ls->rule[c];
            if (!r) { next[c] = 1; continue; }
            uint64_t sum = 0;
            for (const char *p = r; *p; p++) sum = sat_add(sum, len[(unsigned char)*p]);
            next[c] = sum;
        }
        memcpy(len, next, sizeof len);
    }
    uint64_t total = 0;
    for (const char *p = axiom; *p; p++) total = sat_add(total, len[(unsigned char)*p]);
    return total;
}

char *ls_expand(const LSystem *ls, const char *axiom, int n, size_t *out_len) {
    uint64_t maxlen = 0;
    for (int g = 0; g <= n; g++) {
        uint64_t l = ls_length(ls, axiom, g);
        if (l > maxlen) maxlen = l;
    }
    if (maxlen > (1u << 28)) return NULL;
    size_t rlen[128];
    for (int c = 0; c < 128; c++) rlen[c] = ls->rule[c] ? strlen(ls->rule[c]) : 0;
    char *cur = malloc(maxlen + 1), *nxt = malloc(maxlen + 1);
    size_t len = strlen(axiom);
    memcpy(cur, axiom, len + 1);
    for (int g = 0; g < n; g++) {
        size_t w = 0;
        for (size_t i = 0; i < len; i++) {
            unsigned char c = (unsigned char)cur[i];
            const char *r = ls->rule[c];
            if (r) { memcpy(nxt + w, r, rlen[c]); w += rlen[c]; }
            else nxt[w++] = (char)c;
        }
        nxt[w] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        len = w;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { float x0, y0, x1, y1; int depth; } Seg;

#define TURTLE_STACK 64

int turtle2d(const char *s, float step, float angle_deg, float heading_deg, Seg *out, int cap) {
    const float rad = 3.14159265358979f / 180;
    float c = cosf(angle_deg * rad), sn = sinf(angle_deg * rad);
    float x = 0, y = 0, dx = cosf(heading_deg * rad), dy = sinf(heading_deg * rad);
    float stack[TURTLE_STACK][4];
    int sp = 0, count = 0;
    for (const char *p = s; *p; p++) {
        float t;
        switch (*p) {
        case 'F': case 'G':
            if (count < cap) {
                Seg sg = {x, y, x + dx * step, y + dy * step, sp};
                out[count] = sg;
            }
            count++;
            x += dx * step; y += dy * step;
            break;
        case 'f': x += dx * step; y += dy * step; break;
        case '+': t = dx * c - dy * sn; dy = dx * sn + dy * c; dx = t; break;
        case '-': t = dx * c + dy * sn; dy = -dx * sn + dy * c; dx = t; break;
        case '|': dx = -dx; dy = -dy; break;
        case '[':
            if (sp == TURTLE_STACK) return -1;
            stack[sp][0] = x; stack[sp][1] = y; stack[sp][2] = dx; stack[sp][3] = dy; sp++;
            break;
        case ']':
            if (sp == 0) return -1;
            sp--; x = stack[sp][0]; y = stack[sp][1]; dx = stack[sp][2]; dy = stack[sp][3];
            break;
        default: break;
        }
    }
    return count;
}

void seg_bounds(const Seg *s, int n, float *minx, float *miny, float *maxx, float *maxy) {
    if (n <= 0) { *minx = *miny = *maxx = *maxy = 0; return; }
    float a = s[0].x0, b = s[0].y0, c = s[0].x0, d = s[0].y0;
    for (int i = 0; i < n; i++) {
        a = fminf(a, fminf(s[i].x0, s[i].x1)); c = fmaxf(c, fmaxf(s[i].x0, s[i].x1));
        b = fminf(b, fminf(s[i].y0, s[i].y1)); d = fmaxf(d, fmaxf(s[i].y0, s[i].y1));
    }
    *minx = a; *miny = b; *maxx = c; *maxy = d;
}

void draw_segments(Image *im, const Seg *s, int n, int margin, int r, int g, int b) {
    float minx, miny, maxx, maxy;
    seg_bounds(s, n, &minx, &miny, &maxx, &maxy);
    float aw = (float)(im->w - 1 - 2 * margin), ah = (float)(im->h - 1 - 2 * margin);
    float bw = maxx - minx, bh = maxy - miny, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = margin + (aw - bw * scale) / 2, oy = margin + (ah - bh * scale) / 2;
    for (int i = 0; i < n; i++) {
        int x0 = (int)floorf(ox + (s[i].x0 - minx) * scale + 0.5f);
        int y0 = im->h - 1 - (int)floorf(oy + (s[i].y0 - miny) * scale + 0.5f);
        int x1 = (int)floorf(ox + (s[i].x1 - minx) * scale + 0.5f);
        int y1 = im->h - 1 - (int)floorf(oy + (s[i].y1 - miny) * scale + 0.5f);
        img_line(im, x0, y0, x1, y1, r, g, b);
    }
}

uint32_t rng_next(uint32_t *state) {
    *state = *state * 1664525u + 1013904223u;
    return hash32(*state);
}

typedef struct { const char *succ; int weight; } Choice;
typedef struct { Choice choice[128][4]; int count[128]; } StochLSystem;

/* one generation; out == NULL only counts. Returns the new length. */
size_t stoch_pass(const StochLSystem *ls, const size_t rlen[128][4], const int total[128],
                  const char *cur, size_t len, uint32_t *state, char *out) {
    size_t w = 0;
    for (size_t i = 0; i < len; i++) {
        unsigned char c = (unsigned char)cur[i];
        int k = 0;
        if (ls->count[c] == 0) {
            if (out) out[w] = (char)c;
            w++;
            continue;
        }
        if (ls->count[c] >= 2) {
            int r = (int)(rng_next(state) % (uint32_t)total[c]), acc = 0;
            for (k = 0; k < ls->count[c] - 1; k++) {
                acc += ls->choice[c][k].weight;
                if (acc > r) break;
            }
        }
        if (out) memcpy(out + w, ls->choice[c][k].succ, rlen[c][k]);
        w += rlen[c][k];
    }
    return w;
}

char *ls_expand_stochastic(const StochLSystem *ls, const char *axiom, int n, uint32_t seed, size_t *out_len) {
    size_t rlen[128][4];
    int total[128];
    for (int c = 0; c < 128; c++) {
        total[c] = 0;
        for (int k = 0; k < ls->count[c]; k++) {
            rlen[c][k] = strlen(ls->choice[c][k].succ);
            total[c] += ls->choice[c][k].weight;
        }
    }
    size_t len = strlen(axiom), cap_cur = len + 1, cap_nxt = len + 1;
    char *cur = malloc(cap_cur), *nxt = malloc(cap_nxt);
    memcpy(cur, axiom, len + 1);
    uint32_t state = seed;
    for (int g = 0; g < n; g++) {
        uint32_t probe = state;
        size_t need = stoch_pass(ls, rlen, total, cur, len, &probe, NULL);
        if (need + 1 > cap_nxt) {
            size_t nc = cap_nxt * 2 > need + 1 ? cap_nxt * 2 : need + 1;
            free(nxt);
            nxt = malloc(nc);
            cap_nxt = nc;
        }
        len = stoch_pass(ls, rlen, total, cur, len, &state, nxt);
        nxt[len] = '\0';
        char *t = cur; cur = nxt; nxt = t;
        size_t tc = cap_cur; cap_cur = cap_nxt; cap_nxt = tc;
    }
    free(nxt);
    *out_len = len;
    return cur;
}

typedef struct { char sym; float p; } Module;
typedef struct { char sym; float mul, add; } PSucc;
typedef struct { const PSucc *succ[128]; int n[128]; } PLSystem;

int pls_expand(const PLSystem *ls, const Module *axiom, int na, int iterations, Module **out) {
    *out = NULL;
    uint64_t len[128], next[128], maxlen = (uint64_t)na;
    for (int c = 0; c < 128; c++) len[c] = 1;
    for (int g = 0; g < iterations; g++) {
        for (int c = 0; c < 128; c++) {
            if (ls->n[c] == 0) { next[c] = 1; continue; }
            uint64_t s = 0;
            for (int k = 0; k < ls->n[c]; k++) s = sat_add(s, len[(unsigned char)ls->succ[c][k].sym]);
            next[c] = s;
        }
        memcpy(len, next, sizeof len);
        uint64_t total = 0;
        for (int i = 0; i < na; i++) total = sat_add(total, len[(unsigned char)axiom[i].sym]);
        if (total > maxlen) maxlen = total;
    }
    if (maxlen > (1u << 24)) return -1;
    Module *cur = malloc(sizeof(Module) * (maxlen ? maxlen : 1)), *nxt = malloc(sizeof(Module) * (maxlen ? maxlen : 1));
    memcpy(cur, axiom, sizeof(Module) * na);
    size_t count = (size_t)na;
    for (int g = 0; g < iterations; g++) {
        size_t w = 0;
        for (size_t i = 0; i < count; i++) {
            unsigned char c = (unsigned char)cur[i].sym;
            if (ls->n[c] == 0) { nxt[w++] = cur[i]; continue; }
            for (int k = 0; k < ls->n[c]; k++) {
                const PSucc *ps = &ls->succ[c][k];
                nxt[w].sym = ps->sym;
                nxt[w].p = cur[i].p * ps->mul + ps->add;
                w++;
            }
        }
        Module *t = cur; cur = nxt; nxt = t;
        count = w;
    }
    free(nxt);
    *out = cur;
    return (int)count;
}

typedef struct { Vec3 a, b, h, l, u; float r; int depth; } Branch;
typedef struct { Vec3 pos, h, l, u; float size; } Leaf;

void turtle3d_count(const Module *m, int n, int *nbranches, int *nleaves) {
    int b = 0, l = 0;
    for (int i = 0; i < n; i++) { b += m[i].sym == 'F'; l += m[i].sym == 'L'; }
    *nbranches = b; *nleaves = l;
}

typedef struct { Vec3 p, h, l, u; float w; } Turtle3;

/* rotate the pair (x, y) by angle a: x' = x c + y s, y' = y c - x s */
void rot_pair(Vec3 *x, Vec3 *y, float a_deg) {
    float a = a_deg * 3.14159265358979f / 180, c = cosf(a), s = sinf(a);
    Vec3 nx = v3_add(v3_scale(*x, c), v3_scale(*y, s));
    Vec3 ny = v3_sub(v3_scale(*y, c), v3_scale(*x, s));
    *x = nx; *y = ny;
}

int turtle3d(const Module *m, int n, float width0, Branch *br, Leaf *lf) {
    Turtle3 t = {v3(0, 0, 0), v3(0, 0, 1), v3(-1, 0, 0), v3(0, -1, 0), width0}, stack[64];
    int sp = 0, nb = 0, nl = 0;
    for (int i = 0; i < n; i++) {
        float a = m[i].p;
        Vec3 nu;
        switch (m[i].sym) {
        case 'F': {
            Vec3 end = v3_add(t.p, v3_scale(t.h, a));
            Branch b = {t.p, end, t.h, t.l, t.u, t.w / 2, sp};
            br[nb++] = b;
            t.p = end;
            break;
        }
        case 'f': t.p = v3_add(t.p, v3_scale(t.h, a)); break;
        case '+': rot_pair(&t.h, &t.l, a); break;
        case '-': rot_pair(&t.h, &t.l, -a); break;
        case '&': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, a); t.u = v3_scale(nu, -1); break;
        case '^': nu = v3_scale(t.u, -1); rot_pair(&t.h, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '\\': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, a); t.u = v3_scale(nu, -1); break;
        case '/': nu = v3_scale(t.u, -1); rot_pair(&t.l, &nu, -a); t.u = v3_scale(nu, -1); break;
        case '|': t.h = v3_scale(t.h, -1); t.l = v3_scale(t.l, -1); break;
        case '!': t.w = a; break;
        case 'L': {
            Leaf l = {t.p, t.h, t.l, t.u, a};
            lf[nl++] = l;
            break;
        }
        case '[':
            if (sp == 64) return -1;
            stack[sp++] = t;
            break;
        case ']':
            if (sp == 0) return -1;
            t = stack[--sp];
            break;
        default: break;
        }
    }
    return 0;
}

typedef struct { int nverts, ntris; float *pos, *nrm; unsigned char *col; uint32_t *idx; } Mesh;

int mesh_alloc(Mesh *m, int nverts, int ntris) {
    m->nverts = nverts; m->ntris = ntris;
    m->pos = malloc(sizeof(float) * 3 * (size_t)(nverts ? nverts : 1));
    m->nrm = malloc(sizeof(float) * 3 * (size_t)(nverts ? nverts : 1));
    m->col = malloc(3 * (size_t)(nverts ? nverts : 1));
    m->idx = malloc(sizeof(uint32_t) * 3 * (size_t)(ntris ? ntris : 1));
    if (!m->pos || !m->nrm || !m->col || !m->idx) {
        free(m->pos); free(m->nrm); free(m->col); free(m->idx);
        memset(m, 0, sizeof *m);
        return 0;
    }
    return 1;
}

void mesh_free(Mesh *m) {
    free(m->pos); free(m->nrm); free(m->col); free(m->idx);
    memset(m, 0, sizeof *m);
}

void mesh_set_vertex(Mesh *m, int v, Vec3 p, Vec3 n, int r, int g, int b) {
    m->pos[3 * v] = p.x; m->pos[3 * v + 1] = p.y; m->pos[3 * v + 2] = p.z;
    m->nrm[3 * v] = n.x; m->nrm[3 * v + 1] = n.y; m->nrm[3 * v + 2] = n.z;
    m->col[3 * v] = (unsigned char)r; m->col[3 * v + 1] = (unsigned char)g; m->col[3 * v + 2] = (unsigned char)b;
}

/* writes branches starting at vertex 0 / triangle 0 of an already allocated mesh */
void branch_mesh_into(const Branch *br, int n, int sides, Mesh *out) {
    for (int k = 0; k < n; k++) {
        int p = 2 * sides * k, q = p + sides;
        for (int j = 0; j < sides; j++) {
            float th = 6.28318530718f * j / sides;
            Vec3 d = v3_add(v3_scale(br[k].l, cosf(th)), v3_scale(br[k].u, sinf(th)));
            mesh_set_vertex(out, p + j, v3_add(br[k].a, v3_scale(d, br[k].r)), d, 110, 80, 50);
            mesh_set_vertex(out, q + j, v3_add(br[k].b, v3_scale(d, br[k].r)), d, 110, 80, 50);
            int j1 = (j + 1) % sides;
            uint32_t *t = out->idx + 3 * (size_t)(2 * sides * k + 2 * j);
            t[0] = (uint32_t)(p + j); t[1] = (uint32_t)(p + j1); t[2] = (uint32_t)(q + j1);
            t[3] = (uint32_t)(p + j); t[4] = (uint32_t)(q + j1); t[5] = (uint32_t)(q + j);
        }
    }
}

int branch_mesh(const Branch *br, int n, int sides, Mesh *out) {
    if (!mesh_alloc(out, 2 * sides * n, 2 * sides * n)) return 0;
    branch_mesh_into(br, n, sides, out);
    return 1;
}

int tree_mesh(const Branch *br, int nb, const Leaf *lf, int nl, int sides, Mesh *out) {
    int bv = 2 * sides * nb;
    if (!mesh_alloc(out, bv + 4 * nl, bv + 2 * nl)) return 0;
    branch_mesh_into(br, nb, sides, out);
    for (int i = 0; i < nl; i++) {
        int v = bv + 4 * i;
        float s = lf[i].size;
        uint32_t h = hash32((uint32_t)i) % 2000;
        int r = 60 + (int)(h % 40), g = 130 + (int)(h / 40 % 50), b = 40;
        Vec3 mid = v3_add(lf[i].pos, v3_scale(lf[i].h, 0.5f * s)), side = v3_scale(lf[i].l, 0.3f * s);
        mesh_set_vertex(out, v, lf[i].pos, lf[i].u, r, g, b);
        mesh_set_vertex(out, v + 1, v3_add(mid, side), lf[i].u, r, g, b);
        mesh_set_vertex(out, v + 2, v3_add(lf[i].pos, v3_scale(lf[i].h, s)), lf[i].u, r, g, b);
        mesh_set_vertex(out, v + 3, v3_sub(mid, side), lf[i].u, r, g, b);
        uint32_t *t = out->idx + 3 * (size_t)(bv + 2 * i);
        t[0] = (uint32_t)v; t[1] = (uint32_t)(v + 3); t[2] = (uint32_t)(v + 2);
        t[3] = (uint32_t)v; t[4] = (uint32_t)(v + 2); t[5] = (uint32_t)(v + 1);
    }
    return 1;
}

/* the ternary tree with a leaf at every new branch tip */
static const PSucc TREE_A[] = {
    {'!', 0, 1.732f}, {'F', 0, 50}, {'[', 0, 0}, {'&', 0, 18.95f}, {'F', 0, 50}, {'L', 0, 40}, {'A', 0, 0}, {']', 0, 0},
    {'/', 0, 94.74f}, {'[', 0, 0}, {'&', 0, 18.95f}, {'F', 0, 50}, {'L', 0, 40}, {'A', 0, 0}, {']', 0, 0},
    {'/', 0, 132.63f}, {'[', 0, 0}, {'&', 0, 18.95f}, {'F', 0, 50}, {'L', 0, 40}, {'A', 0, 0}, {']', 0, 0}};
static const PSucc TREE_F[] = {{'F', 1.109f, 0}};
static const PSucc TREE_W[] = {{'!', 1.732f, 0}};

int build_tree(int generations, int sides, Mesh *out) {
    PLSystem tt = {.succ = {['A'] = TREE_A, ['F'] = TREE_F, ['!'] = TREE_W}, .n = {['A'] = 22, ['F'] = 1, ['!'] = 1}};
    Module axiom[] = {{'!', 1}, {'F', 200}, {'/', 45}, {'A', 0}};
    Module *m;
    int n = pls_expand(&tt, axiom, 4, generations, &m), nb, nl;
    if (n < 0) return 0;
    turtle3d_count(m, n, &nb, &nl);
    Branch *br = malloc(sizeof(Branch) * (nb ? nb : 1));
    Leaf *lf = malloc(sizeof(Leaf) * (nl ? nl : 1));
    int ok = turtle3d(m, n, 1, br, lf) == 0 && tree_mesh(br, nb, lf, nl, sides, out);
    free(br); free(lf); free(m);
    return ok;
}

#include <float.h>

float edge_fn(float ax, float ay, float bx, float by, float px, float py) {
    return (bx - ax) * (py - ay) - (by - ay) * (px - ax);
}

void render_mesh(const Mesh *me, float yaw_deg, Image *im) {
    int W = im->w, H = im->h;
    img_fill(im, 235, 240, 245);
    if (me->nverts == 0) return;
    float a = yaw_deg * 3.14159265358979f / 180, c = cosf(a), s = sinf(a);
    float *tv = malloc(sizeof(float) * 6 * (size_t)me->nverts);   /* x', depth, z', nx', ny', nz */
    float *zb = malloc(sizeof(float) * (size_t)W * H);
    float minx = FLT_MAX, maxx = -FLT_MAX, minz = FLT_MAX, maxz = -FLT_MAX;
    for (int v = 0; v < me->nverts; v++) {
        const float *p = me->pos + 3 * v, *n = me->nrm + 3 * v;
        float *o = tv + 6 * v;
        o[0] = p[0] * c - p[1] * s; o[1] = p[0] * s + p[1] * c; o[2] = p[2];
        o[3] = n[0] * c - n[1] * s; o[4] = n[0] * s + n[1] * c; o[5] = n[2];
        minx = fminf(minx, o[0]); maxx = fmaxf(maxx, o[0]);
        minz = fminf(minz, o[2]); maxz = fmaxf(maxz, o[2]);
    }
    float aw = (float)(W - 5), ah = (float)(H - 5), bw = maxx - minx, bh = maxz - minz, scale;
    if (bw > 0 && bh > 0) scale = fminf(aw / bw, ah / bh);
    else if (bw > 0) scale = aw / bw;
    else if (bh > 0) scale = ah / bh;
    else scale = 1;
    float ox = 2 + (aw - bw * scale) / 2, oy = 2 + (ah - bh * scale) / 2;
    for (int v = 0; v < me->nverts; v++) {
        float *o = tv + 6 * v;
        o[0] = ox + (o[0] - minx) * scale;
        o[2] = H - 1 - (oy + (o[2] - minz) * scale);
    }
    for (int i = 0; i < W * H; i++) zb[i] = FLT_MAX;
    Vec3 L = v3_norm(v3(-0.4f, -0.6f, 0.7f));
    for (int t = 0; t < me->ntris; t++) {
        const uint32_t *ti = me->idx + 3 * (size_t)t;
        const float *A = tv + 6 * ti[0], *B = tv + 6 * ti[1], *C = tv + 6 * ti[2];
        float area = edge_fn(A[0], A[2], B[0], B[2], C[0], C[2]);
        if (area == 0) continue;
        int x0 = (int)floorf(fminf(A[0], fminf(B[0], C[0]))), x1 = (int)ceilf(fmaxf(A[0], fmaxf(B[0], C[0])));
        int y0 = (int)floorf(fminf(A[2], fminf(B[2], C[2]))), y1 = (int)ceilf(fmaxf(A[2], fmaxf(B[2], C[2])));
        if (x0 < 0) x0 = 0;
        if (y0 < 0) y0 = 0;
        if (x1 > W - 1) x1 = W - 1;
        if (y1 > H - 1) y1 = H - 1;
        Vec3 n = v3_norm(v3(A[3] + B[3] + C[3], A[4] + B[4] + C[4], A[5] + B[5] + C[5]));
        float lit = 0.35f + 0.65f * fabsf(v3_dot(n, L));
        const unsigned char *col = me->col + 3 * ti[0];
        int r = (int)(col[0] * lit + 0.5f), g = (int)(col[1] * lit + 0.5f), b = (int)(col[2] * lit + 0.5f);
        float inv = 1.0f / area;
        for (int py = y0; py <= y1; py++)
            for (int px = x0; px <= x1; px++) {
                float cx = px + 0.5f, cy = py + 0.5f;
                float w0 = edge_fn(B[0], B[2], C[0], C[2], cx, cy);
                float w1 = edge_fn(C[0], C[2], A[0], A[2], cx, cy);
                float w2 = edge_fn(A[0], A[2], B[0], B[2], cx, cy);
                if (!((w0 >= 0 && w1 >= 0 && w2 >= 0) || (w0 <= 0 && w1 <= 0 && w2 <= 0))) continue;
                float d = (w0 * A[1] + w1 * B[1] + w2 * C[1]) * inv;
                float *z = zb + (size_t)py * W + px;
                if (d >= *z) continue;
                *z = d;
                unsigned char *o = im->px + 3 * ((size_t)py * W + px);
                o[0] = (unsigned char)r; o[1] = (unsigned char)g; o[2] = (unsigned char)b;
            }
    }
    free(tv); free(zb);
}

int main(void) {
    Mesh me;
    build_tree(6, 6, &me);
    Image im = img_new(128, 128);
    render_mesh(&me, 30, &im);
    img_write_ppm(&im);
    mesh_free(&me);
    img_free(&im);
    return 0;
}

--- hint
With `area = edge(A, B, C)`, the barycentric weights are `w0 / area`, `w1 / area`, `w2 / area` where `w0 = edge(B, C, P)`, `w1 = edge(C, A, P)`, `w2 = edge(A, B, P)`; they sum to 1, so `depth = (w0 dA + w1 dB + w2 dC) / area` works for either winding.

--- hint
Transform and fit all vertices before the triangle loop: a vertex is shared by up to six triangles, so transforming per triangle repeats the work.

static void ref_render(const Mesh *me, float yaw, Image *im) {
    int W = im->w, H = im->h;
    img_fill(im, 235, 240, 245);
    float a = yaw * 3.14159265358979f / 180, c = cosf(a), s = sinf(a);
    float *sx = malloc(sizeof(float) * me->nverts * 3), *zb = malloc(sizeof(float) * W * H);
    float mnx = 1e30f, mxx = -1e30f, mnz = 1e30f, mxz = -1e30f;
    for (int v = 0; v < me->nverts; v++) {
        float x = me->pos[3 * v] * c - me->pos[3 * v + 1] * s, z = me->pos[3 * v + 2];
        sx[3 * v] = x; sx[3 * v + 1] = me->pos[3 * v] * s + me->pos[3 * v + 1] * c; sx[3 * v + 2] = z;
        mnx = fminf(mnx, x); mxx = fmaxf(mxx, x); mnz = fminf(mnz, z); mxz = fmaxf(mxz, z);
    }
    float aw = W - 5.0f, ah = H - 5.0f, bw = mxx - mnx, bh = mxz - mnz;
    float sc = bw > 0 && bh > 0 ? fminf(aw / bw, ah / bh) : bw > 0 ? aw / bw : bh > 0 ? ah / bh : 1;
    float ox = 2 + (aw - bw * sc) / 2, oy = 2 + (ah - bh * sc) / 2;
    for (int v = 0; v < me->nverts; v++) { sx[3 * v] = ox + (sx[3 * v] - mnx) * sc; sx[3 * v + 2] = H - 1 - (oy + (sx[3 * v + 2] - mnz) * sc); }
    for (int i = 0; i < W * H; i++) zb[i] = 1e30f;
    float ll = sqrtf(0.16f + 0.36f + 0.49f), Lx = -0.4f / ll, Ly = -0.6f / ll, Lz = 0.7f / ll;
    for (int t = 0; t < me->ntris; t++) {
        const float *P[3]; float n[3] = {0, 0, 0};
        for (int k = 0; k < 3; k++) {
            int v = (int)me->idx[3 * t + k]; P[k] = sx + 3 * v;
            n[0] += me->nrm[3 * v] * c - me->nrm[3 * v + 1] * s; n[1] += me->nrm[3 * v] * s + me->nrm[3 * v + 1] * c; n[2] += me->nrm[3 * v + 2];
        }
        float nl = sqrtf(n[0] * n[0] + n[1] * n[1] + n[2] * n[2]);
        float lit = 0.35f + 0.65f * (nl > 0 ? fabsf(n[0] * Lx + n[1] * Ly + n[2] * Lz) / nl : 0);
        const unsigned char *col = me->col + 3 * me->idx[3 * t];
        float ar = (P[1][0] - P[0][0]) * (P[2][2] - P[0][2]) - (P[1][2] - P[0][2]) * (P[2][0] - P[0][0]);
        if (ar == 0) continue;
        for (int py = 0; py < H; py++) for (int px = 0; px < W; px++) {
            float cx = px + 0.5f, cy = py + 0.5f, w[3];
            for (int k = 0; k < 3; k++) {
                const float *A = P[(k + 1) % 3], *B = P[(k + 2) % 3];
                w[k] = (B[0] - A[0]) * (cy - A[2]) - (B[2] - A[2]) * (cx - A[0]);
            }
            if (!((w[0] >= 0 && w[1] >= 0 && w[2] >= 0) || (w[0] <= 0 && w[1] <= 0 && w[2] <= 0))) continue;
            float d = (w[0] * P[0][1] + w[1] * P[1][1] + w[2] * P[2][1]) / ar;
            if (d >= zb[py * W + px]) continue;
            zb[py * W + px] = d;
            unsigned char *o = im->px + 3 * (py * W + px);
            o[0] = (unsigned char)(int)(col[0] * lit + 0.5f); o[1] = (unsigned char)(int)(col[1] * lit + 0.5f); o[2] = (unsigned char)(int)(col[2] * lit + 0.5f);
        }
    }
    free(sx); free(zb);
}

    return n;
}

#include <stdio.h>

int main(void) {
    const char *s = "F[+FF]-F";
    int x = 0, y = 0, dx = 1, dy = 0, sp = 0, st[8][4];
    for (const char *p = s; *p; p++) {
        int t;
        switch (*p) {
        case 'F': x += dx; y += dy; break;
        case '+': t = dx; dx = -dy; dy = t; break;
        case '-': t = dx; dx = dy; dy = -t; break;
        case '[': st[sp][0] = x; st[sp][1] = y; st[sp][2] = dx; st[sp][3] = dy; sp++; break;
        case ']': sp--; x = st[sp][0]; y = st[sp][1]; dx = st[sp][2]; dy = st[sp][3]; break;
        }
    }
    printf("%d %d\n", x, y);
    return 0;
}

The 3D turtle keeps H, L, U. Why store the whole frame instead of just the heading H?

--- choice
H alone cannot be rotated in 3D.

--- answer
Roll and pitch need to know which way "left" and "up" are for the turtle, and the frame also orients each branch's cylinder ring without twisting.

--- choice
It uses less memory than storing angles.

--- choice
Because OpenGL requires three vectors per vertex.

--- explain
With only H, "pitch down" is undefined: down relative to what? The frame makes every rotation well defined, and L and U are exactly the two axes the cylinder's ring of vertices is built from.
